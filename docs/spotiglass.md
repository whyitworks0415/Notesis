# Spotiglass

화면 설정에서 Material, Glassmorphism, Liquid Glass, **Spotiglass**를 선택할 수 있습니다.

Spotiglass는 [SpotiFLAC-Mobile의 유리 내비게이션](https://github.com/spotiflacapp/SpotiFLAC-Mobile/blob/main/lib/widgets/mornye_chrome.dart)을 참고한 Compose 구현입니다. 기존 Kyant Backdrop 렌더러를 사용합니다.

- 하단 도구 행은 아이콘과 이름이 있는 둥근 바입니다. 탭하면 선택 렌즈가 스프링으로 이동합니다. 선택한 펜을 다시 탭하면 기존 펜 설정이 열립니다.
- 바 안에서 옆으로 밀면 렌즈가 손가락을 따라 움직이며 늘어나고 살짝 들립니다. 놓을 때 해당 도구를 선택합니다. 취소하면 이전 선택으로 돌아갑니다. 도형 종류와 텍스트 추가는 바 옆에서 사용할 수 있습니다.
- 페이지/목차/마스킹 선택 바도 같은 스타일을 사용합니다.
- 유리 투명도, 인터랙션 강도, 모서리 곡률, 블러, 생동감, 렌즈 깊이, 굴절량, 색수차와 색을 화면 설정에서 변경할 수 있습니다. 상단 미리보기 바에서 탭과 드래그를 직접 시험할 수 있습니다.
- 투명도 0%, 고대비, 시스템 애니메이션 비활성화, 절전 모드, Android 12L 이하에서는 읽기 쉬운 단색 선택 표시를 사용합니다.

배경 바와 선택 렌즈를 분리하고, 아이콘 레이어와 렌즈를 형제 노드로 두어 렌즈가 자기 자신을 캡처하지 않게 했습니다. 슬라이드 좌표는 RTL도 처리합니다. 설정은 기존 `skinSettings` 저장소에 보관하며 이전 설정에는 기본값을 적용합니다.
