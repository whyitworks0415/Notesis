# Notesis 0.45.2 (113)

획 중간의 꺾인 부분이 각지던 문제, 획 위에서 시작한 지우기, 필압 지우개 크기 방식, 쓰기 시작할 때의 늦은 느낌, PDF 로딩 속도를 고쳤습니다.

## 꺾이는 부분이 각지던 획
- 보내주신 노트 166쪽의 획(굵기 1.4, 점 777개)을 직접 풀어 확인했습니다.
  - 되돌아 꺾이는 끝(103~112번 점, 632~642번 점)에서 펜이 15~20ms쯤 거의 멈춘 채 0.01~0.06만큼 이리저리 흔들린 뒤 방향을 뒤집습니다.
  - 이 작은 되돌림이 획 외곽선을 접어서, 둥근 펜인데도 꺾인 끝이 각지게 그려졌습니다. 0.44.2에서 고친 "시작점이 각진 획"과 같은 원리가 획 중간에서 생긴 것입니다.
- 이제 펜 굵기의 1/4 안에서 방향을 뒤집으며 흔들린 점들은, 원래 가던 방향으로 가장 멀리 간 점 하나로 정리합니다.
  - 꺾인 끝까지의 길이는 그대로 유지됩니다.
  - 흔들림 없이 부드럽게 도는 곡선은 손대지 않습니다.
- 이미 저장된 획도 노트를 다시 열면 깔끔하게 그려집니다.
- 이 정리를 획을 만들기 전 입력 단계에서 하도록 바꿔서, 노트를 열 때 획을 두 번 만들지 않습니다.

## 획 위에서 시작한 지우기, 필압 지우개
- 필압 지우개가 설정 크기를 최대로 보고, 가볍게 누르면 그 20%까지 작아지던 방식이었습니다. 펜이 막 닿는 순간은 압력이 거의 0이라, 획 위에서 시작하면 바늘만 한 지우개로 시작해 느리고 부자연스럽게 지워졌습니다.
- 이제는 **설정한 크기가 가장 약하게 눌렀을 때의 크기**입니다. 누를수록 커져서 최대 2.5배가 됩니다.
- 획 위에서 시작해도 처음부터 설정 크기로 지워집니다.

## 쓰기 시작할 때
- 0.44.2에서 시작점 정리 기준을 펜 굵기의 1/4로 키우면서, 쓰는 중 획도 그만큼 움직일 때까지 기다렸다 나타났습니다. 굵은 펜일수록 첫 순간이 늦게 느껴졌습니다.
- 쓰는 중 획은 다시 아주 작은 움직임(최대 0.3)만 기다립니다. 저장되는 획의 정리는 그대로입니다.

## PDF 로딩
- 미니맵과 페이지 이동 막대 미리보기가 축소 그림을 만들려고 PDF 페이지 렌더를 요청해서, 화면에 보일 페이지보다 먼저 줄을 서는 경우가 있었습니다. 이동 막대로 많은 페이지를 지나가면 그만큼 PDF가 늦게 떴습니다.
- 축소 그림은 이제 이미 메모리에 있는 페이지 그림만 씁니다. 렌더를 새로 요청하지 않습니다.
