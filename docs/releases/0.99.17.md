# Notesis 0.99.17 (258)

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

## 갑자기 전원이 꺼져도 필기가 남도록
- 쪽의 필기는 임시 파일에 다 쓴 다음 이름을 바꿔 원래 파일을 대신하는 방식으로 저장합니다. 그래서 앱이 저장 도중 죽어도 앞서 저장한 내용은 남아 있었습니다.
- 그런데 그 내용이 **실제로 저장 장치에 기록됐는지 확인하지 않고** 이름부터 바꿨습니다. 앱이 죽는 것은 괜찮지만, **배터리가 다 되거나 기기가 갑자기 재부팅되면** 이름 바꾸기만 남고 내용은 사라져 그 쪽이 빈 쪽으로 열릴 수 있었습니다.
- 이제 필기를 저장 장치에 다 쓴 것을 확인한 뒤에 이름을 바꿉니다.
- 새 획만 덧붙여 쓸 때도, 획을 먼저 기록하고 그다음에 "획이 몇 개인지"를 바꿔 씁니다. 중간에 전원이 꺼지면 덧붙이기 전 상태로 남습니다.
- 다른 설정·목록 파일은 이미 이렇게 저장하고 있었습니다. 필기 파일에만 빠져 있었습니다.

## 개발 환경
- 빌드 설정 파일에 개발 PC의 Java 경로가 들어 있어서, 다른 컴퓨터에서 저장소를 받으면 빌드가 바로 실패했습니다. 그 경로를 PC 사용자 설정(`~/.gradle/gradle.properties`)으로 옮겼습니다. 앱 동작은 바뀌지 않습니다.

## 어떻게 확인했나
- 릴리스 빌드와 단위 테스트를 돌렸습니다.

## 하지 않은 것 / 확인하지 못한 것
- 실제로 전원을 끊어 보는 시험은 하지 않았습니다. 파일 시스템이 이런 상황을 어떻게 처리하는지는 기기마다 다릅니다.
- 저장할 때마다 기록을 확인하는 시간이 조금 늘어납니다. 저장은 백그라운드에서 하므로 필기나 스크롤에는 영향이 없어야 하지만, 태블릿에서 재 보지는 않았습니다.

## 태블릿에서 해 볼 것
1. 노트에 계속 써 보기 → 쓰는 느낌이나 스크롤이 0.99.16과 같은지.
2. 노트를 닫았다 다시 열기 → 방금 쓴 필기가 그대로 있는지.
