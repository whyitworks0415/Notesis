# Notesis 0.99.19 (260)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## Liquid glass 스타일에서 iOS(와 Mornye)가 선택되지 않던 문제
- 스타일 목록에서 iOS나 Mornye를 눌러도 Liquid glass(Notesis) 그대로였습니다. "모든 화면 설정 초기화" 뒤에 특히 눈에 띄었습니다.
- 원인: 스타일을 저장하는 연결이 0.99.18에서 Liquid glass를 되살릴 때 빠져 있었습니다. 누른 값이 어디에도 저장되지 않았습니다.
- 이제 앱의 화면 설정에 연결했습니다. 설정 → 모양의 스타일 목록과 툴바의 모양 선택 모두에서 iOS·Mornye가 바로 적용되고 저장됩니다.

## 어떻게 확인했나
- 코드를 읽고 원인과 고친 곳을 확인했습니다. 이 환경에서는 Gradle 플러그인을 받을 수 없어 로컬 빌드는 하지 못했고, 빌드와 단위 테스트는 CI 결과로 확인합니다.
- **태블릿에서 확인하지 못했습니다.**

## 하지 않은 것
- 0.99.18의 다른 부분(유리 그리기, 사이드바 하나만 열기, Ask agent 키보드)은 이번에 바꾸지 않았고, 기기에서 다시 본 것도 아닙니다.

## 태블릿에서 해 볼 것
1. 설정 → 모양 → 화면 설정 초기화 → UI style에서 iOS 고르기 → 선택 표시가 iOS로 가고 툴바가 iOS 유리로 바뀌는지.
2. 앱을 껐다 켜도 iOS가 그대로인지.
3. Mornye도 같은 방식으로 되는지.
