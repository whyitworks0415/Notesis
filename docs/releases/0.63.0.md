# Notesis 0.63.0 (150)

## Tools 패널 (계산기 · 시계 · 캘린더 · 할 일)
- 계산기, 시계, 캘린더, 할 일을 하나의 패널로 합쳤습니다. 위쪽 탭(Calc / Clock / Calendar / To-do)으로 전환합니다.
- 패널은 누른 위치(버튼이나 화면의 시계 알약)에서 커지며 열리고, 닫을 때 그 자리로 접혀 들어갑니다.
- Functions 메뉴의 카메라 버튼 자리에 Tools 버튼을 넣었고, 아래에 있던 시계·캘린더·할 일·계산기 버튼 4개는 뺐습니다. Tools 버튼은 마지막으로 보던 탭으로 열립니다.

## 계산기 단순화
- 미분·적분 모드를 없앴습니다.
- 일반 계산기처럼 4열 키패드(AC, ⌫, %, ÷ / 숫자 / = )만 보입니다. sin, √, 괄호, 거듭제곱 같은 함수는 f(x) 키를 누르면 위에 펼쳐집니다.
- 바로 전 계산은 화면 위쪽에 작게 남습니다.

## 타이머
- 시간 템플릿 칩과 ±1/±5분 버튼을 없애고 슬라이더 하나로 시간을 정합니다. 앞부분은 1분 단위로 세밀하게, 1시간이 넘으면 5분 단위로 최대 3시간까지 움직입니다.

## Functions 메뉴
- Undo/Redo 아래에 붙던 "Nothing to undo/redo" 문구를 없애 두 버튼 높이를 맞췄습니다.
- Direction에서는 Horizontal / Vertical만 고릅니다. 좌우 위치와 Scale 슬라이더는 메뉴에서 뺐습니다(Scale은 Appearance 설정에 그대로 있습니다).
- Functions(동그란) 버튼을 끌어서 툴바를 바꿀 수 있습니다.
  - 가로 툴바: 왼쪽으로 끌면 한 단계씩 짧아지고, 오른쪽으로 끌면 길어집니다.
  - 세로 툴바: 화면 반대쪽으로 끌면 툴바가 그쪽으로 옮겨가고, 위로 끌면 짧아지고 아래로 끌면 길어집니다.
  - 버튼만 남은 4/4 크기에서는 잠깐 누르고 있다가 끌면 버튼 위치를 옮깁니다.
  - 그냥 탭하면 지금처럼 메뉴가 열립니다.

## 버그 수정
- 3/4 크기 툴바가 화면 폭과 상관없이 늘 세로로 바뀌던 문제를 고쳤습니다. 3/4 툴바는 원래 두 줄이므로, 창이 그 툴바보다 좁을 때만 세로로 바뀝니다.
