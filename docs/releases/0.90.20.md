# Notesis 0.90.20 (211)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

## 바뀐 점

이 버전은 0.90.19 위에 쌓았습니다. 0.90.17~0.90.19(반응 속도, 다크 크롬, 정적 아이콘과 Material 모션)의 내용이 모두 들어 있습니다.
- 다만 0.90.19에서 Material 모양에 다시 켰던 **누를 때 회색 반응(ripple)과 Liquid glass의 누를 때 빛**은 요청대로 다시 껐습니다.


### 펜 설정 팝업 새 구성 (손그림 와이어프레임 기준)
- **탭**: 맨 위에 **Setting / Color** 탭이 생겼습니다.
  - 두 탭은 같은 상자 안에 겹쳐 그려지고, 가장 긴 탭에 높이를 맞춥니다. 그래서 탭을 바꿔도 팝업의 폭과 높이가 변하지 않습니다.
  - 새 탭이 미끄러지며 나타나고, 이전 탭은 사라집니다.
- **실시간 미리보기**: 탭 아래에 펜으로 그린 물결선이 있습니다. 두 탭 모두에 보이며 바꾸는 즉시 반영됩니다.
  - 색, 굵기, 선 종류를 그대로 보여 줍니다.
  - 만년필과 캘리그래피는 펜촉 각도대로 굵기가 바뀝니다.
  - 필압을 켜면 양 끝이 가늘어지고, 사라지는 펜은 끝으로 갈수록 옅어집니다.
- **Width**
  - 오른쪽 숫자 칸에서 0.1 단위로 보이고 입력할 수 있습니다.
  - 슬라이더 양옆의 − / + 버튼은 한 번에 0.1씩 바꿉니다.
  - 아래에 프리셋 굵기가 있습니다. ☆로 저장한 굵기가 있으면 그것을 보여 주고, 없으면 자주 쓰는 굵기를 보여 줍니다.
- **펜 종류**: 볼펜, 만년필, 캘리그래피, 사라지는 펜 네 칸으로 나뉩니다.
  - 평소에는 글자로 보입니다. 커서를 올리거나 손가락을 대면 각 펜이 그리는 모양의 아이콘으로 바뀌고, 손을 떼고 잠시 뒤 글자로 돌아옵니다.
  - **펜마다 설정이 따로 저장됩니다**: 굵기, 각도, 색, 옵션 모두입니다. 볼펜에서 만년필로 갔다가 돌아오면 볼펜은 두었던 그대로입니다.
- **펜 종류에 따라 바뀌는 줄**
  - 볼펜과 사라지는 펜에는 **Line type**(실선 / 점선 / 파선)이 나옵니다. 이것도 글자에서 선 모양 아이콘으로 바뀝니다.
  - 만년필과 캘리그래피에는 **Nib angle**이 나옵니다.
  - 펜을 바꾸면 한 줄이 접히면서 다른 줄이 펴집니다.
- **스위치**: Pressure, Straight line, Recognize shape를 바로 켜고 끌 수 있습니다.
- **More for this pen**: 맨 아래에 있으며 두 탭 모두 같습니다. 저장한 펜, 예측, 손떨림 보정, 굵기 한도는 여기로 옮겼습니다.
- **Color 탭**
  - 보기 방식은 **Grid / Square / HSV ring / RGB disc** 네 가지입니다. Grid는 새로 생겼습니다(맨 위 회색 줄, 그 아래는 색상별로 어두운 색부터 연한 색까지).
  - 보기를 바꾸면 뒤의 판이 사각형에서 원으로, 또는 그 반대로 크기와 모양이 변하고, 새 보기가 그 자리에서 커지며 나타납니다.
  - H/S/V, R/G/B, 색 코드 칸과 스포이트 버튼의 높이와 모서리를 하나로 맞췄습니다.
  - 팔레트는 색 화면 아래에 있습니다.
- **지우개와 도형**: 같은 틀로 열립니다. 지우개는 색이 없어서 Setting만 있습니다.
- **연필**: Bubble을 뺐습니다. Bubble로 두었던 연필은 흑연으로 그립니다.

### 설정 사이드바 새 구성
- **Quick actions**: 3칸 격자에 아이콘과 이름만 둡니다(배경과 테두리 없음).
  - 순서는 Dock bar, Rotate, Zoom, Pages & search, Tools, Split notes입니다.
- **Sections**: 아이콘과 이름만 같은 높이와 간격으로 줄 세웠습니다(배경과 설명 줄 없음). 태블릿에서는 스크롤 없이 다 보입니다.
- **Appearance**: 새 **Display** 묶음에 **언어, 밝기, 인터페이스 크기**를 모았습니다.
- **Diagnostics**: 개발자 코드를 넣은 베타 테스터에게만 보입니다.

### 전체 UI·글자 크기 (50~150%)
- 모양 → Display → **Interface size**에서 바꿉니다. 기본은 100%입니다.
- dp와 글자 크기를 함께 바꿔서 레이아웃 비율이 유지됩니다.
- 손을 뗀 뒤 적용됩니다. 끄는 동안 매 프레임 앱 전체를 다시 그리지 않으려는 것입니다.
- 팝업, 메뉴, 다이얼로그는 별도 창이라 원래는 시스템 크기로 그려집니다. 이번에 그 안의 내용도 같은 크기로 그리도록 감쌌습니다.

### 버그 수정
- **툴바 위치(위·아래)**
  - 아래쪽에 둔 툴바는 크기가 바뀔 때 아래 가장자리를 기준으로 커집니다. 오른쪽에 둔 툴바는 오른쪽 기준, 가운데 둔 툴바는 가운데 기준입니다. 이전에는 위로 붙인 것처럼 아래로 커졌다가 밀려 올라갔습니다.
  - 크롬을 숨길 때 아래쪽 툴바는 아래로 사라집니다. 이전에는 위로 올라가서 방향이 반대였습니다.
  - 위아래 가장자리와의 간격을 같게 했습니다. 이전에는 위는 상태 표시줄 높이, 아래는 내비게이션 바 높이를 써서 높이가 달랐습니다.
- **누를 때 회색 번쩍임**: Liquid glass 버튼과 툴바 버튼에 누를 때마다 흰 빛이 퍼지던 효과를 없앴습니다. 밝은 페이지 위에서는 회색 번쩍임으로 보였습니다.
- **커서를 올리거나 클릭한 뒤 남는 회색 하이라이트**: 마우스로 누르면 포커스가 옮겨 가면서 회색 막이 남던 것을 없앴습니다.
- **하이라이트 색**: Liquid glass 툴바에서 선택된 도구 뒤의 알약이 회색 고정이었습니다. 이제 다른 모양처럼 강조색을 따릅니다.
- **필압이 꺼지지 않던 문제**: 만년필, 캘리그래피, 사라지는 펜은 펜 자체가 필압을 읽어서 스위치를 꺼도 필압이 적용됐습니다. 이제 스위치를 끄면 입력 필압을 일정하게 바꿔 넣습니다. 펜 버튼 지우개의 필압은 그대로입니다.
- **꾹 눌러 그린 도형의 시작점**: 직선, 화살표, 곡선이 펜을 댄 바로 그 점에서 시작합니다. 길이와 방향(직각 맞춤 포함)은 그대로 둡니다. 이전에는 펜이 잠시 머문 자리의 평균에서 시작해 조금 어긋났습니다.

### 그 밖
- **툴바 크기**: 최소 50%까지 줄일 수 있습니다(이전 90%). 전체 막대(1/4)는 그대로 100%입니다.
- **툴바 애니메이션 중 버튼 떨림**
  - 원인: 막대가 늘어나는 동안 도구 칸이 매 프레임 정수 픽셀로 다시 나뉘었습니다. 그때마다 남는 픽셀이 다른 칸으로 가서 아이콘이 1px씩 앞뒤로 떨렸습니다.
  - 이제 각 칸의 가운데를 픽셀 단위 아래까지 정확히 둡니다.
- **사이드바 늘림**: 최대 폭보다 더 끌면 고무줄처럼 늘어납니다. 손을 떼면 원래 폭을 살짝 넘었다가 돌아오는 스프링으로 되돌아갑니다. 이전에는 바로 튀어 돌아갔습니다.
- **캡처 → AI**: 웹 패널에 AI가 열려 있지 않으면 **마지막으로 쓴 AI 사이트**를 열고 거기에 첨부합니다. 이전에는 항상 목록의 첫 번째 사이트를 열었습니다.

## 하지 않은 것 / 확인하지 못한 것
- **기기에서는 해 보지 못했습니다.** 새 팝업과 사이드바의 실제 모양, 간격, 애니메이션은 태블릿에서 봐야 합니다.
- **"하이라이트 색상 안 바뀜"**: Liquid glass 툴바의 선택 알약 색으로 해석해 고쳤습니다. 다른 곳(형광펜 색, PDF 글자 선택 등)을 뜻하신 거면 알려 주세요.
- **인터페이스 크기**: Material 기본 AlertDialog의 바깥 여백처럼 다이얼로그 창 자체의 틀은 시스템 크기로 남습니다. 안의 내용만 바뀝니다.
- **도형 시작점 고정**: 직선류(직선, 화살표, 양방향 화살표, 곡선)에만 적용했습니다. 사각형이나 원 같은 도형은 그대로입니다.
- 도형 종류를 고르는 팝업은 이번에 다시 만들지 않았습니다. 이미 같은 유리 패널을 씁니다.

## 태블릿에서 해 볼 것
1. 펜을 두 번 눌러 설정을 열고 Setting과 Color 탭을 오가기. 크기가 그대로인지 봐 주세요.
2. 펜 종류 칸에 커서를 올리거나 손가락을 대서 아이콘으로 바뀌는지, 볼펜과 만년필을 오가며 각자 설정이 남는지 확인하기.
3. 만년필에서 필압을 끄고 써 보기. 굵기가 일정해야 합니다.
4. Color 탭에서 Grid, Square, HSV ring, RGB disc를 바꿔 보기.
5. 설정 사이드바 첫 화면이 스크롤 없이 다 보이는지, 모양 → Display에서 Interface size를 80%와 130%로 바꿔 보기.
6. 툴바를 아래로 옮긴 뒤 크기를 바꾸고, 가장자리를 눌러 숨겨 보기.
7. 사이드바를 최대보다 더 끌었다가 놓기.
8. 캡처한 뒤 AI로 보내기. 마지막으로 쓴 AI가 열려야 합니다.
