# Notesis 0.46.0 (116)

레이어, 화면 나누기, 480Hz 보정, AnimateIcons 아이콘, 하나로 합친 새 노트 버튼을 넣고 다크 모드를 다듬었습니다.

## 레이어
- 기능 메뉴의 **레이어**에서 레이어를 추가하고, 이름을 바꾸고, 보이기·숨기기, 위아래 순서 바꾸기, 삭제를 할 수 있습니다. 레이어 목록은 노트 전체가 함께 씁니다.
- 레이어를 고르면 그 레이어에서만 쓰고 지우고 올가미로 고를 수 있습니다. 다른 레이어의 필기는 지우개에도 올가미에도 걸리지 않습니다.
- **전체 레이어**를 고르면 모든 레이어를 편집할 수 있습니다. 이때 새 필기는 마지막에 고른 레이어로 들어갑니다.
- 위에 있는 레이어의 필기가 아래 레이어의 필기를 덮어 그려집니다.
- 숨긴 레이어는 화면에 그려지지 않고, 지우개나 올가미에도 걸리지 않습니다. 저장은 그대로 됩니다.
- 숨긴 레이어를 고르면 다시 보이게 됩니다. 쓰자마자 사라지는 일을 막기 위해서입니다.
- 레이어 삭제는 모든 페이지에서 그 레이어의 필기를 지웁니다. 실행 취소로 되돌릴 수 없고, 지울 때 실행 취소 기록도 비웁니다.
- 기존 노트의 필기는 모두 "레이어 1"에 들어갑니다.
- 저장 파일 형식이 바뀌었습니다(획마다 레이어 번호를 저장). 이 버전에서 저장한 노트는 0.45.x 이하에서 필기가 보이지 않으니, 예전 버전으로 되돌리지 마세요.

## 화면 나누기
- 기능 메뉴의 **화면 나누기**에서 **위아래로 나누기**나 **좌우로 나누기**를 고르면, 한쪽에는 지금 노트가 열리고 다른 쪽에는 참고 창이 고정됩니다.
- 참고 창 위쪽에서 다른 노트를 고를 수 있고, 양쪽 모두에 쓸 수 있습니다.
- 가운데 손잡이를 끌면 크기가 바뀝니다. 끄는 동안에는 선만 움직이고, 손을 떼면 양쪽이 새 크기로 바뀝니다. 한쪽이 화면의 20%보다 작아지지는 않습니다.
- 참고 창을 닫거나 **나누지 않기**를 고르면 원래대로 돌아갑니다.
- 안드로이드 분할 화면에서 다른 앱(브라우저, 갤러리 등)의 그림을 노트로 끌어다 놓으면 그 페이지에 그림이 들어갑니다.

## 480Hz 보정
- 펜은 120Hz 화면이 한 번 바뀌는 동안 위치를 네 번쯤 보냅니다. 그 사이 펜이 가는 길을 펜 끝 앞에 흐리게 그려서, 끊김 없이 따라오는 것처럼 보이게 합니다.
- 펜 설정 › 세부 설정의 **480Hz 보정**에서 **끄기 · 모션 블러 · 잔상**을 고릅니다. 기본은 끄기입니다.
  - 모션 블러: 펜 끝에서 앞으로 갈수록 옅어지는 줄
  - 잔상: 펜촉 모양이 네 번, 점점 옅게 겹쳐 보임
- 최근 약 7ms의 샘플로 속도를 구해 다음 화면까지 갈 거리만 그립니다. 길이는 펜 굵기의 몇 배로 제한됩니다. 저장되는 획에는 들어가지 않습니다.
- 노트를 돌려 놓았을 때와, 웹 패널이나 참고 창이 열려 있을 때는 나오지 않습니다(예측 머리와 같은 조건).

## 아이콘
- 툴바 아이콘을 **AnimateIcons**(Lucide 기반)로 바꿨습니다. 누르거나 도구를 고를 때 아이콘이 한 번 움직입니다.
- 화면 설정의 **아이콘**에서 **Reicon**과 **AnimateIcons**를 바꿀 수 있고, **아이콘 움직임**을 끌 수 있습니다.
- 도구: 읽기(마우스 포인터, 상하 반전), 펜(연필), 연필(펜 툴, 상하 반전), 형광펜, 마스킹(눈 가림), 지우개, 도형, 텍스트, 올가미(점선 원), 캡쳐(점선 사각형), AI(번개)
- 팔레트, 기능(가로 슬라이더)
- 윗줄: 나가기(왼쪽 화살표), 검색, 실행취소, 다시실행, 마이크, 회전, 테마(Figma), 도구(계산기), 손가락·제스처(설정), 페이지 추가, 노트 메뉴(…), 다른 노트(메뉴)
- 윗줄의 **캡처** 버튼과 **상단 고정** 버튼을 뺐습니다. 둘 다 기능 메뉴에는 그대로 있습니다.
- 기능 메뉴 안의 아이콘도 모두 새 아이콘으로 바꿨습니다.
- 오픈소스 라이선스에 AnimateIcons(MIT)와 Lucide(ISC)를 넣었습니다.

## 새 노트 버튼
- 첫 화면 오른쪽 아래의 여러 버튼을 하나로 합쳤습니다. **+**를 누르면 새 노트, PDF 가져오기, 문서 열기, Markdown 가져오기, 이미지로 새 노트, 웹페이지로 새 노트가 버튼 위로 차례로 올라옵니다.
- +는 ×로 돌아가고, 다시 누르거나 뒤로 가기를 누르면 접힙니다. 백업 버튼은 그대로입니다.

## 다크 모드
- 페이지 바깥의 바탕이 밝은 회색으로 남던 것을 어둡게 바꿨습니다. 종이는 그대로 흰색입니다.
- 유리(글래스모피즘·굴절 유리) 패널, 메뉴, 대화상자에 흰 서리가 덮여 회색으로 뜨고 밝은 글씨가 흐려지던 것을 고쳤습니다. 다크 모드에서는 흰 색조를 아주 옅게만 씁니다.
- 굴절 유리 테두리와 빛번짐이 다크 모드에서 밝은 윤곽선처럼 보이던 것을 줄였습니다.
- 유리 위의 칩이 흰 바탕이라 밝은 글씨가 안 보이던 것, 참고 창 테두리가 밝게 빛나던 것, 지연 측정 글씨가 어두운 바탕에서 안 보이던 것을 고쳤습니다.
- 노트 목록에서 미리보기가 없는 카드의 바탕도 어둡게 바꿨습니다.
