# Notesis 0.99.13 (254)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

크게 이어 쓴 "안녕하세요"를 다시 시험한 결과를 받았습니다. 손글씨 획과 둘 다 나란히는 "땝"으로, 그림 속 글자는 "알아본 글자가 없음"으로 나왔습니다. AI는 키가 필요해서 쓸 수 없었습니다. 그래서 **선택한 부분을 그림으로 만들어 Google 렌즈로 읽는 방법**을 추가하고, 그림 속 글자 인식을 보강했습니다.

## 새로 추가: Google 렌즈
- 결과 창의 "다른 방법으로 읽기"에 **Google 렌즈** 칩이 생겼습니다.
- 누르면 선택한 부분을 그림으로 만들어 **Google 렌즈**(Google 앱)에서 엽니다. 렌즈는 이어 쓴 손글씨도 잘 읽는 편입니다.
- **무료이고 API 키가 필요 없습니다.** 다만 그림이 Google로 전송됩니다.
- 쓰는 법: 렌즈에서 글자를 골라 복사한 뒤 Notesis로 돌아오면, 결과 창에 **"렌즈에서 복사한 글자를 여기에 붙여 넣기"** 칸이 있습니다. 붙여 넣고 **텍스트로 변환**이나 **텍스트 상자로 추가**를 누르면 됩니다.
- Google 앱이 없으면 공유 창이 열립니다. 갤러리의 글자 추출처럼 그림을 읽을 수 있는 다른 앱을 고르면 됩니다.
- 렌즈는 다른 앱으로 그림을 보내는 방식이라 **"다음에도 이 방법으로 읽기"로 기억하지 않습니다.** 고를 때마다 한 번씩만 엽니다.

## 그림 속 글자 보강
- ML Kit 글자 인식기는 인쇄된 글자 크기를 찾도록 만들어졌습니다. 굵은 펜으로 크게 쓴 글씨는 원래 크기 그림에서 아무것도 찾지 못할 수 있습니다.
- 이제 결과가 없거나 아주 짧으면 **그림을 1/2, 1/4 크기로 줄여 다시 읽고**, 글자를 가장 많이 읽은 결과를 씁니다.
- 이 인식기는 인쇄체용이라, 흘려 쓴 글씨는 여전히 못 읽을 수 있습니다. 그런 글씨에는 Google 렌즈가 맞습니다.

## 어떻게 확인했나
- 빌드, 축소(R8) 릴리스 빌드, Android 버전 검사(Lint), 네이티브 커널 점검, 전체 단위 테스트(147개 클래스)를 통과했습니다.
- 읽는 방법 목록에 테스트를 추가했습니다. 렌즈가 별도 방법으로 등록되는지, 저장 키가 겹치지 않는지를 확인합니다.

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 렌즈가 실제로 열리는지 확인하지 못했습니다.** Google 앱의 공유 대상이 렌즈로 이어진다는 것은 Google 앱의 동작에 기대고 있습니다. Google이 바꾸면 공유 창이 대신 열릴 수 있습니다.
- 그림을 줄여 다시 읽는 방식이 보내 주신 글씨를 읽어 낼지는 시험하지 못했습니다.
- 손글씨 획 인식(ML Kit)이 흘려 쓴 글씨를 "땝"처럼 읽는 것은 모델의 한계로 보입니다. 이번에 이 부분은 바꾸지 않았습니다.

## 태블릿에서 해 볼 것
1. 같은 "안녕하세요"를 올가미로 골라 **읽기** → "다른 방법으로 읽기"에서 **Google 렌즈** → 렌즈가 열리고 글자를 읽는지.
2. 렌즈에서 복사 → Notesis로 돌아와 붙여 넣기 칸에 붙여 넣기 → **텍스트로 변환**.
3. **그림 속 글자**를 다시 눌러 이번에는 무언가 읽히는지.
