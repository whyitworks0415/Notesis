# Notesis 0.57.0 (142)

## 환영 애니메이션: 사각형 그리기 제거, 펜 떨어뜨리기를 실제처럼
- 처음에 둥근 사각형을 손으로 그리던 부분을 없앴습니다. 이름이 써진 뒤 아이콘 모양의 흰 종이가 바로 놓입니다.
- 펜이 그 위에 `>`를 손글씨처럼 거칠게 쓰고, 펜을 떼는 순간 `>`가 반듯해집니다.
- 펜을 떨어뜨리는 부분은 막대를 바닥에 떨어뜨리는 물리 계산으로 바꿨습니다.
  1. 펜을 들어 `_` 자리 위에서 펜촉이 아래로 조금 기울어진 채 놓습니다.
  2. 중력으로 점점 빨라지며 떨어지다가 펜촉(앞부분)이 먼저 부딪힙니다.
  3. 펜촉을 축으로 몸통이 넘어가 펜 뒤쪽(윗부분)이 바닥을 칩니다.
  4. 그 반동으로 살짝 튀었다가 한두 번 작게 튕기고, 아이콘과 똑같은 자리와 각도에 눕습니다.
- 회전은 쓰던 각도에서 누운 각도까지만 바뀌고, 흔들림을 합쳐도 90도를 넘지 않습니다. 공중에서 도는 동작은 없습니다.
- "Hold the pen still…" 문구와 펜 주위 고리는 사각형 그리기와 함께 없앴습니다.
- 전체 길이가 6.0초에서 4.7초로 줄었습니다.
