# Notesis 0.90.23 (223)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 바뀐 점

### 1. 첫 화면 끝에서 그냥 멈춤
- 0.90.22에서 넣은 끝 반동을 첫 화면에서는 뺐습니다. 안드로이드 기본 늘어남 효과도 없앴습니다. 맨 위·맨 아래에서 더 당기면 그 자리에서 막힙니다.
- 팝업 메뉴와 도구 패널의 끝 반동은 그대로 둡니다.

### 2. 목록 중간에서 멈추던 문제
- 끝 반동이 목록 중간에서도 작동할 수 있었습니다. 넘긴 스크롤이 자연스럽게 멈출 때 남은 아주 작은 속도도 "끝에 부딪힘"으로 받아서 작은 반동을 시작했습니다. 첫 화면에서는 반동 자체를 뺐고, 팝업에서는 끝에 실제로 부딪힌 빠르기(초당 400px 이상)일 때만 반동합니다.

### 3. 첫 화면 스크롤 렉
- **카드 그림 크기**: 카드 썸네일을 2의 거듭제곱 단위로만 줄여서, 카드 폭 480px에 최대 960px짜리 그림(픽셀 4배)이 들어가고 있었습니다. 새 카드가 나타날 때마다 그만큼 큰 텍스처를 GPU로 올려야 했고, 캐시(16MB)에는 몇 장밖에 남지 않아 위로 다시 올라가도 또 읽었습니다. 이제 배경 스레드에서 카드 폭에 맞게 줄이고, 화면에 그리기 전에 미리 GPU로 올리도록 요청합니다. 캐시도 메모리에 따라 최대 32MB까지 늘렸습니다.
- **카드 위치 계산**: 길게 눌러 여러 개 고르기를 위해 스크롤 프레임마다 모든 카드의 화면 위치를 계산하고 있었습니다. 이제 위치 정보만 들고 있다가 손가락이 닿을 때 계산합니다.
- **Glassmorphism 외관**: 스크롤 중에는 배경 서리 효과를 다시 기록하지 않습니다(0.90.22와 같음).

## 확인 방법

- 그림 크기 맞춤, 반동 최소 속도는 단위 테스트로 확인합니다.
- CI check 빌드로 릴리스 빌드, 전체 단위 테스트, UI 테스트를 돌립니다.

## 하지 않은 것 / 모르는 것

- **기기에서는 시험하지 않았습니다.** 렉이 얼마나 줄었는지 재지 않았습니다. 0.90.22에서 렉이 그대로였기 때문에 이번 원인 추정도 틀릴 수 있습니다. 그대로라면 진단 화면의 프레임 기록을 함께 알려 주시면 원인을 좁히는 데 도움이 됩니다.
- 길게 눌러 고르기 동작은 바꾸지 않았습니다.

## 태블릿에서 해 볼 것

1. 썸네일이 있는 노트가 많은 첫 화면에서 천천히·빠르게 위아래로 스크롤합니다. 새 줄이 나타날 때 멈칫하는지, 중간에서 멈추는지 봅니다.
2. 맨 위·맨 아래에서 더 당겨 보고, 늘어나거나 튕기지 않고 막히는지 봅니다.
3. 카드를 길게 눌러 여러 개 고르기와 폴더로 끌어 옮기기가 그대로 되는지 봅니다.
4. 팝업 메뉴를 스크롤해 끝에서 튕기는지, 중간에서 멈추지 않는지 봅니다.
