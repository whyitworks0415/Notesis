# Notesis 0.90.2 (193)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

## 스마트 폴더

- **기간을 세밀하게:** "쓴 때"에서 **기간 정하기**를 고르면 막대가 나옵니다.
  - 1시간부터 30일까지 고를 수 있습니다: 1·2·3·6·12시간, 1~7일, 10일, 14일, 21일, 30일.
  - 단위가 시간과 날로 크게 달라서 고르게 늘어나는 막대 대신 이런 단계로 나눴습니다. 그래야 1시간도 30일도 손쉽게 맞출 수 있습니다.
- **최근에 연 노트:** "최근에 연 노트"에서 **최근에 연 것만**을 고르면 1~20개를 막대로 정합니다.
  - 그 폴더에는 마지막으로 연 노트가 연 순서대로 나옵니다.
  - 다른 조건(태그, 기간, 즐겨찾기, 종류)과 함께 쓰면 모두 맞는 노트만 나옵니다.
  - 연 기록은 이 태블릿에만 최근 20개까지 남고, 지운 노트는 빠집니다.
  - 기록은 이 버전부터 쌓입니다. 업데이트 직후에는 비어 있고, 노트를 열 때마다 채워집니다.
- 0.90.0에서 "최근 7일"·"최근 30일"로 만든 스마트 폴더는 그대로 7일·30일로 읽습니다.

## 확인한 것 / 못 한 것

- CI 빌드와 단위 테스트까지 확인했습니다.
  - 시간 단위 기간, 최근에 연 N개, 20개 넘으면 오래된 것부터 빠지기, 0.90.0에서 날 단위로 저장한 폴더 읽기를 테스트로 넣었습니다.
- 기기에서는 아직 해 보지 못했습니다. 막대가 대화상자 안에서 잘 움직이는지 확인해 주세요.

## 태블릿에서 해 볼 것

1. ⋯ → 새 스마트 폴더 → 기간 정하기 → 막대를 끝까지 움직여 "1시간"과 "30일"이 나오는지.
2. "3시간"으로 저장하고, 방금 쓴 노트만 나오는지.
3. 노트 몇 개를 열었다 닫은 뒤 → 새 스마트 폴더 → 최근에 연 것만 → 3개로 저장 → 방금 연 3개가 연 순서대로 나오는지.
4. 0.90.0에서 만든 스마트 폴더가 그대로 열리는지.
