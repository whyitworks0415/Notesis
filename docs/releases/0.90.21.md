# Notesis 0.90.21 (221)

<!-- update: automatic -->

> 일반 Notesis의 정식 업데이트입니다. 기존 Notesis 위에 설치합니다. Lab 앱은 별도로 유지되며 Lab의 노트가 자동으로 옮겨지지는 않습니다.

## 첫 화면·색상·팝업

- iOS 외관에서 노트가 많은 첫 화면을 스크롤할 때 노트·폴더 카드와 상단 유리 헤더를 그래픽 레이어로 재사용합니다. 굴절·색·테두리를 단순화하지 않고 반복 그리기 비용을 줄이기 위한 변경입니다. 헤더 그림자 공간을 확보하고 기존 목록 간격을 유지합니다.
- 목록 항목을 종류별로 재사용합니다. 셀 재사용 또는 같은 경로의 썸네일 교체 후 이전 그림이 남을 수 있던 상태 문제를 수정했습니다. 이미지 디코딩은 계속 작업 스레드에서 실행합니다.
- 색상 선택기에 Grid, SV 사각형+H, HSV 막대+색 미리보기+HEX, 색상환+SV+HSV 수치의 네 화면을 제공합니다. 화면 전환 시 현재 색과 불투명도를 유지합니다.
- 공통 팝업이 둥근 형태로 확대·축소되도록 개선했습니다. 변형 중 터치 영역과 모서리를 함께 처리합니다. 호출부가 즉시 제거하는 일부 기본 확인창은 이 닫힘 모션의 대상이 아닙니다.
- 기존 iOS 유리 효과와 정적 Material 아이콘·Reicons 선택을 유지합니다. 효율 유리 설정은 기본적으로 꺼져 있습니다.

## 필기·부분지우개·페이지

- 많은 스트로크의 공간 검색과 부분지우개 구간 계산에 C++ 계산기를 사용합니다. 사용할 수 없거나 연속 비정상 종료가 감지되면 Kotlin 경로를 사용합니다.
- 선택한 부분지우개와 펜 버튼 경로를 정리하고, 입력 샘플 사이를 연속 경로로 계산합니다. 프레임별 처리 묶음과 실행 취소 트랜잭션으로 반복 갱신·복사를 줄입니다.
- 오래된 노트 로딩·형상 재구성 작업의 취소를 강화하고, 타일 재기록 작업량을 프레임 여유와 이전 비용에 맞춰 제한합니다.
- 저장된 페이지와 일치하는 미리보기가 있는 경우 노트 열기 초기에 표시합니다. 실제 필기 형상이 준비되면 교체하며, 변경된 페이지의 이전 미리보기는 사용하지 않습니다.
- 필기 중 성능 힌트를 시스템에 요청합니다. 시스템이 거절하면 기존 경로로 동작합니다. 자체 하드웨어 버퍼를 통한 화면 제출은 실험 옵션이며 **기본값은 꺼짐**입니다.

## 설치·데이터·업데이트

- 패키지 `com.notesis`, 기존 서명 및 키 회전 증명, 기존 `files/notes` 데이터 경로와 위젯 동작을 유지합니다. 기존 노트의 바이너리 형식(v4)과 백업 형식(v1)은 변경하지 않습니다.
- 정식 업데이트 피드로 복귀하며 Lab 태그와 Lab APK는 제외합니다. 자동 확인·개발자 모드에 대한 기존 사용자의 선택을 유지합니다.
- Lab 분기에서 검증한 변경을 정식 앱으로 반영한 릴리즈입니다. Lab 앱을 제거하거나 그 데이터를 덮어쓰지 않습니다. Lab에만 있는 노트는 내보내기/백업으로 옮겨야 합니다.

## 검증과 한계

- 로컬 전체 JVM·Compose 회귀 테스트 **722개 통과**(실패·오류·건너뜀 0). C++ 주소/정의되지 않은 동작 sanitizer 및 무작위 기하 계산 검사도 통과했습니다.
- 정식 피드의 Lab 제외·페이지 검색·일반 사용자 업데이트 노출, 기존 패키지·위젯·설정 보존, 기존 메타데이터와 v4 필기의 읽기를 추가 검증합니다.
- CI에서 APK 빌드, 회귀·UI 테스트, 기존 서명 검증을 통과한 산출물만 공개합니다.
- 실제 태블릿에서 이번 정식 빌드를 설치하거나 프레임·배터리·발열 개선율을 측정하지 않았습니다. 그래픽 레이어는 반복 그리기를 줄이는 대신 화면에 보이는 카드 등의 GPU 메모리를 추가 사용합니다.

## 설치 후 확인

1. 기존 노트·폴더·위젯이 남아 있는지 확인합니다.
2. 노트가 많은 첫 화면에서 iOS 외관으로 빠르게 위아래로 이동합니다. 60Hz와 120Hz에서 같은 목록으로 비교합니다.
3. 썸네일 변경·다크 모드·검색·다중 선택·팝업 열기와 닫기를 확인합니다.
4. 필기 위에서 부분지우개를 시작하고, 펜 버튼과 도구 선택을 각각 사용한 뒤 실행 취소를 확인합니다.
