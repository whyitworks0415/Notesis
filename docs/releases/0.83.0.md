# Notesis 0.83.0 (177)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 서명 키 교체
- **왜**: 예전 서명 키와 그 비밀번호가 공개 저장소에 올라가 있었습니다. 그 키를 가진 사람은 Notesis로 위장한 APK를 만들어 설치된 앱 위에 업데이트로 올릴 수 있습니다.
- **무엇을 했나**
  - 새 서명 키로 바꿨습니다. 새 키는 저장소에 없고 GitHub Secrets에만 있습니다.
  - 새 APK에는 "예전 키 → 새 키"로 이어지는 증명(APK 서명 v3 키 교체)이 들어 있습니다. 그래서 **이미 설치된 앱은 지우지 않고 그대로 업데이트**됩니다. 노트와 설정은 그대로입니다.
  - 이 버전이 설치된 뒤에는 예전 키로 서명한 APK로 덮어쓸 수 없습니다.
  - 저장소에서 키 파일과 비밀번호를 지웠고, `*.jks` 같은 키 파일이 다시 올라가지 않게 막았습니다.
  - 빌드가 서명 뒤에 인증서 지문을 확인하고, 다르면 실패합니다.
- 자세한 설명: 저장소의 `docs/signing.md`

## 알아둘 것
- 예전 키는 git 기록에 남아 있어 **계속 공개 상태**입니다. 이 버전으로 올리지 않은 기기는 그 위험이 남습니다.
- 예전 키로 서명된 APK를 *새로 설치*하는 것은 막을 수 없습니다. 설치 파일은 이 저장소의 Releases에서만 받으세요.
- 설치가 실패해도 노트는 지워지지 않습니다. 그래도 먼저 **Backup all notes**로 내보내 두는 것을 권합니다.
- 이 버전은 안드로이드 9 이상에서만 키 교체를 지원하는데, 앱의 최소 버전이 10이라 해당 없습니다.

## 확인 방법
- CI의 에뮬레이터(안드로이드 10과 14)에서, 예전 키로 서명한 앱 위에 키 교체 APK가 설치되는지, 그 뒤 예전 키 APK가 거절되는지 시험했습니다(결과는 릴리스 노트가 아니라 작업 기록에 있음).
- 실제 기기에서는 확인하지 못했습니다.

## 기기에서 확인할 것

- About · Help에 표시되는 버전이 0.83.0인지
