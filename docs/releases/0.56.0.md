# Notesis 0.56.0 (141)

## 환영 애니메이션 다시 다듬기
- 아이콘의 둥근 사각형을 처음 버전처럼 손으로 거칠게 그립니다. 펜을 잠시 멈추면 펜 주위로 고리가 차오르고, 사각형이 반듯하게 바뀝니다. "Hold the pen still, and it becomes the shape" 문구도 다시 나옵니다.
- 사각형이 흰 종이로 바뀐 뒤, 같은 펜이 `>`를 손글씨처럼 거칠게 씁니다. 펜이 떨어지는 순간 `>`도 반듯해집니다.
- 펜은 더 이상 공중에서 돌지 않습니다. `>`를 다 쓰면 살짝 들려서 `_` 자리 위로 옮겨진 뒤, 점점 빨라지며 떨어집니다. 떨어지는 동안 자연스럽게 눕고, 닿을 때 조금 튕기며 자리를 잡습니다.
- 펜이 검정 `>` 위를 지날 때 펜 둘레에 흰 테두리를 둘러서, 펜과 글씨가 한 덩어리로 뭉쳐 보이지 않게 했습니다.

## 삼성 분할 화면에서 위쪽이 가려지던 문제
- 분할 화면이나 팝업 화면에서는 시스템 바(상태 표시줄, 내비게이션 바)를 숨기지 않습니다. 이런 창에서는 앱이 숨겨 달라고 해도 시스템이 바를 계속 그리는데, 일부 기기(삼성 분할 화면)는 바가 숨겨졌다고 알려 주면서 실제로는 창 위쪽을 덮었습니다.
- 분할·팝업 창에서는 바가 숨겨졌다고 보고돼도 그 높이만큼 비워 둡니다. 팝업 창의 제목 표시줄 높이도 함께 비워서, 툴바와 버튼이 가려지지 않게 했습니다.
- 전체 화면으로 돌아오면 이전처럼 시스템 바를 다시 숨깁니다.

## 측면 툴바: 왼쪽 / 오른쪽 선택
- 툴바 방향을 Vertical로 고르면 그 아래에 Side 선택(Left / Right)이 나타납니다.
- Right를 고르면 고정된 툴바가 화면 오른쪽 가운데에 붙고, 떠 있는 툴바도 처음에는 오른쪽에서 시작합니다.
- 툴바가 오른쪽에 고정돼 있을 때 페이지 스크러버는 툴바 왼쪽에 나타나서 서로 겹치지 않습니다.
- 툴바의 메뉴와 패널은 지금처럼 화면 안쪽으로 열립니다.

## 마스킹 테이프: 꾹 누르면 직선
- 마스킹 테이프를 긋다가 끝에서 펜을 잠시 멈추면 형광펜처럼 직선으로 바뀝니다. 펜을 떼기 전에 움직이면 직선의 끝을 옮길 수 있습니다.
- 직선이 된 테이프도 일반 테이프와 똑같이, 읽기 모드에서 탭하면 들춰 볼 수 있고 실행 취소도 한 번에 됩니다.
- 이 동작은 설정의 "Hold at the end to make a shape"를 따릅니다.
