## 바뀐 점

### 1. 에이전트 연결 (C3)
- **켜는 곳**: 첫 화면 메뉴 → **Agent connection**, 또는 터미널 머리줄의 **Agents**. **켜기 전에는 꺼져 있습니다.**
- 켜면 이 태블릿 안(127.0.0.1)에서 MCP 서버가 열립니다. 포트는 47821부터이고, 사용 중이면 다음 번호를 씁니다. 에이전트에는 `notesis_help`(명령 목록)와 `notesis_run`(명령 실행) 두 도구가 보입니다. 터미널의 `notesis` 명령과 같습니다.
- 켜 두면 알림이 하나 있는 서비스가 돌아서, Termux 같은 다른 앱이 앞에 있어도 응답합니다. 알림의 **끄기**로 바로 끌 수 있습니다.
- **토큰**: 기기에서 만들고, 토큰 없이는 아무것도 답하지 않습니다. 화면에는 앞부분만 보이고, 복사할 때 클립보드에 민감한 정보로 표시합니다. 백업에서 제외했습니다. **새 토큰**을 만들면 기존 연결은 바로 끊깁니다.
- 요청마다 보낸 쪽 주소, `Host`, `Origin`, 토큰을 차례로 검사합니다. 웹페이지(브라우저)에서 오는 요청과 다른 이름으로 들어오는 요청은 막습니다. 본문 1MB, 요청 30초, 동시 8개로 제한합니다.
- **같은 Wi-Fi**: 따로 켜야 합니다. 켜도 사설 주소(192.168…, 10…, Tailscale)에서만 받습니다. 통신은 암호화되지 않으니 믿을 수 있는 네트워크에서만 쓰세요.
- 패널에서 Claude Code 연결 명령, JSON 설정, 주소를 복사할 수 있습니다.

### 2. 변경 카드와 묻기/자동 (C2)
- 설정은 **먼저 묻기**(기본)와 **바로 하기** 중에서 고릅니다.
- **먼저 묻기**: 에이전트가 노트를 바꾸려 하면 카드가 무엇을 하려는지 문장으로 보여 줍니다(예: “수학”에 페이지 하나 추가). **허용 / 허용 안 함** 중에서 고릅니다. 2분 안에 답이 없거나 5개 넘게 밀리면 거절로 처리하고, 에이전트에는 허용되지 않았다고 알려 줍니다.
- **바로 하기**: 바로 바꾸고, 알약에 **되돌리기**가 뜹니다.
- 읽기는 어느 쪽이든 묻지 않습니다.
- 패널의 **최근 변경**에 누가 언제 무엇을 바꿨는지 나오고, 가장 최근 것은 거기서 되돌릴 수 있습니다.
- **화면에 열려 있는 노트는 허용 여부와 상관없이 읽기만 됩니다.** 분할 화면의 각 칸, 참고 노트, Markdown 편집기도 포함합니다.
- 터미널에서 직접 친 명령은 묻지 않습니다. 사용자가 친 것이기 때문입니다.

### 3. 이 태블릿의 에이전트 (T2)
- **먼저 확인한 것**: Notesis 안에서 Linux(proot와 Debian)를 직접 돌리는 방식은 안 됩니다. Android 10부터 최신 버전을 대상으로 하는 앱은 자기 저장소에 내려받은 프로그램을 실행할 수 없습니다. Termux가 오래된 대상 버전에 머무는 이유가 이것입니다.
- 그래서 에이전트는 **Termux 안의 Debian**에서 돌리고, 위의 연결로 Notesis에 붙입니다. 에이전트 패널의 **이 태블릿에서** 부분이 그 설정을 만들어 줍니다.
  1. Claude Code·Codex·OpenCode 중 쓸 것을 고릅니다.
  2. **설정 스크립트 복사**를 누르고 **Termux 열기**를 누릅니다. Termux가 없으면 **Termux 받기**가 F-Droid 페이지를 엽니다.
  3. Termux에 붙여 넣고 Enter를 누른 뒤 `done`이 나올 때까지 기다립니다.
  4. 새 Termux 세션에서 `notesis-agents`를 입력한 다음 `claude`(또는 `codex`, `opencode`)를 입력합니다. 처음 한 번은 각 서비스에 로그인해야 합니다.
- 스크립트가 하는 일: Debian(proot-distro), Node.js, 고른 에이전트를 설치하고, 각 에이전트에 Notesis 다리를 MCP 서버로 등록합니다. 다리는 의존성 없는 작은 스크립트로, 에이전트와 Notesis 사이에서 메시지를 전달합니다. 다시 실행해도 설정이 겹치지 않습니다. 붙여 넣기 전에 내용을 읽어 볼 수 있게 스크립트를 전부 복사합니다.
- 토큰을 새로 만들었다면 **토큰 갱신 명령 복사**를 눌러 Termux에서 실행하세요. 다시 설치할 필요는 없습니다.
- Debian, Node.js, 에이전트를 내려받기 때문에 저장 공간과 시간이 꽤 듭니다. 크기는 재 보지 않았습니다.

### 4. 그 밖에 고친 것
- 명령의 되돌리기용 노트 사본이 20단계를 넘거나 되돌린 뒤에도 지워지지 않던 것을 고쳤습니다.
- 노트를 닫자마자 명령이 그 노트를 읽으면 저장이 끝나기 전 상태를 읽을 수 있던 것을 고쳤습니다. 이제 저장이 끝난 뒤에 읽습니다.

## 확인 방법
- 이 컨테이너에서 앱과 시험을 직접 빌드했고, 단위·Robolectric 시험이 모두 통과했습니다.
- 서버는 실제 소켓으로 시험했습니다. 토큰, `Host`·`Origin` 검사, 크기와 시간 제한, 느리게 흘려 보내는 연결을 확인했고, `curl`로도 확인했습니다.
- 서비스를 실제로 띄워 HTTP로 접속하고 실제 노트 파일에서 시험했습니다. 묻기/바로 하기, 허용·거절, 알약의 되돌리기, 열린 노트 보호, 토큰 교체, 서비스 종료까지 확인했습니다.
- 설정 스크립트는 bash로 문법을 검사했습니다. Termux와 Debian의 도구 대신 흉내 내는 대체 프로그램을 두고 실제로 두 번 실행해서, 파일과 등록이 한 번만 되는지 확인했습니다.
- 다리는 실제 `node`로 서버 코드에 붙여 시험했습니다. 메시지 왕복, 세션 전달, 토큰이 바뀌었을 때와 앱이 꺼졌을 때의 안내를 확인했습니다.
- 카드와 패널 화면은 그림으로 찍어 보았습니다.

## 하지 않은 것
- **태블릿에서는 써 보지 못했고, 아무것도 재지 않았습니다.**
- **실제 Termux에서 스크립트를 돌려 보지 못했고, Claude Code·Codex·OpenCode를 실제로 연결해 보지도 못했습니다.** 각 프로그램의 설정 방식(Claude Code의 `claude mcp add`, Codex의 `config.toml`, OpenCode의 `opencode.json`)을 그 형식에 맞춰 썼을 뿐입니다.
- 앱이 완전히 종료되면 에이전트가 붙을 수 없습니다. 연결이 켜져 있으면 앱을 열 때 다시 시작됩니다.
- 에이전트가 밝히는 이름(예: "Claude Code")은 자기 신고일 뿐이라 카드에도 그렇게 적었습니다.
- HTTPS는 없습니다(같은 Wi-Fi에서 암호화되지 않음).

## 태블릿에서 해 볼 것
1. 첫 화면 메뉴 → **Agent connection**을 열고 연결을 켜 보세요. 알림이 뜨는지, 포트가 보이는지 확인해 주세요.
2. **이 태블릿에서**에서 Claude Code를 고르고 설정 스크립트를 복사해 Termux에 붙여 넣어 보세요. 중간에 멈추면 그 화면을 알려 주세요.
3. `notesis-agents` → `claude`로 들어가 "노트 목록 보여 줘"라고 해 보세요.
4. "수학 노트에 페이지 하나 추가해 줘"라고 해서 Notesis에 묻는 카드가 뜨는지 보고, 허용과 허용 안 함을 둘 다 눌러 보세요.
5. 바로 하기로 바꾸고 같은 요청을 한 뒤 알약의 **되돌리기**를 눌러 보세요.
6. 노트를 열어 둔 채 그 노트를 바꾸라고 해서, 바뀌지 않는다는 답이 오는지 보세요.
