# Notesis 0.35.1 (95)

## 변경 사항

- 전체화면이 항상 켜져 있습니다. 화면 가장자리를 쓸어내리면 시스템 바가 잠깐 나타납니다. 전체화면 켜기/끄기 버튼은 없앴습니다.
- 필기 노트를 좌우 끝에서 노트 너비의 0.8배만큼 더 스크롤할 수 있습니다.
- 연필 도구, 수채화·유화 펜, 스티커를 없앴습니다. 이전에 쓴 필기는 그대로 보입니다.
- 일반 버튼을 눌렀을 때 나오던 리퀴드 글래스 효과를 없앴습니다. 도구 막대의 메뉴 버튼은 그대로입니다.
- 폴더 안이나 설정 화면에서 뒤로가기를 누르면 앱이 꺼지지 않고 이전 화면으로 돌아갑니다.
- PNG 저장(내보내기·영역 캡쳐)은 갤러리의 Pictures/Notesis 앨범에 바로 저장됩니다. 여러 페이지는 ZIP 대신 페이지마다 한 장씩 저장됩니다.

## 검증

- debug Kotlin 컴파일 및 JVM 단위 테스트 통과.
