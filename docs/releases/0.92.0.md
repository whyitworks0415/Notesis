# Notesis 0.92.0 (231)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

원칙: 새로 생기는 것은 그것을 만든 버튼·카드에서 자라나고, 사라질 때는 그 자리로 돌아갑니다(Todo.md 3번).

## 바뀐 점

### 1. 노트가 카드에서 열리고 카드로 돌아감 (A1)
- 카드를 누르면 카드의 썸네일이 화면 전체로 커지고(약 0.3초), 다 커진 뒤 그 아래에 노트가 열립니다. 노트가 첫 페이지를 그리면 썸네일이 사라집니다. 0.7초가 지나도 안 그려지면 그냥 사라집니다.
- 노트 화면을 처음 만드는 순간이 앱에서 가장 무거운 프레임이라, 그동안 애니메이션을 돌리면 중간에 멈춥니다. 그래서 썸네일이 다 커진 다음에 노트를 엽니다. 그 대신 노트가 뜨는 시점은 약 0.3초 늦어집니다.
- 뒤로 가면 썸네일이 화면을 덮은 채로 시작해 원래 카드로 줄어듭니다. 카드가 화면 밖이면 가운데로 줄어들며 사라집니다.
- **첫 화면 위치 유지**: 노트를 닫으면 첫 화면이 맨 위로 돌아가던 것을 고쳤습니다. 이제 열기 전 자리 그대로라, 썸네일이 돌아갈 카드가 보입니다.
- 애니메이션 중에는 터치를 받지 않습니다. 시스템 애니메이션이 꺼져 있거나, 절전 중이거나, 가벼운 모드면 예전처럼 바로 열립니다.

### 2. 알림 알약 (A4, C1)
- 앱의 안내 메시지(약 37곳의 토스트)가 이제 **누른 곳에서 자라나 화면 아래에 자리 잡는 알약**으로 나옵니다. 몇 초 뒤 사라집니다.
- 앱 화면이 떠 있지 않을 때만 예전 토스트를 씁니다.

### 3. 삭제는 확인 대신 되돌리기 (C2 일부)
- 카드 메뉴에서 노트를 삭제하면 묻지 않고 바로 휴지통으로 가고, 알약에 **"되돌리기"**가 나옵니다(5초).
- 여러 개를 골라 삭제하거나 폴더를 삭제할 때는 지금처럼 묻습니다.

### 4. 카드가 미끄러져 자리를 메움 (A3)
- 삭제·정렬·폴더 이동·되돌리기 때 남은 카드들이 미끄러져 빈자리를 메우고, 새 카드는 제자리에서 나타납니다. 스크롤할 때는 움직이지 않습니다.

### 5. 선택 막대 (A6)
- 여러 개 고르기를 시작하면 아래 선택 막대가 처음 누른 카드에서 나와 자리 잡고, 끝나면 줄어들며 사라집니다.
- 막대 맨 앞에 "N개 선택됨"이 있고, 숫자가 늘면 위로, 줄면 아래로 굴러서 바뀝니다.

### 6. 페이지 패널 (A7)
- 페이지를 추가·삭제·이동하면 페이지 카드가 미끄러져 자리 잡습니다.

### 7. 빈 첫 화면 (A9)
- 노트가 하나도 없으면 펜으로 한 줄 쓰는 그림이 한 번 그려집니다.

### 8. 0.91.1 뒤에 따로 바뀐 것
- 펜 설정 Color 탭의 **Color grid를 없애고 Palette 보기로 바꿨습니다.** 피커 아래에 있던 팔레트는 같은 내용이 두 번 나오지 않게 뺐습니다. 격자를 쓰던 기기는 팔레트가 열립니다.

## 확인 방법

- 이 컨테이너에서 앱과 시험을 직접 빌드했고, 단위·Robolectric 시험 126개가 모두 통과했습니다.
- 새 시험: 썸네일이 날아가는 경로와 규칙, 알림 알약의 움직임과 되돌리기, 토스트가 알약으로 바뀌는지, 선택 개수, 빈 화면 그림, 팔레트 보기.

## 하지 않은 것

- **기기에서는 시험하지 않았고, 움직임과 성능을 재지 않았습니다.** 이번 것은 대부분 움직임이라 태블릿에서 직접 봐야 합니다.
- Android 14 이상의 뒤로 밀기 미리보기, 새 노트가 + 버튼에서 날아오는 것, 폴더 열기(A2), 제자리 확인(A5), 버튼 안 진행 표시(A8), B 항목들, 여러 개 삭제의 되돌리기는 아직입니다.
- Todo.md의 4~6번(AI 첨부, 명령·터미널, 문서 편집)은 아직입니다.

## 태블릿에서 해 볼 것

1. 첫 화면에서 카드를 눌러 노트를 열고, 뒤로 가 보세요. 카드에서 커지고 그 카드로 돌아가야 합니다.
2. 목록 아래쪽 노트를 열었다 닫아 보세요. 첫 화면이 그 자리 그대로여야 합니다.
3. 카드 메뉴 → 삭제 후 "되돌리기"를 눌러 보세요.
4. 카드를 길게 눌러 여러 개 고르며 선택 막대와 숫자를 보세요.
5. 노트를 열 때 0.3초 늦어지는 것이 거슬리면 알려 주세요. 노트를 먼저 띄우는 쪽으로 바꿀 수 있습니다.
