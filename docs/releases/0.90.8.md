## 노트 밖(화이트보드) 글씨가 이상하게 나오던 문제, 세 번째

0.90.4와 0.90.6에서 고쳤다고 했지만 필기가 많은 노트에서는 그대로였습니다. 이번에는 원인을 다르게 봤습니다.

- **새로 찾은 원인: 좌표의 크기**
  - 페이지 안 글씨는 페이지마다 따로, 페이지 한 장 크기의 작은 숫자로 저장됩니다.
  - 노트 밖 글씨는 노트 전체 기준 좌표로 저장되어서, 노트 아래쪽으로 갈수록 숫자가 수만 단위까지 커집니다.
  - 펜 글씨를 그리는 라이브러리와 그래픽 칩의 계산은 정밀도가 제한되어 있어서, 숫자가 이만큼 크면 빠른 낙서의 작은 삼각형들이 찌그러지고 고리 안이 검게 칠해질 수 있습니다.
  - 필기가 많은(페이지가 많은) 노트에서만, 노트 밖에서만 생기던 이유가 이것으로 설명됩니다.
- **고친 것:** 노트 밖 글씨는 그릴 때 글씨 가까운 곳을 기준점(0, 0)으로 옮겨 작은 숫자로 다시 만들고, 화면에서 원래 자리로 옮겨 그립니다. 그러면 페이지 안 글씨와 같은 크기의 숫자로 계산됩니다.
  - 0.90.6에서 넣은 것(확대에 맞는 정밀도로 다시 만들기, 외곽선을 칠하지 않는 방식)도 그대로 함께 적용됩니다.
  - 저장되는 글씨는 그대로라서, 이미 쓴 글씨도 고쳐진 모양으로 보입니다.
- **남은 것:** 펜을 대고 쓰는 동안 잠깐 보이는 잉크(펜을 떼기 전 모습)는 아직 큰 좌표로 그려집니다. 그래서 쓰는 순간 잠깐 이상하게 보였다가, 펜을 떼면 바로 바로잡힐 수 있습니다. 그대로 남는다면 알려 주세요.

## 라이브러리 배경: 색 적용하면 원래대로 돌아가던 문제

어디서 되돌아가는지 코드에서 딱 집어내지 못해서, 원인이 될 만한 곳을 모두 고쳤습니다.

- **고르는 즉시 적용:** 색 사각형, 색상 막대, 숫자 칸, 색 목록에서 색을 고르는 순간 첫 화면 바탕에 바로 보입니다. **색 적용**은 지금 색을 확정하고 창을 닫습니다.
- **분위기는 '기본'으로:** 색을 적용하면 첫 화면 분위기가 '기본'으로 바뀝니다. 전에는 분위기가 남아 있어서, 카드·글자 색은 그 분위기대로 나오고 바탕만 고른 색이라 분위기로 되돌아간 것처럼 보일 수 있었습니다.
- **위쪽 머리 부분까지 같은 색:** 제목과 검색창이 있는 위쪽 부분 뒤는 앱 기본색이나 분위기 색으로 칠해져 있었습니다. 이제 고른 색으로 칠합니다.
- **분위기를 바꿀 때 첫 화면이 새로 만들어지던 문제:** '기본'과 다른 분위기 사이를 바꾸면 첫 화면이 통째로 다시 만들어져서, 열려 있던 창과 화면 상태가 초기화됐습니다. 이제 그대로 유지됩니다.

## 확인한 것 / 못 한 것

- CI 빌드와 단위 테스트까지 확인했습니다.
- 기기에서 재현해 보지 못했습니다. 원인이 맞는지는 기기에서 확인해야 합니다.

## 태블릿에서 해 볼 것

1. 페이지가 많은 노트의 아래쪽 페이지 옆(노트 밖)에 빠르게 꼬불꼬불 써 보기 → 펜을 뗀 뒤 검은 쐐기가 없는지.
2. 전에 이상하게 보이던 노트 밖 글씨가 이제 깨끗하게 보이는지.
3. 확대·축소해도 깨끗한지.
4. ⋯ → 라이브러리 배경 → 색을 고르면 바탕이 바로 바뀌는지 → 색 적용 → 그 색이 그대로 남는지(위쪽 머리 부분 포함). 앱을 다시 열어도 그대로인지.
