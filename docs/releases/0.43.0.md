# Notesis 0.43.0 (106)

슬라이더가 정해진 값에만 멈추고, 유리 스킨의 아이콘·설정창이 선명해졌으며, 펜·도구마다 직선 그리기를 켤 수 있고, 자동 예측을 화면 주사율과 지연으로 계산합니다.

## 슬라이더는 정해진 값에만 멈춤

- 모든 슬라이더에 **간격**이 생겼습니다. 끌어도 손잡이가 값 사이를 부드럽게 미끄러지지 않고, **정해진 값의 자리에만** 놓입니다. 보고되는 값도 항상 그 값입니다.
- 간격: 예측 1ms, 획 보정 1%, 모서리 둥글기 1, 펜 굵기 0.1, 사진 불투명도·모서리 1%, 테두리 1, 텍스트 상자 모서리·여백 1, 화면 설정은 범위가 넓으면 1 단위·좁으면 범위의 1% 단위.
- Spoti 유리 스킨의 슬라이더도 유리 효과는 그대로 두고, 손잡이는 정해진 자리에 바로 섭니다.
- 페이지 이동 막대는 원래 페이지 단위로만 움직입니다.

## 아이콘 · 설정창 안티앨리어싱

- Spoti 유리 스킨에서는 유리 패널(설정창, 패널, 버튼 등)의 **내용 전체**가 굴절 셰이더를 거쳐 그려지고 있었습니다. 그래서 아이콘·글자·조절 막대가 한 번 더 늘어지고 다시 샘플링되어 가장자리가 흐리고 계단처럼 보였습니다.
- 이제 가만히 있는 유리 패널은 내용을 셰이더에 넣지 않고 바로 그립니다. 흐림·색·테두리 같은 유리 느낌은 그대로이고, 툴바와 조절기를 움직이는 동안에는 빛 굴절이 여전히 보입니다.

## 펜 · 도구 설정의 직선 on/off

- 펜·연필·형광펜·테이프 설정창에 **직선** 스위치가 생겼습니다. 켜면 펜을 댄 곳에서 뗀 곳까지 곧은 선으로 그립니다.
- 도구마다 따로 기억합니다(예: 형광펜만 직선). 툴바의 직선 버튼도 이제 펜·연필에도 나타나고 같은 설정을 켜고 끕니다.

## 자동 예측은 화면 주사율과 지연으로 계산

- 자동 예측 길이를 화면이 잉크를 보여 주기까지 걸리는 시간으로 계산합니다.
  - 일반 필기(프런트 버퍼): **반 프레임** → 120Hz **4ms**(Galaxy Tab S8 Ultra에서 가장 자연스러운 값), 90Hz 6ms, 60Hz 8ms
  - 호환 필기 경로(Tab S6 Lite 등): 프레임의 약 72% → 60Hz 12ms, 그리고 입력이 프레임 안 어디쯤 들어왔는지에 맞춰 조절
  - 지연 측정(진단의 지연 표시)이 켜져 있고 잉크가 한 프레임보다 늦게 나타나면, 넘는 시간의 절반을 더 예측합니다(최대 12ms).
- 펜 설정의 예측 항목에 **자동 · 4 ms (120Hz)** 처럼 이 화면에서 계산된 값이 표시됩니다. 자동을 끄면 그 값에서 시작합니다.
