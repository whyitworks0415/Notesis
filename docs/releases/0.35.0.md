# Notesis 0.35.0 (94)

팝업 노트·AI(웹) 패널·멀티태스킹(삼성 팝업 화면, 분할 화면) 중에 필기가 심하게 밀리던 문제를 고치고, 60Hz 화면(Galaxy Tab S6 Lite)에서의 필기감, 툴바 Liquid Glass의 끝부분·색, 지우개 크기와 모양을 다듬었습니다.

## 변경 사항

### 필기 속도·안정감 (렉 해결)

- **호환 필기 표시를 전용 Surface로 분리**: S6 Lite처럼 front-buffer가 보이지 않는 기기에서 쓰는 "호환 필기 표시"가 일반 View로 그려져, 펜 입력 한 프레임마다 앱 창 전체(페이지 타일, 툴바 유리 배경의 블러, 옆의 웹 패널, 팝업 노트)를 다시 그렸습니다. 웹 페이지·팝업·다른 앱이 함께 있으면 이 프레임이 16.7ms를 넘어 필기가 펜을 따라오지 못했습니다. 이제 진행 중인 획은 창 위의 별도 SurfaceView에 CPU로, 획 주변 영역만 그립니다. 펜을 움직이는 동안 앱 창·RenderThread·GPU를 전혀 쓰지 않습니다.
- **획 형상 갱신을 프레임당 한 번으로**: S펜의 240Hz 입력마다 획 형상을 다시 계산하던 것을 입력만 모아 두고 화면 프레임마다 한 번 계산하도록 바꿨습니다.
- **펜을 뗄 때 깜빡임 없는 인계**: 별도 Surface의 획은 페이지가 그 획을 그린 프레임이 제출되고 한 프레임이 더 지난 뒤 지웁니다. 빠르게 연속으로 쓸 때 이전 획이 잠깐 사라지던 현상도 획별 관리로 없앴습니다.
- **보이지 않는 front-buffer 작업 축소**: 호환 표시 중에는 화면에 보이지 않는 front-buffer에 예측점을 보내지 않습니다.
- **펜을 뗄 때마다 화면 전체가 재구성되던 문제**: 자동 저장·필기 색인 타이머가 편집 횟수를 Compose 키로 읽어, 획 하나마다 노트 화면 전체가 재구성되었습니다. 이제 코루틴에서 관찰하므로 재구성이 일어나지 않습니다.
- **예측 머리(soft head) 제한**: 웹 패널·팝업 노트·분할/팝업 화면이 함께 있을 때는 매 입력마다 창을 다시 그리게 하는 예측 머리 View를 끕니다.
- **멀티태스킹 크기 변경 시 재시작 방지**: 삼성 팝업 화면·분할 화면에서 창 크기를 바꾸면 `smallestScreenSize` 변경으로 액티비티가 재생성(문서·웹뷰 다시 로드)되던 것을 막았습니다. 키보드 커버 연결도 같은 방식으로 처리합니다.

### 60Hz 필기감

- 호환 표시(프레임에 맞춰 표시되는 필기)가 60Hz 화면에 있을 때 자동 예측 길이를 9ms → 12ms로, 중간 속도는 6ms → 8ms로 늘렸습니다. 느린 획과 모서리에서는 예측을 줄이거나 끄는 기존 규칙을 그대로 따릅니다. 4/6/9ms 고정 모드는 바뀌지 않습니다.

### 툴바 Liquid Glass

- **끝으로 갔을 때 부자연스러운 모양 수정**: 이동 중 커지는 렌즈가 첫/마지막 칸에서 바 밖으로 나가 그리기 영역에 직선으로 잘렸습니다. 이제 바 끝에 닿는 쪽이 벽에 눌리듯 납작해지고 줄어든 폭만큼 높이가 조금 늘어납니다. 손가락으로 끝 너머까지 끌면 저항을 받으며 최대 0.3칸까지만 밀려납니다.
- **볼 색상 고정**: 이동 중 볼에 펜 색을 4% 입히던 처리와, 자기 색이 없는 도구(지우개 등)를 볼 안에서 현재 펜 색으로 칠하던 처리를 없앴습니다. 볼은 항상 중립색이고, 볼 안에는 그 도구 자신의 색만 비칩니다.

### 지우개

- **화면 기준 고정 크기**: 지우개 크기를 페이지 단위에서 화면 dp 단위로 바꿨습니다. 확대·축소와 관계없이 화면에서 같은 크기로 보이고 같은 크기만큼 지웁니다.
- **모양**: 흰 테두리 + 파란 테두리 + 연한 파란 안쪽이던 커서를 테두리와 안쪽이 같은 색(회색)의 반투명 원으로 바꿨습니다.
- 커서는 페이지가 아닌 별도 레이어에 그려져, 호버 중 페이지 전체를 다시 기록하지 않습니다.

## 참고

- 노트를 회전한 상태에서는 Surface가 회전을 따라갈 수 없으므로 기존 방식(창 안의 View)으로 그립니다.
- 별도 Surface는 Ink의 front-buffer와 같이 창 위에 표시되므로, 쓰는 동안 고정 툴바 아래로 지나가는 획은 툴바 위에 보였다가 펜을 떼면 아래로 들어갑니다.
- 실제 S6 Lite 기기에서의 확인은 하지 못했습니다. 빌드와 단위 테스트는 GitHub Actions에서 수행합니다.
