# Notesis 0.35.0 (94)

0.34.6 이후 구현한 필기·도형 편집, 노트와 페이지 관리, 문서 가져오기, 텍스트·이미지 편집 및 사용성 개선을 포함합니다.

## 추가 구현 사항

- 필기: 만년필·캘리그래피·수채화·유화 펜, 지연 모드, 굵기 조절, 색상 스포이드, 레이저 점 모드, 펜 버튼 동작과 지우개 복귀 설정.
- 도형: 추가 도형 18종, 정사각형·원 가이드, 길게 눌러 도형 그리기, 꼭짓점 편집, 다각형·곡선 그리기와 모서리 둥글게 하기. 자·삼각자·각도기 및 정렬 스냅.
- 선택과 개체: 이미지·텍스트 상자 올가미/지우개 처리, 잠금·그룹, 재사용 개체 라이브러리, 붙인 내용을 함께 옮기는 스티커 메모·표, 페이지·다른 노트·웹으로 연결하는 링크.
- 노트 관리: 태그·색상 라벨·비밀번호 잠금, 14일 휴지통, 즐겨찾기 순서 유지 및 변경, 노트 안의 메뉴와 노트별 페이지 배치.
- 페이지: 북마크, 계층형 목차와 검색, PDF 자체 목차, 페이지 이동·회전, 여러 페이지 삭제·복제·내보내기·다른 노트로 보내기. 표준/사용자 페이지 크기와 마지막 페이지를 넘겨 새 페이지 추가.
- 가져오기/내보내기: 웹페이지·여러 사진에서 노트 만들기, 카메라 페이지, 문서를 텍스트 노트로 가져오기, CSV·Office 템플릿 열기, 이미지 전용 PDF 및 색상 반전 PDF 내보내기.
- 텍스트·이미지: 텍스트 구간별 서식·글꼴·배경·모서리·여백, 두 번 눌러 텍스트 편집, 이미지 자르기·스타일·회전·자유 크기 조절 및 이모지 스티커.
- 인식·음성: 필기 인식 언어 선택, 필기를 입력 텍스트로 변환, 읽기 결과 줄별 표시, 기기의 음성 인식으로 받아쓰기. PDF 선택 영역 취소선·번역·검색·공유 및 녹음 내보내기·연속 재생.
- 사용성: 하단 확대 필기 창, 가장자리 필기, 도구 모음 표시·순서와 빠른 색상 설정, 손가락·제스처 설정, 다른 앱에서 붙여넣기, 입력 텍스트 검색, 새 노트·폴더·검색 키보드 단축키, 도움말·진단.

## 변경 사항

- 지우개 설정에서 지울 대상(펜·형광펜·테이프)을 고를 수 있습니다. 기본값은 모두 켜짐입니다.
- 펜 설정의 **낙서로 지우기**(기본 꺼짐): 글씨 위를 지그재그로 문지르면 그 아래 필기가 지워지고 낙서는 남지 않습니다. 실행 취소로 되돌릴 수 있습니다.
- 펜 설정의 **원을 그리고 멈추면 선택**(기본 꺼짐): 필기를 원으로 감싸고 끝에서 0.5초 멈추면 선택으로 바뀌고, 펜을 그대로 움직이면 옮겨집니다. 선택 밖에 쓰면 선택이 풀립니다. 아무것도 감싸지 않은 원은 그대로 필기로 남습니다.
- 올가미: **완전히 포함된 것만** 선택 옵션, 복사·잘라내기·붙여넣기, 최근 10개 클립보드(다른 노트에도 붙여넣기 가능, 앱 종료 시 사라짐).
- 페이지 추가·삭제·복제·이동·배경·템플릿 변경을 실행 취소·다시 실행할 수 있습니다. 삭제한 페이지는 자동 저장 후에도 실행 취소로 되살아납니다.
- 하드웨어 키보드: Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y), Ctrl+= / Ctrl+-, 방향키 이동, Alt+←/→·PageUp/PageDown 페이지 이동.

필기 중 성능: 기본 설정에서는 필기 중 처리가 늘지 않습니다. 낙서 판정은 펜을 뗄 때 한 번, 원 선택 판정은 켰을 때만 펜이 멈춘 순간 한 번 합니다.
