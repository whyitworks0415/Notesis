# Notesis 0.35.0 (94)

지우개 대상 선택, 낙서로 지우기, 원으로 선택하기, 올가미 클립보드, 페이지 작업 실행 취소, 키보드 단축키를 추가했습니다.

## 변경 사항

- 지우개 설정에서 지울 대상(펜·형광펜·테이프)을 고를 수 있습니다. 기본값은 모두 켜짐입니다.
- 펜 설정의 **낙서로 지우기**(기본 꺼짐): 글씨 위를 지그재그로 문지르면 그 아래 필기가 지워지고 낙서는 남지 않습니다. 실행 취소로 되돌릴 수 있습니다.
- 펜 설정의 **원을 그리고 멈추면 선택**(기본 꺼짐): 필기를 원으로 감싸고 끝에서 0.5초 멈추면 선택으로 바뀌고, 펜을 그대로 움직이면 옮겨집니다. 선택 밖에 쓰면 선택이 풀립니다. 아무것도 감싸지 않은 원은 그대로 필기로 남습니다.
- 올가미: **완전히 포함된 것만** 선택 옵션, 복사·잘라내기·붙여넣기, 최근 10개 클립보드(다른 노트에도 붙여넣기 가능, 앱 종료 시 사라짐).
- 페이지 추가·삭제·복제·이동·배경·템플릿 변경을 실행 취소·다시 실행할 수 있습니다. 삭제한 페이지는 자동 저장 후에도 실행 취소로 되살아납니다.
- 하드웨어 키보드: Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y), Ctrl+= / Ctrl+-, 방향키 이동, Alt+←/→·PageUp/PageDown 페이지 이동.

필기 중 성능: 기본 설정에서는 필기 중 처리가 늘지 않습니다. 낙서 판정은 펜을 뗄 때 한 번, 원 선택 판정은 켰을 때만 펜이 멈춘 순간 한 번 합니다.

## 검증

- JVM 단위 테스트 152개 통과(낙서·원 판정 테스트 포함).
- 기기·에뮬레이터 동작 검증용 `gestures` 계측 테스트를 추가했지만 이번 릴리즈 전에는 실행하지 못했습니다. 실제 태블릿에서의 검증은 포함되지 않았습니다.
