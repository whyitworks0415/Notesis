# Notesis 0.90.27 (227)

## 바뀐 점

### 1. 120Hz에서도 모션 블러
- 지금까지는 60Hz 화면에서만 블러를 그렸습니다. 이제 120Hz에서도 그립니다. 블러 길이는 한 프레임 동안 움직인 거리에 비례해서, 120Hz에서는 60Hz의 절반 정도로 짧아집니다.

### 2. 더 많은 곳에 모션 블러
- **사이드바·패널**: 설정 사이드바, 페이지 패널, 레이어 패널이 미끄러질 때 가로 방향으로 흐려집니다. 프레임 사이의 이동 속도로 정하고, 멈추면 바로 사라집니다.
- **노트 페이지 스크롤**: 손가락으로 페이지를 넘기거나 튕길 때, 페이지 그림에만 이동 방향으로 블러가 들어갑니다. 쓰고 있는 잉크, 툴바, 유리 막대에는 넣지 않습니다. 확대·축소 중에는 넣지 않습니다. 페이지가 멈추면 80ms 안에 사라집니다.
- **필기**: 펜은 1초에 480번 위치를 보내는데 화면은 60~120번만 그리므로, 한 프레임 사이에 펜이 지나간 길이 한 번에 툭 나타납니다. 이 사이 구간을 펜 끝 앞에 옅게 이어 그려서 덜 끊겨 보이게 합니다. 예전부터 있던 펜 설정의 "480Hz 사이 프레임" 모션 블러를 모션 블러 설정과 연결한 것입니다. 진하기는 모션 블러 강도를 따릅니다. 펜 설정에서 직접 고른 값(모션 블러·잔상)이 있으면 그것이 우선입니다.
- 팝업과 목록 스크롤은 0.90.26과 같습니다.

### 3. 베타: 부분별로 켜고 끄기
- 개발자 코드를 넣은 기기에서는 설정 → 외관 → 모션의 모션 블러 슬라이더 아래에 **부분별 모션 블러**가 나옵니다. 팝업, 사이드바와 패널, 목록, 페이지 스크롤, 필기를 하나씩 켜고 끌 수 있습니다. 기본값은 모두 켜짐입니다.
- 어느 부분이 무거운지 찾을 때 하나씩 꺼 보세요.

## 렉을 줄이려고 한 것
- 블러가 0.5px보다 작으면 아예 그리지 않습니다. 멈춰 있을 때는 따로 그리는 비용이 없습니다.
- 한 방향으로만 움직일 때는 그 방향으로만 흐리게 해서 계산이 한 번으로 끝납니다.
- 노트 페이지는 블러 크기가 반 픽셀 단위로 같으면 같은 효과를 다시 쓰고, 프레임마다 새로 만들지 않습니다.
- 필기 블러는 펜 이벤트마다 메모리를 새로 쓰지 않습니다. 절전 모드에서는 꺼집니다.

## 확인 방법

- 단위 테스트로 확인했습니다. 블러 크기(120Hz에서 절반, 강도 0%에서 없음, 상한), 미끄러지는 속도 계산(멈추면 0, 긴 끊김 후 0), 필기 블러 진하기, 부분 목록을 봅니다.
- CI에서 릴리스 빌드, 전체 단위 테스트, UI 테스트를 통과해야 게시됩니다.

## 하지 않은 것 / 모르는 것

- **기기에서는 시험하지 않았습니다.** 특히 노트 페이지 스크롤 블러는 페이지 전체를 한 번 더 그리는 것이라 S6 Lite에서 무거울 수 있습니다. 무거우면 부분별 설정에서 "페이지 스크롤"만 꺼 주세요.
- 필기 블러는 펜 끝 미리보기(부드러운 펜 끝)가 켜져 있고, 회전하지 않은 화면에서 둥근 펜 끝을 가진 펜일 때만 그려집니다. 예전 기능과 같은 조건입니다.

## 태블릿에서 해 볼 것

1. 120Hz와 60Hz에서 각각 팝업을 열고, 첫 화면과 노트 페이지를 빠르게 스크롤해 봅니다.
2. 설정 사이드바와 페이지 패널을 열고 닫아 봅니다.
3. 빠르게 글씨를 써서 펜 끝이 덜 끊겨 보이는지 봅니다.
4. 부분별 모션 블러에서 하나씩 꺼 가며 무거워지는 곳이 있는지 봅니다.
