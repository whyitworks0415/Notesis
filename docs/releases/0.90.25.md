## 바뀐 점

### 1. 펜 설정 끝에서 그냥 막힘
- 펜·형광펜·연필·지우개 등 도구 설정 창을 위아래로 스크롤할 때, 끝에서 더 당겨도 튕기거나 늘어나지 않고 그 자리에서 막힙니다. 0.90.22에서 넣은 끝 반동과 안드로이드 기본 늘어남 효과를 모두 뺐습니다.
- 다른 팝업 메뉴의 끝 반동은 그대로입니다.

### 2. 펜 설정의 선택 막대를 Liquid glass로
- Setting·Color 탭, 펜 종류(볼펜·만년필·캘리그래피·사라지는 펜), 연필 종류, 선 모양(실선·점선·파선), 색상 보기(격자·사각형·막대·링)를 고르는 막대가 이제 툴바와 같은 Liquid glass 막대입니다. 고른 항목으로 옮겨 갈 때 선택이 렌즈로 떠올라 이동합니다.
- Liquid glass 외관에서만 바뀝니다. Material과 Glassmorphism 외관은 지금 모양 그대로입니다.
- Liquid glass 막대는 글자만 보입니다. 기존 막대처럼 손가락을 대면 그림으로 바뀌는 동작은 없습니다.

### 3. 색상 보기 전환이 바로
- 격자·사각형·막대·링 사이를 바꿀 때 모양이 변형되는 애니메이션 없이 바로 바뀝니다.

## 확인 방법

- CI에서 릴리스 빌드, 전체 단위 테스트, UI 테스트를 통과해야 게시됩니다.

## 하지 않은 것 / 모르는 것

- **기기에서는 시험하지 않았습니다.** 렌즈가 펜 설정 창 안에서 어떻게 보이는지 화면으로 확인하지 못했습니다.

## 태블릿에서 해 볼 것

1. 펜 설정을 열고 위아래 끝까지 스크롤해 더 당겨 봅니다. 튕기지 않고 막혀야 합니다.
2. Setting·Color 탭, 펜 종류, 선 모양을 바꿔 렌즈가 자연스럽게 움직이는지 봅니다.
3. Color 탭에서 색상 보기를 바꿔 바로 바뀌는지 봅니다.
4. Material 외관으로 바꿔 기존 막대가 그대로인지 봅니다.
