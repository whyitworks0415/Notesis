# Notesis 0.31.9

실시간 stroke stabilization을 낮은 강도와 pen-up 구간까지 보완했습니다.

- 0%는 raw 입력을 그대로 유지합니다.
- perceptual strength mapping으로 5/10/20/30%에서도 단계별 차이가 느껴집니다.
- 속도, 이동 거리, sample 간 시간에 따라 smoothing을 조절합니다.
- corner와 빠른 반전에서는 smoothing을 즉시 줄여 의도적인 꺾임을 보존합니다.
- `ACTION_UP`의 historical sample에도 lift hook/jump 판정을 적용해 마지막 튐이 wet ink에 먼저 들어가는 것을 막습니다.
- pressure는 위치 smoothing과 독립적으로 처리하며 작은 진동만 줄이고 의도적인 필압 변화는 빠르게 따라갑니다.
- wet ink, committed stroke, auto-shape가 동일한 stabilized trajectory를 계속 사용합니다.
- 기존 stroke 저장 형식과 undo/redo 동작은 변경하지 않았습니다.

직선, jitter, 곡선, 90도 corner, 빠른 반전, 짧은 stroke, dot, start spike, lift spike, 빠른/느린 필기와 pressure 회귀 테스트를 실행했습니다. 릴리스 머신에 연결된 Android 기기가 없어 S Pen 실기기 비교는 후속 확인 항목으로 남습니다.
