# Notesis 0.37.0 (97)

연필 도구를 다시 넣고, 동그란 점(파티클)을 흩뿌려 그리는 세 가지 질감을 더했습니다. 0.35.x와 0.36.0의 변경 사항도 이번 버전에 함께 들어 있습니다.

## 변경 사항

### 연필 도구

- **도구 막대에 연필이 돌아왔습니다.** 펜 옆에 붓 아이콘으로 표시됩니다. 0.35.1 이후 도구 막대 순서를 바꾼 경우에도 한 번은 자동으로 펜 옆에 다시 추가됩니다. 그 뒤에 '도구 편집'에서 빼면 빠진 상태가 유지됩니다.
- **연필 종류**: 연필 설정에서 고를 수 있습니다.
  - **흑연**: 기존 연필(종이 질감의 흑연선)
  - **스탬프**: 둥근 점이 겹겹이 찍혀 두툼한 띠가 됩니다. 점마다 크기·위치·진하기가 조금씩 달라 가장자리가 울퉁불퉁하고, 겹친 곳은 더 진해집니다. 가늘게 하면 점이 찍힌 얇은 선이 됩니다. 필압이 있는 펜은 약하게 누를수록 점이 작아집니다.
  - **버블**: 크기가 아주 다른 동그라미가 선보다 넓게 흩어지고, 사이사이에 작은 점이 섞입니다.
  - **스프레이**: 아주 작은 점이 펜 주변으로 흩뿌려지며, 가운데가 촘촘하고 바깥으로 갈수록 성깁니다.
- 연필의 기본값은 빨간 스탬프, 굵기 24입니다. 굵기 범위는 연필만 0.25~80으로 넓혔습니다. 너무 넓다면 굵기 설정의 '얇게/중간' 상한을 쓰면 됩니다.
- 점의 배치는 그릴 때마다 무작위로 정하지 않고 획이 지나간 거리로 정합니다. 그래서 노트를 다시 열거나, 쓰는 중과 펜을 뗀 뒤에 모양이 달라지지 않습니다.
- 스탬프·버블·스프레이에는 펜의 점선/파선 설정과, 펜 앞에 미리 그려 주는 예측 머리를 적용하지 않습니다. 점선이 질감을 덮거나, 점 앞에 매끈한 선이 비치는 것을 막기 위해서입니다.

### 0.35.x와 0.36.0 통합

- 0.36.0은 0.34.6에서 갈라져 나와 0.35.x의 기능(도형 편집, 받아쓰기, 문서 가져오기, 항상 전체화면 등)이 빠져 있었습니다. 두 버전을 합쳤습니다.
- 0.35.1처럼 항상 전체화면이며, 0.36.0의 멀티태스킹(분할·팝업 화면) 감지는 그대로 동작합니다.

## 참고

- 벡터 PDF 내보내기는 점마다 다른 진하기를 담지 못하므로, 스탬프 띠가 화면보다 고르게 칠해져 나옵니다. 점의 크기와 위치는 그대로입니다.
- 이전 버전 앱에서는 새 연필 종류로 쓴 획을 읽을 수 없습니다.
- 이 환경에는 Android SDK가 없어 빌드와 단위 테스트는 GitHub Actions에서 수행합니다. 실제 기기에서는 확인하지 못했습니다.
