# Notesis 0.58.0 (143)

## 나가기 버튼을 툴바에 맞춤
- 2/4~4/4 툴바에서 왼쪽 위의 둥근 나가기(Back to notes) 버튼 크기를 툴바 도구 줄(캡슐)의 높이와 같게 했습니다. 기능(Functions) 버튼도 같은 크기라서, 세 요소의 위·아래 끝이 한 줄로 맞습니다.
- 나가기 버튼의 높이(세로 위치)도 툴바 도구 줄과 같습니다. 툴바가 고정돼 있을 때와 떠 있을 때를 각각 맞췄습니다.
- 측면(세로) 툴바에서는 나가기 버튼이 툴바와 같은 세로줄의 맨 위에 옵니다. 툴바가 오른쪽에 있으면 나가기 버튼도 오른쪽 위에 있습니다.

## 창 크기에 따라 툴바 크기가 바뀜
- 노트 화면의 툴바, 도구 아이콘, 기능 버튼, 나가기 버튼이 창의 짧은 쪽 길이에 맞춰 함께 커지고 작아집니다.
  - 휴대폰이나 분할 화면: 원래 크기와 거의 같습니다(0.95배).
  - 태블릿 전체 화면: 최대 1.2배까지 커집니다.
  - 그 사이 크기의 창(태블릿 절반 분할 등)은 중간 크기입니다.
- 버튼은 손가락으로 누르기 좋은 크기(44dp) 아래로는 작아지지 않습니다.
- 크기는 0.05 단위로만 바뀌어서, 창 크기를 조금 조절할 때마다 툴바가 흔들리지 않습니다.
- 기기를 돌려도 짧은 쪽 길이는 같으므로 크기가 그대로입니다.
- 1/4(전체) 툴바와 설정 화면의 툴바 미리보기는 지금 크기 그대로입니다.
