## 첫 화면 위쪽

- **중간 상태 없이 접히고 펼쳐집니다.** 0.88.1에서는 스크롤한 만큼 조금씩 접혔고, 그래서 중간 상태로 멈춰 있을 수 있었습니다. 이제는 목록 맨 앞의 빈 칸(72dp)을 절반 넘게 올리면 접힌 상태로, 그 위로 내리면 펼친 상태로 바뀝니다. 바뀔 때는 **300ms 동안 가속했다가 감속**(FastOutSlowIn)하며 움직입니다. 둥근 버튼을 눌러 펼치고 접는 움직임도 같은 300ms입니다.
- **펼친 뒤 스크롤하면 다시 들어갑니다.** 스크롤한 상태에서 조절 버튼이나 검색 버튼을 눌러 펼친 뒤 목록을 다시 움직이면 둘 다 둥근 버튼으로 돌아갑니다. 검색창에 입력 중이었다면 키보드가 내려가고, 입력한 검색어는 그대로 남습니다.
- **흐려지는 띠를 1/4 높이로 줄였습니다.** 스크롤했을 때 화면 위를 가리던 그라데이션 띠는 이제 머리 높이의 1/4만, 상태 표시줄 근처에만 깔립니다. 버튼과 검색창 크기는 그대로입니다.

## 폴더 안의 폴더

- 폴더 안에서 **새 폴더**를 만들면 그 폴더 안에 만들어집니다. 깊이 제한은 없습니다.
- 폴더를 열면 위에 그 안의 폴더들이, 아래에 그 폴더의 노트가 보입니다. 폴더 카드의 숫자는 그 안과 그 아래에 있는 노트를 모두 셉니다.
- 뒤로 버튼(화면의 화살표와 기기의 뒤로)은 한 단계 위 폴더로 갑니다.
- 이름을 바꾸면 그 안의 폴더와 노트도 함께 따라갑니다. 지울 때도 안의 폴더까지 함께 지워지고, **노트 유지**를 고르면 노트는 한 단계 위 폴더로 옮겨집니다.
- 저장 방식은 폴더 이름을 `/`로 이은 경로라서, 지금까지 쓰던 폴더는 그대로 맨 위 폴더로 남습니다. 폴더 이름에는 `/`를 쓸 수 없습니다.
- **노트 이동** 창에 `학교/수학`처럼 경로를 적으면 그 안으로 옮겨집니다.

## 종이·템플릿 고르기

- **새 노트**의 첫 페이지 템플릿과 **페이지 추가**의 종이를 이름 칩 대신 **미리보기 그림 카드**로 고릅니다. 줄, 좁은 줄, 모눈, 점, 코넬, 무한(화살표)을 작은 페이지에 그려 보여 주고, 직접 추가한 이미지 템플릿은 그 그림을 보여 줍니다. 고른 카드는 테두리가 강조됩니다.
- **템플릿 이름:** 이미지 템플릿을 추가하면 바로 이름을 정하는 창이 뜹니다(처음 값은 파일 이름). 추가한 템플릿 카드를 **길게 누르면** 언제든 이름을 바꿀 수 있습니다.

## Markdown

- **Markdown 노트를 다시 카드로 보여 줍니다**(0.88.0의 목록 줄 모양을 되돌렸습니다).
- **카드 썸네일은 노트 본문입니다.** 따로 고른 썸네일이 없으면 노트 앞부분을 서식이 적용된 채로 보여 줍니다. 제목은 크고 굵게, 굵게·기울임·취소선·형광펜·코드·링크·태그가 적용되고, 목록 기호는 `•`로, 체크박스는 ☐/☑로 보입니다. `#`, `**` 같은 기호는 보이지 않습니다. 썸네일을 직접 고르면 그 그림이 우선합니다.
- **Markdown 항목 안에 Vault 항목**을 넣었습니다. Markdown 제목 아래 **Vault · 폴더 이름** 줄을 눌러 따로 접고 펼칠 수 있고, 접은 상태는 기억됩니다.
  - 펼치면 마지막으로 연 Vault(기기 안 .md 폴더)의 파일 중 최근 12개가 보이고, 바로 열 수 있습니다. 거기서 뒤로 가면 Vault 화면이 아니라 첫 화면으로 돌아옵니다.
  - 아래 버튼으로 Vault 전체를 열 수 있습니다. 아직 Vault가 없으면 폴더를 고르는 버튼이 나옵니다.
  - Vault 파일 목록은 Vault 항목이 펼쳐져 있을 때만 읽습니다.

- CI에서 릴리스 빌드와 단위 테스트를 돌렸습니다. 새 테스트: 폴더 경로 계산(`FolderPathsTest`), Markdown 썸네일용 본문 변환(`MarkdownPreviewTest`), 그리고 0.88.1의 검색창 위치 계산(`SearchMorphTest`).
- **기기에서는 확인하지 못했습니다.** 접힘 기준 높이와 300ms 움직임의 느낌, 템플릿 카드 크기, 썸네일 글자 크기(9sp), Vault 파일을 읽는 속도는 태블릿에서 봐 주셔야 합니다.
- 폴더 색과 썸네일은 폴더 경로로 기억하므로, 폴더 이름을 바꾸면 색과 썸네일은 따라가지 않습니다(이전 버전과 같음).

## 태블릿에서 해 볼 것

1. 첫 화면에서 조금만 스크롤했다가 놓기: 중간에 멈추지 않고 펼침이나 접힘 중 하나로 부드럽게 바뀌는지.
2. 접힌 상태에서 검색 버튼을 눌러 펼친 뒤 목록 스크롤하기: 다시 둥근 버튼으로 들어가는지. 조절 버튼도 똑같이.
3. 폴더 안에서 새 폴더를 만들고 들어갔다가 뒤로 버튼으로 한 단계씩 나오기. 바깥 폴더 이름을 바꾼 뒤 안쪽 폴더가 그대로 있는지.
4. 새 노트와 페이지 추가에서 종이 그림 카드 고르기. 이미지 템플릿을 추가해 이름을 정하고, 카드를 길게 눌러 이름 바꾸기.
5. Markdown 노트 카드에 본문이 서식대로 보이는지. Vault 항목을 접고 펼치고, 거기서 파일을 연 뒤 뒤로 가기.
