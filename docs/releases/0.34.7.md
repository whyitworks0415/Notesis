# Notesis 0.34.7 (94)

전체화면을 기본 동작으로 바꾸고, 쓰지 않는 도구와 버튼 효과를 정리했습니다. 뒤로가기와 PNG 저장 동작도 고쳤습니다.

## 변경 사항

- 앱 전체가 항상 전체화면으로 표시됩니다. 상태 표시줄과 내비게이션 바는 화면 가장자리에서 밀어 넣을 때만 잠시 나타납니다. 도구막대와 기능 메뉴의 전체화면 켜기/끄기 버튼은 삭제했습니다.
- 필기 노트에서 노트의 좌우 끝을 지나 페이지 너비의 0.8배만큼 더 스크롤할 수 있습니다. 노트가 화면보다 좁을 때도 같은 거리만큼 좌우로 옮길 수 있습니다.
- 연필 도구를 도구막대와 '모든 도구' 메뉴에서 삭제했습니다. 이미 연필로 쓴 필기는 그대로 표시됩니다.
- 할 일 목록에서 수채화·유화 브러시와 스티커 항목을 삭제했습니다.
- 기능 메뉴 안의 일반 버튼과 설정 화면의 버튼·선택 칩을 누를 때 Liquid Glass로 바뀌던 효과를 삭제했습니다. 일반 버튼은 기본 누름 표시만 보입니다. 도구막대의 '기능' 버튼 같은 트리거 버튼은 그대로입니다.
- 뒤로가기 동작
  - 노트 목록에서 폴더 안에 있으면 전체 노트로 돌아갑니다. 검색어가 있으면 검색을 지우고, 여러 노트 선택 중이면 선택을 끝냅니다. 그다음에만 앱을 나갑니다.
  - 화면 설정에서 뒤로가기를 누르면 앱이 꺼지지 않고 이전 화면으로 돌아갑니다.
- PNG 저장은 파일 위치를 고르지 않고 갤러리(`Pictures/Notesis`)에 바로 저장합니다. 여러 페이지를 고르면 ZIP 대신 페이지마다 PNG 한 장씩 저장합니다. 캡쳐 화면의 '저장'도 갤러리에 저장합니다.

## 검증

- 이 변경은 Android SDK가 없는 환경에서 작성했습니다. 빌드와 실제 기기 확인은 GitHub Actions APK 빌드와 태블릿에서 진행해야 합니다.
