# Notesis 0.65.0 (152)

## 새 페이지 패널 (검색 · 페이지 · 목차 · 마스크 · 노트)
오른쪽 페이지 패널(위쪽 줄의 검색 버튼, 또는 Functions › Pages & notes)을 새로 만들었습니다.

- **위쪽 탭**: Pages / TOC / Masks / Notes
- **검색창 하나**: 탭 아래 검색창 하나로 검색합니다.
  - Pages 탭에서는 노트 본문(PDF 글자, 텍스트 상자, 인식된 손글씨)을 검색합니다.
  - 다른 탭에서는 그 탭의 목록을 걸러냅니다(목차 제목, 마스크 이름, 노트 제목).
  - Ctrl+F를 누르면 패널이 열리고 바로 입력할 수 있습니다.
- **Pages**: 페이지를 실제 미리보기 그림으로 보여줍니다.
  - 한 줄에 2~5장까지 − / + 로 조절할 수 있고, 이 값은 저장됩니다.
  - 누르면 그 페이지로 이동하고, 길게 누르면 페이지 메뉴(책갈피, 목차, 이동, 복제, 회전, 배경, 크기, 삭제)가 열립니다.
  - 책갈피만 보기, 여러 장 선택(삭제·복제·PDF·복사·이동), 페이지 이동(Go to), + Page는 그대로 있습니다.
- **TOC**: 목차 항목마다 왼쪽에 해당 페이지 미리보기, 오른쪽에 제목이 나옵니다. PDF 자체 목차도 같은 모양입니다.
- **Masks**: 마스크(마스킹 테이프)가 있는 페이지만, 마스크 하나하나를 보여줍니다.
  - 페이지에서 그 마스크가 놓인 부분을 잘라 보여줍니다. 가려진 동안은 테이프가 덮인 채로, 걷으면 밑의 내용이 보입니다.
  - 위치("Top left", "Bottom right" 등), 페이지 번호, 이름, 보이기/가리기, 삭제, 학습 기능은 그대로 있습니다.
- **Notes**: 다른 노트들을 썸네일로 보여줍니다.
  - 누르면 그 노트로 바뀝니다.
  - 길게 누르면 "Open beside this note"로 지금 노트 옆에 분할로 엽니다.
  - 첫 칸의 New note로 새 노트를 만들어 바로 엽니다.
- **폭 조절**: 패널 왼쪽 회색 막대를 끌어 폭을 바꿉니다(저장됨). 최소 폭보다 훨씬 더 오른쪽으로 끌었다 놓으면 패널이 닫힙니다.

## Functions 메뉴
- Notes, Add page 버튼을 빼고, 그 자리에 Pages & notes(새 페이지 패널)를 넣었습니다. 새 페이지 추가는 패널의 + Page, 새 노트는 패널의 Notes 탭에서 합니다.

## 미리보기 그림
- 아직 열어 보지 않은 페이지와 PDF 페이지도 패널 미리보기에 필기·PDF가 함께 그려집니다.
- 미리보기 저장 공간을 늘려 스크롤할 때 같은 그림을 다시 그리는 일을 줄였습니다.

## 홈 화면 스크롤
- 노트 카드 썸네일을 메인 스레드에서 원본 크기로 읽던 것을, 백그라운드에서 카드 크기로 줄여 읽고 기억해 두도록 바꿨습니다. 노트가 많을 때 스크롤이 끊기던 원인 중 하나입니다.
