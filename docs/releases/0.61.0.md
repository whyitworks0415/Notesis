# Notesis 0.61.0 (146)

## Liquid glass 기본값을 참고 사진처럼
- 패널, 메뉴, 툴바의 기본 유리를 보내주신 사진에 가깝게 바꿨습니다.

  | 항목 | 이전 | 지금 |
  |---|---|---|
  | 투명도 | 75% | 90% |
  | 툴바 배경 불투명도 | 20.5% | 8% |
  | 흐림 반경 | 20dp | 30dp |
  | 색 살림(vibrancy) | 42% | 60% |
  | 굴절 깊이 / 휨 | 12dp / 24dp | 16dp / 32dp |
  | 반사(새 항목) | 35%에 해당 | 75% |

- 투명도를 75% 넘게 올리면 유리 바탕 자체도 얇아집니다(100%에서 절반 이하). 예전에는 투명도를 올려도 바탕색이 남아서 사진처럼 비치지 않았습니다.
- 반사(Reflection)를 새로 넣었습니다. 유리 가장자리의 밝은 테두리와 위쪽에서 내려오는 은은한 광택의 세기를 정합니다.
- 기본값을 그대로 쓰고 있던 경우에는 업데이트 후 새 기본값으로 바뀝니다. 직접 바꾼 값이 있으면 그대로 두고, 반사만 예전과 같은 정도로 맞춥니다.

## 슬라이더·스위치는 원래 유리로 고정
- 슬라이더, 스위치, 세그먼트 버튼(Light/Dark 같은 선택 버튼)은 화면 모양 설정과 상관없이 원래의 곡률(32dp)과 투명도(75%)로 그려집니다.
- 패널 설정을 바꿔도 이 컨트롤들의 모양과 반응은 바뀌지 않습니다. 강조색, 글자색, 고대비 설정은 그대로 따릅니다.

## 비슷한 슬라이더 정리 (9개 → 6개)
- Panels(패널)
  - Corner radius: 그대로
  - Frost: 흐림 반경과 색 살림을 하나로
  - Transparency: 유리 투명도와 툴바 배경 불투명도를 하나로
  - Reflection: 새 항목
- Glass(유리)
  - Depth: 굴절 깊이와 휨을 하나로
  - Lens direction: 그대로
  - Interaction strength: 그대로
- 색수차(Dispersion) 슬라이더는 뺐습니다. 값은 그대로 유지됩니다.

## 화면 모양 설정 화면을 쓰기 편하게
- 위에는 툴바 미리보기와 그룹 선택(Style · Panels · Glass · Colors · Icons)만 남기고, 나머지 화면 전체를 고른 그룹의 설정에 씁니다. 예전에는 위쪽 항목이 많아서 아래 슬라이더 칸이 아주 좁았습니다.
- UI 스타일, Light/Dark, 툴바 크기·방향·Scale, 미리보기 배경은 새 Style 그룹으로 옮겼습니다.
- 넓은 화면(태블릿 가로 등)에서는 미리보기를 왼쪽, 설정을 오른쪽에 나란히 둡니다.
- 슬라이더마다 카드 형태로 바꿨습니다.
  - 이름과 현재 값을 크게 보여 줍니다.
  - 슬라이더는 카드 폭 전체를 씁니다.
  - 양옆의 −/+ 버튼으로 한 칸씩 세밀하게 조절할 수 있습니다.
  - 기본값과 다를 때 값 표시를 누르면 기본값으로 돌아갑니다.
