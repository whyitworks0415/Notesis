# Notesis 0.92.1 (232)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

## 바뀐 점

### 1. 노트가 늦게 뜨던 것 (A1 고침)
- 0.92.0은 카드 그림이 다 커진 **뒤에** 노트를 열어서, 노트가 약 0.3초 늦게 떴습니다.
- 이제는 카드를 누르는 순간 노트를 열고, 노트가 첫 화면을 만드는 동안 그 위에서 카드 모양이 화면 전체로 커집니다. 커지는 동안 노트가 함께 불러와지므로 늦어지지 않습니다. 커지는 시간도 조금 줄였습니다(0.28초).
- 커지는 동안에는 첫 화면이 노트 아래에 그대로 남아 있습니다.

### 2. 뒤로 밀기 미리보기 (Android 14 이상)
- 노트에서 뒤로 가는 제스처를 하면 노트가 손가락을 따라 조금 작아지며 모서리가 둥글어지고, 놓으면 카드로 돌아갑니다. 중간에 취소하면 원래대로 돌아옵니다.
- 앱 전체에 Android의 새 뒤로 가기 방식을 켰습니다. Android 13 이하는 예전처럼 동작합니다.

### 3. 새 노트는 + 버튼에서 (A3)
- + 버튼으로 새 노트를 만들면 + 버튼 자리에서 빈 종이가 자라나며 열립니다.

### 4. 폴더 열기 (A2)
- 폴더를 열면 안의 노트들이 누른 폴더 카드에서 펼쳐져 나옵니다. 위 폴더로 돌아갈 때는 가운데에서 펼쳐집니다.

### 5. 여러 노트 삭제도 되돌리기 (C2)
- 여러 노트를 골라 삭제하면 묻지 않고 휴지통으로 가고, 알약에 "되돌리기"가 나옵니다. 폴더가 함께 골라져 있으면, 폴더 안 노트를 어떻게 할지 골라야 해서 지금처럼 묻습니다.

### 6. 휴지통 비우기는 제자리에서 확인 (A5)
- 되돌릴 수 없는 휴지통 비우기는 여전히 묻지만, 대화상자를 하나 더 띄우지 않고 "Empty" 버튼이 옆으로 늘어나 "취소 / 노트 N개 완전히 삭제"가 됩니다. 5초 동안 안 누르면 접힙니다.

### 7. 메뉴 통일 (B1, C4)
- 아직 Material 기본 모양이던 메뉴 18곳(페이지 패널, 웹 패널, 레이어 등)도 누른 곳에서 자라나는 앱 메뉴로 바꿨습니다. 메뉴 위치가 버튼의 오른쪽 끝에 맞춰지는 것으로 조금 달라질 수 있습니다.

## 확인 방법

- 이 컨테이너에서 앱과 시험을 직접 빌드했고, 단위·Robolectric 시험 126개가 모두 통과했습니다.
- 새 시험: 노트를 바로 열고 첫 화면을 아래에 두는 규칙, 뒤로 밀기 크기, 제자리 확인(두 번째 누름에만 삭제).

## 하지 않은 것

- **기기에서는 시험하지 않았고, 움직임과 성능을 재지 않았습니다.**
- 노트를 먼저 열면서, 노트가 첫 화면을 만드는 동안 카드 그림이 잠깐 카드 크기로 멈춰 있을 수 있습니다(무거운 노트일수록 길게). 거슬리면 알려 주세요.
- 버튼 안 진행 표시(A8), 글자·간격·아이콘 크기 정리(B4~B7), 설정 검색(B9)은 아직입니다.
- Todo.md 4~6번(AI 첨부, 명령·터미널, 문서 편집)은 아직입니다.
