# Notesis 0.31.11 (versionCode 72)

화면 필기의 가장자리와 펜 시작 부분을 개선했습니다.

- 일반 펜과 압력 펜을 PDF 윤곽과 같은 채움 방식으로 그려 화면에서도 가장자리 안티앨리어싱을 적용합니다.
- 화면용 선 윤곽을 더 촘촘하게 생성해 곡선과 둥근 끝을 확대해도 매끄럽게 표시합니다.
- 펜을 대고 잠시 머무를 때 생기는 미세한 입력 흔들림을 제거해 간헐적으로 각지던 시작 부분을 완화합니다. 저장된 필기도 다시 열 때 같은 보정을 적용합니다.

JVM 단위 테스트와 Android 가상 기기의 필기, PDF 회귀 검사를 통과했습니다. 실제 S펜의 간헐적 입력과 기기별 필기 지연은 가상 기기에서 완전히 확인할 수 없습니다.
