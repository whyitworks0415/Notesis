# Notesis 0.50.0 (132)

## 처음 켰을 때: 환영 애니메이션
- 앱을 처음 켜면 약 4.4초짜리 환영 화면이 나옵니다.
  - 펜이 손글씨로 "Notesis"를 쓰고, 글자가 잉크로 채워집니다.
  - 아래에 손으로 그린 듯한 네모가 그려지고, 펜을 잠시 멈추면 링이 닫히면서 반듯한 네모로 바뀝니다. 앱의 "꾹 눌러 도형 만들기"를 그대로 보여줍니다.
  - 마지막에 화면 전체가 노트 목록의 "Welcome to Notesis" 안내 노트 카드 자리로 접혀 들어갑니다.
- 아무 곳이나 탭하거나 오른쪽 위 Skip을 누르면 바로 접히는 마지막 장면으로 넘어갑니다.
- 기기에서 애니메이션을 꺼 두었으면(애니메이터 배율 0) 환영 화면은 건너뜁니다.

## 처음 켰을 때: 튜토리얼
- 스킨 고르기: Material, Glassmorphism, Liquid glass 중 하나를 고르는 카드가 나옵니다. 고르는 즉시 뒤의 화면이 그 스킨으로 바뀌어서 보면서 고를 수 있습니다. 나중에 디스플레이 설정에서 언제든 바꿀 수 있습니다.
- 홈 화면 안내: 화면을 어둡게 하고 한 곳만 밝혀서 차례로 설명합니다.
  - 새 노트 버튼, 안내 노트, 검색, 디스플레이 설정, About & help 순서입니다.
  - 아무 곳이나 탭하거나 Next를 누르면 다음으로 넘어가고, Skip으로 끝낼 수 있습니다.
  - Liquid glass와 Glassmorphism에서는 밝은 부분이 다음 위치로 미끄러지고, Material에서는 바로 옮겨집니다.
- 노트 안 팁: 필기하다 보면 필요할 때 하나씩 아래쪽에 짧은 팁이 나옵니다.
  - 펜을 떼고 손을 잠시 멈췄을 때만 나오고, 펜이 다시 닿으면 바로 사라집니다. 필기 중에는 절대 나오지 않습니다.
  - 팁 사이에는 최소 40초 간격이 있고, 각 팁은 한 번만 나옵니다.
  - 순서: 펜 다시 탭하면 설정 → Functions 버튼 → 꾹 눌러 도형 → 확대·실행 취소 제스처. 마지막 페이지에서는 아래로 당겨 새 페이지 만들기 팁이 먼저 나옵니다.
  - Got it으로 닫거나, No more tips로 팁을 완전히 끌 수 있습니다.

## About & help
- "Show the tips again": 홈 화면 안내를 다시 보여주고 노트 팁도 처음부터 다시 나오게 합니다.
- "Play the welcome again": 환영 애니메이션을 다시 재생합니다(기기 애니메이션이 켜져 있을 때).
- 도움말의 도형 설명을 지금 동작에 맞게 고쳤습니다.

## 업데이트한 경우
- 이미 쓰고 있던 기기에서도 이번 업데이트 후 처음 홈 화면을 열면 환영 애니메이션과 튜토리얼이 한 번 나옵니다.
