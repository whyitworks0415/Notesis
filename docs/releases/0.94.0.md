## 바뀐 점

### 터미널 패널 (T1)

- **여는 곳**: 첫 화면 오른쪽 위 메뉴(설정과 더보기) → **Terminal**, 펜 노트의 빠른 동작 → **Terminal**. 다른 도구 패널처럼 누른 곳에서 자라나서 열리고, 닫으면 그 자리로 접힙니다.
- **`notesis` 명령이 Linux 없이 바로 돌아갑니다.** 앞의 `notesis`는 빼고 써도 됩니다.
  - 노트: `notes list`, `note read|rename|mv|tag|trash|restore`
  - 페이지: `page add|rm|mv`
  - 목차: `toc show|set|rm|clear`
  - 내용: `text add`, `ink add|erase`, `export`
  - 기타: `undo`, `help`
- **키 줄**: 화면 키보드에 없는 Tab, Ctrl, Esc, ← → ↑ ↓, Home, End와 명령에 자주 쓰는 `--`, `"`, `-`, `/`, `|`, `,`가 칩으로 있고, 입력줄 끝에 **Run** 버튼이 있습니다.
- **Tab 완성**: 명령, 그 다음 단어, `--옵션`, 노트 이름을 채웁니다. 이름에 공백이 있으면 따옴표를 붙입니다. 후보가 여럿이면 목록으로 보여 줍니다.
- **기록**: ↑ ↓로 실행했던 줄을 다시 부릅니다. `clear`, `history`, `exit`도 됩니다.
- **Ctrl 단축키**: Ctrl+C(줄 취소), L(화면 지우기), U·K(줄 앞·뒤 지우기), A·E(맨 앞·끝), D(빈 줄에서 닫기). 키 줄의 Ctrl을 누른 뒤 글자를 쳐도 됩니다.
- **묶음 실행과 되돌리기**: 여러 줄을 붙여 넣으면 한 묶음으로 실행되고, 하나가 실패하면 앞의 것까지 전부 되돌립니다. `undo` 한 번에 묶음 전체가 되돌아갑니다.
- 명령으로 노트가 바뀌면 첫 화면 목록이 바로 다시 읽힙니다.
- 패널을 닫았다 열어도 화면 내용, 기록, 되돌리기가 그대로 남습니다. 앱을 끄면 사라집니다.
- **안전 규칙은 그대로입니다.** 화면에 열려 있는 노트는 읽기만 되고(화면이 다시 덮어쓰기 때문), 삭제는 휴지통으로만 가고, 모든 변경은 되돌릴 수 있습니다.

## 확인 방법

- 이 컨테이너에서 앱과 시험을 직접 빌드했고, 단위·Robolectric 시험 782개가 모두 통과했습니다.
- 새 시험: Tab 완성(명령·옵션·노트 이름·따옴표), 기록 오르내리기, 결과 출력, 실제 노트 파일 위에서 패널에 명령을 쳐서 Tab으로 이름을 완성하고 실행한 뒤 `undo`로 되돌리기.
- 패널 화면은 시험 안에서 그림으로 찍어 다른 도구 패널과 같은 틀로 보이는 것을 확인했습니다.

## 하지 않은 것

- **태블릿에서는 써 보지 못했고, 아무것도 재지 않았습니다.** 특히 삼성 키보드에서 Enter가 실행으로 잘 먹는지, 키보드가 올라올 때 패널 높이가 자연스러운지는 기기에서만 알 수 있습니다.
- 결과는 JSON을 들여 쓴 그대로 나옵니다. 사람이 읽기 좋은 표 모양은 아닙니다.
- 변경 카드(무엇이 바뀌었는지 보여 주기)와 묻기/자동 설정(C2 나머지), 기기 안 MCP 연결(C3), Linux 환경(T2)은 아직입니다.
- `ink add`로 넣은 획은 기기에서 보지 못했습니다.

## 태블릿에서 해 볼 것

1. 첫 화면 오른쪽 위 메뉴에서 **Terminal**을 열고 `help`를 쳐 보세요.
2. `notes list`를 치고, `note read` 뒤에 노트 이름 앞부분을 쓰고 Tab을 눌러 보세요(한글 이름도).
3. `page add 노트이름`으로 페이지를 더하고 `undo`로 되돌려 보세요. 첫 화면 목록이 바로 갱신되는지도 봐 주세요.
4. 노트를 열어 둔 채 그 노트에 `page add`를 쳐서, 열린 노트는 안 바뀐다는 안내가 나오는지 보세요.
5. 키 줄의 Tab·Ctrl·화살표 칩과 Run 버튼이 손가락으로 누르기 편한지 봐 주세요.
