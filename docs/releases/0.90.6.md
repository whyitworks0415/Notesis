# Notesis 0.90.6 (197)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

0.90.5는 따로 내보내지 않고 이 버전에 함께 담았습니다.

## 카드 안 썸네일 모서리

- 노트·폴더 카드 안의 썸네일(페이지, 폴더 그림)이 바깥 유리 카드보다 모서리가 많이 덜 둥글었습니다(바깥 20dp, 안쪽 12dp).
- 안쪽은 바깥 카드에서 8dp 안으로 들어간 만큼 줄인 "동심 곡률"로 그리고 있었는데, 실제로는 둥근 카드 안에 각진 사각형이 박힌 것처럼 보였습니다.
- 이제 안쪽 썸네일도 바깥 카드와 같은 20dp로 둥급니다. 노트, 폴더, 스마트 폴더 모두 같습니다.

## 첫 화면 스크롤이 끊기던 문제

0.90.4에서 첫 화면 스크롤이 심하게 끊겼습니다. 원인은 두 가지였습니다.

1. **카드 유리:** 0.90.4에서 폴더·노트 카드를 유리로 바꾸면서, 카드마다 뒤 바탕을 흐리게 처리했습니다. 화면에 보이는 카드가 10~20장이면 스크롤하는 동안 매 프레임 그만큼 흐림 처리를 다시 했습니다.
   - **고친 것:** 카드 유리를 뒤를 들여다보지 않는 방식으로 바꿨습니다. 반투명한 몸체, 위에서 내려오는 은은한 광택, 테두리에 맺히는 빛을 직접 그립니다.
   - 첫 화면 바탕은 단색이거나 부드러운 그러데이션이라, 흐리게 하든 안 하든 거의 똑같이 보입니다. 그래서 겉모습은 거의 그대로이고 비용은 크게 줄었습니다.
   - 바탕을 **사진**으로 쓰신 경우에는 카드 뒤 사진이 흐려 보이지 않고 반투명하게 비칩니다.
   - 카드용으로 바탕을 따로 기록하던 것도 없앴습니다.
2. **위쪽 유리(검색창, 버튼):** 위쪽 유리에 비치게 하려고, 스크롤하는 매 프레임마다 첫 화면 전체를 다시 기록하고 있었습니다(0.90.3부터 검색창이 늘 유리가 되면서 더 눈에 띄었습니다).
   - **고친 것:** 스크롤하는 동안은 기록을 멈추고, 멈추면 한 번 다시 기록합니다. 노트 화면이 이미 쓰던 방식입니다.
   - 그래서 스크롤하는 동안 위쪽 유리에는 직전 모습이 비치고, 멈추면 바로 맞춰집니다.

## 노트 밖(화이트보드) 글씨가 이상하게 나오던 문제, 다시

0.90.4에서 고쳤다고 한 문제가 필기가 많은 노트에서 그대로 남아 있었습니다.

- **원인:** 페이지 안 글씨는 확대 정도에 맞춰 나중에 다시 다듬는 과정을 거칩니다. 노트 밖 글씨는 이 과정을 한 번도 거치지 않고, 처음 쓸 때 만들어진 모양을 그대로 썼습니다.
  - 필기가 많은 노트에서는 쓸 때 거친 모양으로 먼저 만들어 두기 때문에, 그 거친 모양과 외곽선을 칠하는 펜 방식이 겹쳐 빠른 낙서의 고리가 검게 칠해졌습니다.
- **고친 것:** 노트 밖 글씨는 그릴 때 원래 펜 입력에서 새로 만듭니다.
  - 지금 확대 정도에 맞는 정밀도로 만듭니다.
  - 불투명 잉크는 외곽선을 칠하지 않는 방식으로 만듭니다.
  - 확대 정도가 바뀌면 다시 만들고, 한 프레임에 최대 24획씩만 만들어 화면이 멈추지 않게 했습니다.
- 저장되는 글씨는 그대로이고, 화면에 그리는 방식만 바뀝니다.

## 확인한 것 / 못 한 것

- CI 빌드와 단위 테스트까지 확인했습니다.
- 기기에서 재지 못해서, 스크롤이 얼마나 부드러워졌는지는 말씀드릴 수 없습니다. 두 원인 모두 스크롤 중 매 프레임 하던 일이라 효과가 클 것으로 보지만, 확인은 기기에서 해야 합니다.

## 태블릿에서 해 볼 것

1. 첫 화면 카드의 바깥 모서리와 안쪽 썸네일 모서리의 둥근 정도가 같아 보이는지.
2. 노트가 많은 상태로 빠르게 위아래 스크롤 → 전보다 부드러운지.
3. 카드가 여전히 유리처럼 보이는지(반투명, 테두리 빛).
4. 스크롤을 멈춘 뒤 위쪽 검색창 유리에 바로 아래 카드가 제대로 비치는지.
5. 필기가 많은 노트에서 노트 밖(화이트보드)에 빠르게 꼬불꼬불 써 보기 → 검은 쐐기가 없는지. 확대·축소해도 깨끗한지.
