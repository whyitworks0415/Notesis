# Notesis 0.99.31 (272)

- 페이지·레이어·설정·AI 사이드바는 라이트·다크 테마의 불투명 배경을 씁니다. 폭 조절 손잡이 뒤도 같은 색입니다. 사이드바에서는 노트 배경을 흐리거나 굴절시키지 않습니다.
- 옆에 고정한 웹 패널에도 불투명 배경을 적용했습니다. 사이드바의 투명도 항목을 설정에서 정리했습니다.

릴리스 CI에서 APK 빌드, Android 호환성 검사, 단위 테스트와 스크린샷 테스트를 실행합니다. iOS 라이트·다크 모드의 사이드바가 뒤의 색을 비치지 않는지 확인하는 테스트를 추가했습니다. 실제 태블릿의 프레임 시간은 측정하지 않았습니다.

태블릿에서는 레이어 사이드바를 열고 연속 필기를, 페이지 사이드바를 열고 스크롤과 확대를 확인해 주세요.
