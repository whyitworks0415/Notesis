# Notesis 0.99.9 (250)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

글자 인식(OCR)을 다섯 가지로 늘렸고, 0.99.8 이후 검토에서 나온 개선을 함께 넣었습니다.

## 글자 인식 다섯 가지
올가미로 고른 뒤 **읽기**를 누르면 결과 창 위에 **"다른 방법으로 읽기"** 칩이 나옵니다. 칩을 누르면 같은 선택을 그 방법으로 다시 읽습니다. 마지막에 쓴 방법을 기억해 다음 선택도 그 방법으로 읽습니다.

1. **손글씨 획** (지금까지의 방식, 태블릿 안)
   - 펜으로 쓴 획을 쓴 순서대로 ML Kit 손글씨 인식기로 읽습니다. 손글씨에 가장 좋습니다.
2. **그림 속 글자** (새로 추가, 태블릿 안, 무료)
   - 선택한 부분을 그 아래의 PDF·그림과 함께 그림으로 그려서 ML Kit 글자 인식기(한국어·영어)로 읽습니다.
   - 인쇄된 글자, PDF 위의 글자, 붙인 사진 속 글자, 또박또박 쓴 손글씨에 좋습니다.
   - 모델은 Play 서비스가 처음 쓸 때 받아 옵니다. 그래서 앱이 커지지 않고, 처음 한 번은 "받는 중"이라고 나올 수 있습니다.
3. **둘 다 나란히** (새로 추가, 태블릿 안)
   - 1번과 2번으로 모두 읽고, 줄마다 두 결과를 함께 보여 줍니다. 칩으로 줄마다 나은 쪽을 고르면 됩니다.
4. **문서 스캔** (새로 추가, 태블릿 안, 무료)
   - 홈의 **+ → 문서 스캔**으로 카메라 문서 스캐너(ML Kit)를 엽니다. 자동으로 테두리를 잡고 원근을 맞춘 PDF가 새 노트가 됩니다.
   - 노트를 열기 전에 페이지마다 글자를 읽어 두기 때문에, **검색과 에이전트가 스캔 내용을 찾을 수 있습니다**.
   - 이미 있는 스캔 PDF 노트는 노트 설정 → 손글씨 인식 → **"스캔한 페이지의 글자 읽기"**로 같은 일을 할 수 있습니다. 글자가 이미 있는 페이지는 건드리지 않습니다.
5. **AI (Gemini, 무료 키)** (새로 추가)
   - 선택한 부분의 작은 그림을 **내 Google AI Studio 무료 API 키**로 Gemini에 보내 읽습니다. 고를 수 있는 형태는 **글자 / 수식(LaTeX) / 표(Markdown)** 세 가지입니다.
   - 토큰을 아끼는 방법:
     - 그림 해상도를 낮게 요청합니다. 기본값이 '토큰 최소'이고, 작거나 번진 글씨는 '균형'이나 '가장 정확'으로 올리면 됩니다.
     - 지시문을 한 문장으로 짧게 보냅니다.
     - 생각(thinking)은 최소로 합니다.
     - 답 길이에 상한을 둡니다.
     - 모델이 이 설정을 받지 않으면 설정을 빼고 한 번만 다시 묻습니다.
   - 결과 창에 **이번에 쓴 토큰(입력·출력)**이 표시됩니다.
   - 설정: 노트 설정 → **AI 글자 읽기**에서 키, 모델(기본 `gemini-flash-lite-latest`), 정밀도를 정합니다.
   - 키는 이 태블릿에만 저장됩니다. 기기 백업·기기 이전·앱 설정 내보내기에서 빠지고, 로그에 남지 않으며, 요청 주소가 아닌 헤더로 보냅니다.
   - **선택한 부분의 그림이 Google로 전송됩니다.** 키를 넣고 AI를 고르기 전에는 아무것도 보내지 않습니다.

## 함께 넣은 개선
- **손글씨 인식 라이브러리 업데이트 (18.1.0 → 19.0.0)**: 이전 라이브러리는 메모리 페이지가 16KB인 새 기기에서 불러오지 못할 수 있었습니다(4KB 정렬). 새 버전은 16KB 정렬입니다.
- **Android 기본 메모 앱 등록**: Android 14 이상에서 Notesis를 기본 메모 앱으로 고를 수 있고, 펜 버튼·작업 표시줄의 "새 메모"가 Notesis 새 노트를 엽니다.
  - 잠금 화면 위에서 바로 여는 것은 노트가 잠금 화면에 보일 수 있어서 넣지 않았습니다.
- **앱 아이콘 길게 누르기 → 새 노트** 바로가기를 추가했습니다.
- **계산기**: 괄호나 부호를 수천 개 겹쳐 넣으면 앱이 꺼질 수 있었습니다. 이제 200단계까지만 받고, 그 이상은 "너무 깊게 겹쳐 있다"고 알립니다.
- **손떨림 보정(슬라이딩 창)**: 펜 점마다 창 전체를 다시 더하던 것을 누적 합으로 바꿨습니다. 결과는 같고 계산이 일정합니다.
- **숨은 웹 AI 창**: 노트를 바꿔도 유지하는 브라우저가 숨은 채 최대 10분 머물던 것을 3분으로 줄였습니다.

## 어떻게 확인했나
- 빌드, 축소(R8)를 거친 릴리스 빌드, 네이티브 커널 점검, 전체 단위 테스트(143개 클래스)를 통과했습니다.
- 새 OCR 코드의 순수 부분은 테스트를 추가했습니다.
  - AI 요청 내용(저해상도·생각 최소·답 상한, 거절 시 빼는 항목)
  - 답 읽기(생각 부분 제외, 토큰 수, 오류)
  - 그림 크기 줄이기, 모델 이름 검사
  - "둘 다" 합치기, 계산기 깊이 제한

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 직접 써 보지 않았습니다.** 카메라 스캐너, Play 서비스 모델 받기, 그림 속 글자 인식, 기본 메모 앱 등록, 바로가기 모두 기기에서 확인이 필요합니다.
- **AI 읽기는 실제 키로 요청해 보지 않았습니다.** 기본 모델 이름(`gemini-flash-lite-latest`)과 무료 사용 한도는 Google이 정하고 바뀔 수 있습니다. 모델 이름이 맞지 않으면 설정에서 바꿔 넣으면 됩니다.
- 그림 해상도 단계별로 토큰이 얼마나 드는지는 측정하지 않았습니다. 실제 사용량은 결과 창의 토큰 표시로 확인하세요.
- **APK가 25.3MB에서 28.7MB로 커졌습니다.** 대부분 새 손글씨 인식 라이브러리 때문입니다.
- 검토에서 나온 전체 작업·메모리 예산 통합, 노트 버전 기록, 페이지 파일 체크섬, PDF 글자 선택은 이번에 하지 않았습니다.

## 태블릿에서 해 볼 것
1. 손글씨를 올가미로 골라 **읽기** → "다른 방법으로 읽기"에서 **그림 속 글자**, **둘 다 나란히**를 차례로 눌러 보기.
2. PDF 위 인쇄된 글자 근처를 올가미로 골라 **그림 속 글자**로 읽기.
3. 홈 **+ → 문서 스캔**으로 종이 한 장 찍기 → 새 노트가 열리는지, 노트 검색에 그 종이의 단어가 걸리는지.
4. 노트 설정 → **AI 글자 읽기**에 키를 넣고 수식을 손으로 쓴 뒤 **AI → 수식(LaTeX)**. 결과 창의 토큰 표시 확인.
5. 설정 → 애플리케이션 → 기본 앱 → **메모 앱**에 Notesis가 나오는지, 고른 뒤 S Pen 버튼·작업 표시줄의 새 메모가 Notesis를 여는지.
6. 앱 아이콘 길게 누르기 → **새 노트**.
