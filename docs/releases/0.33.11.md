# Notesis 0.33.11

- 펜·필압 펜·연필의 진행 방향을 추적하고 수직 방향의 작은 흔들림을 따로 줄여, 빠른 필기와 연속 고리가 매끈하게 이어지도록 개선했습니다.
- 작은 흔들림을 모서리로 잘못 판단하지 않도록 변경했습니다. 실제 급회전·되돌림과 펜을 떼는 지점은 빠르게 따라갑니다.
- 획 보정을 따로 지정하지 않은 경우 기본값을 20%로 적용합니다. 기존에 직접 지정한 값과 0%의 원본 입력 모드는 유지됩니다.
- 빠른 얇은 획의 흔들림·지연, 작은 원의 반지름과 끝점, 기존 모서리·필압·접촉 회귀 테스트로 검증했습니다.
