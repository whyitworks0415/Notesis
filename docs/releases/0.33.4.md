# Notesis 0.33.4

- 연속 필기에서 새 획마다 페이지 전체 비트맵을 재생성하던 비용을 줄였습니다. 기존 그림은 재사용하고 추가된 획은 즉시 표시하며, 전체 캐시는 필기가 700ms 동안 멈춘 뒤 갱신합니다.
- 새 펜 입력이 시작되면 진행 중인 캐시 작업을 중단하여 필기 렌더링과의 경쟁을 줄였습니다. 실행 취소·지우기·획 이동·메시 교체 때는 캐시를 검증하여 이전 그림이 남지 않도록 했습니다.
- 성능 디버그 표시의 500ms 갱신이 노트 화면 전체를 재계산하던 경로를 분리했습니다. 표시 내용과 위치는 유지합니다.
- 확대된 줄·격자·점 배경은 화면에 보이는 부분만 그립니다. 배경의 간격과 정렬은 유지합니다.
- 유리 UI 애니메이션의 임시 목록 할당을 제거했습니다. 기존 움직임 계산과 UI 형태·제스처·필기 설정은 유지합니다.
- 확대·스크롤 중 새로 보이는 페이지의 필기 로딩과 PDF 고해상도 캐시 재사용을 개선했습니다.
- 형광펜의 multiply 합성을 보존하도록 페이지 비트맵 캐시 조건을 보완했습니다.

검증: 단위 테스트 119개 통과, debug/release APK 빌드 성공, lint 오류 0개(기존 경고 59개 및 hint 1개). 유리 애니메이션 계산을 기존 결과와 2,000개 sample에서 비교했습니다.

실제 태블릿의 지연(ms) 감소량·온도·GPU 표시 결과는 연결된 기기가 없어 아직 측정하지 않았습니다. 같은 페이지·배율·펜·주사율에서의 실기기 비교 절차는 `docs/performance-continuous-ink.md`에 정리했습니다.
