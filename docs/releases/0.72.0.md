# Notesis 0.72.0 (159)

## Markdown → PDF를 GitHub에서 보이는 모양 그대로
이전에는 Markdown을 일반 문서 보기 화면 그대로 PDF로 옮겨서, 실제 Markdown 모양과 달랐습니다. 이번에는 GitHub에서 널리 쓰이는 md→pdf 도구들과 같은 오픈소스 구성으로 페이지를 새로 그립니다. 모두 앱 안에 들어 있어 인터넷 없이 동작합니다.

- **marked** (MIT): Markdown 해석, GitHub 방식(GFM: 표, 할 일, 취소선, 자동 링크) 포함
- **github-markdown-css** (MIT): GitHub의 README와 같은 글꼴, 제목 밑줄, 표, 인용, 코드 블록 모양
- **highlight.js** (BSD-3): 코드 블록 문법 색칠(GitHub 색)
- **KaTeX** (MIT): `$수식$`, `$$수식$$`
- 라이선스 전문은 `assets/viewer/md/THIRD_PARTY_NOTICES.txt`에 있습니다.

Obsidian 문법도 PDF에 반영됩니다.
- `[[링크]]`, `[[이름|별칭]]`
- `==하이라이트==`, `#태그`
- `> [!note]` 같은 콜아웃
- `%%주석%%`(PDF에서는 빠짐)
- 맨 위 속성(front matter)은 PDF에서 빠짐

## 페이지마다 어디까지 담을지 직접 편집
PDF 레이아웃 화면이 실제 종이 크기의 페이지로 나뉘어 보이고, 보이는 그대로 PDF가 됩니다.

- **블록을 탭**하면 그 블록부터 새 페이지가 시작됩니다.
- **페이지의 첫 블록을 탭**하면 그 블록을 앞 페이지로 끌어올립니다.
  - 앞 페이지는 들어갈 만큼 글자가 줄어듭니다. 최소 45%까지 줄어듭니다.
- 같은 블록을 다시 탭하면 되돌아갑니다.
- **Reset pages**를 누르면 손으로 바꾼 나눔이 모두 처음대로 돌아갑니다.
- 종이(A4/Letter/A5), 가로/세로, 글자 크기(A−/A+), 여백을 바꾸면 바로 다시 나뉩니다.

자동으로 나눌 때 내용이 잘리지 않게 했습니다.
- 페이지에 다 들어가지 않는 **코드 블록**은 줄 단위로 나뉩니다.
- 긴 **표**는 행 단위로 나뉘고, 다음 페이지에도 머리 행이 다시 붙습니다.
- **목록**은 항목 단위로, 긴 **문단**은 단어 사이에서 나뉩니다.
- **제목**이 페이지 맨 아래에 혼자 남지 않고, 아래 내용과 함께 다음 페이지로 갑니다.
- 아래에 페이지 번호가 붙습니다.

## Markdown 노트에서 바로 PDF
- Markdown 노트(라이브러리 노트, 볼트 파일 모두) 위쪽에 **PDF** 버튼이 생겼습니다. 누르면 지금 내용으로 곧바로 PDF 레이아웃 화면이 열립니다.
- 미리보기에 **Save PDF**가 생겼습니다. 노트로 만들지 않고 PDF 파일로 원하는 곳에 저장할 수 있습니다. 다른 문서 형식의 미리보기에도 있습니다.

## 기기에서 확인할 것
- 표, 코드, 수식, 콜아웃, 할 일이 섞인 `.md`를 Convert to PDF → GitHub 모양으로 보이는지, 미리보기 PDF가 화면과 같은지
- 블록 탭으로 새 페이지 시작, 첫 블록 탭으로 앞 페이지로 끌어올리기(글자 축소), 다시 탭해서 되돌리기, Reset pages
- 긴 코드/표가 페이지에 걸칠 때 잘리지 않고 나뉘는지(표 머리 행 반복)
- 종이/방향/글자 크기/여백 변경 시 다시 나뉘는지
- Markdown 노트의 PDF 버튼 → 뒤로 가기/Cancel이 노트로 바로 돌아오는지
- Save PDF로 저장한 파일이 다른 앱에서 열리는지
- 일부 기기에서 시스템 인쇄 화면으로 넘어가는 경우, 그 화면의 미리보기가 같은 페이지 나눔인지
