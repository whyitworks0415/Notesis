# Notesis 0.31.8

60Hz 화면에서 펜촉과 wet ink가 더 가깝게 보이도록 예측 경로를 다듬었습니다.

- 예측은 세 개의 안정적인 이동 벡터가 확인된 뒤 시작합니다.
- 저속에서는 예측을 끄고, 속도와 방향 변화에 따라 4/6/9ms 범위에서 자동 조절합니다.
- 자동 모드는 60Hz에서 최대 9ms, 90Hz 이상에서 최대 6ms를 사용합니다.
- 펜 설정에서 자동/4/6/9ms를 선택해 같은 기기에서 직접 비교할 수 있습니다.
- 급회전 뒤에는 새 방향이 안정될 때까지 예측을 중단합니다.
- 빠른 필기의 마지막 예측 구간에만 24ms 이하의 짧고 반투명한 soft head를 표시합니다.
- soft head는 별도 overlay이며 blur를 사용하지 않고 저장되는 stroke에 포함되지 않습니다.
- AndroidX Ink의 front-buffer wet-ink 경로는 eager initialization을 유지하며 deprecated high-latency helper를 강제하지 않습니다.

단위 테스트로 안정 벡터 gate, 저속 억제, corner 복구, 4/6/9ms 상한 및 60/120Hz 자동 선택을 검증했습니다. 릴리스 빌드 머신에는 Android 기기가 연결되어 있지 않아 실제 input-to-display 수치는 포함하지 않았으며, 앱의 latency HUD에서 같은 조건으로 비교할 수 있습니다.
