# Notesis 0.62.1 (148)

## AI(웹) 패널 옆의 흰 띠 제거
- 노트 옆에 붙은 웹 패널과 노트 사이에 있던 흰 세로 띠를 없앴습니다. 이제 웹 패널이 노트 바로 옆에 붙습니다.
- 크기를 조절하는 회색 작은 막대는 그대로 있고, 웹 패널의 왼쪽 가장자리 위로 옮겼습니다. 지금처럼 좌우로 끌면 패널 폭이 바뀝니다.
- 웹 패널이 위, 오른쪽, 아래로 떨어져 있던 여백을 없애고 화면 끝까지 채웁니다. 화면 끝에 닿으므로 모서리는 각지게 했습니다.
- 팝업으로 띄운 웹 창은 지금처럼 둥근 모서리의 떠 있는 창입니다.
