# Notesis 0.67.0 (154)

## 페이지에 첨부하기 (주석 · 연습장 페이지)
- 페이지에 다음 세 가지를 붙일 수 있습니다.
  - **Practice page**: 이 페이지 옆에서 풀어 볼 빈 연습장 페이지를 새 노트("Practice · 노트이름 p.N")로 만들어 붙입니다.
  - **A page of another note**: 이미 있는 다른 노트의 원하는 페이지를 붙입니다.
  - **Comment or link**: 짧은 메모(포스트잇)와, 필요하면 웹 주소를 붙입니다.
- 붙이는 방법은 두 가지입니다.
  - 페이지 패널(Pages 탭)에서 페이지를 길게 눌러 "Attach…"를 고릅니다.
  - 페이지를 길게 눌러 나오는 메뉴(길게 누르기 메뉴를 켠 경우)에서 "Attach to this page…"를 고릅니다.
- 붙인 것은 페이지 오른쪽 가장자리에 탭으로 보입니다. 페이지는 주황색, 주석은 파란색이고, 확대·축소해도 화면에서 같은 크기로 보입니다.
- 탭을 펜이나 손가락으로 누르면 열립니다.
  - 페이지(연습장·다른 노트)는 노트 위 팝업 창(세 손가락으로 여는 그 창)에서 열려 바로 필기할 수 있습니다. 분할 화면 중이면 두 번째 칸에서 열립니다.
  - 주석은 카드로 열립니다. 링크 열기, 수정, 삭제, 이 페이지의 탭 숨기기를 할 수 있습니다.
- 숨기기: 주석 카드의 "Hide tabs", 또는 페이지 패널 메뉴의 "Hide attachment tabs"로 탭을 숨깁니다. 붙인 것은 그대로 남고, 같은 메뉴의 "Show attachment tabs"로 다시 보입니다. 페이지 패널의 미리보기에는 첨부가 있는 페이지 오른쪽에 작은 주황색 표시가 붙습니다(숨긴 경우 흐리게).
- 첨부는 노트와 함께 저장되고, 페이지를 복제하거나 회전·옮겨도 따라갑니다.

## 전체(1/4) 툴바에도 Scale 적용
- Appearance 설정의 Scale(기본 90%)이 2/4~4/4 툴바뿐 아니라 1/4 전체 툴바에도 적용됩니다. 작은 태블릿에서 툴바가 크게 보이던 문제에 대한 조정입니다.
