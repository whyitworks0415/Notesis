# Notesis 0.33.8

- 읽기 모드에서 S펜 지우개 버튼을 누른 채 드래그하면, 시작점과 끝점을 대각선 꼭짓점으로 하는 사각형 영역을 캡처합니다.
- 읽기 모드에서 S펜 지우개 버튼을 누른 채 PDF 글자를 두 번 터치하면, 같은 페이지의 첫 터치 지점부터 두 번째 터치 지점까지 텍스트가 선택됩니다. 두 터치 사이에는 시간 제한이 없습니다.
- 읽기 모드에서는 S펜 버튼을 눌러도 지우개 커서가 표시되지 않습니다. 작은 펜 흔들림은 터치로 처리하며, 드래그·취소·모드 변경 시 기억한 텍스트 선택 지점을 초기화합니다.

검증: 단위 테스트 및 디버그 APK 빌드 통과. 실제 S펜 기기에서의 동작은 아직 확인하지 않았습니다.
