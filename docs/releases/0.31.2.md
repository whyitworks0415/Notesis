# Notesis 0.31.2 (versionCode 63)

태블릿에 설치할 서명 APK는 아래 Assets에서 받으세요.

## 성능 기준선 계측

- 상단의 속도계 아이콘을 켜면 새 측정 세션이 시작됩니다.
- stylus 입력부터 wet ink draw/presentation 경계까지의 지연을 p50/p95/p99로 표시합니다.
- pen-up부터 stroke commit과 편집 알림 완료까지의 시간을 p50/p95/p99로 표시합니다.
- mesh/refine, PDF page render, 일반 page draw, 화면에 500획 이상 보이는 dense draw 시간을 각각 분리해 표시합니다.
- 입력 샘플률, 실제 frame period, prediction lead, 프로세스 allocation rate와 GC 횟수를 함께 표시합니다.
- 진단 중 Perfetto trace에는 stylus DOWN/MOVE/UP, mesh/refine, PDF render 구간이 기록됩니다.
- 진단 패널을 끄면 고정 크기 버퍼 기록과 trace/런타임 샘플링이 중단됩니다. 저장 포맷과 필기 결과는 바뀌지 않았습니다.

## 발견된 우선 병목 후보

1. pen-up callback에서 시작점 보정과 전체 획 smoothing이 연속으로 새 stroke를 만드는 경로
2. dense page cache miss와 highlighter 2-pass draw
3. refine 중 stroke 전체 재생성, identity map 구성, UI thread 교체 및 undo history remap
4. prediction 사용 시 MOVE마다 만들어지는 recyclable `MotionEvent`
5. dense page eraser MOVE마다 생성되는 candidate filter collection
6. 직렬·비중단 native PDF render와 대형 bitmap 할당

실기기가 연결되지 않은 환경에서 구현했으므로 위 항목은 코드 감사로 찾은 측정 대상이며, 기기별 수치 결론은 아래 절차로 수집해야 합니다.

## 태블릿 테스트 체크리스트

각 항목을 시작하기 전에 속도계 아이콘을 껐다 켜서 측정 창을 초기화하고, 30초간 실행한 뒤 화면을 캡처해 주세요.

- [ ] 빈 노트에 보통 속도로 연속 필기: `wet ink`, `pen-up 확정`, `input`, `frame`, `allocation/GC`
- [ ] 빈 노트에 빠른 짧은 획 50개: `pen-up 확정` p95/p99와 획 누락 여부
- [ ] 500획 페이지에서 필기·pan·zoom: `dense draw`, `frame`, GC
- [ ] 1,000~2,000획 페이지에서 빠른 pan/zoom: `dense draw` p95/p99와 화면 끊김
- [ ] 최대 zoom 후 1초 정지: `mesh/refine` p95/p99와 최종 선명도
- [ ] PDF를 한 페이지씩 20장 이동: `PDF render`와 최근 MP(pixel count)
- [ ] 긴 PDF에서 100페이지 빠르게 이동 후 정지: 도착 페이지 우선 표시 여부와 PDF p99
- [ ] dense page에서 지우개를 30초 연속 사용: allocation MB/s, GC 증가, 입력 끊김
- [ ] dense page에서 lasso를 30초 연속 사용: allocation MB/s, GC 증가, 선택 정확도
- [ ] 속도계 아이콘을 끈 상태로 같은 필기 반복: 필기 결과·저장·undo/redo 회귀 없음
- [ ] 앱을 background로 보냈다가 복귀: 측정 패널과 노트 내용 정상, crash 없음

가능하면 같은 화면에서 세 번 반복해 p50보다 p95/p99 재현성을 우선 확인해 주세요. PDF 시간은 `최근 MP`가 비슷한 표본끼리 비교해야 합니다.

## 검증

- JVM unit test로 p50/p95/p99 계산, dense-page 분류, 세션 reset, 진단 비활성 시 무수집을 검증했습니다.
- `testDebugUnitTest`, `lintDebug`, debug APK 및 서명 release APK 빌드를 실행했습니다.
- 연결된 Android 기기가 없어 instrumentation과 실기기 성능 수치 수집은 이번 릴리스에 포함되지 않았습니다.
