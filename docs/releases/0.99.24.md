# Notesis 0.99.24 (265)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 유리에 필기와 지우기가 늦게 비치던 것
- 0.99.23은 펜을 쉰 뒤(0.7초)에야 유리에 새 필기를 비췄습니다. 이제 기본으로 **획을 끝내고 펜을 떼는 순간** 한 번 비춥니다. 지우개도 같습니다. 펜을 대고 있는 동안에는 지금처럼 유리를 다시 그리지 않습니다.
- 지우개는 펜을 뗄 때 페이지를 다시 그리지 않는 경우가 있어서, 유리가 페이지를 보고 있을 때만 펜을 뗄 때 페이지를 한 번 더 그리게 했습니다.
- **새 설정: 설정 → 모양 → Glass → 유리에 새 필기 반영**
  - **쓰는 동안:** 펜이 바꿀 때마다 유리도 바로 바뀝니다. 0.99.22까지의 방식으로, 가장 무겁습니다.
  - **획마다 (기본):** 펜을 뗄 때 한 번 바뀝니다.
  - **잠시 멈춘 뒤:** 펜을 쉰 뒤에 바뀝니다. 0.99.23의 방식으로, 가장 가볍습니다.

## iOS 유리의 모든 요소를 켜고 끌 수 있습니다
**설정 → 모양 → Glass**(iOS 스타일)에 **구성 요소**가 생겼습니다. 끈 요소는 값을 0으로 그리는 게 아니라 아예 그리지 않으므로 그만큼 가벼워집니다. 모두 켜면 지금까지의 iOS 유리입니다.

| 요소 | 무엇 | 끄면 |
|---|---|---|
| 맑은 층 | 서리 아래 흐리지 않은 페이지를 렌즈로 비춤 | 페이지가 그대로 비치고, 면마다 렌즈 계산 1번 줄어듦 |
| 서리 층 | 흐린 서리 | 두 층 모두 끄면 페이지를 보지 않는 반투명 면(가장 가벼움) |
| 렌즈 | 테두리 굴절 셰이더 | 층이 단순 블러가 됨(채도는 색 필터로 유지) |
| 채도 | 색을 선명하게 | — |
| 가장자리 흡수 | 가장자리로 갈수록 어두워짐 | — |
| 테두리 빛 | 테두리에 맺히는 빛 | — |
| 테두리 그늘 | 테두리 안쪽 가는 선 | — |
| 그림자 | 면 그림자 | — |
| 유리 색 | 위에 덮는 옅은 색 | 글자가 읽기 어려울 수 있음 |
| 유리 버튼 | 따로 떠 있는 둥근 버튼의 유리 | 불투명 버튼 |
| 유리 슬라이더와 스위치 | 누르면 렌즈가 되는 컨트롤 | 일반 컨트롤 |
| 유리 시계 | 떠 있는 시계의 유리 | 불투명 |

- 이미 있던 것: 연속 곡률 모서리(Smooth corners), 누름·선택·열림 움직임(Motion), Efficient glass, Light mode, 스크롤할 때 유리도 따라가기.
- 렉이 있으면 **맑은 층, 렌즈, 유리 버튼**부터 꺼 보세요. 코드상 이 셋이 가장 무겁습니다.
- "기본값으로" 버튼과 프리셋 버튼은 구성 요소 선택을 그대로 둡니다. 구성 요소 아래 **모든 요소 켜기**로 되돌립니다.

## 어떻게 확인했나
- CI의 릴리스 빌드, Lint, 단위 테스트, 스크린샷 테스트로 확인합니다. 새 테스트는 요소 설정의 저장과 복원, iOS에서만 적용되는지, 필기 반영 시점 규칙입니다.
- **태블릿에서 확인하지 못했습니다. 요소별로 얼마나 가벼워지는지는 측정하지 않았습니다.**

## 태블릿에서 해 볼 것
1. 툴바 아래에서 쓰고 펜 떼기 → 바로 유리에 비치는지. 지우개도 같은지.
2. "쓰는 동안"으로 바꾸고 → 쓰는 중에도 비치는지, 대신 무거워지는지.
3. 구성 요소를 하나씩 끄면서 → 팝업과 펜이 어떻게 달라지는지, 모양이 어떻게 바뀌는지.
4. 맑은 층과 서리 층을 모두 끄기 → 유리가 단순한 반투명 면이 되는지.
