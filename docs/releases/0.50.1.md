# Notesis 0.50.1 (133)

## 선택창 UI 통일
펜 설정창과 같은 패널 하나로 도구·선택 창을 모았습니다. 누른 곳에서 나오고 그곳으로 들어가는 애니메이션, 툴바와 같은 재질과 모서리, 제목 줄, 구역 제목, 간격, 스위치 모양이 모두 같습니다.

- 도형 선택창: 예전에는 일반 대화상자였는데, 이제 펜 설정과 같은 패널입니다.
  - 도형 칸의 모서리가 패널 곡률에 맞춰 동심으로 둥글어집니다.
  - Shape, Pen, Corners 구역 제목과 스위치가 펜 설정창과 같은 모양입니다.
  - 도형을 고르면 패널이 접혀 들어간 뒤 그 도형으로 바뀝니다.
- UI(스킨) 선택창: 툴바의 Look 버튼이 드롭다운 대신 같은 패널을 엽니다.
  - 첫 실행 스킨 선택과 똑같은 목록(미리보기, 이름, 설명, 라디오 버튼)입니다.
  - 고르면 뒤의 툴바가 바로 바뀌어서 보면서 고를 수 있습니다.
- 디스플레이 설정의 UI style도 칩 대신 같은 미리보기 타일 세 개로 바꿨습니다.
- 스킨 이름 통일: 어떤 화면에서는 "Frosted glass", 다른 화면에서는 "Glassmorphism"으로 나오던 것을 모든 곳에서 Glassmorphism으로 맞췄습니다.

## AI 패널
- 상단 버튼이 노트 툴바와 같은 아이콘 버튼입니다. 아이콘 스타일 설정(Reicons/AnimateIcons)도 따릅니다.
- 주소창이 홈 화면 검색창과 같은 모양(돋보기 아이콘)입니다.
- 패널 안에서 바로 AI를 고를 수 있는 칩 줄을 넣었습니다: Web, Gemini, Claude, ChatGPT, Grok, Perplexity, Cerebras. 펜 설정창의 칩과 같은 모양이고, 지금 열린 사이트가 선택돼 보입니다.
- 자주 안 쓰는 버튼(데스크톱/모바일 사이트, 브라우저로 열기, 오류 로그)은 ⋮ 메뉴 하나로 모았습니다. 오류가 기록되면 ⋮ 버튼이 빨갛게 표시됩니다.
