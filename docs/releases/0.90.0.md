# Notesis 0.90.0 (191)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

이번 버전은 정리(제거한 기능의 흔적, 이름 통일), 성능, 기능 보완, 새 기능을 한꺼번에 담았습니다. 모두 **기기에서는 확인하지 못했고**, 빌드와 단위 테스트까지만 확인했습니다.

## 1. 정리

**제거한 기능의 흔적을 없앴습니다**
- **자·삼각자·각도기:** 화면에서 열 방법이 없어진 지 오래였는데 코드가 남아 있었습니다. `Ruler.kt`와 그 테스트, 캔버스의 자 따라 긋기 경로, 자 설정 창을 지웠습니다.
- **레이저 포인터:** 펜 버튼 포인터 코드, 색, "자국 남김" 설정을 지웠습니다. 읽기 모드에서 탭하면 남는 동그라미를 그리던 부분은 그대로 쓰므로 `GestureTrailView`로 이름만 바꿨습니다.
- **Claude 손글씨 읽기, 에이전트 기능:** 남아 있던 번역 문구와 에이전트 설계 문서를 지웠습니다. 비교 조사 문서(todo.md)에는 "제거됨"으로 표시했습니다.

**코드의 이름을 앱에서 부르는 이름으로 통일했습니다**
- `SpotiGlass*`/`Spoti*`(처음 포팅한 원본 프로젝트의 이름)를 `LiquidGlass*`/`Glass*`로 바꿨습니다. 파일, 셰이더 에셋 폴더, 생성 스크립트, 문서까지 함께 바꿨습니다.
- `Skin.SPOTIGLASS`는 `Skin.LIQUID_GLASS`가 됐습니다. 예전 이름으로 저장된 설정도 그대로 읽습니다.
- 저장된 설정 키(`spotiglassClarity` 등)는 일부러 그대로 두었습니다. 바꾸면 기존 모양 설정이 사라지기 때문입니다.
- 첫 화면 함수 `NoteListScreen`은 `HomeScreen`이 됐습니다.

## 2. 성능

- **화면을 두 번 그리지 않습니다:** Android 11 이하에서는 유리 효과를 그릴 수 없으므로, 가벼운 모드를 꺼도 화면 기록을 하지 않습니다.
- **느려지면 먼저 물어봅니다:** 앱이 그리는 프레임을 지켜보다가 4분의 1 이상이 늦거나 기기가 뜨거워지면 "가벼운 모드를 켤까요?"라고 **한 번만** 묻습니다. 화면이 멈춰 있을 때는 아무 일도 하지 않습니다.
- **처음 실행이 빨라지도록:** Baseline Profile과 profileinstaller를 넣었습니다. GitHub에서 설치한 앱도 앱 코드를 미리 컴파일해 둡니다.
- **첫 화면 목록:** 바뀌지 않은 노트는 `meta.json`을 다시 읽지 않습니다.
- **검색:**
  - 정정합니다. 지난 답변에서 검색이 매번 디스크에서 색인을 읽는다고 말씀드렸는데, 실제로는 이미 SQLite 색인을 쓰고 있었습니다.
  - 실제로 남아 있던 비용은 매 검색마다 Markdown 노트 전체를 읽는 것이었습니다. 이제 Markdown 본문도 같은 색인에 들어갑니다.
- **Markdown 카드:** 썸네일용 앞부분을 저장할 때 따로 만들어 두고 카드는 그것만 읽습니다.
- **Vault:** 지난번 목록을 바로 보여 주고, 새로 훑은 결과로 뒤에서 바꿉니다.
- **PDF 캐시:** Android 12 이하이고 메모리 7GB 미만인 기기는 상한을 192MB로 낮췄습니다. 화면이 커도 화면 3장 분량보다 작아지지는 않습니다.
- **진단 보고서:** 백그라운드에서 메모리를 얼마나 돌려줬는지와 가벼운 모드 상태가 함께 나옵니다.
- **큰 파일 나누기:** `MainActivity.kt`에서 Internet 패널(`WebPanel.kt`)과 페이지 패널(`PageSidebar.kt`)을 떼어 냈습니다(약 1만 600줄 → 9천 줄).
- **기기 없이 화면 확인:** 검색창, 종이 고르기, 섹션 제목을 Robolectric/Roborazzi로 그려 보는 스크린샷 테스트를 넣었습니다. CI의 확인용 빌드에서만 돌고 그림을 3일 보관합니다.

## 3. 기능 보완

- **폴더:**
  - 이름을 바꾸면 색과 썸네일이 따라갑니다. 지우면 함께 지워집니다.
  - **노트 이동** 창에서 폴더를 트리로 고릅니다. 고른 폴더 안에 새 폴더를 바로 만들 수도 있습니다.
  - 폴더 안의 폴더에 있으면 제목에 `학교 › 수학`처럼 경로가 보입니다.
- **끌어서 옮기기:** 선택 모드에서 이미 선택한 노트를 길게 눌러 끌고 폴더 카드 위에 놓으면 그 폴더로 옮겨집니다.
- **템플릿:**
  - 카드를 길게 누르면 이름 바꾸기, 앞으로, 뒤로 보내기, 삭제를 할 수 있습니다.
  - **PDF 첫 페이지를 템플릿으로** 추가할 수 있습니다.
  - 노트마다 마지막으로 고른 종이를 기억해, 다음에 그 노트에 페이지를 추가할 때 먼저 보여 줍니다.
- **Vault:** "최신순"과 "폴더별"로 볼 수 있습니다. 첫 화면 검색에 Vault 파일도 이름과 폴더로 걸립니다.
- **업데이트:**
  - GitHub의 프리릴리스도 테스트 빌드로 취급합니다.
  - 자동 업데이트는 Wi-Fi처럼 데이터 요금이 없는 연결에서 알리기 전에 미리 받아 둡니다. 그래서 바로 "설치"를 누를 수 있습니다.
- **번역:** 아이콘 설명(화면 낭독기용)도 한국어로 번역됩니다.

## 4. 새 기능

- **자동 백업(기본값 꺼짐):** 백업 버튼 → **자동 백업…**에서 켭니다.
  - **이 태블릿에:** 최근 5개를 보관합니다. 앱을 지우면 함께 지워지므로, 이것만으로는 태블릿을 잃어버렸을 때 대비가 되지 않습니다.
  - **폴더에:** 태블릿의 폴더나, 폴더를 보여 주는 클라우드 앱(OneDrive, Dropbox 등)에 매번 새 파일로 저장하고 최근 5개를 남깁니다.
  - **Google 드라이브 파일 하나:** 드라이브에 파일 하나를 만들어 매번 덮어씁니다. Android에서는 앱이 드라이브 "폴더"에 계속 쓸 수 없고, 고른 "파일"에만 계속 쓸 수 있기 때문입니다.
  - 매일 또는 매주로 고를 수 있고, 배터리가 충분할 때 시스템이 깨워서 백업합니다. 꺼 두면 예약 자체를 하지 않습니다.
- **펜이 없는 태블릿:** 처음 설치할 때 S5e처럼 펜이 없으면 한 손가락으로 쓰고 두 손가락으로 화면을 옮기도록 기본값을 정합니다.
- **홈 화면 위젯:** 새 노트 버튼과 최근 노트 3개가 나오고, 누르면 바로 열립니다. 잠긴 노트는 이름도 보이지 않습니다.
- **스마트 폴더:** 첫 화면 ⋯ 메뉴 → **새 스마트 폴더**에서 만듭니다.
  - 태그, 기간(7일/30일), 즐겨찾기, 종류로 노트가 저절로 모입니다.
  - 노트를 옮기지 않고 모아서 보여 주기만 하며, 보라색 ✦ 카드로 보입니다.
- **손글씨를 텍스트 상자로:** 손글씨 인식 결과 창에 **텍스트 상자로 추가**가 생겼습니다. 손글씨는 그대로 두고 그 아래에 텍스트 상자를 놓습니다.
- **손글씨 노트를 Markdown으로 내보내기:** 페이지마다 인식한 손글씨, 텍스트 상자, PDF 글자를 모아 `.md`로 저장합니다. 아직 인식하지 않은 페이지는 비어 있다고 적힙니다.

## CI

- **확인용 빌드:** CI에 `update: check` 모드를 넣었습니다. 빌드와 테스트만 하고 릴리스는 게시하지 않아서, 버전을 쓰지 않고 바꾼 내용을 확인할 수 있습니다. 이번 작업도 이 방식으로 단계별로 확인했습니다.
- **스크린샷 테스트:** 스크린샷 테스트는 Java 21에서 돕니다.

## 확인한 것 / 못 한 것

- **확인한 것:** CI 빌드와 단위 테스트입니다. 새로 넣은 테스트는 프레임 감시(`JankWatchTest`), 자동 백업 시기(`AutoBackupTest`), 스마트 폴더(`SmartFolderTest`), PDF 캐시 상한, 펜 없는 기기 기본값, 손글씨 Markdown입니다.
- **스크린샷 테스트:** 처음에는 Java 버전 문제로 실패해서 고쳤고, 이제 3개 모두 통과해 그림 3장이 만들어집니다. 다만 GitHub Actions 저장 공간이 차서 그림을 올리지 못해, 그림을 눈으로 확인하지는 못했습니다.
- **기기에서 해 보지 못한 것:** 자동 백업이 실제로 드라이브나 폴더에 써지는지, 위젯 모양, 끌어서 폴더로 옮기기, 프레임 감시가 너무 자주 묻지 않는지는 기기에서 확인해야 합니다.
- **하지 않은 것:**
  - 큰 화면에서 유리 배경을 절반 해상도로 기록하는 것: 쓰는 라이브러리(Backdrop)가 기록 해상도를 정하는 방법을 열어 두지 않았습니다.
  - Gradle 구성 캐시: CI에서 매번 새로 시작하는 구조라 얻는 것이 적어 넣지 않았습니다.

## 태블릿에서 해 볼 것

1. About · Help에 개발자 코드가 그대로 적용돼 있는지(베타 테스터 문구).
2. 백업 버튼 → 자동 백업… → "이 태블릿에" → **지금 백업**. 그다음 드라이브 파일 하나로 바꿔 다시 **지금 백업**.
3. 홈 화면에 Notesis 위젯을 놓고 새 노트와 최근 노트 열기.
4. ⋯ → 새 스마트 폴더(예: 최근 7일)를 만들고 열어 보기.
5. 선택 모드에서 선택한 노트를 길게 눌러 끌어 폴더 카드에 놓기.
6. 템플릿 카드 길게 누르기(이름 바꾸기, 순서, 삭제)와 PDF 페이지 템플릿 추가.
7. 손글씨를 올가미로 고르고 인식 → 텍스트 상자로 추가. 손글씨 노트를 ⋯ → Export as .md로 내보내기.
8. S5e: 처음 설치하면 손가락으로 쓰이는지, 가벼운 모드가 켜져 있는지.
