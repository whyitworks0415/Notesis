# Notesis 0.49.0 (128)

## 기능 안내 노트 "Welcome to Notesis"
- 처음 설치해서 켜면 노트 목록에 기능 안내 노트가 하나 생깁니다. 이미 쓰던 경우에도 이번 업데이트 뒤 한 번 생깁니다.
- 지우면 다시 생기지 않습니다. About & help의 "Open the guide note"를 누르면 새로 만들어서 열어 줍니다.
- 일반 필기 노트라서 그 위에 바로 써 볼 수 있습니다. 내용은 텍스트 상자로 되어 있어 검색할 수 있고, 옮기거나 지울 수도 있습니다.
- 8쪽으로 이루어져 있습니다.
  1. 시작하기 (줄 노트, 이름 써 보기)
  2. 도구막대 (1/4~4/4, Functions, 도구를 다시 눌러 설정, Ctrl+1~9)
  3. 필기 (펜·연필·형광펜·지우개, 펜 설정 더 보기, 꾹 눌러 도형 만들기와 이어 늘이기, 모눈 연습 칸)
  4. 도형과 선택 (도형 도구 다시 누르면 고르기, 올가미, 꼭짓점 끌기)
  5. 손가락과 제스처 (스크롤·확대, 두·세 손가락 탭, 세 손가락 팝업 노트·회전, 제스처 모드)
  6. 페이지와 검색 (페이지 패널, 노트 안 검색, 페이지 추가, 단축키)
  7. 페이지 위의 다른 것들 (레이어, 사진·카메라, 텍스트 상자, 캡쳐, 녹음, 인터넷 패널)
  8. 나에게 맞추기 (스킨·색·모서리, 도구 편집, 백업과 업데이트)
