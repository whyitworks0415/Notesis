## 텍스트 상자에 LaTeX 수식
- 지금까지 텍스트 상자의 Markdown은 제목·굵게·목록 정도만 그렸고, LaTeX은 아예 그리지 않았습니다. Markdown 노트의 수식 표시는 웹 화면이라 페이지 위 텍스트 상자에는 쓸 수 없었습니다.
- 그래서 페이지 위에서 바로 그리는 **수식 엔진을 새로 넣었습니다.** 인터넷이나 웹 화면 없이 앱 안에서 그립니다. 저장 그림, PDF 내보내기, 캡처에도 똑같이 들어갑니다.
- 쓰는 법은 **Markdown과 LaTeX**를 켠 텍스트 상자에서 이렇게 씁니다. 텍스트 도구 패널에서 켜며, 기본으로 켜져 있습니다.
  - 줄 안: `$x^2 + y^2 = r^2$`
  - 따로 한 줄(가운데, 크게): `$$\int_0^1 x\,dx$$`. 여러 줄로 써도 됩니다.
- 지원하는 것
  - 위·아래 첨자, 분수(`\frac`, `\dfrac`, `\binom`), 루트(`\sqrt[3]{}`)
  - 그리스 문자와 기호 대부분(≤, ≠, →, ∞, ∈ …), `\sin`·`\log` 같은 함수 이름
  - 큰 연산자: `\sum`, `\prod`, `\int`, `\lim`. 블록 수식에서는 위아래에 범위가 붙습니다.
  - 내용 높이에 맞춰 커지는 괄호: `\left( … \right)`
  - 행렬: `pmatrix`, `bmatrix`, `vmatrix`
  - 경우 나누기 `cases`, 여러 줄 맞춤 `aligned`
  - `\hat`, `\vec`, `\bar`, `\overline`, `\mathbb{R}`, `\text{}`, `\color{red}`, `\boxed{}`
- 모르는 명령은 빨간 글씨로 그대로 보여 주고, 나머지 수식은 정상으로 그립니다. 어떤 글을 써도 상자가 깨지지 않습니다.
- `50%`처럼 쓴 %는 그대로 나옵니다. LaTeX에서는 %부터 줄 끝까지가 주석이지만, 노트에서는 퍼센트로 쓰는 경우가 많아서입니다.

## Markdown 확장
- 새로 되는 것
  - 제목 1~6단계
  - 번호 목록(`1.`)
  - 들여쓴 하위 목록: 줄이 넘어가도 글머리표 뒤에 맞춰집니다.
  - 표(`| a | b |`). 칸 정렬(`:-:`)을 지키고, 칸 안의 굵게·코드·수식도 그립니다.
  - 코드 블록(```), 가로줄(`---`), 겹 인용(`>>`)
  - `==형광==`, `***굵은 기울임***`, `<u>밑줄</u>`, `[[노트 링크]]`
  - `\*`처럼 써서 기호를 글자 그대로 보이기
- 페이지 위에서 바로 쓰는 동안에도 수식(보라색)과 형광이 표시됩니다. 수식은 다 쓰고 놓으면 그려집니다.

## 글자 설정이 많아졌습니다
- 텍스트 상자 편집 창(**Styles**)에 다음이 생겼습니다.
  - 정렬: 왼쪽, 가운데, 오른쪽, 양쪽 맞춤
  - 자간, 줄 간격, 문단 간격, 첫 줄 들여쓰기
  - 상자 전체 굵게·기울임
  - 테두리(색, 두께), 모서리 둥글기
  - 글꼴 3종 추가: Medium, 아주 굵게, 타자기
- 글자 크기는 12~96에서 **6~200**으로 넓어졌습니다.
- 편집 창에 **미리 보기**가 생겨, 고치는 대로 실제 모양을 보여 줍니다.
- Markdown을 켠 상태에서 B·I·U·S를 누르면 고른 글자 둘레에 `**`, `*` 같은 표시가 들어갑니다. 수식·블록 수식·형광 버튼도 있습니다.
- 페이지 위에서 바로 쓸 때도 그 상자의 글꼴·자간·줄 간격·정렬로 보여서, 놓을 때 모양이 튀지 않습니다.
- 고친 버그 두 가지
  - 편집 창에서 저장하면 상자의 Markdown 설정과 정해 둔 폭이 사라졌습니다.
  - Markdown 상자를 편집 창으로 열면 `**` 같은 표시가 지워진 채 열렸습니다.

## 에이전트가 쓰기 쉽게
- `text add`, `text edit`이 모든 모양 옵션을 받습니다.
  - `--size --color --font --bold --italic --align --letter --line --para --indent --pad --bg --border --border-width --corner --width --md/--plain`
- **`text style NOTE PAGE BOX ...`** 새 명령: 글은 그대로 두고 모양만 바꿉니다. 예: `--align center --line 1.4 --bg none`
- `text list`가 상자마다 기본값과 다른 모양(`style`)을 함께 알려 줍니다. 에이전트가 지금 모양을 보고 고칠 수 있습니다.
- PAGE 자리에 **`board`**를 쓰면 노트 밖(화이트보드)에 글을 넣고, 목록을 보고, 고치고, 지웁니다.
  - `--near 3 --x X --y Y`로 위치를 정합니다. 필기의 `ink add … board`와 같습니다.
  - `note read`에도 노트 밖 글이 나옵니다.
- 바뀌는 명령은 모두 바꾸기 전에 묻는 카드에 무엇을 하는지 적히고, `undo`로 되돌릴 수 있습니다.
- 에이전트 안내문(가이드)에 Markdown·LaTeX 쓰는 법과 `text style`을 짧게 넣었습니다.

## 어떻게 확인했나
- 통과한 점검
  - 빌드, 축소(R8) 릴리스 빌드, Android 버전 검사(Lint), 네이티브 커널 점검, 전체 단위 테스트
- 새로 넣은 테스트
  - 수식 읽기(TexParseTest): 첨자, 분수, 행렬, 경우 나누기, 잘못 쓴 수식, 아주 깊은 괄호
  - 상자 모양 저장·읽기: 예전에 저장한 상자도 모양 그대로 열리는지
  - 그리기(TextBoxRenderTest): 수식과 표가 공간을 제대로 차지하는지, 줄·문단 간격과 테두리가 크기를 바꾸는지, 이상한 글을 써도 그려지는지
  - 에이전트 명령: 옵션, `text style`, `board`, 되돌리기
- 컴퓨터에서 실제로 그린 그림(적분, 합, 극한, 행렬, 경우 나누기, 루트, 표, 목록)을 눈으로 확인하고 괄호 굵기와 수식 사이 간격을 다듬었습니다.

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 직접 써 보지 않았습니다.**
- 기기에 따라 글꼴이 달라, 수식 모양이 컴퓨터에서 본 것과 조금 다를 수 있습니다. `\mathcal`, `\mathfrak`처럼 기기 글꼴에 없는 글자는 보통 글자로 대신 나옵니다.
- 아직 안 되는 것
  - 직접 만든 LaTeX 명령(`\newcommand`), 패키지
  - `\overbrace`·`\underbrace` 위아래에 붙는 글
  - 수식 자동 줄바꿈: 긴 수식은 상자를 넓힙니다.
- 노트 밖 텍스트 상자는 아직 검색, 페이지 패널, PDF 내보내기에 들어가지 않습니다.

## 태블릿에서 해 볼 것
1. 텍스트 도구 패널에서 **Markdown과 LaTeX**가 켜져 있는지 보고, 페이지를 탭해 `$\frac{1}{2}$`와 `$$\sum_{i=1}^n i$$`를 써 보기.
2. 상자를 두 번 탭 → **Styles** → 미리 보기를 보면서 정렬, 자간, 줄 간격, 테두리 바꿔 보기.
3. 표(`| a | b |` 다음 줄 `|---|---|`)와 번호 목록 써 보기.
4. 에이전트에게 "1쪽 첫 글상자를 가운데 정렬하고 글자 크게" 같은 부탁 해 보기.
