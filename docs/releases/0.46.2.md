# Notesis 0.46.2 (118)

개선 검토표의 '적용 권장' 항목을 넣었습니다. 기능과 보이는 모습은 그대로이고, 필기·로딩·저장에서 반복되던 작업을 줄였습니다.

## 필기
- 펜을 뗄 때 획을 두 번 다시 만들던 것을 한 번으로 줄였습니다(접촉 튐 정리와 머묾 정리를 한 번에 계산).
- 펜을 한 곳에 오래 대고 있던 획에서 정리 계산이 급격히 늘던 것을 고쳤습니다. 2만 개 샘플 기준 3.5초 → 약 0.002초입니다. 결과 모양은 이전과 똑같습니다(무작위 획 3만 개로 비교).
- 정리할 게 없는 획은 복사 없이 그대로 씁니다. 노트를 열 때 모든 펜 획에 적용되던 비용도 함께 줄었습니다.
- 펜이 닿아 있는 동안에는 PDF 주변 페이지를 미리 그리는 일을 미루고, 페이지 읽기는 코어를 2개만 씁니다. 화면에 보이는 PDF는 그대로 그립니다.
- 480Hz 보정과 아이콘 애니메이션이 매 프레임 새로 만들던 객체를 재사용합니다.

## 밀집 페이지
- 레이어 정리가 획 하나 쓸 때마다 페이지 전체 획을 확인하던 것을, 새로 추가된 획만 보도록 바꿨습니다. 레이어 순서 조회도 표로 바꿨습니다.
- 타일 캐시가 획 하나 추가에도 페이지 전체를 비교하고 복사하던 것을 끝부분만 확인하게 했습니다.
- 핀치 후 배율이 2.5% 안쪽으로만 달라졌으면 타일을 버리지 않고 그대로 씁니다.
- 화면 밖의 그림·텍스트 상자는 디코드하지 않고, 화면 밖의 마스킹 테이프는 그리지 않습니다.
- 한 번 배치한 텍스트 상자는 그림 파일을 다시 읽지 않습니다.
- 가로·펼침 배치에서 옆으로 화면 밖에 있는 페이지는 그리지도 읽지도 않습니다.
- 현재 페이지 찾기와 가장 가까운 페이지 찾기를 이분 탐색으로 바꿨습니다.
- 멀리 떨어진 페이지를 내려놓을 때 타일 캐시와 기록해 둔 화면도 같이 놓아 메모리가 남지 않게 했습니다. 그 검사는 화면이 움직였을 때만 합니다.

## 저장
- 저장할 때마다 바뀌지 않은 페이지의 마스킹 테이프까지 복사하던 것을 없앴습니다.
- 잉크만 바뀐 페이지는 마스킹 테이프 파일을 다시 쓰지 않습니다.
- 텍스트 검색 색인이 바뀌지 않았으면 파일을 읽지도 쓰지도 않습니다.
- 획을 저장할 때의 임시 복사를 줄였습니다. 저장 파일 내용은 똑같습니다.

## PDF
- 미니맵·스크러버 미리보기를 찾을 때 캐시 전체를 복사하던 것을 없앴습니다.
- 다 쓴 타일 그림을 모아 두는 공간을 전체 메모리 예산 안에 넣고, 메모리가 부족하면 비웁니다.

## 발열
- 기기가 '보통' 이상으로 뜨거워졌다고 알리면, 주변 페이지 미리 읽기를 멈추고 페이지 읽기를 코어 2개로 줄입니다.

## 진단
- 지연 측정 화면에 백그라운드 작업 횟수(읽은 페이지, 버려진 작업, 미룬 PDF, 타일 기록, 레이어 정리 방식)를 같이 보여줍니다.
- 지연 측정을 켜면 자동 예측 길이가 바뀌던 것을 없앴습니다. 이제 켜고 끄는 것만으로 펜 동작이 달라지지 않습니다.
- 레이어 정리와 refine 적용 구간을 시스템 trace에 표시합니다.
