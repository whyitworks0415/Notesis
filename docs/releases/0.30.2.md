# Notesis 0.30.2 (versionCode 58)

필기 렌더링을 영역별 타일 계획으로 바꿨습니다. 타일 하나가 빠져도 준비된 영역은 계속 표시하고, 형광펜·이미지/텍스트·일반 필기 순서를 유지합니다. 이미지나 텍스트 상자가 있는 페이지에서도 필기 캐시를 사용합니다.

작은 편집은 겹치는 타일만 갱신합니다. 추가 획은 즉시 표시하고, 삭제·복원·이동은 해당 영역을 다시 합성한 bitmap이 준비되면 교체합니다. 올가미 이동 중 선택 필기와 배경은 준비된 bitmap으로 표시합니다. 렌더 작업은 한 worker와 최대 32개의 대기 작업으로 제한하고, 표시 중인 bitmap의 수명을 따로 관리합니다.

설정의 **지연 상세 렌더링**은 확대·이동·플링 동안 상세 타일 요청을 미루며 기본 coverage와 편집 결과는 계속 준비합니다. 저장 파일 형식과 PDF의 벡터 출력은 유지했습니다.

검증: JVM 17개 클래스·87개 테스트가 debug/release에서 통과했습니다. 500·1,500·5,000·10,000획 fixture에서 interaction의 확정 획 벡터 fallback은 0이고, 전체 준비 시 필기 소스 8개·한 타일 누락 시 7개입니다. `lintDebug`, debug/benchmark APK 빌드와 로컬 서명 release APK 빌드를 확인했습니다.

연결 기기가 없어 instrumentation, 실제 시각 검사 및 Macrobenchmark frame timing은 아직 실행하지 않았습니다. 구조 테스트 결과는 실기기 frame time 개선율을 뜻하지 않습니다.
