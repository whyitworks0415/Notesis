# Notesis 0.34.0

## 필기 화질
- 펜을 대고 잠시 머무는 동안의 미세한 입력을 쓰는 중에도 걸러냅니다. 펜을 뗄 때 획 시작 모양이 바뀌지 않습니다.
- 연필 질감을 2×2 픽셀 블록 대신 부드러운 노이즈로 다시 만들었습니다. 확대해도 네모난 점이 보이지 않습니다.
- 0.33.9의 메시 렌더링(실험) 스위치는 그대로 유지됩니다.

## 편집
- 부분 지우개: 지우개를 고른 상태에서 지우개 버튼을 한 번 더 누르면 ‘획 지우개 / 부분 지우개’를 고를 수 있습니다. 부분 지우개는 지나간 부분만 잘라냅니다.
- 올가미 선택: 축소·확대·15° 회전·현재 펜 색으로 바꾸기·복제를 추가했습니다. 실행 취소도 됩니다.
- 페이지 메뉴에 ‘페이지 복제’를 추가했습니다.
- 레이저 포인터: 도구막대에서 켜면 펜으로 가리킨 자리에 빨간 궤적이 잠깐 남았다 사라집니다. 노트에는 저장되지 않습니다.

## 노트 목록
- 삭제한 노트는 휴지통으로 갑니다. 30일 동안 복원할 수 있고, 그 뒤 자동으로 지워집니다.
- 즐겨찾기한 노트는 목록 맨 앞에 별표와 함께 표시됩니다.
- 최근 수정·이름·쪽수 순으로 정렬할 수 있습니다.
- 검색 결과에 단어를 찾은 쪽과 주변 문장이 함께 나옵니다. 누르면 그 쪽으로 바로 열립니다. 검색은 페이지 텍스트를 SQLite에 담아 두고, 바뀐 파일만 다시 읽습니다.

## PDF·학습·녹음
- 읽기 모드에서 PDF 안의 링크를 누르면 웹 주소는 인터넷 창으로 열리고, 같은 PDF의 다른 쪽으로 가는 링크는 그 쪽으로 이동합니다(Android 15 이상).
- 마스킹 학습: 마스킹 탭에서 마스크에 이름을 붙이고 ‘학습’을 누르면 하나씩 정답 확인 → 맞음/틀림을 표시합니다. 끝나면 틀린 것만 다시 볼 수 있고, 페이지마다 맞음·틀림 수가 남습니다.
- 녹음 중에 쓴 획은 녹음 시각과 함께 기록됩니다. 재생하면 그때 쓰던 필기를 표시하고 해당 쪽으로 이동합니다. 읽기 모드에서 필기를 누르면 그 시점으로 건너뜁니다. 이전 녹음은 예전처럼 재생만 됩니다.

## 성능
- 획이 많은 페이지의 캐시를 화면 배율 그대로, 보이는 영역만 렌더링합니다. 이전에는 A4 페이지에서 100% 배율일 때만 동작했습니다.
- 획 윤곽 정밀도를 화면 0.1px 기준으로 조정해 꼭짓점 수를 줄였습니다.
- 형광펜 여부와 필기 재생 대상을 매 프레임 다시 계산하지 않습니다.
- 올가미 삭제를 선택 개수에 비례하는 시간으로 처리합니다.
- 실행 취소 기록을 최근 1000개로 제한해, 오래 쓰는 동안 메모리가 계속 늘지 않습니다.

검증: 릴리스 APK 빌드와 단위 테스트 코드 추가까지 했습니다. 실제 S펜 기기에서는 아직 확인하지 않았습니다.
