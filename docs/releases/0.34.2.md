# Notesis 0.34.2

메시 렌더링을 켠 상태에서 획이 많은 페이지를 넘기거나 움직일 때의 끊김을 줄였습니다.

- 메시 렌더러는 그릴 때마다 획 하나당 셰이더 값 설정 등 여러 번의 네이티브 호출을 합니다. 그래서 획이 많은 페이지는 조금만 움직여도 매 프레임 수십 ms가 걸렸습니다.
- 이제 페이지의 필기를 하드웨어 디스플레이 리스트(RenderNode)에 한 번 기록해 두고, 스크롤·페이지 이동 중에는 그 기록만 다시 그립니다. 메시 셰이더는 배율에만 영향을 받아서, 같은 배율이면 위치가 달라도 기록을 그대로 쓸 수 있습니다.
- 필기 중에는 새 획만 따로 그리고, 쓰기를 잠시 멈추면 페이지 기록을 갱신합니다. 확대·축소 중에는 이전 기록을 확대해 보여주고, 손을 떼면 새 배율로 다시 기록합니다.
- 메시 렌더링을 끈 경우에도 같은 방식이 적용됩니다.

검증: 릴리스 APK 빌드. 실제 기기에서의 체감은 아직 확인하지 않았습니다.
