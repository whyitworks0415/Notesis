# Notesis 0.96.0 (237)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

에이전트와 터미널이 쓰는 노트 명령을 크게 늘렸습니다(Todo.md Q1~Q5). 계기는 Termux의 Claude Code가 PDF 노트에 목차를 넣지 못하고 멈춘 일입니다. 에이전트가 PDF에 인쇄된 글자도, PDF 책갈피도, 쪽 모양도 볼 수 없었고, 읽기 명령은 노트 전체를 한 번에 돌려줬습니다.

## 바뀐 점

### PDF 노트 (Q5)
- `pdf info 노트`: 책갈피가 몇 개인지, 글자 층이 있는지(스캔본인지), 인쇄된 쪽 번호와 PDF 쪽이 몇 쪽 어긋나는지 추정하고, 다음에 할 명령을 알려 줍니다.
- `toc import-pdf 노트`: PDF 책갈피를 그대로 노트 목차로 넣습니다. 책갈피가 있는 PDF는 이 한 줄로 끝납니다. `toc show 노트 --pdf`로 먼저 볼 수 있습니다.
- `pdf text 노트 --pages 1-8`, `pdf find 노트 낱말`: PDF에 인쇄된 글자를 쪽별로 읽고 찾습니다. `toc set 노트 쪽 "제목" --pdf`는 PDF 쪽 번호로 목차를 넣습니다.
- `page image 노트 쪽`: 쪽을 그림(JPEG)으로 에이전트에게 직접 보냅니다(한 번에 4장까지). 스캔본의 목차 쪽을 에이전트가 눈으로 읽는 길입니다.
- **앱 검색도 좋아집니다**: 앱이 PDF 글자를 뽑는 방식(Android 기본 기능)은 Android 15부터만 동작해서, S6 Lite처럼 그 아래 버전에서는 PDF 쪽의 검색 글이 비어 있었습니다. 이제 비어 있으면 앱에 들어 있는 PDFBox로 뽑고, 뽑은 글을 검색 글로 남깁니다. 에이전트가 한 번 읽은 PDF는 앱 검색에서도 찾힙니다.

### 적게 읽기 (Q1)
- `notes list --limit 20 --offset 20 --brief`: 최근 수정 순으로 나눠서, 간단히.
- `note read 노트`는 기본 2만 자까지만 주고, 넘으면 `truncated`와 이어 읽을 명령(`next`)을 함께 줍니다. `--outline`(목차만), `--text-only`(글이 있는 쪽의 글만), `--max-chars`, Markdown은 `--from`. 쪽 크기는 `--sizes`일 때만 줍니다.
- 에이전트 패널 **사용량**: 앱을 켠 뒤 호출 수, 보낸·받은 글자 수, 가장 긴 답, 그림 수. 토큰은 모델마다 달라 글자 수로만 보여 줍니다.

### 정확하게 (Q2)
- 실패하면 `code`(NOT_FOUND, AMBIGUOUS, OPEN_ON_SCREEN, LOCKED, BAD_PAGE, NO_PDF 등)를 주고, 노트를 못 찾으면 **비슷한 노트 후보**를 함께 줍니다. 제목은 대소문자·띄어쓰기·한글 조합 방식과 상관없이 찾습니다.
- `preview 명령…`: 그 줄이 무엇을 할지 말만 하고 아무것도 바꾸지 않습니다.

### 새 명령 (Q4)
- 찾기·상태: `search 낱말`(제목·글 상자·PDF 글자·필기 인식·Markdown 안), `status`(열린 노트, 되돌리기 수), `tags list`, `folder list`
- 노트: `note new`, `note new-md`, `note dup`, `note merge`, `note fav`, `note label`. 새로 만든 노트를 되돌리면 휴지통으로 갑니다.
- 폴더: `folder new`, `folder rename`
- 쪽: `page dup`, `page paper 노트 1-3 grid`, `page bookmark`
- 글 상자: `text list`, `text edit 노트 쪽 번호 "새 글"`, `text rm`
- 필기: `ink read 노트 쪽`(손글씨를 글로 읽음)
- Markdown: `md write`, `md append 노트 "- 할 일" --under 제목`, `md replace`, `md outline`, `md links`(링크·백링크)
- `export 노트 --to shared`: **Download/Notesis**에 사본을 둡니다(Termux에서는 `termux-setup-storage` 뒤에 읽을 수 있음). 앱 밖에 노트 내용을 두는 일이라 **변경으로 취급해 "먼저 묻기"에서는 묻고**, 되돌리면 사본을 지웁니다.
- 모든 새 변경 명령은 변경 카드에 한국어로 설명되고 `undo`로 되돌릴 수 있습니다. 화면에 열린 노트는 여전히 읽기만 합니다.

### 지침 (Q3)
- 에이전트용 **안내**(규칙과 요령: 찾기, PDF 목차 만들기, 필기 요약, 쓰기, 정리)가 `notesis_help`에 들어갑니다.
- MCP 프롬프트 3개: `build_toc_from_pdf`, `summarize_note`, `organize_notes`. Claude Code에서는 `/mcp__notesis__build_toc_from_pdf` 같은 이름으로 보입니다.
- **Termux 설정 스크립트를 다시 실행하면** 안내가 `~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`, `~/.config/opencode/AGENTS.md`의 `<!-- notesis:start -->`~`<!-- notesis:end -->` 사이에만 들어갑니다. 직접 쓴 줄은 그대로 두고, 다시 실행하면 그 사이만 바뀝니다.
- 에이전트 패널의 **안내 복사**.
- 설정 스크립트가 Debian이 이미 있는지 확인하는 방법도 고쳤습니다(이미 있는데 다시 설치하려다 "container 'debian' already exists"로 멈추던 것).

### 터미널
- 답을 JSON 대신 **읽기 쉬운 글**로 보여 줍니다(노트 목록, 검색 결과, 목차, 폴더, 태그, PDF 글). `json`을 입력하면 JSON으로 바꾸고, 다시 입력하면 글로 돌아갑니다.
- 실패하면 비슷한 노트 후보를 보여 주고, 쪽 그림은 크기만 표시합니다.
- 입력한 명령 기록이 앱을 다시 켜도 남습니다(최근 200줄, 앱 설정 안에).
- 따옴표 안의 `\n`이 이제 실제 줄바꿈이 됩니다(`text add`, `md append` 등).

## 어떻게 확인했나
- 단위 테스트 873개 통과(로컬, 네이티브 검사 포함). 새 명령마다 메모리 노트로 시험하고(AgentCommandsTest 26개), **실제 노트 파일**로도 시험했습니다: PDFBox로 만든 2쪽짜리 시험 PDF에서 글자 뽑기, 책갈피 → 목차, PDF 안 찾기, 노트 만들기·복제·Markdown 추가와 되돌리기.
- MCP: 쪽 그림이 글이 아닌 그림으로 가는지, 4장 제한, 프롬프트 목록·채우기를 시험.
- Termux 설정 스크립트를 가짜 명령으로 두 번 실행해 지침 파일에 안내가 한 번만 들어가고 직접 쓴 줄이 남는지 확인.
- CI `check` 통과.

## 하지 않은 것
- **태블릿에서도, 실제 에이전트로도 아직 해 보지 않았습니다.** 특히 `page image`의 그림 크기·속도, `export --to shared`(Download 폴더에 쓰기), `ink read`는 기기에서만 확인할 수 있습니다.
- 스캔본 글자 인식(OCR)은 넣지 않았습니다. 먼저 쪽 그림을 에이전트가 읽는 길을 써 보고 부족하면 하겠습니다.
- 그림 넣기(`image add`), 스마트 폴더 목록, 바뀌지 않은 노트에 짧게 답하기는 다음으로 미뤘습니다(Todo.md Q1·Q4).

## 태블릿에서 해 볼 것
1. Termux에서 설정 스크립트를 **다시** 실행(에이전트 패널 → 이 태블릿에서 → 설정 스크립트 복사). `~/.claude/CLAUDE.md`에 Notesis 안내가 들어갔는지 확인.
2. Claude Code에게 지난번처럼 "수능완성 노트의 PDF를 보고 목차를 추가해 줘". `pdf info` → `toc import-pdf` 또는 `pdf text` → `toc set --pdf`로 가는지 보기.
3. 앱 검색에서 PDF 안의 낱말 찾기(에이전트가 그 PDF를 한 번 읽은 뒤).
4. 터미널에서 `notes list --brief`, `status`, `json`, 앱을 껐다 켜고 ↑로 기록 확인.
5. 에이전트 패널 아래 **사용량** 숫자가 늘어나는지.
6. `export 노트 --to shared` 뒤에 파일 앱의 Download/Notesis에 있는지, `undo`로 사라지는지.
