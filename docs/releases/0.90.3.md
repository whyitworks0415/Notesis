## 첫 화면 분위기

**여는 곳:** 첫 화면 ⋯ → **라이브러리 배경** → 맨 위 **첫 화면 분위기**

### 더 많은 기본 분위기

기본, 따뜻한 종이, 안개, 세이지, 노을에 여덟 가지를 더했습니다. 모두 밝은 모드와 다크 모드 색이 따로 있습니다.

| 이름 | 느낌 |
|---|---|
| 바다 | 청록 → 하늘 → 연보라, 대각선 |
| 라벤더 | 옅은 보라 |
| 복숭아 | 살구색에서 분홍빛으로 |
| 민트 | 옅은 민트, 왼쪽에서 오른쪽으로 |
| 오로라 | 청록 → 연두 → 연보라, 대각선 |
| 해질녘 | 주황 → 분홍 → 보라, 대각선 |
| 흑연 | 차분한 회색 |
| 모래 | 가운데가 밝은 모래색 |

새 분위기들은 바탕색에 맞춰 카드·종이·글자·선 색을 자동으로 정합니다. 밝은 바탕에는 진한 글자, 어두운 바탕에는 밝은 글자가 나옵니다.

### 직접 만들기

맨 끝의 **직접 만들기**를 누르면 나만의 분위기 창이 열립니다.

- **색 1~4개:** **+ 색 추가**로 늘리고 **삭제**로 줄입니다.
- **위치:** 막대 위의 손잡이를 좌우로 끌어 그 색이 바탕의 어디에 올지 정합니다. 위치 슬라이더로도 정할 수 있습니다.
- **강도:** 고른 색을 얼마나 진하게 섞을지 정합니다. 0%면 바탕 그대로, 100%면 그 색 그대로입니다.
- **색 고르기:** 동그라미를 눌러 색을 고르고, 아래에서 색상·채도, `#RRGGBB` 입력, 자주 쓰는 색으로 바꿉니다.
- **방향:** 위에서 아래로 / 왼쪽에서 오른쪽으로 / 대각선으로 / 가운데에서 바깥으로.
- 창 맨 위의 미리보기는 그 바탕 위에 제목과 카드가 어떻게 보일지 그대로 보여 줍니다.
- **이 분위기 쓰기**를 누르면 적용되고 저장됩니다. 이미 만든 것이 있으면 그 자리의 이름이 **내 것 고치기**로 바뀌어, 다시 고칠 수 있습니다.

## 첫 화면 검색창과 버튼의 유리

- **검색창:** 펼쳐져 있을 때는 회색 칸이었고 접힐 때만 유리였습니다. 이제 언제나 툴바와 같은 유리입니다.
- **설정 버튼(세로 세 줄) 옆 버튼들:** 스크롤했을 때 펼쳐지는 버튼 묶음 뒤의 유리가, 펼쳐지는 동안 사라졌습니다. 이제 언제나 유리가 버튼들 뒤에 있고, 버튼이 늘어나는 만큼 함께 늘어납니다.
- **늘어나는 느낌:** 손으로 펼치면 유리가 원래 폭보다 조금 더 늘어났다가 돌아옵니다. 길게 늘어나는 동안에는 높이가 살짝 얇아집니다. 스크롤해서 접히는 동작은 지금처럼 부드럽게 접힙니다.
- 폴더 안의 뒤로 가기 버튼도 언제나 유리입니다.
- 유리로 보이는 것은 Liquid glass 모양을 쓸 때입니다. 다른 모양에서는 그 모양의 재질로 보입니다.

## 확인한 것 / 못 한 것

- CI 빌드와 단위 테스트까지 확인했습니다.
  - 새 테스트: 색이 위치 순서로 놓이는지, 강도 0%·100%, 저장하고 다시 읽기, 색 4개 제한, 바탕에 따른 글자색, 검색창이 늘어나도 줄을 넘지 않는지.
- 기기에서는 해 보지 못했습니다.
  - 특히 유리가 늘어났다 돌아오는 정도가 자연스러운지, 손잡이 끌기가 잘 되는지 확인해 주세요.
  - 늘어나는 정도는 숫자 하나로 조절할 수 있으니, 더 크게 또는 작게 원하시면 말씀해 주세요.

## 태블릿에서 해 볼 것

1. ⋯ → 라이브러리 배경 → 첫 화면 분위기에서 새 분위기들을 눌러 보기(밝은/다크 모드 둘 다).
2. **직접 만들기** → 색 3개로 늘리고, 손잡이를 끌어 위치를 옮기고, 강도를 바꿔 보기 → 미리보기가 바로 바뀌는지 → **이 분위기 쓰기**.
3. 방향 네 가지를 바꿔 보기.
4. 첫 화면 검색창이 펼친 상태에서도 유리인지.
5. 목록을 아래로 스크롤 → 세로 세 줄 버튼을 눌러 버튼들을 펼치기 → 유리가 함께 늘어나고, 살짝 더 늘어났다 돌아오는지.
