# Notesis 0.60.0 (145)

## 툴바 크기를 설정에서 직접 조절
- 0.58.0에서 넣은 "창 크기에 따른 자동 크기 조절"을 없앴습니다. 큰 화면에서는 툴바가 기본 상태부터 너무 커졌기 때문입니다.
- 대신 툴바 설정의 Direction 아래에 Scale 슬라이더를 추가했습니다. 90%~140% 사이에서 5% 단위로 조절할 수 있고, 기본값은 100%(예전 크기)입니다.
- Scale은 2/4~4/4 툴바의 도구 줄, 도구 아이콘, 기능(Functions) 버튼, 나가기 버튼에 함께 적용됩니다. 그래서 나가기 버튼은 어떤 크기에서도 툴바와 높이·크기가 맞습니다.
- 슬라이더는 두 곳에 있습니다.
  - 설정의 화면 모양(Appearance) 툴바 칸: 바로 아래 미리보기에 바뀐 크기가 보입니다.
  - 노트 툴바의 기능 메뉴
- 정한 크기는 앱을 다시 켜도 그대로 유지됩니다.
- 좁은 창에서 툴바가 나가기 버튼을 피해 가는 동작(0.59.0)은 그대로입니다.
