# Notesis 0.34.3

로컬 0.33.13의 UI·수정 사항과 클라우드 0.34.2의 기능·최적화를 통합했습니다.

## 유지한 로컬 수정

- Reicon 아이콘, 도구막대의 유리 굴절·폭 애니메이션·그림자 수정.
- 축소 도구막대의 설정창 슬라이더, 색상 드래그, 팔레트 및 형광색 불투명도 수정.
- 일반 펜·형광펜·마스킹의 브러시 식별 분리와 기존 불투명 펜 복원.
- 진행 방향에 따른 획 보정, 확대 필기 캐시 좌표 및 해상도 수정.
- PDF 미리보기 캐시와 필기·이동 중 유리 배경 중복 캡처 중단.

## 통합한 클라우드 기능

- 부분 지우개, 올가미 확대·축소·회전·색 변경·복제, 페이지 복제, 레이저 포인터.
- 휴지통·복원, 즐겨찾기, 목록 정렬, 페이지·주변 문장을 보여 주는 검색 인덱스.
- 마스킹 학습 기록 및 녹음 시각과 필기 연결.
- 불투명 펜의 메시 렌더링 선택, 부드러운 연필 질감과 쓰기 시작 입력 정리.
- 페이지 필기의 RenderNode 재사용, 메시용 획 사본 사전 준비 및 반복 계산 감소.
- 실행 취소 기록을 최근 1,000개로 제한.

## 겹치는 기능 조정

- 지우개를 다시 누르면 한 설정창에서 획/부분 지우개, 굵기, 예측을 설정합니다.
- 내부·웹 PDF 링크를 문서 열기 시 한 번 인덱싱합니다. 손가락 탭과 읽기 모드의 펜 링크 처리가 같은 좌표 변환을 사용하며 Android 15 이전에도 동작합니다. 인덱스 조회는 PDF 렌더 잠금을 기다리지 않습니다.
- 저장용 브러시의 고유 식별자를 메시용 브러시에도 유지하고, 저장 시 원래 도구로 복원합니다.
- 실시간 필기는 로컬의 경로 렌더링을 유지하고, 메시·RenderNode 최적화는 완성된 획에 적용합니다. 실시간 입력까지 메시로 바꾼 상태에서 연속 화면 종료 검사 중 나타난 비동기 렌더러 종료 충돌을 피하도록 조정했으며, 조정 후 전체 Android 회귀 검사가 통과했습니다.
- 필기 파일 v1·v2를 모두 읽고 새 파일은 v2로 저장합니다.
- versionCode를 90으로 올려 로컬 0.33.13(89)과 클라우드 0.34.2(88)보다 새 버전으로 설치됩니다.

클라우드와 로컬에서 서로 다른 내용에 사용한 0.33.9 릴리스 기록은 `0.33.9.md`와 `0.33.9-cloud.md`로 각각 보존했습니다.

## 검증

- 단위 테스트 142개 통과. 이전 상수가 인라인된 빌드 캐시를 제거하고 테스트를 새로 컴파일해 확인했습니다.
- arm64 release APK 빌드와 APK v2 서명 검증 통과.
- Android 36 에뮬레이터에서 기존 유리 효과·슬라이더·형광 팔레트·지우개 설정, 필기 렌더링, 브러시 식별 및 v1·v2 저장 회귀 검사 통과.
- 추가 통합 검사: 올가미 확대·색 변경·복제와 실행 취소/다시 실행, 부분 지우개와 실행 취소/다시 실행, 레이저의 비저장 동작, 페이지 복제 후 v2 재로드, 페이지 검색, 즐겨찾기·휴지통·복원, 학습 기록·녹음 타임라인 저장, 회전된 PDF 내부·웹 링크 조회 통과.
- 실기기 S Pen 입력과 장시간 성능은 아직 측정하지 않았습니다.
