# Notesis 0.48.2 (127)

## 세 스킨의 모서리 곡률 통일
- 이전에는 같은 요소라도 스킨마다 모서리가 달랐습니다.
  - Material은 20, Glassmorphism은 26, Liquid glass는 32의 반지름을 썼습니다.
  - Liquid glass는 일부에 다른 형태의 곡선을 섞어 썼습니다.
- 이제 세 스킨 모두 같은 반지름의 둥근 모서리를 씁니다. 도구막대, 도구 줄, 선택 알약, 기능 버튼, 기능 메뉴, 펜 설정 창이 해당됩니다.
- UI 화면 설정의 "Corner radius" 슬라이더 하나가 세 스킨 모두에 적용됩니다.

## 모서리 그림자 잘림
- 기능 메뉴: 창 경계와 크기 애니메이션이 그림자를 잘랐습니다. 패널 둘레에 그림자 자리를 비워 두고, 크기 애니메이션은 표면 안쪽으로 옮겼습니다.
- 펜 설정 창: 열리고 닫히는 동안 그림자가 잘리던 것을 고쳤습니다.
- Liquid glass 도구 줄: 렌즈가 움직이는 동안 양 끝 그림자가 잘리던 것을 고쳤습니다.

## Material·Glassmorphism 선택 하이라이트
- Liquid glass 렌즈와 같은 스프링으로 움직여서 속도가 같아졌습니다.
- 둥근 정도도 Liquid glass의 알약과 같습니다.
- 선택된 도구 아이콘이 그 도구의 색(펜 잉크 색)으로 바뀝니다.

## 펜 설정 "More for this … / Fewer settings"
- 크기 애니메이션 두 개가 겹쳐서 배경이 내용보다 늦게 따라왔습니다. 하나로 합쳐 펼칠 때 280ms, 접을 때 220ms에 내용과 배경이 같이 움직입니다.
- Material은 바로 바뀝니다.

## 팝업과 사이드바 애니메이션 (Liquid glass·Glassmorphism)
- 기능 메뉴와 펜 설정 창은 같은 비율의 사각형으로 커지지 않습니다. 누른 곳에서 폭이 먼저 살짝 넘치듯 펴지고, 높이가 부드럽게 따라옵니다. 닫힐 때는 빠르게 가속하며 접힙니다.
- 설정 사이드바는 가장자리에서 미끄러져 들어오고, 내용이 뒤따라 나타납니다. 닫을 때는 반대로 빠르게 나갑니다.
- 애니메이션 중에도 유리 뒤 배경 위치가 맞게 유지됩니다.
- Material은 이전 요청대로 애니메이션 없이 바로 나타나고 사라집니다.
