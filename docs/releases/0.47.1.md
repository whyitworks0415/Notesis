# Notesis 0.47.1 (120)

60Hz 화면과 절전 모드에서 필기, 손가락 스크롤, 확대, 노트 이동이 덜 끊기도록 손봤습니다. 평균 FPS보다 프레임 마감(60Hz에서 약 16.7ms)을 반복해서 놓치지 않는 데 맞췄습니다. 실제 기기 측정은 아직 하지 않았으니, 아래 내용은 코드에서 고친 점입니다.

## 상호작용 상태 하나로 통합
- 필기 중, 손가락 이동 중, 잠깐 정지, 유휴 네 가지 상태를 모든 캔버스와 백그라운드 작업이 함께 봅니다. 절전 모드, 기기 온도, 화면 주사율도 같은 곳에서 읽습니다.
- PDF 미리 읽기, 주변 페이지 로딩, 정밀화, 손글씨 인식, 썸네일이 이 상태에 맞춰 양을 줄이거나 기다립니다. 절전 모드에서는 동시에 돌리는 스레드 수를 낮춥니다.
- 팝업 노트에서 펜을 떼거나 팝업을 닫으면 원래 노트의 필기 상태까지 함께 풀리던 문제를 고쳤습니다.
- 절전 모드나 발열 때문에 사용자 설정이 바뀌어 저장되는 일은 없습니다. 120Hz를 강제하거나 절전 제한을 풀지도 않습니다.

## 필기
- 첫 점을 그리기 전에는 다른 일을 하지 않습니다. 페이지 패널 닫기 같은 처리는 첫 점을 넘긴 뒤로 미뤘습니다. 펜이 화면에 닿기 전(호버 중)에 브러시를 미리 준비하고, 최근 쓴 브러시는 다시 만들지 않습니다.
- 펜 입력 이벤트마다 화면 주사율을 시스템에 묻던 것을 캐시로 바꿨습니다. 입력 샘플은 하나도 버리지 않습니다.
- 예측은 실제 주사율과, 입력이 처리되기까지 기다린 시간을 반영합니다. 길이 상한(12ms)은 그대로입니다.
- 펜을 뗀 획이 한꺼번에 넘어올 때 지금 페이지에 붙던 버그를 고쳤습니다. 이제 각 획은 처음 쓴 페이지에 들어갑니다(페이지 경계, 펼침 보기).
- 반투명 레이어가 있는 노트에서 펜을 뗄 때마다 페이지 전체를 다시 기록하던 것을, 그 레이어에 새로 쓴 경우로 좁혔습니다.
- 예측 끝부분, 480Hz 잔상, 지우개 커서가 그릴 때마다 전체 화면을 다시 그리게 하던 것을 작은 영역만 갱신하도록 바꿨습니다.
- 지우개는 최근 획부터 찾고, 올가미 미리보기는 새로 그은 부분만 다시 계산합니다. 결과는 이전과 같습니다.
- 절전 모드에서는 480Hz 잔상만 끕니다. 필기 품질은 그대로입니다.
- S6 Lite 계열에서 노트를 돌렸을 때도 저지연 표면을 계속 씁니다.

## 손가락 스크롤·확대·회전
- 핀치 배율과 이동을 한 번에 계산해 손가락 아래 위치가 흔들리지 않습니다. 작은 이동량도 버리지 않습니다.
- 손가락이 움직이는 동안 페이지 추적, 미리 읽기, 확대 표시 같은 부가 작업은 한 프레임에 한 번만 합니다.
- 관성 스크롤을 화면 프레임 시간에 맞춰 60Hz와 120Hz에서 같은 거리를 가게 했습니다. 문서 끝에 닿은 방향은 더 이상 프레임을 그리지 않습니다.
- 새 터치나 펜 입력이 들어오면 관성 스크롤을 바로 멈춥니다.
- 손가락을 대면 진행 중인 정밀화를 취소합니다.
- 고친 버그:
  - 펜을 대거나 페이지 끝을 당겨 새 페이지를 만든 뒤 화면 이동 상태가 계속 켜져 있던 문제
  - 관성이 없는데도 터치할 때마다 유리 배경 갱신이 멈췄다 켜지던 문제

## 페이지·PDF 로딩
- 확대를 멈춘 뒤 화면의 잉크 타일을 한 프레임에 모두 다시 기록하던 것을 여러 프레임에 나눴습니다. 새 타일이 준비될 때까지 이전 타일을 그대로 보여 줍니다.
- 주변 페이지 미리 읽기 범위:
  - 필기나 이동 중에는 쉽니다.
  - 평소에는 이동 방향으로 앞 3쪽, 뒤 2쪽을 읽습니다.
  - 절전 모드에서는 앞뒤 1쪽만 읽습니다.
  - 기기가 뜨거우면 읽지 않습니다.
- 미리 읽은 페이지는 한 프레임에 하나씩 반영합니다. 획 검색용 색인은 백그라운드에서 만듭니다.
- 펜을 뗀 뒤 미뤄 둔 PDF 렌더링을 한꺼번에 다시 시작하지 않고, 화면이 쉴 때까지 기다립니다. 보이는 페이지는 바로 그립니다.
- 새 요청에 밀려 끝난 정밀화가, 이미 읽어 둔 페이지까지 버리던 문제를 고쳤습니다.

## 저장과 손글씨 인식
- 계속 쓰고 있어도 자동저장이 무한정 밀리지 않습니다. 첫 수정 후 8초가 지나면 다음 쉬는 틈에 저장하고, 12초가 되면 무조건 저장합니다. 획을 쓰는 중간에는 저장용 복사를 하지 않습니다.
- 바뀌지 않은 페이지는 이전 저장 복사본을 다시 씁니다. 저장 파일 형식과 안전한 쓰기 방식은 그대로입니다.
- 손글씨 인식은 필기와 화면 이동이 모두 멈추고 충분히 쉰 뒤에만 돌고, 저장과는 시간을 띄웁니다. 화면을 만지면 중간에 멈추고 나중에 다시 읽습니다.

## 화면(UI)
- 첫 획에서 페이지 패널이 닫힐 때 노트 화면 전체를 다시 구성하지 않습니다. 펜으로 닫을 때는 애니메이션 없이 바로 사라집니다.
- UI 화면 설정 슬라이더는 미리보기에만 바로 적용하고, 손을 멈춘 뒤 노트에 반영합니다. 그동안 뒤의 노트는 다시 그리지 않습니다.
- 확대 수치 표시는 핀치가 끝나면 갱신합니다.
- 팝업 노트 이동과 크기 조절은 레이아웃을 다시 계산하지 않고 그림만 옮깁니다.
- 유리 효과는 필기 중, 이동 중, 직후 잠깐 동안 배경 캡처를 쉽니다. 절전 모드에서는 장식 효과를 먼저 단순화합니다. 필기 프레임은 낮추지 않습니다.
- 숨긴 웹 패널은 일시정지합니다.

## 진단
- 오버레이는 0.5초(필기 중에는 1초)에 한 번만 갱신합니다.
- 항목:
  - 첫 획 표시(제출 기준), 입력 처리 시간, 펜 확정 p50/p95/p99
  - 프레임 간격과 마감을 놓친 프레임 수
  - 페이지 반영 시간, 저장 복사 시간, 미뤄 둔 타일과 재사용한 저장 페이지
  - 필기 경로, 절전 모드, 온도, 주사율, 상호작용 상태
- 앱 안의 수치는 버퍼를 넘긴 시점까지입니다. 실제로 화면에 보이기까지의 지연은 아닙니다.
- "Copy measurements"로 아래 조건에서 잰 값을 복사해 비교할 수 있습니다.
  - 60Hz 절전 끔
  - 60Hz 절전 켬
  - 절전 켜고 15~30분 사용한 뒤
  - 고주사율
