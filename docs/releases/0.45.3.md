# Notesis 0.45.3 (114)

앱 안에서 바로 업데이트하는 기능과 오픈소스 라이선스 화면을 넣고, 다른 회사 이름이 떠오르는 문구를 바꿨습니다.

## 앱 안에서 업데이트
- 앱을 열면 GitHub에 새 버전이 올라왔는지 확인합니다. 새 버전이 있으면 바뀐 내용과 함께 알려 줍니다.
- **업데이트**를 누르면 앱 안에서 APK를 내려받고, 다 받으면 안드로이드 설치 화면이 열립니다. 거기서 업데이트를 한 번 누르면 끝납니다. 노트와 설정은 그대로 남습니다.
- 처음 한 번은 안드로이드가 "이 출처 허용"을 물어봅니다. 켜고 돌아와서 **설치**를 누르세요.
- 내려받은 파일은 크기, SHA-256 값, Notesis의 더 새 버전인지를 확인한 뒤에만 설치 화면으로 넘깁니다.
- **나중에**를 누르면 다음에 앱을 열 때 다시 알려 줍니다. **이 버전 건너뛰기**를 누르면 그 버전은 다시 알리지 않습니다.
- 노트 목록 오른쪽 위 **앱 정보 · 도움말**(벌레 아이콘)에서 현재 버전을 보고, 직접 **업데이트 확인**을 누를 수 있습니다. "앱을 열 때 업데이트 확인"을 끄면 자동 확인을 하지 않습니다.
- 이 기능은 이번 버전부터 들어가서, 0.45.3은 한 번만 예전처럼 직접 설치해 주세요. 다음 버전부터는 앱 안에서 업데이트됩니다.

## 오픈소스 라이선스
- **앱 정보 · 도움말**에 **오픈소스 라이선스**를 넣었습니다. Notesis에 들어 있는 오픈소스 목록이 나오고, 항목을 누르면 라이선스 전문을 볼 수 있습니다.
- 목록: AndroidX·Jetpack Compose·Ink, Kotlin, PdfBox-Android, Bouncy Castle, Backdrop, liquid_glass_easy, SpotiFLAC-Mobile, Reicon 아이콘, 문서 보기 구성 요소(@rhwp/core 등). ML Kit 필기 인식은 Google 약관을 따른다는 안내를 붙였습니다.

## 이름 바꾸기
- 화면 스타일 **리퀴드 글래스**를 **굴절 유리**로 바꿨습니다.
- **Spotiglass**를 **유리 바**로 바꾸고, 설명의 "SpotiFLAC 스타일"을 뺐습니다.
- 굴절 방향 설명의 "Apple식 렌즈"를 "렌즈"로 바꿨습니다.
- 이름만 바뀌었고, 모양과 동작, 저장된 스타일 설정은 그대로입니다.
