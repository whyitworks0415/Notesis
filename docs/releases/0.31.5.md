# Notesis 0.31.5 (versionCode 66)

태블릿에 설치할 서명 APK는 아래 Assets에서 받으세요.

## 긴 문서 / PDF 메모리

- PDF cache를 source당 64~96MB의 byte budget으로 제한했습니다.
- preview, visible full-page, visible tile cache를 역할별로 분리했습니다.
- viewport 밖 full-resolution page와 tile의 strong reference를 제거합니다.
- 주변 prefetch page는 최대 1024px preview만 렌더링합니다.
- dense-page ink raster는 36MB로 제한하고 현재 page ±1 밖의 항목을 제거합니다.
- main/reference custom template을 byte LRU로 cache합니다.
- reference-panel image에 24MB byte LRU를 추가해 draw마다 decode하지 않습니다.
- 기존 lazy page loading과 clean-page unload 구조를 그대로 사용합니다.

stroke, PDF 화면 결과, undo/redo와 저장 형식은 변경하지 않았습니다.

## 태블릿 확인 항목

- [ ] 100~1000 page PDF에서 처음·중간·끝으로 빠르게 이동
- [ ] 같은 이동을 5회 이상 반복하고 PSS/heap이 계속 증가하지 않는지 확인
- [ ] fit-width와 1000% zoom을 반복해 OOM과 tile 누락 확인
- [ ] main note와 reference PDF를 동시에 열고 각각 빠르게 이동
- [ ] image/custom template page 재방문 시 화면과 GC 확인
- [ ] 멀어진 page 재방문 시 preview → 선명한 detail 전환 확인
- [ ] 빠른 page scrub 중 최종 page 우선 렌더 확인
- [ ] background/restore, undo/redo, 저장 후 재열기 확인

## 검증

- cache budget, active-page policy, 1000-page viewport 단위 테스트를 추가했습니다.
- `testDebugUnitTest`, `lintDebug`, debug APK 및 서명 release APK 빌드를 실행했습니다.
- 연결된 Android 기기가 없어 instrumentation과 실제 PSS/OOM stress 측정은 포함되지 않았습니다.
