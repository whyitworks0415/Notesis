# Notesis 0.31.6 (67)

5단계 저장 / 편집 경로 최적화 릴리스입니다. 3단계 렌더 / refine 버전을 기준으로 하며 4단계 PDF 메모리 변경은 포함하지 않습니다.

## 변경 사항

- 동일한 저장 generation의 중복 snapshot/serialize 방지
- 연속 편집 저장 요청을 최신 snapshot 하나로 coalesce
- 참고 패널 autosave에 1.2초 debounce 적용
- 앱 background 및 노트/참고 패널 닫기 시 즉시 flush
- 저장 I/O 실패 최대 3회 재시도
- 기존 저장 포맷 및 undo/redo 동작 유지

세부 분석과 기기 테스트 목록은 `docs/performance-stage5.md`를 참고하세요.
