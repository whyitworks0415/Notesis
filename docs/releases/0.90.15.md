# Notesis 0.90.15 (206)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

## 바뀐 점

### 팝업이 펼쳐질 때 프레임 올리기 (20fps 문제)
- **원인**: 0.90.14에서는 외곽선만 바꿨지만, 매 프레임 화면이 갱신될 때마다 팝업 안의 유리(블러, 렌즈)가 다시 계산되었습니다. 그래서 S6 Lite에서 20fps 근처에 머물렀습니다.
- **바꾼 방식**: 이제 팝업이 펼쳐지거나 접히는 동안에는 **팝업을 한 번 찍은 이미지**를 외곽선으로 잘라서 보여 줍니다.
  - 이미지는 움직이기 직전에 한 번 찍습니다. 닫힐 때는 그 사이 내용이 바뀌었을 수 있어 다시 찍습니다.
  - 렌더 스레드는 텍스처 하나를 잘라 합성만 하면 되고, 유리 효과는 계산하지 않습니다.
  - 다 펼쳐지면 실제 유리로 돌아갑니다.
- **적용 범위**: Functions 메뉴, 도구·펜 패널, 홈의 유리 메뉴, 다이얼로그에 모두 적용됩니다.
- **120fps에 대해**: 앱은 화면이 그리는 만큼 따라갑니다. **S6 Lite 화면은 60Hz라 60fps가 상한**이고, 120Hz 화면에서는 120fps까지 따라갑니다. 실제 수치는 기기에서 측정하지 않았습니다.
- **그림자**: 펼쳐지는 동안 따라붙던 렌더 스레드 그림자는 뺐습니다. 경로 모양 그림자도 프레임마다 계산 비용이 있어서입니다. 그림자는 다 펼쳐진 뒤의 유리 그림자만 남았습니다.

### 펼쳐지는 모양을 더 둥글게
- **비율**: 지금 버전의 사다리꼴 **40%**와 이전 버전의 둥근 물방울 **60%**를 섞었습니다.
- **결과**: 여전히 누른 버튼 쪽이 좁게 시작해 그 버튼에서 나오고 들어가지만, 모서리가 훨씬 둥글고 각지지 않게 펴집니다.
- **모서리 반경**: 사다리꼴 쪽 반경과 물방울 쪽 반경(퍼질 때까지 둥근 상태 유지)을 같은 비율로 섞었습니다.

### 노트 아래쪽 양옆 회색 막대 제거
- **정체**: **화이트보드의 양옆 여백 조절 손잡이**였습니다. 화이트보드가 켜진 노트에서 화면 아래 왼쪽과 오른쪽에 6×48dp 회색 막대로 보였고, 끌면 페이지 양옆 여백이 바뀌었습니다.
- **조치**: 손잡이를 지웠습니다. 같은 값은 노트 보기 설정의 **"양옆 여백(Room either side)"** 슬라이더로 계속 조절할 수 있습니다.

### 페이지 패널과 레이어 패널 부드럽게
- 설정 사이드바와 같은 방식으로 바꿨습니다.
  - 레이어 이동으로 미끄러지므로 프레임마다 레이아웃을 다시 계산하지 않습니다.
  - 패널의 유리는 멈출 자리의 페이지를 처음부터 보고, 미끄러지는 동안 다시 블러하지 않습니다.
  - 움직이는 동안 페이지 배경도 다시 기록하지 않습니다.
- 펜으로 쓰기 시작해 페이지 패널이 닫힐 때는 지금처럼 바로 닫힙니다.

## 확인한 것
- CI에서 빌드, 단위 테스트, 스크린샷 테스트를 돌렸습니다.
- 단위 테스트로 펼침 외곽선을 확인합니다.
  - 버튼 쪽이 좁게 시작하고, 이전보다 둥글며, 다 열리면 패널과 같은지
  - 위·아래·옆 방향
- **기기(태블릿)에서는 시험하지 못했습니다.** 실제 프레임 수는 측정하지 않았습니다.
  - **설정 › 모양 › 모션**의 "늦은 프레임"으로 확인해 주세요.

## 하지 않은 것
- 펼쳐지는 동안 내용이 서서히 나타나는 효과는 뺐습니다. 이미지 한 장으로 그리기 때문에, 내용은 처음부터 유리와 함께 보입니다.

## 태블릿에서 해볼 것
1. 설정 › 모양 › 모션에서 "늦은 프레임"을 초기화합니다.
2. Functions 메뉴, 펜 패널, 홈 메뉴, 다이얼로그를 여러 번 열고 닫아 봅니다.
   - 부드러운지 봅니다.
   - 덜 각지게, 둥글게 펴지는지 봅니다.
3. 화이트보드가 켜진 노트를 열고 아래쪽 양옆 회색 막대가 없어졌는지 봅니다.
4. 페이지 패널과 레이어 패널을 열고 닫아 봅니다.
5. "늦은 프레임" 숫자를 알려 주세요.
