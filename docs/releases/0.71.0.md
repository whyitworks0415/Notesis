# Notesis 0.71.0 (158)

## Markdown 편집을 Obsidian처럼
Obsidian 앱 자체는 공개된 소스 코드가 없습니다. GitHub에는 플러그인용 API 정의 같은 주변 도구만 MIT로 공개되어 있습니다. 그래서 코드를 가져오지 않고, Obsidian의 사용 방식을 참고해 Notesis용으로 새로 만들었습니다.

### 세 가지 보기
- **Live**(기본)
  - 쓰는 중인 줄만 `#`, `**`, `[[ ]]` 같은 기호가 보이고, 나머지 줄은 기호가 숨겨진 채 완성된 모양으로 보입니다.
  - 제목은 크게, 굵게/기울임/취소선/하이라이트(`==`)/코드는 그 모양대로 보입니다.
  - 목록 `-`는 `•`로, 할 일 `- [ ]`은 `☐`/`☑`로, `---`는 선으로 보입니다.
- **Source**: 모든 기호가 그대로 보이고, 기호만 흐리게 색칠됩니다.
- **Read**: 읽기 화면입니다.
  - 제목, 목록, 인용, 코드 블록, 표, 구분선, 맨 위 속성(front matter)이 정리되어 보입니다.
  - 할 일 체크박스를 탭하면 체크/해제되고, 원본 `.md` 파일에도 반영됩니다.
  - `[[링크]]`와 웹 링크를 탭하면 열립니다.
- 마지막으로 쓴 보기 방식을 기억합니다.

### 쓰기 편의
- 목록, 번호 목록, 할 일, 인용에서 Enter를 누르면 **다음 줄도 같은 형식**으로 이어집니다. 번호는 1씩 늘어납니다. 빈 항목에서 Enter를 누르면 목록이 끝납니다.
- 아래 **서식 막대**: B, I, S, ==, 코드, H(누를 때마다 #→##→###→없음), •, 1., ☐, 인용, [[ ]], 웹 링크.
  - 선택한 글자에 적용하고, 다시 누르면 해제됩니다.
- 위에 단어 수와 저장 상태(Saved / Editing)가 보입니다. 쓰는 것을 멈추면 곧바로 저장되고, 나갈 때도 저장됩니다.

### 노트 연결
- `[[`를 치면 **연결할 노트 이름이 추천**됩니다. 없는 이름을 고르면 그 이름으로 새 노트가 만들어집니다.
- 커서가 `[[링크]]` 안에 있으면 **Open “이름”** 버튼이 나타납니다.
- 링크를 따라가면 그 노트가 열리고, **뒤로 가기**로 왔던 노트로 차례대로 돌아갑니다.
- **Links**: 이 노트를 가리키는 다른 노트(백링크), 이 노트가 가리키는 노트, 태그(`#태그`)를 보여 줍니다.
- **Outline**: 제목 목록입니다. 누르면 그 위치로 이동합니다.
- `[[이름|별칭]]`, `[[이름#제목]]` 형식도 읽습니다.

### Markdown 폴더(볼트) 열기
- 홈의 + 버튼 → **Markdown folder (vault)** → 태블릿의 폴더(예: Obsidian 볼트 폴더)를 고르면 그 안의 `.md` 파일이 하위 폴더까지 모두 목록으로 나옵니다.
  - 이름 검색, 최근순/이름순 정렬, **New note**로 새 파일 만들기를 할 수 있습니다.
- 파일을 **복사하지 않고 그 자리에서** 읽고 씁니다. 같은 파일을 Obsidian 등 다른 앱에서도 그대로 열 수 있습니다.
- `.obsidian`, `.trash`처럼 점(.)으로 시작하는 폴더는 건드리지 않습니다.
- 처음 한 번만 폴더를 고르면 다음부터 바로 열립니다. 다른 폴더로 바꾸려면 **Change folder**를 누르면 됩니다.
- 라이브러리 안의 Markdown 노트끼리도 `[[링크]]`, 백링크가 똑같이 동작합니다.

## 기기에서 확인할 것
- 이 버전은 CI 빌드와 단위 테스트(Markdown 해석·편집 16개)만 거쳤고, 실제 태블릿에서는 확인하지 못했습니다.
