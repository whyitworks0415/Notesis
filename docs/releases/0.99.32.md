# Notesis 0.99.32 (273)

- iOS 유리의 맑은 층을 기기 원본 해상도로 그립니다. 노트가 움직일 때 축소된 픽셀 격자에서 가는 필기선이 깜박이는 경우를 줄였습니다. 맑은 층을 끄고 서리층만 쓰면 절반이나 4분의 1 해상도를 계속 선택할 수 있습니다.
- 유리 배경의 첫 기록과 화면 크기가 바뀐 뒤의 첫 기록은 갱신을 멈춘 상태에서도 준비합니다. 서리층의 축소 버퍼 크기를 반올림하더라도 렌즈는 실제 크기를 쓰며, 배치 좌표를 기다리는 동안 유리의 바탕색이 표시됩니다.

릴리스 CI에서 APK 빌드, Android 호환성 검사, 단위 테스트와 UI 스크린샷 테스트를 실행합니다. 실기기에서의 깜박임과 프레임 시간은 측정하지 않았습니다.

태블릿에서는 iOS 모드로 가는 필기선이나 줄무늬가 있는 페이지를 열고 툴바 아래로 스크롤·확대해 보세요. 팝업을 여닫거나 화면 방향을 바꾼 직후에도 유리 뒤 배경을 확인해 주세요.
