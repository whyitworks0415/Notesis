## 바뀐 점

### 1. Markdown 편집기를 Obsidian·Notion식으로 새로 만듦 (E1)

**Live 모드는 블록 편집기가 됐습니다.**
- 노트가 블록으로 나뉘고, 각 블록은 읽히는 모양으로 보입니다. 제목, 중첩 목록, 누를 수 있는 체크박스, 콜아웃(접기 포함), 중첩 인용, 정렬된 표, 색이 입혀진 코드(복사 버튼), 수식, 그림, 속성(front matter), 각주가 모두 그려집니다.
- 누른 블록만 `#`, `**` 같은 표시가 보이며 편집됩니다. 나머지는 계속 읽히는 모양입니다.
- Enter를 누르면 다음 블록이 생기고, 블록 맨 앞에서 지우기를 누르면 위 블록과 합쳐집니다.
- **`/` 메뉴**: 빈 줄이나 공백 뒤에서 `/`를 치면 만들 블록을 고를 수 있습니다. 제목 1~3, 목록, 번호 목록, 할 일, 인용, 콜아웃(팁·경고), 토글, 코드, 수식, 표, 구분선, 노트 링크, 그림, 각주, 오늘 날짜, 주석. 한글로도 찾습니다(`/표`, `/코드`).
- **블록 손잡이**: 편집 중인 블록 왼쪽의 `⋮⋮`를 누르거나 블록을 길게 누르면 다른 종류로 바꾸기, 위·아래로 옮기기, 복제, 복사, 삭제를 할 수 있습니다.
- **제목 접기**: 제목 왼쪽의 ▾를 누르면 그 아래 내용이 다음 같은 단계 제목까지 접힙니다.
- **표 편집**: 표를 누르면 칸마다 바로 입력할 수 있고, 행·열 추가와 삭제, 열 정렬을 할 수 있습니다. 저장할 때 열 너비를 한글 폭까지 맞춰 줍니다. "텍스트로 편집"으로 원문을 고칠 수도 있습니다.
- **그림 넣기**: 툴바의 그림 버튼이나 `/그림`으로 갤러리에서 넣으면 노트와 함께 보관되고 `![[이름]]`으로 들어갑니다. 라이브러리 노트는 노트 폴더 안 `files/`에, 보관함(vault) 노트는 그 폴더 맨 위에 둡니다. `![[그림.png|300]]`처럼 폭도 지정할 수 있습니다.
- **되돌리기·다시 하기**: 툴바 맨 앞에 생겼습니다. 타자는 단어 단위로 한 번에 되돌아갑니다.
- **키보드**: Ctrl+Z / Ctrl+Y(또는 Ctrl+Shift+Z) / Ctrl+B / Ctrl+I / Ctrl+K(링크) / Ctrl+E(코드), Tab·Shift+Tab으로 목록 들여쓰기·내어쓰기. 위·아래 화살표로 블록 사이를 옮겨 다닙니다. 툴바에도 들여쓰기·내어쓰기와 표 버튼이 생겼습니다.
- 뒤로 가기를 누르면 먼저 편집 중인 블록이 닫힙니다.

**Markdown 문법을 규칙대로 처리합니다.**
- CommonMark 규칙을 따릅니다. `***굵은 기울임***`, 단어 안의 `_`(snake_case)은 기울임이 아님, `\*` 이스케이프, 코드 안 표시는 무시, 참조 링크(`[글][이름]`), `<주소>`와 맨 주소 자동 링크, 두 줄 제목(`===`, `---`), 4칸 들여쓴 코드.
- Obsidian 문법도 처리합니다. `[[링크|별칭]]`, `[[노트#제목]]`, `![[그림]]`, `==형광==`, `%%주석%%`, `$수식$`(`$5`는 돈으로 둠), `[^각주]`, `#태그`, 콜아웃 `> [!tip]`.
- 일부 HTML도 처리합니다: `<u>`, `<sub>`, `<sup>`, `<kbd>`, `<mark>`, `<br>`.

**읽기(Read) 모드**는 PDF 만들기에 쓰던 marked·KaTeX·highlight.js로 그립니다. GitHub·Obsidian, 그리고 PDF와 같은 모양입니다. 링크를 누르면 따라가고, 체크박스를 누르면 원문이 바뀌고, 각주를 누르면 아래 각주로 갑니다. 코드에는 복사 버튼이 있습니다.

**Source 모드**는 그대로이며 되돌리기와 단축키가 추가됐습니다. 여러 블록에 걸친 선택은 Source에서 하세요.

### 2. 버그 수정: 줄 중간의 `%%`, `$$`
- 줄 중간에 `%%`나 `$$`가 있으면 문단이 거기서 끊기고 주석이 보이던 문제를 고쳤습니다. **Markdown → PDF 만들기**에도 같은 문제가 있었고 함께 고쳤습니다.

### 3. AI 채팅에 노트 보내기 (P1~P3)
- 인터넷 패널에서 AI 채팅을 열고 노트 옆 메뉴로 보낼 수 있습니다.
  - 범위: 이 페이지 / 페이지 지정(`1-3, 5`) / 전체
  - 필기 포함 켜기·끄기(끄면 PDF나 종이만)
  - 형식: PDF / 그림(그림은 한 페이지만)
  - 손글씨 인식 결과가 있으면 텍스트 파일로 함께 보냄
- 파일은 채팅 입력창에 바로 붙입니다. 6MB가 넘으면 채팅의 **+ › Files**에서 고를 수 있게 넘깁니다.

### 4. 노트 명령 코어 (C1, C2 일부)
- `notesis` 명령을 처리하는 내부 코어를 만들었습니다(노트 목록·읽기·이름·폴더·태그·휴지통, 페이지 추가·삭제·이동, 목차, 글·필기 넣기·지우기, 내보내기, 되돌리기). 결과는 JSON입니다.
- 안전 장치: 화면에 열린 노트는 읽기만, 삭제는 휴지통으로만, 여러 줄 중 하나가 실패하면 전부 되돌림, `undo` 한 번에 묶음 전체가 되돌아감.
- **아직 앱 화면에서 부를 곳은 없습니다.** 터미널 패널(T1)이나 MCP 연결(C3)을 만들면 쓸 수 있습니다.

## 확인 방법

- 이 컨테이너에서 앱과 시험을 직접 빌드했고, 단위·Robolectric 시험 775개가 모두 통과했습니다.
- 새 시험: Markdown 블록 나누기와 문법 규칙(강조 짝맞추기, 이스케이프, 링크 종류, 수식·각주·태그·HTML), 표 읽기·고치기·다시 쓰기, `/` 메뉴, 블록 옮기기·복제·삭제·바꾸기, 체크박스, 되돌리기, 그림 넣기, 읽기 화면이 접근할 수 있는 주소. 명령 코어는 메모리 위 노트와 실제 노트 파일로 시험했습니다.
- Live 화면은 시험 안에서 그림으로 찍어 직접 봤습니다. 블록이 읽히는 모양으로 그려지는 것, 누른 블록이 표시와 함께 열리는 것, 입력이 노트에 들어가는 것, 체크박스가 원문을 바꾸는 것을 확인했습니다.
- 읽기 화면은 컴퓨터용 Chromium에서 모든 문법이 든 견본 노트로 확인했습니다.

## 하지 않은 것

- **태블릿에서는 써 보지 못했고, 아무것도 재지 않았습니다.** 특히 블록이 바뀔 때 키보드가 깜빡이는지, 한글을 조합하는 중에 Enter·지우기가 자연스러운지는 기기에서만 알 수 있습니다.
- Android 웹뷰의 읽기 화면과 수식 블록, 갤러리에서 그림 넣기, 실제 AI 채팅 사이트에 파일을 붙이는 것은 기기에서 해 보지 못했습니다.
- 처음엔 Obsidian과 같은 편집기 라이브러리(CodeMirror 6)를 쓰려 했으나, 이 작업 환경에서 새 외부 코드 설치가 막혀 앱 안에서 직접 만들었습니다.
- 아직 없는 것: 블록을 끌어서 옮기기, 여러 블록에 걸친 선택(Source에서는 됨), 노트 안 찾기·바꾸기, Live에서 줄 중간 그림을 그림으로 보여 주기(그림만 있는 줄은 그림으로 보임), PDF 만들기에서 노트 그림 보이기.
- xlsx·docx·pptx·hwpx 편집(E2~E6)과 터미널(T1)은 아직입니다.
