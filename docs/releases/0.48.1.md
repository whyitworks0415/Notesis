# Notesis 0.48.1 (126)

## 노트·설정을 열면 앱이 꺼지던 문제
- **원인:** 0.48.0에서 Liquid glass 스킨의 도구막대, 기능 메뉴, 펜 설정 창의 유리를 굴절 효과로 바꿨습니다. 그런데 이 유리에 쓴 모서리 모양을 유리 라이브러리의 굴절 효과가 지원하지 않아서, 처음 그리는 순간 오류로 앱이 꺼졌습니다.
- **설정 화면도 꺼진 이유:** UI 화면 설정과 도구 편집의 미리보기가 같은 도구막대를 그리기 때문입니다.
- **Material·Glassmorphism:** 이 문제가 없었습니다.
- **수정:** 굴절 유리에 넘기는 모양을 같은 반지름의 둥근 모서리로 바꿨습니다. 앞으로 지원하지 않는 모양이 들어오면 굴절 없이 그리도록 막아 두었습니다.
- **달라 보이는 점:** Liquid glass 유리 패널의 모서리가 0.47.5처럼 일반 둥근 모서리로 그려집니다.
