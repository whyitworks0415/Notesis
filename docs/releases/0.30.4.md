# Notesis 0.30.4 (versionCode 60)

태블릿에 설치할 서명 APK는 아래 Assets에서 받으세요.

이번 버전은 획이 많은 페이지의 잉크 렌더링에 제한된 비트맵 캐시를 추가하고, 확대 후 메시 재생성 대상을 화면에 보이는 획으로 좁혔습니다. 펜과 형광펜의 팁을 원형·중앙 정렬로 바꾸고, 사각형·화살표를 선분별로 생성하되 한 번에 실행 취소·다시 실행되도록 묶었습니다. 펜 설정에 0~100% 획 보정을, 형광펜 설정에 필기 위·아래 표시 선택을 추가했습니다.

AI 패널은 너비를 드래그하는 동안 윤곽을 표시하고 손을 떼면 크기를 적용합니다. 키보드가 화면 전체를 이동시키는 현상을 줄이기 위해 창의 입력 모드를 `adjustResize`로 고정했습니다. 팝업노트도 크기 조절 중에는 윤곽을 표시하고 손을 뗐을 때 실제 크기를 적용합니다. 디버그 표시에는 화면의 획 수, 그리기 시간, 확대율을 추가했습니다.

`testDebugUnitTest`와 서명된 Release APK 빌드는 통과했습니다. 연결된 Android 기기가 없어 실제 펜·키보드·팝업 동작과 프레임 시간 개선은 검증하지 못했습니다. AI 모드의 그 밖의 불편함은 구체적인 재현 절차가 없어 이번 릴리스에 포함하지 않았습니다.
