# Notesis 0.90.19 (210)

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 정적 아이콘으로 통일

- 모든 스킨의 기본 아이콘을 기존 Material 모드에서 쓰던 **Material Symbols Rounded**로 통일했습니다. 스킨을 바꿔도 아이콘 세트가 강제로 바뀌지 않습니다.
- **Reicons 선택지는 유지**합니다. 모양 설정의 Icon set에서 선택하면 Material을 포함한 모든 스킨에 적용되며 저장됩니다.
- AnimateIcons/Lucide 아이콘 데이터·재생기·재생용 상태와 애니메이션 설정을 제거했습니다. 관련 라이선스 항목과 사용하지 않는 아이콘 의존성도 정리했습니다. 유용한 펼침 화살표 회전이나 컨트롤 자체의 움직임은 유지합니다.
- 기존 AnimateIcons 설정은 더 이상 읽지 않습니다. 새 정적 아이콘 선택이 없으면 Material Symbols로 시작하며 필기·노트·다른 설정은 초기화하지 않습니다.

## Material의 연결된 모션

- **누르기 → 선택 → 패널**을 같은 계열의 스프링으로 맞췄습니다. 아이콘의 선이 따로 재생되는 대신 버튼 전체의 작은 눌림, 선택색의 전환과 도구 선택 표시의 이동이 반응합니다.
- **메뉴·대화상자·사이드바**의 움직임을 통일했습니다. 대화상자는 최근 누른 위치가 있으면 그 방향을 기준으로 나타나고 사라집니다. 메뉴와 대화상자는 92%에서 펼쳐져 과한 확대를 줄입니다.
- **설정의 앞/뒤 이동**은 탐색 스택에 맞는 짧은 가로 이동과 페이드로 구분합니다. 화면 크기를 늘였다 줄이는 방식은 쓰지 않습니다.
- **도중에 방향 바꾸기**: 팝업·사이드바·선택 표시의 마지막 프레임 속도를 보존합니다. Animatable 취소 시 속도가 0으로 초기화되던 경로를 보완했습니다.
- 클릭 처리를 애니메이션이 끝날 때까지 미루지 않습니다. 누름 효과는 그리기에만 적용해 버튼의 실제 터치 영역을 줄이지 않습니다.
- 기존 Motion 속도, 시스템 애니메이션 끔·절전·고대비에 따른 동작을 따릅니다. 필기 입력·노트 스크롤의 물리와 저장 경로는 변경하지 않았습니다.

## 검증

- 정적 아이콘 선택의 저장·마이그레이션·스킨 독립성을 검사합니다.
- Material의 공통 스프링, 60/120Hz 샘플에서의 첫 움직임과 과도한 넘침, 탐색 방향을 단위 테스트합니다. 이는 기기 FPS 측정이 아닙니다.
- Robolectric에서 눌림 도중 터치 영역 유지·클릭 1회 처리, 설정을 빠르게 왕복한 뒤 최신 화면만 남는지 검사합니다.
- 릴리스 빌드·전체 단위 테스트·UI 테스트를 통과해야 기존 배포 키로 서명합니다. 실제 검사 결과는 PR/CI에 기록합니다.

실제 태블릿의 설치·프레임 시간과 애니메이션 체감은 직접 확인하지 못했습니다. Material에서 도구를 빠르게 바꾸기, 팝업을 열었다 바로 닫기, 설정 화면 앞뒤 이동, Reicons 선택 후 스킨 변경을 확인해 주세요.
