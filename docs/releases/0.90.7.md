## 첫 화면 위쪽 버튼, 검색창, 아래 분류 막대의 유리

- **증상:** 0.90.6에서 첫 화면 위쪽 버튼들, 검색창, 아래에 떠 있는 분류 막대(전체·폴더·노트·Markdown)가 유리로 보이지 않았습니다.
- **원인:** 0.90.5에서 스크롤 렉을 줄이려고, 스크롤하는 동안 화면 기록을 멈출 수 있게 기록하는 방식을 바꿨습니다.
  - 바뀐 방식의 기록에는 "화면 어디에 있는지" 정보가 들어가지 않습니다.
  - 그런데 첫 화면의 유리들은 그 위치 정보에 기대어 뒤 화면을 비추고 있어서, 비출 곳을 잡지 못했습니다.
- **고친 것:** 노트 화면이 이미 쓰는 방식처럼, 유리들이 기록의 실제 화면 위치를 따로 받아 맞춰서 비추게 했습니다.
  - 위쪽 버튼, 검색창, 아래 분류 막대가 다시 유리로 보입니다.
  - 스크롤하는 동안 기록을 멈추는 것(렉 줄이기)은 그대로입니다. 스크롤 중에는 유리에 직전 모습이 비치고, 멈추면 바로 맞춰집니다.
- 노트·폴더 카드는 말씀대로 뒤를 비추지 않는 지금 모습 그대로 둡니다.

## 확인한 것 / 못 한 것

- CI 빌드와 단위 테스트까지 확인했습니다.
- 기기에서는 해 보지 못했습니다.

## 태블릿에서 해 볼 것

1. 첫 화면 위쪽 버튼들과 검색창이 유리로 보이는지(뒤 카드와 바탕이 흐리게 비치는지).
2. 아래 분류 막대가 유리로 보이는지.
3. 스크롤하다 멈췄을 때 유리에 바로 아래 카드가 맞게 비치는지.
