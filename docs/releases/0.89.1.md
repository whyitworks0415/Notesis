# Notesis 0.89.1 (190)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## Galaxy Tab S5e가 느려지던 문제

S5e에 설치하자 태블릿 전체가 느려지고, 앱을 지우니 괜찮아졌다는 보고를 받고 코드를 살펴봤습니다. 기기 없이 찾은 것이라 **확실한 원인이라고 말할 수는 없습니다.** 다만 S6 Lite와 다른 점에서 가장 유력한 원인을 찾아 고쳤습니다.

**확인한 것**
- 앱에는 부팅 때 켜지는 기능, 예약 작업, 상시 서비스가 없습니다. 녹음할 때만 서비스가 켜집니다. 앱이 꺼져 있을 때 몰래 도는 작업은 없습니다.
- 메모리 상한은 S6 Lite(4GB)와 같습니다. S6 Lite에서는 문제가 없었으니 메모리만으로는 설명이 되지 않습니다.

**유력한 원인**
- S5e는 **Android 11**이고 화면이 **2560×1600**(S6 Lite보다 약 1.7배 많은 픽셀)입니다. 6GB 모델도 있습니다.
- 앱은 메모리가 약 5GB 미만인 기기와 S6 Lite만 "느린 기기"로 보고 **가벼운 모드**를 기본으로 켰습니다. 6GB S5e는 여기에 걸리지 않아 모든 효과가 켜진 채로 돌았을 수 있습니다.
- 그런데 Liquid glass 셰이더는 **Android 13부터만** 동작합니다. 그래서 Android 11에서는 유리 효과는 그려지지도 않으면서, 유리 뒤에 비칠 화면 전체를 매 프레임 한 번 더 기록하는 일만 했습니다. 오래된 GPU가 큰 화면을 두 번씩 그리며 계속 부하가 걸리고 기기가 뜨거워지면, 다른 앱까지 느려질 수 있습니다.

**바꾼 것**
- **Android 12 이하 기기는 처음 설치할 때 가벼운 모드가 기본으로 켜집니다.** 메모리와 상관없습니다. 가벼운 모드에서는 유리를 단색으로 그리고 화면 기록을 하지 않으며, 미리 읽는 페이지와 백그라운드 작업도 줄입니다. 설정의 **Light mode**에서 끌 수 있습니다.
- 이미 설치된 기기에서는 사용자가 정한 값을 그대로 둡니다. S5e는 앱을 지웠으니 다시 설치하면 새 기본값이 적용됩니다.

**그래도 느리면**: **About · Help → Diagnostics**의 보고서를 복사해 보내 주세요. 기기 모델, Android 버전, 메모리, 가벼운 모드 여부, 백그라운드 작업이 들어 있어 원인을 좁힐 수 있습니다. 기기 설정 → 디바이스 케어 → 배터리에서 Notesis가 얼마나 썼는지도 함께 알려 주시면 좋습니다.

## 베타 테스터(개발자 코드)

- **About · Help → 개발자 코드 입력**에 코드를 넣으면 베타 테스터가 됩니다.
  - **베타 테스터:** 지금처럼 수동 업데이트(테스트 빌드)도 받습니다. 수동 업데이트는 따로 알리지 않고 About · Help에서 기다리며, 자동 업데이트는 앱을 열 때 알려 줍니다.
  - **베타 테스터가 아닌 경우:** 수동 업데이트는 아예 보이지 않고, **자동 업데이트만** 앱을 열 때 알려 줍니다. **Check for updates**를 눌러도 최신 자동 업데이트만 찾습니다.
- 코드는 **대소문자를 구분**하고, 앞뒤 공백만 무시합니다. 앱에는 코드 자체가 아니라 코드의 해시(SHA-256)만 들어 있습니다. 테스트 빌드는 원래 공개된 릴리스이므로 보안 장치가 아니라 일반 사용자에게 안 보이게 하는 장치입니다.
- **테스트 빌드 그만 받기**를 누르면 일반 사용자로 돌아갑니다.
- **주의:** 이 버전부터 수동으로 낸 업데이트는 베타 테스터에게만 보입니다. 이 버전을 설치한 뒤 **개발자 코드를 한 번 넣어 주세요.** 그러지 않으면 다음 수동 업데이트가 보이지 않습니다. 일반 사용자에게 내보낼 버전은 CI를 `update: automatic`으로 돌리면 됩니다.

## 확인한 것 / 못 한 것

- CI에서 릴리스 빌드와 단위 테스트를 돌렸습니다. 추가한 테스트: Android 12 이하는 가벼운 모드(`DeviceClassTest`), 베타 테스터와 일반 사용자가 받는 버전 및 코드 확인(`AppUpdateTest`).
- **S5e에서 직접 확인하지 못했습니다.** 이번 수정으로 느려짐이 사라졌는지는 S5e에 다시 설치해 봐야 알 수 있습니다.

## 태블릿에서 해 볼 것

1. S5e에 새로 설치한 뒤 설정에서 **Light mode**가 켜져 있는지, 이전처럼 기기 전체가 느려지는지.
2. 느리면 About · Help → Diagnostics 보고서를 복사해 보내기.
3. About · Help에서 개발자 코드를 넣고 "베타 테스터" 문구로 바뀌는지, 틀린 코드에 오류가 뜨는지.
