# Notesis 0.49.2 (130)

## 팝업이 누른 곳에서 빨려 나오고, 빨려 들어갑니다
- 기능 메뉴와 펜 설정 창이 누른 지점에서 아주 작게 시작해 빠르게 펼쳐지고, 부드럽게 멈춥니다(0.24초).
- 닫을 때는 같은 지점으로 빨려 들어가듯 접힙니다. 처음엔 천천히, 끝으로 갈수록 빠르게 움직입니다(0.18초).
- 이전처럼 가로와 세로가 따로 다른 속도로 커지거나 튕기지 않습니다. 하나의 모양 그대로 커지고 줄어들어서 눈이 덜 피곤합니다.
- 열리고 닫힐 때 함께 나오던 유리 렌즈 일렁임을 없앴습니다. 메뉴 안에서 페이지를 바꿀 때만 나옵니다.
- Liquid glass와 Glassmorphism에 적용됩니다. Material은 애니메이션 없이 바로 나타납니다.
