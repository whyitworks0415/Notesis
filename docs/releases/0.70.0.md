# Notesis 0.70.0 (157)

## 페이지 보기(페이지 패널) 개선

### 미리보기가 느리고 흐리던 문제
- **흐림**: 미리보기를 항상 가로 320px로 그린 뒤 카드 크기로 늘려서 흐렸습니다. 이제 **카드의 실제 크기**(화면 밀도 반영)로 그립니다. 패널 폭이 조금 바뀌어도 다시 그리지 않도록 64px 단위로 맞춥니다.
- **느림**
  - 카드마다 0.12초 간격으로 "다 그렸나?"를 다시 물어보던 방식을 없애고, **다 그려지는 즉시** 카드에 나타나게 했습니다.
  - 미리보기를 그리는 작업의 우선순위를 "가장 낮음"에서 "백그라운드"로 올렸습니다.
  - **가장 최근에 요청한 카드부터** 그립니다. 패널을 빠르게 넘긴 뒤에는 지금 화면에 보이는 페이지가 먼저 나옵니다.
  - 스크롤해서 지나간 페이지는 아예 그리지 않습니다.
- 새로 그리는 동안 카드가 비지 않고 **이전 그림을 그대로 보여 줍니다**. 필기 후나 열 수를 바꾼 뒤에도 마찬가지입니다.
- 미리보기 메모리를 절반으로 줄여(흰 종이라 투명도 정보가 필요 없음) 같은 메모리에 두 배 많은 페이지를 보관합니다.

### 꾹 눌러서 선택, 여러 장 편하게 선택
- 페이지 카드를 **꾹 누르면 선택 모드**로 들어가고, 그 페이지가 선택됩니다.
- **손으로 쭉 드래그**: 꾹 누른 채로 손가락을 움직이면 지나가는 페이지가 모두 선택됩니다. 목록 위/아래 끝으로 가면 자동으로 스크롤됩니다. 이미 선택된 페이지에서 시작하면 반대로 선택이 풀립니다.
- **n부터 n까지**
  - 선택 모드에서 한 페이지를 탭하고 다른 페이지를 꾹 누르면 **그 사이가 전부** 선택됩니다.
  - 상단의 **Range** 버튼으로 "From ~ To" 페이지 번호를 입력해 고를 수도 있습니다.
- 선택 막대에 **"N selected"**, **All / None** 버튼을 추가했습니다. 한 장만 선택했을 때는 **More**로 그 페이지의 메뉴(북마크, 첨부, 목차, 배경, 회전 등)가 열립니다. 예전에는 꾹 누르면 바로 이 메뉴가 열렸습니다.
- 선택된 카드는 색으로도 표시됩니다. TalkBack에서는 "Selected / Not selected"로 읽고, 길게 누르기 동작으로 선택할 수 있습니다.

## 사이드바를 끝까지 밀어 넣을 때 커졌다가 들어가던 문제
- 페이지 패널과 설정 사이드바의 안쪽 가장자리를 끝까지 밀어서 닫으면, 닫히는 순간 원래 폭으로 되돌아갔다가 미끄러져 나가서 중간에 커지는 것처럼 보였습니다.
- 이제 **손가락을 뗀 그 폭 그대로** 밀려 나갑니다.

## 파일 → PDF 변환 개선 (Convert to PDF)

### 실제 파일 모양 그대로
- 지금까지는 파일에서 글자만 뽑아 새로 배치해서 PDF를 만들었기 때문에 원래 파일과 모양이 달랐습니다.
- 이제 **문서 보기(Document view)에 보이는 모습 그대로** PDF로 만듭니다. HWP/HWPX, PPT/PPTX, XLS/XLSX, Markdown, 텍스트 파일이 해당됩니다.
  - **Markdown**: 제목, 굵게/기울임/취소선, 인라인 코드, 링크, 목록(중첩 포함), 인용, 표, 코드 블록, 구분선이 실제 Markdown 모양으로 나옵니다. `**`, `#` 같은 기호가 그대로 찍히지 않습니다.
  - **HWP, 슬라이드**: 페이지마다 **원래 페이지 크기**로 한 장씩 들어갑니다 (예: 16:9 슬라이드는 16:9 페이지).
  - **엑셀**: 지금 보고 있는 시트를 페이지 너비에 맞게 줄여서 잘리지 않게 넣습니다. Landscape(가로)로 하면 더 크게 나옵니다.
- Word(DOC/DOCX)는 문서 보기가 없어서 예전처럼 글자를 다시 배치하는 방식이고, 아래 크기·여백 설정만 적용됩니다.

### 변환 전에 크기 조절과 "글자 내리기"
- "Convert to PDF"를 누르면 바로 변환하지 않고 **PDF layout** 화면이 먼저 나옵니다.
  - **용지**: A4 / Letter / A5, **방향**: Portrait / Landscape (페이지 크기가 정해진 HWP·슬라이드는 원래 크기를 씀)
  - **글자 크기**: A− / A+ 로 60%~180% (Markdown·텍스트)
  - **여백**: Narrow / Normal / Wide
- **글자 내리기**: Markdown·텍스트 문서에서 문단(제목, 표, 코드 블록 등)을 탭하면 **그 문단부터 새 페이지**에서 시작합니다. 파란 점선과 "New page" 표시가 붙고, 다시 탭하면 취소됩니다.
- 자동으로도 잘림을 줄입니다: 코드 블록·인용·표의 행·그림·목록 항목은 페이지 중간에서 잘리지 않게 다음 페이지로 넘기고, 제목이 페이지 맨 아래에 혼자 남지 않게 합니다.
- **Preview**로 완성될 PDF를 페이지별로 먼저 보고, **Adjust**로 돌아가 고치거나 **Create note**로 노트를 만듭니다.
- 기기가 앱이 직접 PDF 파일로 인쇄하는 것을 막는 경우에는, 시스템 인쇄 화면이 열립니다. 거기서 "PDF로 저장"한 뒤 그 PDF를 Notesis에서 열면 됩니다.

## 기기에서 확인할 것
- 이 버전은 CI 빌드와 단위 테스트만 거쳤고, 실제 태블릿에서는 확인하지 못했습니다.
- PDF 인쇄 결과는 같은 렌더링 엔진(Chromium)으로 PC에서 Markdown·슬라이드·엑셀 샘플을 만들어 모양을 확인했습니다. 안드로이드 WebView에서 파일로 바로 인쇄되는지는 기기에서 확인이 필요합니다.
