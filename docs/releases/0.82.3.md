# Notesis 0.82.3 (176)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 업데이트를 소스 저장소가 private이어도 받을 수 있게
- 지금까지 앱은 소스 저장소(`Notesis`)의 릴리스만 봤습니다. 이 저장소를 private으로 바꾸면 로그인하지 않은 앱은 릴리스를 볼 수도, APK를 받을 수도 없습니다.
- 이제 앱은 **릴리스 전용 저장소**(`Notesis-releases`)를 먼저 보고, 그다음 소스 저장소를 봅니다. 두 곳에서 찾은 것 중 **가장 새로운 빌드**를 씁니다. 같은 빌드가 두 곳에 있으면 한 번만 나옵니다.
- 한쪽을 읽지 못해도(없거나, private이거나, 인터넷 문제) 다른 쪽에서 찾은 것으로 계속 동작합니다.
- 화면에서 달라지는 것은 없습니다. 자동 업데이트, 수동 업데이트(About · Help) 모두 지금처럼 동작합니다.

## 빌드 설정
- 빌드가 끝나면 릴리스를 소스 저장소에 올리고, 접근 토큰(`RELEASES_TOKEN`)이 설정되어 있으면 릴리스 전용 저장소에도 같은 릴리스를 올립니다. 토큰이 없으면 둘째 단계는 건너뜁니다.
- 설정 방법은 저장소의 `docs/private-repo-releases.md`에 적었습니다.

## 중요: 이 버전부터 새 주소를 압니다
- 0.82.2 이하 앱은 소스 저장소만 봅니다. **소스 저장소를 private으로 바꾸기 전에** 모든 기기를 이 버전(0.82.3) 이상으로 업데이트하세요.

## 확인 방법
- 단위 테스트: 여러 저장소의 릴리스를 합치는 규칙(중복 제거, 최신순, 한쪽이 비었을 때)
- 기기에서는 확인하지 못했습니다. 릴리스 전용 저장소가 아직 없어서, 이 버전의 앱은 소스 저장소에서 업데이트를 찾습니다.

## 기기에서 확인할 것
- About · Help → Check for updates가 지금처럼 최신 버전을 찾는지
