## 노트 밖(화이트보드)에도 텍스트 상자
- 지금까지 노트 밖에는 필기·테이프·올가미·도형만 쓸 수 있었습니다. 텍스트 상자는 놓을 수 없었고, 저장할 곳도 없었습니다.
- 이제 **텍스트 도구로 노트 밖을 탭하면** 그 자리에 바로 글을 쓸 수 있습니다. 노트 안과 같은 입력 방식입니다.
- 노트 밖 텍스트 상자도 노트 안과 똑같이 다룰 수 있습니다.
  - 탭하면 선택되고, 끌면 옮겨지고, 오른쪽 아래 손잡이로 크기를 바꿉니다.
  - 한 번 더 탭하면 고쳐 쓸 수 있습니다.
  - 지우기와 되돌리기도 됩니다.
- 노트와 함께 저장되고, 다시 열면 같은 자리에 있습니다.
- 노트 밖 필기 아래에 그려집니다. 노트 안에서 텍스트 상자가 필기 아래에 있는 것과 같습니다.
- 노트 밖을 영역 캡처하면 텍스트 상자도 함께 찍힙니다.
- 그림 넣기는 지금처럼 페이지 가운데로 들어옵니다.

## 어떻게 확인했나
- 빌드, 축소(R8) 릴리스 빌드, Android 버전 검사(Lint), 네이티브 커널 점검, 전체 단위 테스트(158개 클래스)를 통과했습니다.
- 노트 밖 텍스트 상자가 저장되고 같은 자리·같은 내용으로 다시 읽히는지 테스트를 추가했습니다.

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 직접 써 보지 않았습니다.**
- 노트 밖 텍스트 상자는 아직 다음에 들어가지 않습니다.
  - 노트 안 검색, 페이지 패널
  - 에이전트 명령(`text list` 등)
  - PDF 내보내기

## 태블릿에서 해 볼 것
1. 화이트보드를 켠 노트에서 텍스트 도구로 페이지 바깥을 탭하고 글 쓰기.
2. 쓴 텍스트 상자를 옮기고, 크기를 바꾸고, 두 번 탭해서 고치기.
3. 노트를 닫았다 열기: 같은 자리에 남아 있는지.
4. 되돌리기·다시 하기.
