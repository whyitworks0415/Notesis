## 노트 합치기(Merge) 오류 수정
- **증상**: 노트 여러 개를 선택해서 **Merge**를 누르면 "Couldn't merge the notes"만 나오고 합쳐지지 않았습니다.
- **원인**
  - 합칠 때 각 노트의 PDF 페이지를 새 PDF로 가져옵니다. 가져온 페이지는 원본 PDF 파일에서 내용을 계속 읽습니다.
  - 그런데 원본 PDF를 페이지를 가져오자마자 닫고, 합친 PDF는 그 뒤에 저장했습니다. 저장할 때 이미 닫힌 파일을 읽으려다 실패했습니다.
  - 그래서 **PDF 페이지가 들어 있는 노트**를 합치면 항상 실패했습니다. 손으로만 쓴 노트끼리는 이 오류가 없습니다.
- **수정**: 합친 PDF를 저장한 뒤에 원본 PDF를 닫습니다. 같은 일을 하는 "페이지를 다른 노트로 보내기"는 처음부터 이 순서였습니다.

## 함께 고친 것
- **실패하면 이유를 알려 줍니다.** "Couldn't merge the notes: …" 뒤에 원인이 붙습니다. 이유를 알 수 있으면 다음에 고치기 쉽습니다.
- **원본 PDF가 없거나 페이지 수가 모자란 경우** 합치기 전체가 실패하지 않고, 그 페이지만 빈 페이지로 바뀝니다.
- **연습 페이지**(페이지 옆에 붙인 페이지)가 합친 뒤에도 원래 페이지 옆에 붙어 있습니다. 전에는 연결이 끊겨 따로 떨어진 페이지가 되었습니다.

## 그대로인 것
- 합친 노트의 **레이어 구조**는 합치기 전 노트의 것을 가져오지 않고 기본 레이어 하나로 시작합니다. 잉크는 모두 남고, 레이어 이름·숨김·잠금 설정만 사라집니다. 노트마다 레이어 번호가 겹쳐서 간단히 합칠 수 없습니다.
- Markdown 노트는 합칠 수 없습니다(필기 노트만 가능).

## 확인 방법
- 빌드와 기존 단위 테스트만 확인했습니다. 합치기는 기기에서 PDF 처리가 필요해서 단위 테스트로 돌리지 못했습니다.
- 에뮬레이터나 기기에서는 확인하지 못했습니다.

## 기기에서 확인할 것
- PDF 페이지가 들어 있는 노트 두 개 이상을 선택해 Merge가 되는지, PDF 페이지가 그대로 나오는지
- 손으로만 쓴 노트끼리도 합쳐지는지
- 합쳐지지 않으면 나오는 문구(이유)를 알려 주세요.
