## 첫 화면 (그림대로)
- **위쪽**
  - 맨 위에서는 "Notes · N notes"와 검색창이 목록 안에 있고, 버튼 줄(선택 ☑, 정렬, 새 폴더, 도구, 도움말 ?, 설정 슬라이더)은 오른쪽 위에 떠 있습니다.
  - 스크롤하면 제목은 목록과 함께 사라집니다. 버튼 줄은 **둥근 슬라이더 버튼 하나로 접히고**, 검색창은 그 아래 **둥근 검색 버튼으로 줄어듭니다**.
  - 둘 중 하나를 누르면 버튼 줄과 검색창이 다시 펼쳐집니다. 검색을 눌렀으면 바로 입력할 수 있게 됩니다.
  - 아래로 지나가는 목록은 딱 끊긴 바 대신 위로 갈수록 **점점 흐려지는 페이드**로 덮입니다.
- **슬라이더 메뉴**: ⋯ 버튼을 없애고 슬라이더 하나에 모았습니다. 모양(Appearance), 휴지통, 목록 배경, About · Help가 들어 있고, 폴더 안이면 폴더 이름 바꾸기·삭제도 있습니다.
- **메뉴를 리퀴드 글래스로**: 정렬, 슬라이더, 노트 ⋯, 폴더 ⋯ 메뉴가 흰 메뉴 대신 툴바와 같은 유리 재질입니다.
- **하단 바**: 목록 화면 녹화(배경 캡처) 바깥으로 옮겼습니다. 그래서 이제 툴바처럼 진짜 리퀴드 글래스로 보입니다.
- **섹션 제목**: › Folders / Notes / Markdown을 눌렀을 때 잠깐 생기던 회색 눌림 표시를 없앴습니다.
- **폴더 카드**: 그림자를 없애 노트 카드와 같게 했습니다.
- **Markdown 노트**:
  - 큰 카드 대신 **한 줄짜리 목록**(두 줄로 나란히: 이름, 수정 시각, 폴더, 태그)으로 보여 줍니다. 파일이 많아도 한눈에 보입니다.
  - 맨 위에 **"마크다운 보관함 열기"**가 있어 폴더 트리로 볼 수 있습니다.
  - 각 줄의 ⋯에서 이름 바꾸기, 폴더로 옮기기, .md로 내보내기, 삭제를 합니다.
- **튜토리얼**: 모든 페이지의 팝업 크기를 가장 큰 페이지에 맞춰, 넘길 때 커졌다 작아지지 않습니다.

## 텍스트
- **누른 자리 입력칸이 페이지에 붙어 다닙니다**: 스크롤하면 같이 움직이고, 확대·축소하면 글자도 페이지 배율대로 같이 커지고 작아집니다.
- **글상자 크기를 바꾸면 줄이 다시 맞춰집니다**: 글상자 모서리를 끌어 키우거나 줄이면, 글자가 늘어나는 대신 **상자 폭이 바뀌고 글이 그 폭에 맞춰 줄바꿈**됩니다. 끄는 동안은 잠깐 늘어나 보이고, 손을 떼면 다시 맞춰집니다. 표는 해당하지 않습니다.
- **Markdown 실시간 표시**: 입력하는 동안에도 `#` 제목은 크고 굵게, `**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``, 링크, 목록 기호가 바로 보입니다. 기호(#, ** 등)는 지우지 않고 흐리게 남겨 커서가 튀지 않습니다.

## 표
- **편집기 배경을 불투명하게**, 바깥은 어둡게 덮어 표가 잘 보이게 했습니다. 화면 폭의 92%까지 넓게 열립니다.
- 고른 칸이 있는 행 번호와 열 이름이 강조됩니다. 행·열 이름을 누르면 그 행이나 열로 이동합니다.
- 칸 테두리를 진하게 하고, 줄마다 번갈아 옅은 색을 넣었습니다. 숫자는 오른쪽 정렬입니다.
- 키보드 **다음(Next)**으로 오른쪽 칸, 줄 끝이면 다음 줄로 갑니다. 마지막 칸이면 새 줄을 만듭니다.
- **Σ**: 지금 칸 위쪽 열을 합하는 `=SUM(...)`을 넣습니다.
- 행 위/아래, 열 왼쪽/오른쪽 추가, 행·열 삭제가 됩니다.

## 확인 방법과 한계
- CI 빌드와 단위 테스트로만 확인했습니다. **기기에서는 써 보지 못했습니다.**
- 첫 화면 접힘 애니메이션은 크기·투명도 변화로 만들었습니다. 그림처럼 한 덩어리가 미끄러지듯 줄어드는 모양과는 다를 수 있습니다. 보시고 말씀해 주시면 맞추겠습니다.
- "점차적 블러"는 실제 블러가 아니라 위로 갈수록 진해지는 페이드로 만들었습니다.

## 기기에서 확인할 것
1. 첫 화면을 스크롤했을 때 버튼 줄과 검색창이 둥근 버튼으로 접히는지, 누르면 펼쳐지는지
2. 하단 바와 메뉴들이 유리로 보이는지
3. Markdown 목록과 보관함 열기
4. 페이지 누른 자리 입력 중에 스크롤·확대하면 입력칸이 따라오는지
5. 글상자 모서리로 크기를 바꿨을 때 줄바꿈이 다시 맞춰지는지
6. 표 편집기(다음 키, Σ, 행·열 추가)
