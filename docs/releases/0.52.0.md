# Notesis 0.52.0 (137)

## 세로 툴바와 가로·세로 전환
- 툴바를 화면 옆으로 세워 쓸 수 있습니다. 2/4, 3/4 크기에서 도구들이 세로 캡슐로 서고, 그 아래에 Functions 버튼이 붙습니다.
- 전환하는 곳:
  - Functions 메뉴 맨 위 툴바 크기 아래의 Direction: Horizontal / Vertical
  - 설정 › Appearance의 툴바 크기 아래
- 세 스킨 모두 지원합니다.
  - Liquid glass: 렌즈와 하이라이트가 위아래로 움직이고, 손가락으로 끌면 렌즈가 따라옵니다.
  - Material·Glassmorphism: 선택 하이라이트가 위아래로 미끄러집니다.
- 위치:
  - 떠 있는 툴바는 처음에 화면 왼쪽 가운데에 놓이고, 원하는 곳으로 옮길 수 있습니다.
  - 고정(Dock)하면 왼쪽 가장자리 가운데에 붙습니다.
- 화면이 낮아 도구가 한 줄에 다 안 들어가면 세로 캡슐 여러 개가 나란히 섭니다. 도구를 숨기지 않습니다.
- 세로일 때 Functions 메뉴는 툴바 오른쪽에 열립니다. 오른쪽에 자리가 없으면 왼쪽에 열립니다.
- 1/4(전체 툴바)는 맨 위 줄과 펜 줄이 있어서 항상 가로입니다. Vertical을 골라 둔 채 1/4로 바꾸면 가로로 나오고, 2/4~3/4로 돌아오면 다시 세로가 됩니다.
- 4/4(버튼 하나)는 방향과 상관없이 같습니다.
- Appearance 미리보기에도 세로 툴바가 그대로 나와서 눌러볼 수 있습니다. 툴바 사용자화 화면의 미리보기는 도구 순서를 보기 쉽게 가로로 보여줍니다.
