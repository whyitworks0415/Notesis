## 필기 중 메인 스레드 일 줄이기
손글씨는 획을 빠르게 이어 씁니다. 펜을 뗄 때 하는 일이 다음 획의 첫 잉크를 늦출 수 있어서, 획과 획 사이에 메인 스레드가 하던 일을 줄였습니다.

- **툴바가 획마다 다시 구성되던 것**: 되돌리기/다시하기 버튼을 켤지 정하려고 툴바가 획을 하나 쓸 때마다 통째로 다시 구성(recompose)되고 있었습니다. 이제 버튼 상태가 실제로 바뀔 때만(처음 쓴 획, 되돌릴 것이 다 떨어졌을 때 등) 다시 구성합니다.
- **획 사이의 다시 계산**: 획을 쓸 때마다 0.2초 뒤에, 화면에 보이는 모든 획을 현재 배율과 맞춰 보는 확인과 멀리 있는 페이지 정리가 돌았습니다. 손글씨에서는 이것이 다음 획을 쓰기 직전의 틈에 겹칩니다. 방금 쓴 획은 이미 현재 배율로 만들어져 있어서, 이제 손이 0.7초 쉰 뒤에 합니다(그림 캐시와 같은 기준). 확대·축소나 새 페이지 읽기는 지금처럼 바로 합니다.
- **팁 표시**: 노트를 연 뒤 첫 획에 팁 영역이 한 번 다시 구성되던 것을 없앴습니다.

0.84.0의 "필기 중 썸네일 미루기"와 함께, 펜을 쓰는 동안과 그 틈에 도는 다른 일을 줄이는 쪽입니다. 획 모양, 예측, 안정화는 바꾸지 않았습니다.

## 확인 방법
- 코드로 확인: 툴바가 구성 중에 캔버스에서 읽는 값은 되돌리기/다시하기 두 개뿐이고, 펜 상태와 입력 상태는 모두 그리기 단계에서만 읽힙니다.
- **실기기에서 빨라졌는지는 재지 않았습니다.** 얼마나 나아졌는지는 기기에서 측정해야 알 수 있습니다.

## 기기에서 확인할 것
- 빠르게 손글씨를 쓸 때 획 시작이 덜 늦거나 덜 끊기는지(S6 Lite)
- 되돌리기/다시하기 버튼이 지금처럼 켜지고 꺼지는지: 첫 획 뒤 켜지고, 모두 되돌리면 꺼지는지
- 확대한 뒤 쓴 글씨가 손을 멈추고 잠시 뒤에도 선명한지
- 설정 › 진단 화면의 "Page apply"와 "frames missed"가 0.85.0보다 줄었는지(비교해 주시면 다음에 반영하겠습니다)
