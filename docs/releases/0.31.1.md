# Notesis 0.31.1 (versionCode 62)

태블릿에 설치할 서명 APK는 아래 Assets에서 받으세요.

## 필기와 성능

- 점선·파선·일점쇄선과 도형을 각각 하나의 획으로 저장해 획 수와 렌더링 부하를 줄였습니다.
- 필기 시작점이 반대 방향으로 짧게 튀는 디지타이저 입력을 자동으로 보정합니다.
- 연필을 매끈한 볼펜 형태에서 필압·기울기·흑연 질감이 드러나는 연필 브러시로 교체했습니다.
- 획이 많은 페이지의 비트맵 캐시 기준을 조정하고, 지우는 동안 매 입력 샘플마다 저장과 메시 재생성을 예약하던 병목을 제거했습니다.
- 한 번의 지우개 동작으로 지운 모든 획이 실행 취소·다시 실행 한 번에 함께 복원됩니다.

## 도구와 노트 보기

- 직선을 수평·수직 90° 간격으로 맞추는 보정을 도형 설정에서 켜고 끌 수 있습니다.
- 상단 도구막대의 회전 버튼으로 필기 화면을 0°·90°·180°·270°로 돌릴 수 있으며 선택한 각도를 기억합니다.
- 음성 녹음 버튼을 상단 도구막대로 옮기고 녹음 중일 때 강조해 표시합니다.

## PDF

- 시스템 파일 선택기에서 여러 PDF를 한 번에 선택해 각각의 Notesis 노트로 가져올 수 있습니다.
