# Notesis 0.99.10 (251)

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

0.99.9(OCR 다섯 가지)에 이어, 앞서 정리한 개선·추가 목록의 나머지 중 이번에 할 수 있는 것을 넣었습니다.

## 고친 버그
- **Android 10~12에서 에이전트 연결이 요청을 받으면 앱이 꺼질 수 있었습니다.** 요청 머리글을 읽는 데 Android 13에만 있는 함수를 썼기 때문입니다. 모든 버전에 있는 방법으로 바꿨습니다.
- 같은 종류의 문제가 다시 들어오지 않게, 릴리스 빌드마다 **"이 Android 버전에 없는 기능을 부르는 곳"을 자동으로 검사**합니다(Lint NewApi). 하나라도 있으면 릴리스가 만들어지지 않습니다. 지금 코드에서는 위의 한 곳만 걸렸고 고쳤습니다.

## 최적화
- **화면 여러 개가 메모리를 나눠 씁니다.** 지금까지는 노트, 팝업 노트, 분할 화면이 각자 필기 타일 메모리를 꽉 채워 쓸 수 있었습니다. 이제 셋을 합쳐 한 화면 몫의 1.5배를 넘지 않게 나눠 씁니다. 화면에 보이는 타일은 절대 버리지 않고, 각 화면은 자기 몫의 1/4은 항상 보장받습니다.
- **배경 작업이 코어를 나눠 씁니다.** 페이지 획 만들기와 타일 칠하기가 각자 스레드를 돌려, 8코어에서 최대 9개가 화면과 함께 돌 수 있었습니다. 이제 둘이 한 예산(코어 수 − 2)을 나눠 쓰고, **코어 2개는 항상 화면(UI·렌더 스레드)에 남깁니다.**

## 새 기능
- **노트 이전 버전**
  - 노트를 열 때, 그 전 모습을 태블릿 안에 따로 보관합니다. 바뀐 게 없거나 30분 안이면 건너뜁니다.
  - 노트당 최근 10개, 전체 300MB까지 보관하고, 오래된 것부터 지웁니다.
  - 홈의 노트 카드 메뉴 → **이전 버전**에서 시각을 골라 **복원**합니다.
  - 복원하기 전에 지금 모습도 버전으로 남기므로, 복원 자체도 되돌릴 수 있습니다.
  - PDF 원본과 녹음은 바뀌지 않는 파일이라 복사하지 않습니다(공간 절약).
  - 이전 버전은 기기 백업(Google 백업)에는 넣지 않습니다.
- **가림 테이프 간격 반복 복습**
  - 맞히면 다음 복습까지의 간격이 1→2→4→8…일(최대 60일)로 늘고, 틀리면 오늘 다시 나옵니다.
  - 페이지 패널의 테이프 목록에 **"오늘 복습 (N)"** 버튼이 생겨, 오늘 볼 차례인 테이프만 공부합니다.
  - 기존 맞음·틀림 기록은 그대로 남습니다.
- **원래 PDF에 저장**
  - Chrome PDF 보기의 펜 버튼이나 다른 앱의 "편집"으로 받은 PDF가, 그 앱이 쓰기를 허락한 경우에는 노트 카드 메뉴에 **"원래 PDF에 저장"**이 생깁니다.
  - 필기를 합친 PDF를 그 파일에 다시 씁니다. 사본을 따로 만들 필요가 없습니다.
  - 먼저 임시 파일로 완성한 뒤 쓰기 때문에, 실패해도 원래 파일은 그대로입니다. 허락이 끝났으면 "PDF로 내보내기"를 쓰라고 알려 줍니다.
- **이 페이지 글자 복사**: 노트 설정 → 손글씨 인식에서, 지금 보는 페이지의 글자를 한 번에 복사합니다. PDF 글자, 스캔에서 읽은 글자, 인식된 손글씨가 함께 들어갑니다.

## 어떻게 확인했나
- 빌드, 축소(R8) 릴리스 빌드, 새 Android 버전 검사(Lint NewApi), 네이티브 커널 점검, 전체 단위 테스트(145개 클래스)를 통과했습니다.
- 다음 부분에 테스트를 추가했습니다.
  - 복습 간격 계산(늘리기·상한·틀리면 처음부터)
  - 이전 버전(보관·건너뛰기·복원·개수 제한)

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 써 보지 않았습니다.** 메모리·코어 나눠 쓰기가 체감 속도를 얼마나 바꾸는지는 측정하지 않았습니다.
- "원래 PDF에 저장"은 PDF를 보낸 앱이 **쓰기 허락**을 줄 때만 나옵니다. Chrome이 허락을 주는지는 확인하지 못했습니다.
- 이번에도 하지 않은 큰 작업(각각 따로 진행해야 하는 규모):
  - 자체 GPU 잉크 렌더러
  - C++ 불러오기 파이프라인
  - 계산한 메시 저장
  - PDFBox 교체
  - PDF 글자 선택·형광펜 맞춤·양식 채우기
  - 녹음 내용 글자 변환
  - 기기 간 동기화
  - 페이지 파일 체크섬
  - SQLite 검색 색인 교체: 한글 부분 검색을 유지하려면 지금 방식이 맞습니다.

## 태블릿에서 해 볼 것
1. 노트를 열어 무언가 쓰고 닫기 → 30분 뒤 다시 열고 닫기 → 홈 카드 메뉴 **이전 버전**에서 복원되는지.
2. 테이프를 붙이고 공부에서 맞음/틀림 → 페이지 패널의 **오늘 복습** 숫자가 바뀌는지.
3. 팝업 노트·분할 화면을 같이 연 채 필기 많은 페이지를 넘기기 → 이전보다 버벅임·메모리 부족이 덜한지.
4. 다른 앱(파일 관리자의 "편집" 등)으로 PDF를 열어 필기 → 홈 카드 메뉴 **원래 PDF에 저장**.
5. Android 10~12 기기가 있다면 에이전트 연결 켜고 연결해 보기.
