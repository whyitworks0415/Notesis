# Notesis 0.48.0 (125)

## 스킨 정리
- 기존 "Liquid glass" 스킨을 없애고 Material, Glassmorphism, Liquid glass 세 가지로 정리했습니다. 새 Liquid glass는 이전의 "Glass bar"입니다.
- 예전에 Liquid glass를 쓰던 경우에는 새 Liquid glass로 열립니다. 백업에서 불러올 때도 같습니다.
- Material과 Glassmorphism도 Liquid glass와 같은 모양으로 맞췄습니다(도구막대, 도구 줄, 기능 버튼, 메뉴). 재질만 다릅니다.
  - Material: 단색
  - Glassmorphism: 반투명 유리
  - Liquid glass: 빛을 굴절시키는 유리

## Liquid glass
- 1/4 크기 도구막대를 한 장의 유리로 바꿨습니다. 이전에는 배경 위에 투명도가 다른 도구 줄이 한 겹 더 겹쳐 있어서, 그 아래로 획이 지나갈 때 경계에서 색과 밝기가 확 바뀌었습니다. 이제 도구 줄은 같은 유리 위에 내용으로만 그려집니다.
- 2/4~4/4 크기의 도구 줄과 기능 버튼, 기능 메뉴, 펜 설정 창도 굴절 유리로 바꿨습니다.
- 기능 메뉴가 열리는 동안 유리 뒤로 비치는 페이지 위치가 어긋나던 문제를 고쳤습니다. 커지는 애니메이션 중에도 화면의 실제 위치와 크기를 계산해 맞춥니다.

## 팝업
- 기능 메뉴와 펜 설정 창이 자기 중심이 아니라, 누른 곳에서 자라나듯 열립니다.
  - 마지막으로 누른 도구막대 위치가 기준이고, 없으면 기능 버튼에서 열립니다.
  - Liquid glass와 Glassmorphism에 적용됩니다. Material은 애니메이션 없이 바로 나타납니다.

## 도구막대 크기 전환 애니메이션
- Sine in-out, Quad in-out 곡선을 추가했습니다.
- 기본값은 500ms, Sine in-out입니다.
- 이전에 고른 곡선은 그대로 유지됩니다.

## Material
- 도구 아이콘을 모두 같은 색으로 바꿨습니다.
- 다른 도구를 누르면 하이라이트가 가감속하며 옮겨 갑니다. 크기는 바뀌지 않고, 고른 도구의 아이콘 색이 바뀝니다.
- 다른 UI 애니메이션은 모두 뺐습니다.
  - 아이콘 움직임, 팝업 커짐, 크기 전환 모션, 누를 때 들림이 없습니다.
  - 누를 때나 커서를 올릴 때 생기던 하이라이트도 없습니다. 키보드 포커스 표시는 남겨 두었습니다.
- 슬라이더 손잡이와 스위치는 흰 단색이고, 버튼도 단색입니다.

## Glassmorphism
- Material과 같은 규칙입니다. 같은 도구막대에 하이라이트가 옮겨 가고, 애니메이션과 누를 때 하이라이트가 없습니다.
- 차이점은 표면이 단색이 아닌 반투명 유리라는 것입니다. 슬라이더와 버튼은 이전 모습 그대로입니다.

## 모서리 곡률 (iOS 방식)
- 바깥 모서리 곡률을 정해 두고, 안쪽 요소는 "바깥 곡률 − 안쪽 여백"으로 맞춰 곡선이 서로 평행하게 했습니다.
- 적용한 곳:
  - 도구막대 안의 도구 줄과 버튼
  - 기능 메뉴와 그 안의 버튼
  - 펜 설정 창과 그 안의 칸
  - 설정 사이드바의 카드와 줄
  - 대화상자 안의 입력칸
- 유리 스킨에서 직접 정한 모서리 값이 바깥 곡률이 됩니다.
