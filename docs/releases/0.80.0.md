## Liquid glass · iOS: 테두리 빛 방향
- **좌우 끝이 흐려지던 이유**
  - iOS 프리셋(ios27Light)은 빛이 위에서 옵니다. 그래서 테두리는 빛을 마주하는 위·아래만 밝고, 좌우 끝으로 갈수록 흐려집니다.
- **Settings › Appearance › Glass › Rim**에 두 가지를 추가했습니다.
  - **Light from**: 빛이 오는 방향을 0°~180°로 정합니다(5° 단위).
    - 90°(기본): 위·아래가 밝음, 좌우 끝이 흐림(지금과 같음)
    - 0° 또는 180°: 좌우 끝이 밝음
    - 45° 또는 135°: 모서리가 밝음
  - **Light all the way round**: 테두리 전체에 같은 빛을 넣어 흐려지는 곳이 없게 합니다. 켜면 Light from은 잠깁니다.
- 다크 모드는 지금처럼 빛이 반대편에서 옵니다.

## 툴바·팝업·사이드바 투명도를 따로
- **Settings › Appearance › Panels, menus and the toolbar** 맨 위에 새 설정이 있습니다.
  - **Toolbar transparency**: 툴바, 도구 줄, 둥근 버튼(Functions 등)
  - **Popup transparency**: Functions 메뉴, 펜 설정창, 도구 등 툴바에서 열리는 창, 크게 보기한 페이지
  - **Sidebar transparency**: Settings, 페이지 패널, 레이어 패널
  - **Dim behind popups**: 도구·펜 설정창이 열릴 때 뒤 페이지를 얼마나 어둡게 할지(0~60%, 기본 12%로 지금과 같음)
- 투명도는 **100%가 지금 스타일이 그리는 유리 그대로**이고, 낮출수록 그 위에 패널 색을 깔아 불투명해집니다. 0%는 완전히 불투명합니다.
- 기본값은 모두 100%라서, 업데이트 직후 보이는 모습은 그대로입니다.
- Glassmorphism과 Liquid glass(iOS, Kyant0, QWEA0 포함) 모두에 적용됩니다. Material은 원래 불투명해서 투명도 설정이 잠겨 있고, "뒤 어둡게"만 바뀝니다.

## 바꾸지 않은 것
- 유리 자체보다 **더 투명하게** 하려면, 지금처럼 각 스타일의 Glass 설정을 쓰면 됩니다.
  - iOS: Body, Frost opacity
  - Liquid glass: Transparency
- 이번에 넣은 투명도는 역할별로 더 불투명하게만 조절합니다.
- 홈 화면의 폴더 카드, 선택 막대 같은 다른 패널에는 적용하지 않았습니다.

## 확인 방법
- 단위 테스트
  - 역할별 투명도와 어둡게 하기의 저장·불러오기
  - 예전 설정 파일은 그대로 보이는지
  - iOS 빛 방향 저장과 범위 밖 값 보정
- 실제 화면에서는 확인하지 못했습니다.

## 기기에서 확인할 것
- iOS 스타일에서 Light from을 0°로 하면 좌우 끝이 밝아지는지, Light all the way round를 켜면 테두리 전체가 고르게 밝은지
- 팝업 투명도를 낮추면 펜 설정창과 Functions 메뉴만, 사이드바 투명도를 낮추면 Settings와 페이지 패널만 불투명해지는지
- Dim behind popups를 바꾸면 펜 설정창 뒤 어두움이 바뀌는지
