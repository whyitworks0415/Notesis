# Notesis Lab 0.90.21-lab.8 (219)

<!-- update: manual -->

> 기존 Notesis Lab에 업데이트 설치하는 사전 릴리스입니다. 정식판과 별도입니다.

## 색상 선택

- 색상 화면을 **색상 격자 / SV 사각형+아래 Hue 막대 / 세로 HSV 막대+미리보기 / Hue 링+SV 사각형** 네 가지로 구성했습니다.
- 이전 버전의 세로 HSV 막대 구현을 복원했습니다. 오른쪽 미리보기 아래에서 HEX를 편집할 수 있고 링 화면에서는 H·S·V 수치를 직접 입력합니다. 공통 팔레트·불투명도·스포이드는 유지합니다.
- 화면을 바꿔도 같은 HSVA 상태를 사용합니다. 기존 모드 번호는 바꾸지 않고, 저장된 RGB 화면은 HSV 막대, RGB 원판은 HSV 링으로 엽니다. 기존 필기 색상과 저장 형식은 변경하지 않습니다.

## 팝업 형태 변화

- Apple 앱 전환의 둥근 창 확장·축소를 참고해 공통 팝업 전환을 개편했습니다. 사다리꼴로 내용을 잘라 보이던 방식에서 **내용과 둥근 창이 함께 확대·축소**되는 방식으로 바꿨습니다. 닫힐 때 폭만 먼저 접혀 얇고 각진 모양이 되지 않도록 두 축을 함께 움직입니다.
- 버튼 쪽의 작은 둥근 사각형에서 패널로 확장하고 다시 접힙니다. 창 밖의 앵커는 가장 가까운 안쪽 가장자리로 제한해 모서리가 창 경계에 잘리지 않도록 합니다. OS 앱 전환을 그대로 실행하는 기능은 아닙니다.
- 둥근 모서리는 확대율의 영향을 보정해 유지하고, 터치 좌표도 같은 그래픽 변환을 사용합니다. 열리는 중에도 보이는 컨트롤 위치와 터치 위치가 맞도록 했습니다.
- 움직이는 동안 유리와 내용을 한 번 기록한 레이어로 재사용합니다. 팝업을 매 프레임 다시 측정하거나 유리 전체를 새로 생성하지 않습니다. 완전히 열리면 일반적인 실시간 갱신으로 돌아옵니다.
- Material에서도 공통 둥근 형태 전환을 사용하며, 모션을 끈 경우에는 즉시 표시·닫기를 유지합니다. 열고 닫는 도중의 방향 전환은 기존 속도를 이어받습니다. 확인 버튼이 즉시 상위 화면을 바꾸는 일부 일반 대화상자는 해당 호출부의 수명에 따릅니다.

## 검증

- 로컬 전체 Debug 테스트 **714개**가 실패·오류·건너뜀 없이 통과했습니다.
- 네 색상 화면 렌더, 전환 시 색상 유지, Hue 막대와 SV 사각형 터치 시 불투명도·다른 채널 유지, 애니메이션 중 터치 위치 및 닫기 완료 대기를 검사합니다.
- 진행률별 둥근 창의 범위·모서리·시작과 끝, 작은 패널과 화면 밖 앵커를 검사합니다. 전체 테스트·릴리스 빌드·UI/JNI·기존 서명 검증을 거쳐 게시합니다.

실기기에서의 외관·프레임 개선량은 아직 측정하지 않았습니다. 네 색상 화면에서 색을 바꾸고 저장·취소·다시 열기를 확인해 주세요. 펜·색상·기능 팝업을 열고 닫고, 닫히는 도중 다시 열어 모양과 터치 위치를 확인해 주세요.
