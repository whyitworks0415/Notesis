# Notesis 0.38.0 (99)

도구 설정 창을 리퀴드 글래스 패널로 새로 만들었습니다. 색상 고르는 방식 다섯 가지와 팔레트를 함께 두고, 예측·획 보정 같은 필기 설정을 도구마다 따로 저장합니다.

## 변경 사항

### 새 도구 설정 창

- 페이지 위에 뜨는 유리 패널입니다(스킨의 리퀴드 글래스 설정을 따르며, Material 스킨에서는 반투명 표면).
- 위에서부터 **색상**(왼쪽 색상 모드, 오른쪽 팔레트) → **굵기**(슬라이더, −·값·+, ☆ 즐겨찾기, 오른쪽에 실제 색·굵기·선 모양 미리보기) → **펜 종류·필압** → **선 스타일** → **세부 설정** 순서입니다.
- **세부 설정**을 누르면 패널이 아래로 펼쳐지며 나머지 설정이 나옵니다.
- 바깥을 누르거나 뒤로 가기로 닫아도 적용되고, '취소'는 바꾸기 전으로 돌아갑니다.

### 색상 모드 5가지 (마지막에 쓴 모드를 기억)

1. **사각형**: 채도·명도 사각형 + 색상(H) 띠
2. **HSV 막대**: H·S·V 세로 막대 3개 + 색 미리보기
3. **링**: 색상 링 안에 채도·명도 사각형, H°·S%·V% 숫자 입력
4. **RGB**: R·G·B 막대와 숫자 입력
5. **컬러 디스크**: 각도는 색상, 바깥으로 갈수록 채도, 옆에 명도 막대와 %

모든 모드에 #헥스 입력과 스포이드가 있습니다.

### 투명도

- **펜·마스킹테이프**: 투명도 없이 불투명합니다. 이전에 반투명으로 저장된 펜은 불투명으로 바뀝니다.
- **연필·형광펜**(그리고 도형): 투명도 막대가 있습니다.

### 도구마다 따로 저장되는 설정

- **예측**, **획 보정**, **선 스타일**, **자동 도형 인식**이 도구마다 저장됩니다. 도구를 바꾸면 그 도구의 설정으로 바로 바뀝니다. 처음에는 각 도구가 이전의 공통 설정값으로 시작합니다.
- **예측을 1ms 단위로**: '자동' 또는 0~12ms 슬라이더(0은 예측 끔). 기존의 4/6/9ms 세 가지 대신 1~12ms 모두를 고를 수 있습니다.
- 손가락 동작·호환 필기 표시·확대 후 선명하게·메시 렌더링은 기기 전체 설정이라 '모든 도구 공통'으로 따로 묶었습니다.
