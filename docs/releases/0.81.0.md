## 툴바·팝업·사이드바마다 배경 색과 어둡게
- **Settings › Appearance › Panels, menus and the toolbar**가 **Toolbar / Popups / Sidebars** 세 묶음으로 나뉘었습니다. 묶음마다 다음 세 가지를 정합니다.
  - **Transparency**: 0.80에서 넣은 투명도입니다. 100%는 스타일이 그리는 유리 그대로이고, 낮출수록 아래의 색이 덮이며, 0%는 불투명합니다.
  - **Color**: 투명도를 낮췄을 때 덮이는 배경 색입니다.
    - A: 테마 색(기본, 지금과 같음)
    - 강조색
    - 흰색, 밝은 회색, 회색, 짙은 회색, 검정
    - 크림, 민트, 하늘, 분홍
  - **Darken**: 조금 더 어둡게 그립니다(0~60%). 투명도와 상관없이 유리 위에도, 불투명한 패널 위에도 적용됩니다. 60%를 넘으면 위의 글자가 잘 안 읽혀서 거기까지만 둡니다.
- 색을 골랐는데 투명도가 100%면 색이 보이지 않습니다. 이때 설정 화면에 안내 문구가 나옵니다.
- 기본값은 모두 지금과 같습니다(테마 색, 어둡게 0%).
- Material 스타일은 원래 불투명해서 이 설정이 잠겨 있습니다.

## 확인 방법
- 단위 테스트: 역할별 색과 어둡게 하기의 저장·불러오기, 범위 보정, 다른 역할이 바뀌지 않는지
- 실제 화면에서는 확인하지 못했습니다.

## 기기에서 확인할 것
- Popups의 Transparency를 낮추고 Color를 짙은 회색으로 바꾸면, 펜 설정창과 Functions 메뉴만 그 색이 되는지
- Darken을 올리면 해당 패널만 어두워지는지, 글자가 잘 읽히는지
