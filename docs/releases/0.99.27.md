# Notesis 0.99.27 (268)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

유리 스타일에 **"iOS 라이트"**를 새로 넣었습니다. iOS 스타일의 모양을 Liquid glass만큼 가볍게 그리는 방식입니다. 기존 Liquid glass와 iOS 스타일은 그대로 두었으니 셋을 나란히 비교해 볼 수 있습니다.

## 왜 iOS가 무거웠나 (코드상 그리기 단계 비교, 태블릿에서 잰 값 아님)
- **Liquid glass**: 가만히 있는 유리 하나에 흐리기 1번, 색 보정, 반투명 색 한 겹, 선으로 그린 테두리만 씁니다. 렌즈는 움직일 때만 돕니다.
- **iOS**: 유리마다 페이지를 두 번 흐리고(맑은 층과 서리 층), 렌즈 셰이더를 두 층 모두에 돌린 뒤 합성하고, 테두리 빛을 셰이더로 한 번 더 그립니다. 메뉴는 쏟아지며 열려서, 열리는 동안 매 프레임 이 과정을 다시 합니다.

## iOS 라이트는 어떻게 그리나
- **흐리기 1번**:
  - iOS의 "약한 흐림 위에 서리를 겹치는" 두 층을, 둘 사이 값으로 한 번 흐리는 것으로 대신합니다.
  - 서리 불투명도만큼 서리 쪽으로 기웁니다.
- **iOS의 색**: 채도 올림, #F8F8F8 계열 몸체, 파란 강조색, iOS 회색 배경색을 그대로 씁니다. 어두운 모드에서는 iOS의 어두운 값을 씁니다.
- **테두리 빛**: 셰이더 대신 그라데이션 선으로 그립니다. 빛이 오는 쪽이 밝고 양 끝은 희미하며, 각도 설정도 따릅니다.
- **안쪽 테두리 그림자·바깥 그림자·각진 둥근 모서리(squircle)**: iOS와 같습니다.
- **렌즈**: 가만히 있는 유리에는 돌리지 않습니다.
- **메뉴 열림**: Liquid glass처럼 열립니다. 쏟아지는 열림은 매 프레임 유리를 다시 계산해서 뺐습니다.
- **눌림과 선택 이동의 움직임**: iOS와 같은 스프링을 씁니다.
- **설정**: 강조색, 모서리, 흐림, 서리, 채도, 몸체, 테두리 값을 **iOS 스타일과 함께 씁니다.** iOS에서 맞춘 값이 iOS 라이트에도 그대로 적용됩니다.

## iOS와 달라 보일 수 있는 점
- 맑은 층 위에 서리가 겹쳐 페이지가 흐릿한 잔상처럼 비치는 깊이감이 조금 덜합니다.
- 가장자리의 상시 굴절이 없습니다.
- 테두리 빛이 선이라 셰이더 빛보다 단순합니다.

## 어떻게 확인했나
- 빌드, 축소(R8) 릴리스 빌드, Android 버전 검사(Lint), 네이티브 커널 점검, 전체 단위 테스트(155개 클래스)를 통과했습니다.
- 한 번의 흐리기 값을 정하는 계산과 스타일 이름 저장·읽기에 테스트를 추가했습니다.

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 보거나 렉을 재 보지 않았습니다.** 얼마나 가벼워졌는지는 숫자로 말할 수 없습니다.
- iOS 스타일과 Liquid glass 자체는 바꾸지 않았습니다.

## 태블릿에서 해 볼 것
1. 모양 → 유리 스타일에서 **iOS 라이트** 고르기.
2. iOS ↔ iOS 라이트를 바꿔 가며 툴바, 메뉴, 패널 모양 비교하기.
3. 메뉴 열기, 페이지 스크롤, 사이드바 열기에서 렉이 Liquid glass만큼 적은지.
4. 유리 설정에서 흐림·서리·몸체 값을 바꿔 iOS에 더 가깝게 맞춰 보기.
