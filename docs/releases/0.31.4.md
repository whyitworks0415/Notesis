# Notesis 0.31.4 (versionCode 65)

태블릿에 설치할 서명 APK는 아래 Assets에서 받으세요.

## Render / Refine pipeline

- page mesh 상태를 `Dirty / Rendering / ViewportCached / Complete`로 명확히 구분합니다.
- zoom 또는 page 이동으로 obsolete해진 mesh refine을 generation과 Future cancellation으로 중단합니다.
- dense stroke rebuild는 stroke마다 취소 여부를 확인해 최신 viewport 작업이 오래 기다리지 않게 합니다.
- stale PDF bitmap/tile은 cache에 게시하지 않고 즉시 해제합니다.
- 같은 key의 stale pending 작업이 현재 generation 요청을 막지 않습니다.
- PDF page priority는 page뿐 아니라 zoom width bucket 변경도 반영합니다.
- pan, pinch, fling 중에는 cached/base 품질을 사용하고 idle 이후 high-quality refine을 한 번 수행합니다.
- viewport를 벗어난 dense-page bitmap 작업은 중단하며 게시 시 visibility를 다시 확인합니다.

stroke 입력, stabilization, 화면의 최종 품질과 저장 형식은 변경하지 않았습니다.

## 태블릿 확인 항목

- [ ] 500~2,000 stroke page에서 빠른 zoom/pan 후 frame 및 refine p50·p95·p99 비교
- [ ] zoom 직후 다른 page로 이동해 이전 generation 결과가 뒤늦게 덮어쓰지 않는지 확인
- [ ] 긴 PDF를 빠르게 scrub한 뒤 최종 page가 우선 렌더되는지 확인
- [ ] pan/pinch 중 cached 화면이 끊기지 않고 idle 후 선명해지는지 확인
- [ ] 화면 밖 dense page 작업의 CPU/allocation이 빠르게 멈추는지 확인
- [ ] PDF 위 필기, highlighter, masking tape, lasso, undo/redo 확인
- [ ] 앱 종료·재실행 후 stroke와 PDF 배치가 동일한지 확인

각 시나리오 전에 속도계 아이콘을 껐다 켜 측정 세션을 초기화하세요.

## 검증

- render generation/state 전이 단위 테스트를 추가했습니다.
- `testDebugUnitTest`, `lintDebug`, debug APK 및 서명 release APK 빌드를 실행했습니다.
- 연결된 Android 기기가 없어 instrumentation과 실기기 p50/p95/p99 비교는 포함되지 않았습니다.
