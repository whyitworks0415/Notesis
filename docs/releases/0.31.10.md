# Notesis 0.31.10 (versionCode 71)

노트별 목차와 필기 PDF 내보내기 품질 개선 릴리스입니다.

- 페이지에 이름을 붙여 목차로 등록하고, 목차 항목을 눌러 해당 페이지로 이동할 수 있습니다. 항목 이름 변경, 삭제, 강조 표시를 지원하며 페이지 순서를 바꿔도 연결이 유지됩니다.
- 원본 크기 벡터 PDF에서 겹친 펜, 형광펜, 마스킹 윤곽이 흰 틈으로 빠지는 채움 오류를 수정했습니다.
- PDF용 필기 윤곽을 더 촘촘하게 생성해 확대 시 곡선과 둥근 끝부분을 매끄럽게 표시합니다.
- 펜 시작과 끝에서 입력이 아주 짧게 나갔다 돌아오는 경우에만 해당 샘플을 제거해 간헐적인 각진 끝을 줄였습니다. 의도적인 꺾임과 느린 되돌림은 보존합니다.

JVM 단위 테스트와 Android 가상 기기 회귀 검사를 통과했습니다. 시작 샘플 위치와 방향을 바꾼 간헐적 튐, 정상 꺾임 보존, PDF 겹침 픽셀을 검사했고 600dpi PDF 렌더링도 확인했습니다. 실제 S펜 하드웨어에서의 간헐적 입력은 가상 기기에서 재현할 수 없어 별도 확인이 필요합니다.
