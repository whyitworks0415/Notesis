# Notesis 0.73.0 (162)

## Liquid glass 테두리를 iOS처럼
- 유리 테두리가 한 줄로 똑같이 하얗던 것을 바꿨습니다. 이제 iOS의 유리처럼 **왼쪽 위 모서리**에 빛이 가장 밝게 맺히고, **오른쪽 아래**에 한 번 더 약하게 맺힙니다. 그 사이 옆면은 거의 투명합니다.
- 흰 종이 위에서도 테두리가 보이도록 아주 옅은 어두운 선을 밑에 깔았습니다.
- 툴바, 팝업, 패널, 슬라이더 손잡이에 모두 적용됩니다. Appearance의 테두리 색과 반사(reflection) 값을 그대로 따릅니다.

## 툴바
- **세로 4/4 버그 수정**: 세로 모드에서 4/4(버튼만)가 되면 Functions 버튼을 끌어도 커지지 않고, 가운데로 끌어 가로로 돌아가지도 않던 문제를 고쳤습니다. 이제 4/4에서도 위아래로 끌면 3/4, 2/4로 커지고, 화면 가운데에서 놓으면 가로로, 반대쪽에서 놓으면 그쪽 옆으로 갑니다. 버튼을 잠깐 누르고 있다가 끌면 예전처럼 툴바 자체가 움직입니다.
- 가로에서도 4/4에서 끌기 시작해 3/4로 커지는 순간 끌기가 끊기던 문제를 같이 고쳤습니다. 이제 크기가 바뀌어도 손가락을 따라 계속 이어집니다.
- **1/4에서도 Liquid glass**: 1/4(전체) 툴바에서 도구를 누르거나 끌 때 선택 표시가 다른 크기처럼 유리 렌즈로 부풀어 움직입니다. 예전에 렌즈가 위아래 줄로 튀어나오던 문제 때문에 꺼 두었던 것을, 도구 줄 높이 안에서만 늘어나게 해서 다시 켰습니다.
- **가로/세로 전환 애니메이션**: 가로 ↔ 세로, 왼쪽 ↔ 오른쪽으로 바꾸면 툴바가 한 번에 사라졌다 나타나지 않고, 원래 자리에서 새 자리로 이동하면서 커지고 선명해집니다. 툴바 애니메이션 시간·곡선 설정을 따르고, Liquid glass 스킨에서만 움직입니다.

## 오른쪽 가장자리 탭으로 화면 비우기
- 페이지 **오른쪽 가장자리**(약 56dp)를 손가락으로 빠르게 탭하면, 정해 둔 동작을 합니다.
- 기본값: **두 번 탭 → 툴바 숨기기**. 툴바, 뒤로가기 버튼, 페이지 스크러버가 **위로 밀려 올라가며** 사라집니다.
- 숨긴 뒤에는 화면 맨 위 가운데에 작은 탭이 남습니다. **누르거나 아래로 당기면** 툴바가 손가락을 따라 내려옵니다. 3분의 1 이상 당기고 놓으면 돌아오고, 덜 당기면 다시 올라갑니다. 가장자리를 다시 탭해도 돌아옵니다.
- **Settings › Touch & gestures › Right edge of the page**에서 한 번/두 번/세 번 탭마다 동작을 따로 정할 수 있습니다: Nothing, Hide toolbar, Undo, Redo, Next page, Previous page, Pages panel.

## Pages
- **펜을 2초 올려 두면 크게 미리보기**: Pages 탭에서 펜(또는 마우스)을 페이지 카드 위에 닿지 않게 2초 이상 올려 두면, 패널 왼쪽에 그 페이지가 크게 튀어나오는 애니메이션과 함께 보입니다. 펜을 카드 밖으로 옮기거나 화면에 대면 닫힙니다. 큰 그림은 따로 그려지는 동안 작은 썸네일이 먼저 보입니다.
- **이동 후 돌아가기**: Pages 탭이나 목차에서 다른 페이지로 이동하면, 위쪽에 **"Back to page N"** 버튼이 나타나서 원래 보던 페이지로 돌아갈 수 있습니다. Go to(페이지 번호로 이동)도 같습니다. 여러 번 이동하면 순서대로 거슬러 올라갑니다.
- **썸네일을 더 빠르게**: 페이지 그림을 두 장씩 동시에 그립니다. 연필·입자 브러시가 없는 페이지는 GPU 렌더러를 띄우지 않고 바로 그립니다. 실제로 얼마나 빨라졌는지는 측정하지 못했습니다.

## 검색 결과 표시를 더 빠르게
- PDF에서 찾은 결과를 누르면 위치를 PDF에 다시 물어보느라 페이지 위 표시가 늦게 떴습니다. 이제 검색이 끝나면 앞쪽 결과 12개의 위치를 미리 찾아 두어, 누르자마자 페이지 이동과 표시가 함께 됩니다.
- 같은 페이지 안의 여러 결과는 한 번 찾은 위치를 다시 씁니다.

## 무한 노트: 아래로 / 모든 방향
- 무한 노트가 두 가지가 됐습니다. 새 노트의 첫 페이지 선택과 페이지 메뉴(배경)에서 고릅니다.
  - **Infinite down (아래로)**: 폭은 그대로, 아래쪽 끝에 가까워지면 페이지가 저절로 4장씩 길어집니다. 끝이 없습니다.
  - **Infinite all ways (모든 방향)**: 아주 큰 한 장(A4 20장 × 20장)의 **한가운데**에서 시작합니다. 오른쪽과 아래쪽은 끝에 가까워지면 저절로 계속 늘어나 끝이 없습니다. 왼쪽과 위쪽은 시작점에서 A4 10장 거리까지 쓸 수 있습니다.
- 늘어나는 것은 편집이 아니라서 되돌리기에 들어가지 않지만, 저장은 됩니다.
- 모든 방향 노트의 100% 확대는 A4 폭 기준입니다. 노트를 다시 열면 시작한 가운데 자리로 열립니다.
- 참고: 모든 방향 노트를 PDF/이미지로 내보내면 전체 한 장이 한 페이지로 줄어들어 글씨가 작게 나옵니다.

## 마이크 화면을 Liquid glass로
- 마이크(녹음 목록)와 받아쓰기 창이 일반 안드로이드 대화상자였던 것을, 다른 툴바 팝업과 같은 **유리 패널**로 바꿨습니다. 누른 버튼에서 커져 나오고 그쪽으로 접혀 들어갑니다.
- 녹음/받아쓰기 버튼이 커졌습니다. 빨간 점이 녹음 중에는 둥근 사각형으로 바뀌고, 둘레로 고리가 퍼집니다. 받아쓰기에서는 목소리가 클수록 고리가 넓어집니다.

## Tools 창 위치 고정
- Tools(계산기·시계·달력·할 일) 창에서 탭을 바꾸거나 내용이 늘어날 때, 창의 위쪽이 위아래로 움직이지 않고 **위는 그대로, 아래로만** 늘어납니다. 화면 아래를 넘을 만큼 커질 때만 필요한 만큼 위로 올라갑니다. 펜 설정 등 같은 종류의 다른 패널도 같습니다.

## Save & reset (설정 저장 · 툴바 리셋)
- Settings에 **Save & reset** 화면을 새로 만들었습니다.
  - **Save current settings**: 지금 설정(펜, 도구, 제스처, 모양, 툴바)을 이름을 붙여 태블릿 안에 저장합니다. 목록에서 **Load**로 되돌리거나 지울 수 있습니다. 불러오면 화면이 한 번 다시 열리고, 노트는 그대로입니다.
  - **Save to a file / Open a file**: 같은 설정을 파일로 저장하거나 엽니다(다른 태블릿으로 옮길 때).
  - **Reset toolbar**: 툴바를 처음 상태로 돌립니다. 크기별 도구와 순서, 가로 방향, 크기(1/4), 배율, 애니메이션, 위치, 고정 여부가 모두 처음대로 돌아갑니다. 다른 설정은 그대로입니다.

## Web & AI에 원하는 주소 추가
- **Settings › Web & AI › Your sites**에서 **+ Add a site**로 주소와 이름을 넣어 추가합니다. `example.com`처럼 써도 https로 엽니다.
- 추가한 사이트는 툴바의 AI 메뉴, 브라우저 패널 위쪽 칩, Web & AI 목록에 함께 나옵니다. 순서 바꾸기(Up)와 지우기가 됩니다.
- 브라우저 패널에서 목록에 없는 사이트를 보고 있으면 칩 끝에 **+ Add this site**가 나와서 바로 추가할 수 있습니다.
- 설정 파일/저장된 설정에도 함께 들어갑니다.

## 업데이트: 자동 / 수동 릴리즈
- 이제 릴리즈마다 **자동 업데이트**와 **수동 업데이트**를 나눌 수 있습니다.
  - **자동**(기본): 지금처럼 앱을 열 때 새 버전 알림이 뜹니다.
  - **수동**: 알림이 뜨지 않습니다. 홈 화면 메뉴의 **About · Help**에 들어가면 "Version X is ready (manual update)"와 **Update** 버튼이 보이고, 거기서만 업데이트합니다.
- 수동 릴리즈는 릴리즈 노트에 `<!-- update: manual -->` 한 줄이 들어 있는 것으로 구분합니다(릴리즈 페이지에는 보이지 않습니다). Actions에서 APK 워크플로를 직접 돌릴 때 `update`를 `manual`로 골라도 됩니다.
- 이전 버전에서 수동 버전으로 건너뛰는 사이에 자동 버전이 끼어 있으면, 그 자동 버전 때문에 알림은 뜨고 가장 새 버전을 받습니다.
- 이 0.73.0은 **자동** 업데이트입니다.

## 기기에서 확인할 것
- 툴바·팝업·슬라이더 테두리: 왼쪽 위가 밝고 오른쪽 아래가 약하게 밝은지, 흰 종이 위에서도 테두리가 보이는지 (밝은/어두운 모드)
- 세로 툴바 4/4에서 Functions 버튼을 아래로 끌어 3/4·2/4로 커지는지, 가운데에서 놓아 가로로 돌아가는지, 길게 눌러 끌면 툴바가 움직이는지
- 가로 4/4에서 오른쪽으로 끌어 1/4까지 한 번에 이어지는지
- 1/4에서 도구를 누르고 좌우로 끌 때 렌즈가 생기고 위아래 줄로 넘치지 않는지
- 가로↔세로, 왼쪽↔오른쪽 전환 애니메이션
- 오른쪽 가장자리 두 번 탭 → 툴바가 위로 사라짐, 위쪽 탭 누르기/당기기로 돌아옴, 설정에서 동작 바꾸기
- Pages에서 펜을 2초 올려 미리보기, 펜을 떼거나 옮기면 닫힘
- Pages/목차/Go to로 이동 후 "Back to page N"
- PDF 노트 검색 결과를 눌렀을 때 표시가 바로 뜨는지
- 무한 노트 두 종류: 끝까지 내려가거나 오른쪽으로 가면 계속 늘어나는지, 다시 열면 가운데에서 열리는지
- 마이크·받아쓰기 패널 모양과 녹음 버튼 애니메이션, 녹음/재생/받아쓰기 동작
- Tools에서 탭을 바꿀 때 위쪽이 고정되는지
- Save & reset: 저장 → 다른 설정으로 바꾼 뒤 Load, Reset toolbar
- Web & AI에 사이트 추가 → AI 메뉴와 브라우저 칩에 나오는지, + Add this site
- About · Help에 새 버전 줄이 보이는지(다음 릴리즈부터 확인 가능)
