# Notesis 0.40.0 (103)

설정 저장·불러오기를 추가하고, 펜 자국이 펜 위치와 어긋나 보이던 문제와 특정 확대 수준에서 글자가 깜박이던 문제를 고쳤습니다.

## 설정 저장 · 불러오기

- 노트 목록 오른쪽 아래 **백업 버튼** 메뉴에 **설정 저장**과 **설정 불러오기**가 생겼습니다.
- 펜과 펜 프리셋, 도구·지우개·올가미 옵션, 손가락·제스처, 스킨과 화면 설정, 툴바 구성, 빠른 색, 시계 설정(타이머 시간, 알람, 순공 측정 방식)을 `Notesis-설정.json` 파일 하나로 저장합니다.
- 불러오면 바로 적용되고 화면이 한 번 새로 열립니다. 다른 태블릿으로 옮길 때도 쓸 수 있습니다.
- 파일에 넣지 않는 것: 노트 잠금, 노트마다 마지막으로 본 페이지·보기 방식, 이 기기에서만 열 수 있는 홈 배경 사진, 이 기기 화면에 맞춘 필기 표시 방식, 진단 ID, 돌아가는 타이머·스톱워치와 순공 기록.

## 고친 문제

### 쓰는 동안 펜 자국이 펜 위치와 다르게 보이던 문제

- 유리(글래스) 스킨에서 툴바·패널의 유리 효과가 뒤에 있는 페이지를 녹화해서 다시 그리는데, 이 녹화에 **필기 중인 잉크를 그리는 별도 화면 층**까지 함께 들어가 있었습니다. Android는 이런 화면 층을 마지막으로 그려진 위치로 옮기기 때문에, 유리 효과가 녹화를 조금 옮기고 축소해 그릴 때마다 쓰고 있는 잉크도 그쪽으로 밀려 보였습니다. 펜을 떼면 페이지가 직접 그린 획만 남으니 제자리로 돌아온 것처럼 보였습니다.
- 이제 유리 효과는 **완성된 페이지만** 녹화하고, 필기 중 잉크 층은 녹화하지 않습니다. 필기 중 잉크는 항상 펜 끝 아래에 그려집니다.

### 특정 확대 수준에서 글자가 흐림↔선명을 반복하던 문제

- PDF 페이지는 확대하면 선명한 조각(타일)으로 그립니다. 확대 배율이 약 2배·4배를 막 넘는 구간에서는 한 화면에 필요한 타일이 캐시보다 많아져, 새 타일을 그릴 때마다 이미 보이던 타일이 밀려나고 다시 그리기를 끝없이 반복했습니다(가로 2560px 태블릿의 가로 맞춤 배율이 딱 이 구간입니다).
- 이제 화면에 필요한 타일이 캐시에 다 들어가지 않으면 한 단계 낮은 해상도를 씁니다. 이 구간에서는 차이가 몇 퍼센트라 거의 같은 선명도이고, 가만히 두면 더 이상 다시 그리지 않습니다. 화면을 조금 움직일 때 해상도가 왔다 갔다 하지 않도록 계산을 고정했습니다.

## 참고

- 이 환경에는 Android SDK가 없어 빌드와 단위 테스트는 GitHub Actions에서 수행합니다. 실제 기기에서 두 문제가 사라졌는지 확인하지는 못했습니다.
- 메모리가 적은 기기에서 PDF 페이지 두 장이 함께 보일 때 생길 수 있는 비슷한 깜박임은 이번에 다루지 않았습니다.
