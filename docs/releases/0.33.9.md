# Notesis 0.33.9

- 불투명한 펜·필압 펜을 AndroidX Ink의 메시 셰이더로 그리는 실험 옵션을 추가했습니다. 기존 방식은 획 윤곽을 경로로 채우며, 가장자리 안티앨리어싱을 GPU 경로 렌더러에 맡깁니다. 메시 셰이더는 화면 배율을 반영해 가장자리를 직접 계산합니다.
- 펜 설정의 ‘메시 렌더링 (실험)’ 스위치로 켜고 끌 수 있으며, 기본값은 켜짐입니다. 끄면 이전 방식으로 바로 돌아가므로, 같은 필기를 확대해 두 방식을 비교할 수 있습니다.
- 화면에 그리는 방식만 바뀝니다. 저장되는 획, PDF 내보내기, 반투명 펜·형광펜·마스킹은 기존과 같습니다.

검증: 코드 변경만 했고, 실제 S펜 기기에서 화질은 아직 비교하지 않았습니다.
