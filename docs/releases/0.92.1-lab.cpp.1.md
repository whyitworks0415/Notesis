# Notesis Lab 0.92.1-lab.cpp.1 (233)

<!-- update: manual -->

> C++ 이전 **1/4단계** 프리릴리즈입니다. 정식 0.92.1(232)을 기준으로 만들었습니다. 전체 C++ 이전 완료판은 아닙니다.
> `com.notesis.lab`으로 정식판과 함께 설치합니다. 정식판의 노트는 내보내기·가져오기로 복사해 시험할 수 있습니다.

## 바뀐 점

- 필기 후처리의 시작 정지 구간, 접촉·종료 돌기, 획 중간 정지·반전 구간의 계산을 C++로 옮겼습니다. 충분히 긴 획은 일괄 호출하며, 입력 이벤트마다 JNI를 호출하지 않습니다.
- 기존 NTSS v1~v4 페이지 파일의 획 레코드 해석을 C++로 옮겼습니다. 색상·레이어·펜촉·순서·입력 바이트를 유지합니다. 파일 I/O와 Ink 메시 생성까지 이전한 것은 아닙니다.
- 진단에 **C++ bulk processing** 비교 스위치, 코어 상태, 실제 호출 횟수를 넣었습니다.
- 라이브러리 미준비·꺼짐·안전 모드·범위 밖에서는 기존 경로를 사용합니다. 작은 획, 8MiB 초과 파일, 동시 페이지 읽기도 기존 경로를 유지합니다.
- 직접 버퍼는 동시에 하나만 사용하며 메모리 회수 요청 때 비사용 버퍼의 참조를 해제합니다.
- Material 화면, 노트가 카드에서 열리는 모션과 뒤로가기, 기존 저장 형식은 정식 0.92.1을 유지합니다. 자체 표시 버퍼는 계속 기본 꺼짐입니다.
- Lab 업데이트는 Lab 프리릴리즈만 읽고, 정식 앱 업데이트는 Lab 태그와 APK를 제외합니다. 정식 main에는 이 변경을 합치지 않습니다.

## 확인 방법

- C++ 주소/정의되지 않은 동작 검사: 파일 버전·잘림·길이·잘못된 좌표·타임스탬프.
- JNI 회귀시험: 세 후처리 모드를 기존 Kotlin 알고리즘과 무작위 입력으로 비교, v1~v4 파일의 메타데이터·입력 위치 검증.
- 빌드 및 JVM·Robolectric 회귀시험은 배포 CI에서 통과해야 서명·게시됩니다.
- 호스트 측정 파일은 시험용 레코드의 해석 시간만 나타냅니다. 기기 측정이나 앱 개선율이 아닙니다.

## 아직 하지 않은 것

- **실기기 시험과 성능·발열·배터리 개선 측정은 하지 않았습니다.**
- 문서 모델·저장·Undo·Redo의 C++ 소유권, 캔버스·입력·그래픽 전면 이전, Compose UI의 네이티브 재구현은 다음 단계입니다.
- 이번 빌드의 Kotlin 코드가 모두 제거된 것은 아닙니다. 자세한 범위는 첨부한 `Cpp-migration.md`를 참고하세요.

## 태블릿에서 해 볼 것

1. 진단에서 코어가 Loaded인지 확인합니다.
2. 동일 노트를 C++ 켜기/끄기로 다시 열고, 호출 횟수와 성능 기록을 비교합니다.
3. 실제 펜으로 필기·부분지우개·Undo·Redo·레이어 변경 후 닫았다 다시 열어 보세요.
4. 60Hz·절전 모드에서도 필기 누락, 끊어진 획, 달라진 모양이 없는지 확인합니다.
5. 정식판으로 내보내기·가져오기 왕복을 해 보세요. 시험은 복사한 노트로 진행할 수 있습니다.
