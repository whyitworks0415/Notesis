# Notesis 0.90.18 (209)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 다크 모드에서 안 보이던 글자

- 최상위 테마에서 기본 글자·아이콘 색을 명시합니다. `MaterialTheme`만으로는 `LocalContentColor`가 바뀌지 않아 Surface 밖의 일반 Column/Box에서 검정 글자와 아이콘이 남던 경로를 수정했습니다.
- 설명·힌트·날짜·검색 안내·업데이트 안내에 테두리용 색을 쓰던 곳을 보조 글자 색으로 바꿨습니다. 보조 글자 색도 반투명 흰색 대신 불투명한 전용 색을 사용합니다.
- 강조색·버튼·선택 컨테이너의 전경색을 실제 바탕과 대조해 보정합니다. 검정·노랑·연두 같은 사용자 강조색도 읽을 수 있도록 하며, 저장된 사용자 색 값과 실제 필기 색은 바꾸지 않습니다.

## Material 개편

- 라이트는 옅은 회색과 종이색에 가까운 흰 카드, 다크는 차콜·그래파이트의 여러 층으로 구분합니다. 배경 화면에서 가져온 강조색은 버튼·선택 상태에 남깁니다.
- 툴바·패널·카드의 표면 역할을 나누고 얇은 경계를 더했습니다. 무거운 블러나 새로운 상시 애니메이션은 추가하지 않습니다.
- 설정 항목의 아이콘을 작은 강조색 타일에 담고 그룹·설명·제목의 계층을 정리했습니다. 제목·라벨의 굵기도 통일합니다.
- Material의 기본 눌림 상태 피드백을 복원했습니다. 유리 모드의 누름 모션은 유지합니다.
- AMOLED와 고대비 설정은 유지합니다.

## iOS 다크 모드 개편

- 검정·차콜·높은 패널의 색을 구분하고, 강조색과 보조 글자를 해당 표면에서 읽을 수 있도록 조정합니다.
- 흰 노트 페이지 위에서 밝은 글자가 묻히지 않도록 유리의 어두운 읽기 바탕을 보강합니다. 패널은 바보다 더 짙습니다. 야간에는 종전보다 투명도가 낮게 보일 수 있으며, 곡률·굴절·테두리 광학 효과는 유지합니다.
- 팝업 창은 더 안정적인 어두운 표면을 사용하고, 노트 목록 카드의 제목 영역도 밝은 사용자 배경 위에서 읽을 수 있도록 했습니다.

## 검증

- 색상 쌍의 대비, 여러 강조색, AMOLED·고대비, 흰 종이 위의 iOS 다크 바탕을 단위 테스트합니다. 일반 글자의 목표는 4.5:1 이상이며, 실제 동적 배경의 모든 픽셀을 보장하는 수치는 아닙니다.
- Robolectric에서 Material 라이트·다크와 iOS 다크의 정적 UI 및 기본 글자 색 전달을 검사합니다. 버튼 내부의 자체 글자 색이 덮어써지지 않는지도 확인합니다.
- 릴리스 빌드와 전체 단위 테스트를 실행하며, 실제 결과는 PR/CI에 기록합니다. 시뮬레이션의 정적 미리보기는 실제 기기 AGSL 유리·창 합성·성능 검증과 다릅니다.
