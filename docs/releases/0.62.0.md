# Notesis 0.62.0 (147)

## 툴바가 두 줄이 될 만큼 좁으면 세로 툴바로
- 창이 좁아서 2/4~4/4 툴바의 도구가 한 줄에 다 들어가지 않으면(두 줄 이상이 되면) 툴바가 자동으로 세로(측면) 툴바로 바뀝니다.
- 창이 다시 넓어져서 한 줄에 들어가면 원래 가로 툴바로 돌아옵니다.
- 측면 툴바는 설정의 Side(왼쪽/오른쪽)를 따르고, 나가기 버튼도 측면 툴바와 같은 줄에 놓입니다.
- 방향을 직접 Vertical로 정해 둔 경우는 지금처럼 항상 세로입니다.

## 펜·지우개 설정에서 스크롤 없이
- 펜 설정에서 Pressure(필압) 스위치가 펜 종류 줄 오른쪽에 붙어 있어서 펜 종류를 가리던 것을 고쳤습니다. Pressure는 펜 종류 아래에 별도 줄로 옮겼습니다.
- 펜 종류와 선 모양(Solid, Dotted …) 칩은 옆으로 스크롤하지 않고, 자리가 모자라면 다음 줄로 넘어갑니다.
- 지우개 설정의 "Erases"(지울 대상) 칩도 스크롤 없이 두 줄로 나뉘어 한눈에 보입니다.

## AI(웹) 화면 상단
- 상단 막대가 페이지 맨 위 색을 한 가지 색이 아니라, 맨 위 가로 다섯 지점의 색을 각각 읽어 왼쪽에서 오른쪽으로 이어지는 그라데이션으로 보여 줍니다.
- 페이지를 확인하는 간격을 1.5초에서 0.2초로 줄였습니다. 색이 바뀔 때는 확인 간격만큼 천천히 이어서 바뀌므로, 스크롤하거나 테마가 바뀌어도 끊기지 않고 따라갑니다.
- Liquid glass와 Glassmorphism에서는 막대를 유리처럼 보이게 했습니다. 위쪽에 빛이 맺히고 아래로 갈수록 옅어지며, 위·아래 가장자리에 밝은 선이 있습니다. Material에서는 색만 칠합니다.
- 막대 아래의 구분선을 없앴습니다.

## AI(웹) 화면을 감싸던 흰 배경 제거
- 웹 화면 둘레(내비게이션 바, 화면 가장자리 쪽 여백)에 보이던 흰 배경을, 그 페이지 아래쪽의 색으로 바꿨습니다. 페이지와 둘레가 한 색으로 이어집니다.

## 레이저 삭제
- 툴바의 Laser 도구, 레이저 설정 창, 레이저 색·모양 설정을 없앴습니다. 툴바 배치에 레이저를 넣어 둔 경우에도 자동으로 빠집니다.
- 읽기(제스처) 모드에서 펜이 지나간 자리를 보여 주는 궤적과, 탭한 곳에 퍼지는 원은 그대로입니다.
