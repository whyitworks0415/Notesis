# Notesis 0.99.18 (259)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## Liquid glass와 Glassmorphism이 돌아왔습니다
- 0.91.0에서 빼 두었던 유리 화면 두 가지를 다시 넣었습니다. **설정 → 모양**에서 Material, Glassmorphism, Liquid glass 중에 고릅니다.
  - **Glassmorphism:** 뒤의 노트가 흐리게 비치는 반투명 유리입니다.
  - **Liquid glass:** 뒤를 휘게 굴절시키는 렌즈 유리입니다. 툴바에서 도구를 고르면 선택 표시가 렌즈가 되어 손가락을 따라 미끄러집니다.
- 툴바, 사이드바, 팝업, 메뉴 등 모든 테두리 화면에 한꺼번에 적용됩니다. 노트 쪽 자체는 바뀌지 않습니다.
- 예전에 고른 스타일(Notesis, iOS, Mornye)과 유리 설정(흐림, 굴절, 투명도, 모서리 등)이 저장되어 있었다면 그대로 돌아옵니다.
- 유리가 뒤를 보려면 노트 화면과 홈 화면을 한 번 더 그려 두어야 합니다. 그래서 다음 경우에는 다시 그리지 않고 방금 그린 그림을 씁니다.
  - 펜으로 쓰거나 스크롤하거나 패널이 움직이는 동안
  - 절전 모드일 때 (유리가 불투명해집니다)
  - Android 12 미만일 때 (유리를 그리지 않습니다)
- 지난 버전들에서 바꾼 Material 화면(같은 모양의 사이드바, 팝업 높이 등)은 그대로입니다. 유리 부분만 다시 넣었습니다.

## 사이드바는 한 번에 하나만 열립니다
- 페이지(검색 포함), 설정, 레이어, Agent 패널이 같은 자리를 씁니다. 하나를 열면 열려 있던 다른 패널이 닫히고 새 패널로 바뀝니다. 이전에는 여러 개가 겹쳐 열렸습니다.
- 인터넷 AI 패널은 노트 옆에 붙어 노트를 좁히는 방식이라 따로 남겨 두었습니다.

## Ask agent: 키보드가 대화를 가리던 문제
- 입력창을 누르면 키보드가 대화창 아래쪽을 덮어 대화와 입력창이 보이지 않았습니다.
- 이제 대화창이 키보드 위로 올라가고, 최신 대화가 보이도록 아래로 내려갑니다.

## 어떻게 확인했나
- 릴리스 빌드, Lint, 전체 단위 테스트를 돌렸습니다.
  - 예전 유리 테스트(렌즈 이동, 스타일, Mornye 등)도 다시 넣었습니다.
  - 새 테스트: 패널을 하나만 남기는 규칙
- 스크린샷 테스트로 Glassmorphism과 Liquid glass 패널이 그려지는 것을 확인했습니다. 다만 테스트 환경에는 GPU 셰이더가 없어서, 실제 굴절 대신 흐린 유리 대체 화면으로 확인했습니다.

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 확인하지 못했습니다.** 굴절, 블러, 렌즈 움직임과 필기·스크롤 속도는 기기에서 봐야 합니다. 유리는 노트를 한 번 더 그리므로 Material보다 무겁습니다. 느리면 Material로 바꾸거나 설정에서 흐림을 0으로 낮추세요.
- 예전의 "버튼에서 쏟아지는" 팝업 애니메이션은 다시 넣지 않았습니다. 팝업은 지금처럼 누른 곳에서 자라납니다.
- 처음 설치할 때 나오는 안내 화면과 툴바에 있던 스타일 고르기 버튼은 다시 넣지 않았습니다. 설정 → 모양에서 고릅니다.
- Liquid glass의 슬라이더·스위치 모양은 지금의 Material 컨트롤을 그대로 씁니다.

## 태블릿에서 해 볼 것
1. 설정 → 모양에서 Liquid glass 고르기 → 툴바와 패널 뒤로 노트가 휘어 보이는지. 도구를 고르면 렌즈가 미끄러지는지.
2. Glassmorphism으로 바꾸기 → 뒤가 흐리게 비치는지.
3. 유리 스킨에서 계속 쓰고 스크롤하기 → 느려지지 않는지.
4. 페이지 패널을 연 상태에서 설정 열기 → 페이지 패널이 닫히고 설정만 보이는지.
5. Ask agent 입력창 누르기 → 키보드 위로 대화와 입력창이 보이는지.
