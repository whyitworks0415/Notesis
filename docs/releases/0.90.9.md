# Notesis 0.90.9 (200)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

## 바뀐 점

- **노트 밖(화이트보드) 필기가 쓰는 도중에도 깨지지 않게** 했습니다. 0.90.8에서 펜을 뗀 뒤의 잉크는 고쳐졌지만, 쓰는 중의 잉크는 여전히 큰 문서 좌표(필기가 많은 노트에서는 수만 단위) 그대로 만들어져서 검은 쐐기 모양이 생겼습니다.
  - 이제 화이트보드 획은 쓰기 시작한 점 근처의 원점(512 단위 격자)을 기준으로 실시간 잉크를 만들고, 펜을 뗄 때 원래 문서 좌표로 옮겨 저장합니다. 저장되는 획의 좌표와 파일 형식은 그대로입니다.
  - 페이지 위 필기는 바뀌지 않았습니다.

## 확인한 것

- CI에서 빌드, 단위 테스트, 스크린샷 테스트를 돌렸습니다.
- 기기(태블릿)에서는 시험하지 못했습니다. 성능은 측정하지 않았습니다.

## 하지 않은 것

- 화이트보드 획은 펜을 뗄 때 좌표를 옮기느라 한 번 더 만들어집니다. 획 하나당 한 번이며, 쓰는 도중에는 일이 늘지 않습니다.

## 태블릿에서 해볼 것

1. 필기가 많은 노트에서 페이지 밖(아래쪽 멀리)에 길게 써 보고, 쓰는 도중에 검은 쐐기가 생기지 않는지 봅니다.
2. 펜을 뗀 뒤 획이 같은 자리에 그대로 남는지, 위치가 튀지 않는지 봅니다.
3. 되돌리기/다시 실행, 지우개, 올가미 선택이 화이트보드 획에서 전처럼 되는지 봅니다.
4. 페이지 위 필기가 전과 같은지 봅니다.
