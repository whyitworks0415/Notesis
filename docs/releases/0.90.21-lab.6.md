# Notesis Lab 0.90.21-lab.6 (217)

<!-- update: manual -->

> 수동 Lab 사전 릴리스입니다. 기존 Notesis Lab에 업데이트 설치하며 정식판과 별도입니다.

- 타일의 선택적 신규 기록은 기록 시간뿐 아니라 그리기 시작 후 경과 시간과 직전 타일의 검색·기록 비용을 함께 확인합니다. 한 프레임의 선택적 기록은 최대 8개이며, 밀린 작업은 다음 프레임으로 넘깁니다. 최소 한 타일은 진행합니다. 편집 때문에 바뀐 필기는 정확성을 위해 즉시 갱신하는 기존 경로를 유지합니다. 큰 타일 하나의 작업 자체를 중단하는 방식은 아닙니다.
- 노트를 처음 열 때 현재 페이지를 다른 보이는 페이지보다 먼저 읽고 반영합니다. 주변 페이지 로딩과 정밀 보정 때문에 첫 페이지 반영이 기다리지 않도록 분리했으며 나머지 페이지는 후속 요청으로 읽습니다. 기존 저장 형식은 유지합니다.
- 측정 로그에 `tile query+record (frame)`과 `tile cleanup (frame)`을 추가했습니다. 전자는 타일 검색과 기본 기록 시간, 후자는 캐시 정리 시간입니다. GPU 업로드 완료나 실제 화면 출력 시각은 아닙니다.
- Ink 렌더 계측은 공통 완료 필드 외에 front-buffer/HWUI 백엔드의 실제 그리기 완료 필드도 확인합니다. 추정 표시 시각을 실제 완료로 대체하지 않습니다. `ink callbacks`와 누락 개수로 콜백 자체가 없는 경우와 타임스탬프가 없는 경우를 구분합니다. 기기에서 콜백이 제공되지 않으면 지연 값은 계속 `-`일 수 있습니다.
- 프레임 작업 허용 범위, 첫 로딩 순서와 후속 로딩, 백엔드 완료 필드·잘못된 타임스탬프의 회귀 검사를 추가했습니다. 전체 단위 테스트와 릴리스 빌드·UI/JNI·서명 검증을 거쳐 게시합니다.

실기기의 속도·프레임·발열 개선율은 아직 측정하지 않았습니다. 216과 같은 노트·100% 확대·120Hz 조건에서 벤치마크를 비교하고, 실제 필기와 부분 지우개 사용 후 일반 측정 로그도 확인해 주세요. 첫 노트 열기와 미리보기에서 실제 획으로 바뀌는 과정, 여러 페이지가 보이는 상태의 로딩 누락도 확인해 주세요.
