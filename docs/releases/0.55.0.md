# Notesis 0.55.0 (140)

## 새 앱 아이콘
- 앱 아이콘을 `>_` 모양으로 바꿨습니다. 검정 배경 위에 흰색 `>`가 있고, `_` 자리에 펜이 누워 있으며 펜촉은 민트색입니다.
- 아이콘을 벡터로 그려서 화면 밀도와 상관없이 선명합니다. 런처가 원형이든 둥근 사각형이든 어떤 모양으로 잘라도 기호가 안전 영역 안에 들어옵니다.
- 테마 아이콘(Android 13 이상의 단색 아이콘)도 같은 모양으로 들어 있습니다.

## 처음 실행할 때 환영 애니메이션
- 손으로 그린 사각형이 반듯해지던 부분을 새 아이콘을 그리는 장면으로 바꿨습니다.
  1. 이름이 써진 뒤 펜이 내려와서 아이콘의 둥근 사각형을 한 바퀴 그립니다.
  2. 사각형이 흰 종이로 바뀌며 살짝 떠오릅니다.
  3. 같은 펜이 `>`를 씁니다.
  4. 펜이 위로 튀어 오르며 한 바퀴 돌고 `_` 자리에 떨어집니다. 바닥에 닿으면 조금 튕기며 자리를 잡습니다.
- 결과는 흰 바탕에 검정 `>`와 펜입니다. 다크 모드에서도 흰 종이 위에 검정으로 끝납니다.
- 사각형 아래에 있던 "Hold the pen still…" 문구는 없앴습니다.
- 지금처럼 화면을 탭하거나 Skip을 누르면 건너뛸 수 있습니다.
- 환영 애니메이션을 다시 보려면 About & help에서 처음 설치 상태로 되돌린 뒤 앱을 다시 실행하면 됩니다.
