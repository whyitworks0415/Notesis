# Notesis 0.31.0 (versionCode 61)

태블릿에 설치할 서명 APK는 아래 Assets에서 받으세요.

## 필기와 도형

- 자유 필기를 직선·사각형·타원으로 바꾸는 자동 도형 인식과 켜기/끄기를 추가했습니다.
- 직선 도형이 수평·수직에 가까울 때 자동으로 맞추는 옵션을 추가했습니다.
- 획 보정을 기본 0%에서 100%까지 조절할 수 있습니다.
- 연필 도구를 추가했습니다.
- 실선, 점선, 파선, 일점쇄선 세 가지 점선 패턴을 선택할 수 있습니다.
- 하나의 펜 동작이 여러 선분으로 만들어져도 실행 취소·다시 실행 한 번으로 함께 처리합니다.

## 노트와 페이지

- 폴더 생성·이름 변경·삭제와 노트 이동을 추가했습니다.
- 여러 노트를 선택해 폴더 이동, 병합, 삭제할 수 있습니다.
- 무지·줄·좁은 줄·모눈·도트·코넬 템플릿과 긴 무한 노트를 추가했습니다.
- 사용자가 이미지를 페이지 템플릿으로 등록하고 새 노트나 기존 페이지에 적용할 수 있습니다.
- 세로/가로 스크롤과 1×1, 2×1 펼침, 2×2 페이지 보기를 추가했습니다.
- 페이지 순서를 앞뒤로 옮기고 PDF 노트의 페이지를 추가·삭제·재배치할 수 있습니다.
- 여러 필기/PDF 노트를 편집 가능한 한 노트로 병합할 수 있습니다.
- 외부 파일 앱에서 PDF를 열면 Notesis 노트로 가져옵니다.

## 녹음, 재생, OCR, 내보내기

- 노트별 음성 녹음·재생·삭제를 추가했습니다.
- 현재 페이지의 필기를 획 순서대로 재생할 수 있습니다.
- 올가미로 고른 필기만 OCR하고 결과를 복사할 수 있습니다.
- 페이지 범위를 골라 PDF 또는 PNG로 내보낼 수 있으며 원본/A4/Letter 크기와 0/90/180/270도 회전을 지원합니다. 여러 PNG는 ZIP으로 저장합니다.
- 부분 캡처를 PNG 파일로 바로 저장할 수 있습니다.
- Android 시스템 파일 선택기를 통해 Google Drive와 OneDrive의 파일을 열고 내보낼 수 있습니다. 해당 서비스 앱이 기기에 파일 제공자로 등록되어 있어야 합니다.

## AI와 성능

- AI 창을 도킹 또는 팝업으로 전환할 수 있고, 도킹 크기 조절 중에는 윤곽만 표시한 뒤 손을 떼면 적용합니다.
- 키보드 표시 시 노트 화면이 튀는 문제를 줄이도록 시스템 바와 키보드 인셋을 분리했습니다.
- 많은 획을 화면 영역별로 걸러 그리고 제한된 캐시를 사용합니다.
- 디버그 표시에 FPS, 프레임 시간, 입력률, 지연, 예측 시간, 화면 획 수, 그리기 시간과 확대율을 표시합니다.

`testDebugUnitTest`와 서명된 Release APK 빌드를 통과했습니다.
