## 바뀐 점

### 1. 첫 화면 스크롤
- **확인한 것**: 썸네일은 원래부터 노트 폴더에 그림 파일(`auto.png`, 직접 고른 그림은 `thumb.png`)로 저장되어 있었고, 스크롤할 때 그 파일을 백그라운드에서 읽어 메모리에 보관하고 있었습니다. 말씀하신 방식은 이미 들어가 있었습니다.
- **찾은 원인 후보와 고친 것**:
  - **화면 전체 모션 블러**: 0.90.27에서 넣은 목록 모션 블러가 첫 화면 목록 전체에 걸려 있었습니다. 빠르게 넘기는 동안 화면 전체를 따로 그려서 흐리게 하는 일을 매 프레임 했습니다. 첫 화면에서는 뺐습니다(메뉴·패널 안 목록은 그대로).
  - **썸네일 읽기 몰림**: 빠르게 넘기면 새로 들어오는 카드마다 그림 읽기가 동시에 시작돼, 태블릿 코어가 모두 그림 읽기에 쓰였습니다. 이제 한 번에 2개까지만 읽습니다.
  - **미리 읽기**: 첫 화면이 뜨고 잠시 뒤, 보이는 순서대로 썸네일을 메모리에 미리 올려 둡니다(메모리 여유만큼, 대략 수십 개). 스크롤 중에는 멈춥니다. 보관 메모리도 조금 늘렸습니다.
- **썸네일 교체**: 필기 중에는 썸네일을 20초에 한 번만 다시 그리는데, 그 20초 안에 첫 페이지를 고치고 노트를 닫으면 예전 그림이 남았습니다. 이제 첫 페이지가 바뀌었으면 노트를 닫을 때 꼭 다시 그립니다.

### 2. 도형 설정
- 도형 도구를 **처음 누를 때 바로** 도형 설정 창이 열리게 했습니다. 지금까지는 첫 번째 누름은 도형 선택, 두 번째 누름에 설정이 열렸습니다.
- 도형 설정 창과 도형 펜 설정 창 자체가 열리는지는 자동 시험으로 확인했습니다. **"안 켜진다"는 상황을 제가 재현하지는 못했습니다.** 이번에도 안 열리면 어느 버튼을 눌렀는지 알려 주세요.

### 3. 텍스트의 표 기능 제거
- 텍스트 도구의 표 만들기, 표 편집 창, 표 그리기 코드를 모두 지웠습니다.
- 이미 노트에 있던 표는 **내용이 사라지지 않게 일반 글로** 바뀝니다(한 줄에 한 행, 칸 사이는 탭). 수식 칸은 수식 글자 그대로 남습니다.

### 4. 사이드바·AI 창 모서리
- 설정 사이드바, 페이지 패널, 옆에 붙은 AI 창은 화면 오른쪽 끝에 붙는 쪽 모서리를 직각으로 바꿔 끝까지 꽉 차게 했습니다. 떠 있는 AI 창은 그대로 네 모서리가 모두 둥근 모양입니다.

### 5. 펜 설정
- 탭 순서를 **Color, Setting**으로 바꾸고, 펜 설정을 열면 Color가 먼저 나옵니다(색이 없는 지우개는 Setting).
- HSV 막대 모드의 `#______` 입력칸을 다른 모드와 같은 자리(아래 줄, 색 견본과 스포이트 사이)로 옮겼습니다.
- **팔레트**를 다시 만들었습니다. 이름 아래에 색이 줄바꿈되며 다 보이고(잘리지 않음), 색을 조금 키웠고, 지금 쓰는 색에 테두리가 표시됩니다. 팔레트 칸도 높였습니다.

### 6. Tools
- 계산기·시계·달력·할 일 탭을 모두 같은 높이로 맞췄습니다. 어느 탭으로 열든 패널이 같은 자리·같은 크기에 뜨고, 내용이 긴 탭은 안에서 스크롤됩니다.

## 확인 방법

- 이 컨테이너에서 앱과 시험을 직접 빌드했고, 단위·Robolectric 시험 122개가 모두 통과했습니다.
- 새 시험: 썸네일을 다시 그리는 규칙, 미리 읽는 개수, 옛 표를 글로 바꾸기, 펜 설정 첫 탭, 끝에 붙는 패널 모양, 도형 설정 창과 도형 펜 설정 창이 열리는지, 툴바 크기마다 도형 버튼이 노트까지 전달되는지.

## 하지 않은 것

- **기기에서는 시험하지 않았고, 스크롤이 얼마나 나아졌는지 재지 않았습니다.** 위 두 원인은 코드를 읽어 찾은 것이라 이번에도 렉이 남으면 진단 → 성능 기록을 보내 주세요. 숫자로 다음 원인을 찾겠습니다.
- 최적화 다음 단계 중 기기 측정이 필요한 것(유휴 주사율, 메모리 예산, 작업 큐 등)은 성능 기록을 받은 뒤 하겠습니다.

## 태블릿에서 해 볼 것

1. 노트가 많은 첫 화면을 빠르게 위아래로 넘겨 보세요. 첫 화면이 뜬 뒤 1~2초 기다렸다 넘기면 더 부드러워야 합니다.
2. 노트 첫 페이지에 뭔가 쓰고 바로 닫아 보세요. 카드 썸네일이 바뀌어야 합니다.
3. 도형 도구를 한 번 눌러 설정 창이 뜨는지 보세요.
4. 펜 설정을 열면 Color 탭이 먼저인지, 팔레트가 잘리지 않는지 보세요.
5. Tools를 계산기·달력 등 다른 탭으로 열어도 같은 자리에 뜨는지 보세요.
