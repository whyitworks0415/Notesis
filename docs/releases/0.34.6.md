# Notesis 0.34.6 (93)

메시 렌더링을 사용하는 페이지에서 크게 확대했다가 축소할 때 필기가 사라져 보일 수 있는 캐시 처리 경로를 수정했습니다.

## 변경 사항

- 축소 중에도 확대 상태의 타일 해상도를 계속 유지하던 처리를 바꿨습니다. 배율이 절반 이하로 내려가거나 화면에 필요한 타일이 캐시 목표를 넘으면 현재 배율로 다시 만듭니다. 작은 배율 변화에서는 기존 캐시를 재사용합니다.
- 한 화면에 그리도록 예약한 타일과 페이지는 캐시 정리 대상에서 제외합니다. 여러 페이지를 그리는 경우에도 전체 화면의 기록을 마친 뒤 화면 밖의 항목만 정리합니다.
- 기존 24MiB/48MiB 캐시 목표는 유지하되, 화면에 필요한 타일 자체가 목표를 초과하는 경우에는 현재 필기를 표시하는 것을 우선합니다. 화면 밖의 캐시를 지워 용량을 줄입니다.
- 에뮬레이터 검증용 `-Pnotesis.testAbi=x86_64` 빌드 옵션을 추가했습니다. 일반 빌드의 기본 ABI는 기존과 같은 arm64-v8a입니다.
- 기존 0.34.5의 S6 Lite 호환 필기 표시·S펜 버튼 지우개 수정을 포함합니다. 호환 필기 표시에도 페이지→화면 좌표 변환을 적용해 확대·축소 상태에서 입력 위치에 획을 표시합니다.

## 검증

- JVM 단위 테스트 146개 통과. S펜 전용 동작 코드와 S6 Lite 모델 판별 검사 포함.
- 3,000획 GPU 비교 검사: 8배 확대 → 1배 축소, 손가락을 뗀 뒤 표시, 16배 확대 → 0.5배 축소 3회 반복에서 원본 메시 렌더링과 픽셀 차이 0.
- 캐시 목표를 2MiB로 낮춘 검사에서도 보이는 필기 픽셀 보존. 같은 화면을 다시 그릴 때 기존 타일을 반복 재기록하지 않는 것 확인.
- 형광펜 합성, 새 획 추가, 부분 영역 변경, 올가미, 메시 교체, 소수 배율 이동 검사 통과.
- 실제 Android View에 기존 3,000획과 합성 펜 입력 24획을 함께 표시하는 검사 통과.
- 호환 필기 표시를 켠 실제 View 입력 검사와 1배·8배·0.5배에서의 GPU 화면 좌표 검사 통과.
- arm64 release 빌드, 버전 0.34.6/93 및 APK v2 서명 확인.

GPU 검사는 Android 36.1 x86_64 / SwiftShader 에뮬레이터에서 수행했습니다. 실제 태블릿에서의 검증은 포함하지 않습니다.
