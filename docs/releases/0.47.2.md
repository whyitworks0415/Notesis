# Notesis 0.47.2 (121)

## 펜으로 쓰고 꾹 누르면 도형으로
- 새로 알아보는 도형:
  - **삼각형**
  - **사각형:** 꼭짓점은 항상 정확히 4개이고, 그린 자리에 생깁니다. 네 각이 직각에 가까우면 반듯한 직사각형으로 맞추고, 거의 수평이면 수평으로 맞춥니다.
  - **원:** 가로세로가 15% 안쪽으로 비슷하면 정원으로, 아니면 타원으로 만듭니다.
  - **꺾인 직선:** 꺾은 점이 그린 자리에 생깁니다.
  - **꺾인 곡선:** 휘어진 부분은 매끄러운 곡선으로 하고, 꺾인 점은 그대로 뾰족하게 둡니다.
- 꺾인 직선, 꺾인 곡선, 고르지 않은 사각형은 펜을 꾹 눌렀을 때만 만들어집니다. 자동 도형 인식에서는 직선, 삼각형, 직사각형, 원만 알아보고, 조건도 더 엄격하게 했습니다. 그래서 평소 글씨가 도형으로 바뀌지 않습니다.
- 사각형의 꼭짓점이 4개가 아닌 모양으로 나오던 문제를 고쳤습니다.
  - 원인: 도형 획을 꼭짓점 몇 개만으로 짧은 시간 안에 만들어서, 필기 엔진이 입력을 부드럽게 다듬는 과정에서 모서리를 깎아 먹었습니다.
  - 이제 꼭짓점마다 잠깐 머물고 변 길이에 맞춰 일정한 속도로 그려서, 모서리가 정확하고 변이 곧습니다.
  - 도형 도구, 자, 다각형, 둥근 모서리에도 똑같이 적용했습니다.
  - 올가미로 선택한 도형의 꼭짓점을 끌어 고치는 기능은 그대로 됩니다.

## AI(인터넷) 패널
- 키보드가 올라오는 동안 웹 페이지 크기를 프레임마다 바꾸던 것을 없앴습니다. 이것 때문에 버벅이고 입력창이 키보드를 따라 같이 올라왔습니다. 이제 키보드가 나타나면 바로 최종 높이로 맞추고, 키보드가 완전히 내려간 뒤에 원래대로 돌아옵니다.
