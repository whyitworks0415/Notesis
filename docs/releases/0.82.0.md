## AI에 캡처를 바로 첨부
- **지금까지**: Functions › Capture → 영역 드래그 → 대화상자에서 Attach to AI → 채팅에서 + → Files → 고르기. 여섯 단계였습니다.
- **이제**
  - AI 패널 위쪽 막대의 **캡처 버튼**(점선 사각형)을 누르고, 노트에서 보낼 부분을 드래그합니다. 손을 떼면 바로 채팅 입력창에 이미지가 붙습니다. **두 단계**입니다.
  - AI 패널의 **⋮ › Send this page to the chat**: 지금 보고 있는 페이지 전체를 한 번에 보냅니다.
  - 기존 캡처 대화상자의 **Attach to AI**도 같은 방식으로 바로 붙습니다.
- 캡처가 끝나면 쓰던 도구(펜 등)로 저절로 돌아옵니다. 드래그하기 전에 다른 도구를 고르면 채팅 캡처는 취소됩니다.
- **붙이는 방식**
  - 이미지를 채팅 입력창에 붙여넣은 것처럼 넣습니다. ChatGPT, Claude, Gemini는 붙여넣은 이미지를 받습니다.
  - 입력창이 받지 않으면 페이지의 파일 입력에, 그것도 없으면 끌어 놓기로 넣습니다.
  - AI 패널이 닫혀 있으면 열고, 페이지가 다 열릴 때까지 최대 12초 동안 다시 시도합니다.
  - 그래도 들어가지 않는 사이트에서는 예전처럼 "채팅에서 +를 누르고 '파일'을 고르세요" 안내가 나오고, 고르면 캡처가 들어갑니다.
- 보내는 이미지는 긴 변이 최대 2048픽셀인 PNG입니다. 글씨가 읽힐 만큼 선명하고, 빨리 보낼 수 있는 크기입니다.

## AI 패널 둥근 모서리 뒤의 흰 배경 제거
- **원인**
  - 패널 안쪽 배경(채팅 페이지의 아래쪽 색, 보통 흰색)과 웹 화면이 둥근 모양으로 잘리지 않고 네모로 칠해져, 둥근 모서리 자리에 흰 네모가 보였습니다.
  - 노트 옆에 붙인(도킹) 패널은 모서리 뒤가 노트가 아니라 책상색 띠였습니다.
- **수정**
  - 패널 내용을 모서리 모양대로 잘라 그립니다.
  - 도킹 패널은 모서리 크기만큼 노트 위에 겹쳐 놓습니다. 노트 쪽 둥근 모서리 뒤로 노트가 보입니다.
  - 화면 가장자리 쪽 모서리 뒤는 지금처럼 책상색입니다.
- 노트 오른쪽에 붙는 페이지 스크러버, 페이지 패널, 레이어 패널, 오른쪽 툴바는 겹친 만큼 안쪽으로 비켜서 패널에 가리지 않습니다.
- AI 패널도 이제 **사이드바**로 보고, 0.80~0.81의 Sidebars 투명도·색·어둡게 설정을 따릅니다.

## 확인 방법
- 빌드와 기존 단위 테스트만 확인했습니다.
- 실제 ChatGPT·Claude·Gemini 화면에서 붙여넣기가 되는지는 확인하지 못했습니다. 사이트가 바뀌면 붙여넣기를 받지 않을 수 있습니다. 그때는 위의 + › Files 안내로 넘어갑니다.

## 기기에서 확인할 것
- AI 패널의 캡처 버튼 → 드래그 → 채팅 입력창에 이미지가 바로 붙는지(ChatGPT, Claude, Gemini 각각)
- ⋮ › Send this page to the chat로 페이지 전체가 붙는지
- AI 패널의 둥근 모서리 뒤로 노트가 보이는지, 흰 네모가 없어졌는지
- 오른쪽 페이지 스크러버나 페이지 패널이 AI 패널에 가리지 않는지
