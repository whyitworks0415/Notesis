# Notesis 0.44.0 (108)

제스처 모드 표시, 세 손가락 회전, 기화펜, 필압 설정, 확대 단계, 올가미 미리보기 등을 넣고 자·각도기·삼각자와 레이저를 뺐습니다.

## 제스처 모드
- 펜으로 한 동작이 화면에 잠깐 남습니다. 드래그는 지나간 길이 파란 선으로 보였다가 사라지고, 버튼을 누른 채 탭하면 누른 자리에 원이 퍼집니다.
- PDF 글자를 드래그해 고를 때 펜을 떼기 전에도 선택 범위가 바로바로 따라옵니다. 예전에는 드래그 중에는 안 보이다가 펜을 떼야 나타났습니다.

## 세 손가락 회전
- 세 손가락을 돌리면 노트가 그 각도대로 돌아갑니다. 90° 근처(±4°)에서 손을 떼면 반듯하게 맞춰집니다.
- 노트가 돌아가 있어도 스크롤과 이동은 돌아간 노트 방향을 따라갑니다.
- 세 손가락을 위아래로 밀면 예전처럼 참고 창을 엽니다. 12° 이상 돌려야 회전으로 인식합니다.
- 도구막대의 회전 버튼은 다음 90° 칸으로 돌립니다.

## 펜
- 펜 종류에 **기화펜**을 넣었습니다. 쓰는 느낌은 필압 펜과 같지만 저장되지 않아서, 노트를 나갔다 오면 사라집니다.
- **필압 반영 정도**(0~100, 기본 10)를 펜·연필·지우개 설정의 세부 설정에 넣었습니다. 10은 지금과 같고, 0은 필압을 무시합니다. 값을 올릴수록 살짝 누를 때 더 가늘어집니다.
- 지우개 설정에 **필압 지우개**를 넣었습니다. 켜면 누르는 힘에 따라 지우개 크기가 바뀝니다. 가볍게 누르면 설정 크기의 20%, 세게 누르면 설정 크기 그대로입니다.

## 확대
- "화면 맞추기" 버튼을 없앴습니다. 대신 확대 수치(예: 100%)를 누르면 100·200·400·1000% 가운데 하나를 고를 수 있습니다.
- 원하는 값(10~1000%)을 입력해 바로 적용하거나, 저장해 두고 다음에 다시 쓸 수 있습니다. 저장한 값은 ×로 지웁니다.
- 핀치 확대가 지수함수처럼 치솟던 것을 고쳤습니다. 250%까지는 예전처럼 손가락 아래 내용이 그대로 따라오고, 그 위부터는 같은 만큼 벌리면 같은 만큼 커집니다. 그래서 1000%는 그만큼 오래 벌려야 닿습니다. 오므리면 벌린 만큼 정확히 돌아옵니다.

## 올가미
- 올가미를 그리는 동안, 지금 펜을 떼면 선택될 획·그림·텍스트 상자가 파랗게 칠해져 미리 보입니다.

## 도구막대
- 1/4~4/4 크기 전환이 부드러워졌습니다. 높이도 함께 움직이고, 새 내용은 흐려졌다 선명해지며 나타납니다.
- 기능 메뉴의 "전환 애니메이션"에서 전환 시간(0~1000ms, 기본 360ms)과 움직임(가감속·감속·일정·탄성)을 고를 수 있습니다.

## Spoti 유리
- 페이지 이동 막대의 손잡이가 평소에는 단색이고, 누르거나 끄는 동안에만 Liquid Glass로 바뀝니다.

## 제거
- 자, 각도기, 삼각자를 뺐습니다.
- 레이저 포인터를 뺐습니다. 펜 버튼 동작에서도 빠졌고, 레이저로 설정돼 있었다면 지우개로 바뀝니다.
