# Notesis 0.90.1 (192)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

## 고친 것

- **폴더 안에서 만든 노트가 폴더 밖에 생기던 문제:** 노트를 만드는 코드가 지금 열린 폴더를 모른 채 항상 맨 위에 노트를 만들고 있었습니다. 이제 첫 화면에서 만드는 노트는 열려 있는 폴더 안에 생깁니다.
  - 새 손글씨 노트, 새 Markdown 노트
  - Markdown 파일 가져오기, 사진으로 노트 만들기, 웹 페이지로 노트 만들기, PDF 가져오기
- 맨 위(폴더 밖)에서 만들면 예전처럼 맨 위에 생깁니다.
- 홈 화면 위젯의 **+ 새 노트**와 다른 앱에서 공유받은 파일은 지금처럼 맨 위에 생깁니다.

## 스마트 폴더

- **기간을 세밀하게:** "쓴 때"에서 **기간 정하기**를 고르면 막대가 나옵니다.
  - 1시간부터 30일까지 고를 수 있습니다: 1·2·3·6·12시간, 1~7일, 10일, 14일, 21일, 30일.
  - 단위가 시간과 날로 크게 달라서 고르게 늘어나는 막대 대신 이런 단계로 나눴습니다. 그래야 1시간도 30일도 손쉽게 맞출 수 있습니다.
- **최근에 연 노트:** "최근에 연 노트"에서 **최근에 연 것만**을 고르면 1~20개를 막대로 정합니다.
  - 그 폴더에는 마지막으로 연 노트가 연 순서대로 나옵니다.
  - 다른 조건(태그, 기간, 즐겨찾기, 종류)과 함께 쓰면 모두 맞는 노트만 나옵니다.
  - 연 기록은 이 태블릿에만 최근 20개까지 남고, 지운 노트는 빠집니다.
  - 기록은 이 버전부터 쌓입니다. 업데이트 직후에는 비어 있고, 노트를 열 때마다 채워집니다.
- 0.90.0에서 "최근 7일"·"최근 30일"로 만든 스마트 폴더는 그대로 7일·30일로 읽습니다.

## 펜 굵기 직접 입력

- 펜을 한 번 더 눌러 여는 **펜 설정 창**의 굵기 칸에 숫자를 직접 칠 수 있습니다. 막대 크기 2/4~4/4에서는 굵기를 이 창에서 정합니다.
  - 막대나 −/+로 바꾸면 숫자 칸도 따라 바뀝니다.
  - 범위 안의 숫자를 치면 바로 적용되고, 범위를 벗어나면 칸이 빨갛게 표시됩니다.
  - mm 표시는 숫자 칸 아래로 옮겼습니다.
- 1/4 막대에서는 예전처럼 굵기 버튼(▾)에서 입력할 수 있습니다.

## 도형 색

- 도형 도구를 한 번 더 누르면 나오는 **도형 창**에 **색** 칸을 넣었습니다.
  - 펜 줄의 빠른 색과 같은 색들이 나오고, 누르면 도형 색이 바뀝니다.
  - **다른 색과 굵기…**를 누르면 도형 도구의 전체 설정(모든 색, 굵기)이 열립니다.
- 도형 색은 펜 색과 따로 저장됩니다. 지금까지는 1/4 막대의 펜 줄에서만 바꿀 수 있었습니다.

## 분할 화면

삼성 분할 화면처럼, 두 노트가 주와 부가 아니라 같은 모양, 같은 조작으로 나란히 있도록 다시 만들었습니다.

- **모든 칸이 같은 모양:** 추가한 칸에만 있던 카드 테두리, 둥근 모서리, 아래쪽 막대를 없앴습니다. 모든 칸이 처음 연 노트처럼 책상 위에 페이지가 끝까지 놓입니다.
- **모든 칸이 같은 조작:**
  - 추가한 칸도 처음 연 노트처럼 축소하고 옆으로 옮길 수 있습니다. 전에는 화면 폭보다 작게 줄일 수 없었습니다.
  - 툴바의 실행 취소/다시 실행은 **마지막으로 쓴 칸**에 적용됩니다. 전에는 항상 처음 연 노트에만 적용됐습니다.
- **칸 사이 선:**
  - 8dp에서 3dp로 얇게 바꿨고, 가운데에 작은 손잡이가 있습니다. 손가락으로 잡는 범위는 그대로 넓습니다.
  - 선을 끌면 크기가 바뀝니다.
  - 선을 화면 끝 가까이까지 끌면 덮인 칸이 어두워지며 "놓으면 닫힘"이 뜨고, 놓으면 그 칸이 닫힙니다.
  - **처음 연 노트도 이렇게 닫을 수 있습니다.** 닫으면 옆 칸의 노트가 화면의 노트가 되고, 나머지 칸은 그대로 남습니다.
- **손잡이를 누르면:** 칸 서로 바꾸기, 각 칸의 노트 바꾸기, 둘로 나누기, 닫기를 할 수 있습니다. 처음 연 노트의 칸도 노트를 바꿀 수 있습니다.
- **툴바 유리:** 유리가 처음 연 노트만 비춰서, 다른 칸 위에서는 엉뚱한 페이지나 빈 책상이 비쳤습니다. 이제 유리 아래에 있는 칸이 그대로 비칩니다.
- 칸마다 있던 페이지 번호 버튼과 "폭에 맞춤" 버튼은 막대와 함께 없앴습니다. 페이지는 스크롤로 넘깁니다.

## 밝기

설정 → 밝기에 두 가지를 나눠, 각각 켜고 끄고 조절할 수 있게 했습니다.

- **이 앱에서의 기기 밝기(새 기능):** Notesis를 쓰는 동안 기기 화면 밝기 자체를 바꿉니다.
  - 기기 밝기보다 밝게도, 어둡게도 할 수 있습니다(2%~100%).
  - 켜면 지금 기기 밝기에서 시작하므로, 막대를 움직이기 전에는 바뀌지 않습니다.
  - 앱에서 나가면 화면이 기기에 설정된 밝기로 돌아갑니다. 다른 앱에는 영향이 없습니다.
- **앱 화면 어둡게(기존 "앱 밝기"):** 앱 화면 위에 어두운 막을 덮습니다. 기기 밝기를 가장 낮춰도 밝을 때 씁니다. 기기 밝기는 그대로입니다.
- 둘을 함께 켜면 둘 다 적용됩니다. 예를 들어 기기 밝기를 낮추고 그 위에 더 어둡게 덮을 수 있습니다.
- 예전에 "앱 밝기"를 켜 두었다면 "앱 화면 어둡게"로 그대로 남습니다.

## 확인한 것 / 못 한 것

- CI 빌드와 단위 테스트까지 확인했습니다.
  - 스마트 폴더: 시간 단위 기간, 최근에 연 N개, 20개 넘으면 오래된 것부터 빠지기, 0.90.0에서 날 단위로 저장한 폴더 읽기를 테스트로 넣었습니다.
  - 분할 화면: 선을 끝까지 끌었을 때 닫히는 쪽, 처음 연 노트를 닫으면 옆 칸이 이어받는 것, 칸 서로 바꾸기를 테스트로 넣었습니다.
  - 밝기: 기기 밝기 값의 범위, 어둡게 덮는 막의 진하기를 테스트로 넣었습니다.
- 기기에서는 아직 해 보지 못했습니다. 대화상자 안의 막대와 숫자 칸이 잘 움직이는지, 분할 화면의 선 끌기와 유리가 자연스러운지 확인해 주세요.

## 태블릿에서 해 볼 것

1. 폴더(또는 폴더 안의 폴더)에 들어가 새 손글씨 노트, 새 Markdown 노트, PDF 가져오기를 해서 그 폴더 안에 생기는지. 맨 위에서 만든 노트는 맨 위에 생기는지.
2. ⋯ → 새 스마트 폴더 → 기간 정하기 → 막대를 끝까지 움직여 "1시간"과 "30일"이 나오는지.
3. "3시간"으로 저장하고, 방금 쓴 노트만 나오는지.
4. 노트 몇 개를 열었다 닫은 뒤 → 새 스마트 폴더 → 최근에 연 것만 → 3개로 저장 → 방금 연 3개가 연 순서대로 나오는지.
5. 0.90.0에서 만든 스마트 폴더가 그대로 열리는지.
6. 막대를 2/4나 4/4로 두고 펜을 두 번 눌러 굵기 칸에 `3.5`를 쳐서 바로 바뀌는지, 막대를 움직이면 칸의 숫자도 바뀌는지.
7. 도형 도구를 두 번 눌러 색을 고른 뒤 도형을 그려 그 색으로 나오는지, 펜 색은 그대로인지. **다른 색과 굵기…**도 눌러 보기.
8. 노트를 둘로 나눈 뒤 두 칸에 번갈아 쓰기 → 두 칸이 같은 모양인지, 오른쪽 칸에 쓰고 실행 취소하면 오른쪽 것이 지워지는지.
9. 가운데 선을 오른쪽 끝까지 끌어 놓기 → 오른쪽 칸이 닫히는지. 다시 나눈 뒤 왼쪽 끝까지 끌기 → 처음 연 노트가 닫히고 오른쪽 노트가 화면에 남는지.
10. 선 가운데 손잡이 누르기 → 칸 바꾸기, 노트 바꾸기, 둘로 나누기.
11. 툴바를 오른쪽 칸 위로 옮겼을 때 유리에 오른쪽 칸 페이지가 비치는지.
12. 설정 → 밝기 → **이 앱에서의 기기 밝기**를 켜고 막대를 움직여 화면 자체가 밝아지고 어두워지는지. 홈 버튼으로 나갔을 때 원래 밝기로 돌아가는지.
13. **앱 화면 어둡게**를 따로 켜고 끄기. 둘을 함께 켰을 때 둘 다 적용되는지.
