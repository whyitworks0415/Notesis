## 고친 것

### 키보드가 잠깐 올라왔다 내려가던 문제

- **원인:** 페이지를 만질 때마다 필기 화면이 입력 포커스를 가져갔습니다. 하드웨어 키보드 단축키 때문이었습니다. 그 뒤 툴바 같은 화면 요소를 누르면, 앱이 마지막으로 쓰던 글 입력칸(검색칸, 굵기 숫자칸 등)으로 포커스를 되돌리면서 키보드가 올라왔습니다. 다음에 페이지를 만지면 다시 내려갔습니다.
- **고친 것:**
  - 페이지를 만지면 글 입력칸의 포커스를 완전히 놓아서, 나중에 키보드가 다시 불려 나오지 않습니다.
  - 필기 화면은 키보드(실제 자판)가 연결돼 있을 때만 포커스를 가져갑니다.
  - 분할 화면의 다른 칸도 똑같이 바꿨습니다.

### 노트 밖(화이트보드)에 쓴 글씨가 이상하게 나오던 문제

- **원인:** 빠르게 꼬불꼬불 쓴 곳에 검은 쐐기 모양이 채워졌습니다. 일부 펜은 획의 외곽선을 통째로 칠하는 방식으로 그리는데, 획이 급하게 되돌아가면 외곽선이 꼬이면서 그 안이 칠해진 것입니다.
- **원래 대책의 빈틈:** 기본 펜과 필압 펜 두 가지는 원래부터 이 문제가 없는 그리기 방식으로 화면에 그리고 있었습니다. 그런데 펜촉 각도를 준 펜, 만년필, 캘리그래피, 유화 붓은 그 대상이 아니었습니다.
- **고친 것:** 외곽선을 칠하는 방식의 펜이면 종류와 상관없이, 불투명한 잉크는 화면에서 문제없는 방식으로 그립니다.
  - 저장되는 펜 종류는 그대로입니다. 바뀌는 것은 화면에 그리는 방식뿐이라 PDF 내보내기 결과는 그대로입니다.
  - 노트 안(페이지 위)에 쓴 같은 종류의 펜에도 똑같이 적용됩니다.

## 첫 화면 바탕 직접 만들기: 자유 배치

한 방향 그라데이션 대신, 화면 모양의 사각형 위에 색마다 "점"을 원하는 곳에 놓는 방식으로 바꿨습니다.

**여는 곳:** 첫 화면 ⋯ → 라이브러리 배경 → 첫 화면 분위기 → **직접 만들기**(또는 **내 것 고치기**)

- **화면 모양의 미리보기:** 지금 태블릿 화면 비율의 사각형에 바탕과 제목, 카드 두 줄이 그대로 그려집니다.
- **색 놓기:** 동그라미 손잡이를 끌어 화면 어디에나 놓습니다. 손가락에 가장 가까운 손잡이가 따라옵니다.
- **강도:** 그 자리에서 색이 얼마나 진한지 정합니다.
- **퍼짐:** 색이 얼마나 멀리까지 번진 뒤 바탕으로 사라지는지 정합니다(화면 긴 변의 10%~150%).
- **바탕색:** 맨 왼쪽 네모를 누르면 색들 아래에 깔리는 바탕색을 바꿉니다. **기본 바탕 쓰기**로 되돌릴 수 있습니다.
- **색 1~4개:** **+ 색 추가**는 아직 색이 없는 쪽에 새 점을 놓습니다. **삭제**로 지웁니다.
- 0.90.3에서 한 줄로 만든 바탕은, 그 줄 위의 점들로 바뀌어 그대로 이어집니다.
- 카드와 글자색은 바탕 전체의 밝기에 맞춰 자동으로 정해집니다.

## 첫 화면 유리

- **폴더·노트 카드:** 카드 바탕이 Liquid glass로 바뀌었습니다.
  - 카드들이 첫 화면 전체 화면을 비추면 자기 자신까지 비춰 버리기 때문에, 바탕(색·분위기·사진)만 따로 기록하고 카드는 그것을 비춥니다.
  - Liquid glass 모양이 아니거나 가벼운 모드일 때는 지금처럼 반투명 카드입니다.
- **세로 세 줄 버튼 메뉴의 유리:** 메뉴 유리에 엉뚱한 곳이 비치던 문제를 고쳤습니다.
  - 메뉴는 별도의 창으로 뜨는데, 첫 화면은 그 창의 위치를 보정하지 않고 화면을 넘겨주고 있었습니다(노트 화면은 이미 보정하고 있었습니다).
  - 이제 메뉴 아래에 실제로 있는 부분이 비칩니다.
- **스크롤한 뒤 세로 세 줄 버튼:** 스크롤해서 버튼들이 접혔을 때 세로 세 줄 버튼을 누르면 버튼들이 펼쳐졌다 접혔다만 해서, 길게 누르지 않으면 메뉴(모양, 휴지통, 라이브러리 배경 등)를 열 수 없었습니다.
  - 이제 첫 번째 누름에 버튼들이 펼쳐지고, 한 번 더 누르면 메뉴가 열립니다.
  - 다시 스크롤하면 버튼들이 접힙니다.

## 색 고르기

- **원하는 색 만들기:** 색 고르기 창에서 색 사각형(채도·밝기)과 색상 막대가 버튼 뒤에 숨어 있었습니다. 이제 처음부터 펼쳐져 있습니다.
- **회색에서 색 바꾸기:** 흰색·검은색·회색에서 색상 막대를 움직이면 아무것도 바뀌지 않았습니다. 이제 색이 들어갑니다.
- **내 색:** 모든 색 고르기 창에 "내 색" 줄이 생겼습니다.
  - **+ 이 색 저장**으로 지금 색을 저장하고, 누르면 그 색을 씁니다. 길게 누르면 지웁니다.
  - 최대 16개이고, 이 태블릿에 저장됩니다.
- **색 템플릿 추가:** 이름을 쓰지 않으면 저장 버튼이 눌리지 않았습니다. 이제 이름 없이도 저장되고, 이름은 "내 색"이 됩니다. 색 추가 버튼도 더 눈에 띄게 바꿨습니다.
- **기본 템플릿 추가:** 공부(검정·빨강·파랑·초록·보라·주황), 형광(반투명 6색), 흙, 바다, 숲, 해질녘, 차분한, 빈티지를 더했습니다.

- CI 빌드와 단위 테스트까지 확인했습니다.
  - 새 테스트: 점의 강도와 퍼짐, 저장하고 다시 읽기, 0.90.3 형식 읽기, 바탕에 따른 글자색.
- 기기에서는 해 보지 못했습니다.
  - 키보드: 어떤 상황에서 올라왔는지 정확히 재현하지 못하고 원인으로 보이는 것을 고쳤습니다. 계속 그러면 언제 그러는지 알려 주세요.
  - 쐐기 모양: 사진의 증상과 맞는 원인을 찾아 고쳤지만, 같은 펜으로 다시 써 보고 확인해 주세요.

## 태블릿에서 해 볼 것

1. 노트에서 검색칸이나 굵기 숫자칸을 한 번 쓴 뒤, 필기와 툴바 누르기를 번갈아 해도 키보드가 올라오지 않는지.
2. 화이트보드(노트 밖)와 페이지 위에서 만년필·캘리그래피·펜촉 각도를 준 펜으로 빠르게 꼬불꼬불 써 보기 → 검은 쐐기가 없는지.
3. 직접 만들기 → 색 점을 끌어 옮기고, 강도와 퍼짐을 바꾸고, 바탕색을 바꿔 보기 → 이 분위기 쓰기.
4. Liquid glass 모양에서 첫 화면의 폴더·노트 카드가 유리인지, 바탕 분위기가 비치는지.
5. 세로 세 줄 버튼 메뉴를 열었을 때 유리에 메뉴 바로 아래 부분이 비치는지.
6. 목록을 스크롤한 뒤 세로 세 줄 버튼을 두 번 눌러 메뉴가 열리는지.
7. 펜 색 고르기 → 팔레트 → + 추가로 템플릿 만들기(이름 없이도). 색 고르기에서 + 이 색 저장.
