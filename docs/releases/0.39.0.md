# Notesis 0.39.0 (102)

시계(타이머·스톱워치·알람·순공 시간)를 추가하고, 표와 스티키 노트 추가 기능을 없앴습니다.

## 시계

노트 툴바의 **시계 아이콘**이나 화면에 떠 있는 **작은 시계 버튼**을 누르면 리퀴드 글래스 시계 창이 열립니다. 위쪽 탭으로 타이머 · 스톱워치 · 알람 · 순공을 오갑니다. **소리는 나지 않고**, 모든 알림은 화면에만 표시됩니다.

### 화면 위 시계 버튼(인디케이터)

- 노트 목록과 필기 노트 위에 작은 유리 알약 모양 버튼이 뜹니다. 끌어서 원하는 곳에 둘 수 있고, 위치는 기억됩니다.
- 버튼에는 지금 돌아가는 것이 보입니다:
  - 타이머: 남은 시간(일시정지 중에는 흐리게)
  - 스톱워치: 지난 시간
  - 순공 측정 중: 초록 점과 오늘 순공 시간
  - 아무것도 없으면 시계 아이콘만
- **타이머가 끝나거나 알람 시각이 되면** 버튼 테두리가 천천히 깜빡이고 `타이머 끝` / `알람 07:30` 옆에 **확인** 버튼이 나타납니다. 확인을 누를 때까지 남아 있습니다.
- 시계 창 맨 아래 **화면에 시계 버튼**으로 버튼을 끌 수 있습니다. 꺼도 **타이머와 알람은 화면에 표시**됩니다.
- 마크다운 노트·설정·문서 보기 화면에서도 끝난 타이머와 울린 알람은 표시됩니다.

### 타이머

- 원형 진행 표시와 큰 숫자로 남은 시간을 보여 주고, 끝나는 시각(예: `14:25에 끝`)도 표시합니다.
- 1·3·5·10·15·25·30·45·60분 바로 고르기와 −5/−1/+1/+5분 조정을 지원합니다.
- 시작 · 일시정지 · 계속 · 초기화.
- 노트를 닫거나 앱을 나가도 계속 갑니다. 돌아오면 그 사이에 끝난 타이머는 끝난 상태로 보입니다.

### 스톱워치

- 1/100초 단위로 표시하고, 랩 기록(구간 시간과 누적 시간)을 남깁니다.
- 앱을 나가도 계속 갑니다.

### 알람

- 시각을 직접 입력해 추가하고, **한 번** 또는 **매일**을 고릅니다. 알람마다 켜기/끄기, 매일 전환, 삭제가 가능하고 남은 시간(예: `3시간 12분 후`)이 보입니다.
- 앱이 열려 있는 동안 시각이 되면 화면에 표시됩니다. 앱을 나가 있던 사이에 지난 알람은 돌아왔을 때 표시하고, 6시간 넘게 지난 알람은 건너뜁니다.
- 소리·진동·알림창 알림은 없습니다(요청대로 화면 표시만).

### 순공 시간

- **자동 측정(켜기/끄기)**: 노트가 열려 있고, 앱이 화면에 있고, 펜이나 손가락 입력(펜을 화면 위에 띄운 것 포함)이 최근에 있었던 동안만 셉니다. 입력이 없으면 1·3·5·10분 뒤에 멈추도록 고를 수 있습니다(기본 3분).
- 자동 측정을 끄면 **시작/정지**로 직접 잽니다. 이때는 앱을 나가 있어도 정지할 때까지 계속 셉니다.
- **하루마다 초기화(켜기/끄기)**: 켜면 자정마다 0부터 다시 셉니다. 끄면 직접 초기화할 때까지 누적됩니다. 자정을 넘긴 공부는 두 날짜에 나눠 기록합니다.
- 최근 7일 막대그래프로 하루별 순공 시간을 보여 줍니다. 기록은 두 달치를 보관합니다.
- 기록 초기화는 두 번 눌러야 지워집니다.

## 없앤 기능

- 노트 툴바의 **메모(스티키 노트)** 와 **표** 추가 버튼, 표 편집 창을 없앴습니다. 그 자리에 시계 버튼이 들어갔습니다.
- 이미 페이지에 있는 스티키 노트와 표는 그대로 보이고, 옮기기·삭제도 됩니다(스티키 노트 접기·펼치기도 그대로). 표는 다시 만들거나 행·열을 바꿀 수 없습니다.

## 참고

- 이 환경에는 Android SDK가 없어 빌드와 단위 테스트는 GitHub Actions에서 수행합니다. 실제 기기에서 화면을 확인하지는 못했습니다.
- 시간 계산(자정 나누기, 다음 알람 시각, 표시 형식)은 단위 테스트로 확인합니다.
