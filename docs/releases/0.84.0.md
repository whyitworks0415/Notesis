# Notesis 0.84.0 (178)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

노트 앱 비교 문서(6개 앱 분석)의 통합 TODO 중 코드로 할 수 있는 항목의 첫 묶음입니다.

## 선택 메뉴가 선택한 것 옆에 (U03)
- 올가미로 고른 뒤 나오는 메뉴가 화면 아래가 아니라 **선택한 것 바로 위**에 나옵니다. 위에 자리가 없으면 아래에, 둘 다 안 되면 예전처럼 화면 아래에 나옵니다.
- 화면 좌우 밖으로 나가지 않고, 화면보다 길면 메뉴 안에서 가로로 넘깁니다.
- 페이지를 움직이거나 선택을 옮기면 메뉴가 따라갑니다. 따라가는 동안 화면 전체를 다시 그리지 않고 메뉴 위치만 바꿉니다.

## 떠 있는 노트 창이 화면 밖에 남지 않게 (U04)
- 화면을 돌리거나, 창 크기가 바뀌거나, 분할이 바뀌면 떠 있는 참조 노트 창을 화면 안으로 다시 넣습니다. 필요하면 작게 줄입니다. 제목 막대를 언제든 다시 잡을 수 있습니다.

## 연필 농도 (E01)
- 연필(Graphite)에 **Density(농도)** 설정이 생겼습니다. 1~10단계(10~100%)이고 기본은 50%로 지금과 같습니다.
- 농도는 불투명도와 다릅니다. 종이 결을 얼마나 채우는지를 바꿔서, 낮으면 결 사이로 종이가 더 비치고 높으면 결이 메워집니다.
- 이미 쓴 연필 획은 그대로입니다. 새 저장 형식은 만들지 않았습니다(펜촉 각도를 저장하던 칸을 연필에서는 농도로 씁니다). 예전 버전 앱으로 열면 그 획은 기본 농도로 보입니다.

## 펜 두께를 mm로도 표시
- 펜·연필·형광펜의 두께 옆에 A4 기준 mm가 함께 나옵니다(예: `5 · 0.85 mm`). 지우개는 화면 기준이라 그대로입니다.

## 저장한 펜 (펜함)
- 펜 설정창 위쪽에 **Saved pens(저장한 펜)**가 생겼습니다. **Save this pen**을 누르면 종류·두께·색·필압·농도·예측·안정화까지 지금 설정 전체를 저장합니다.
- 저장한 펜을 누르면 그 설정이 한 번에 돌아옵니다. 길게 누르면 지워집니다. 도구마다 12개까지 둡니다.

## 지우개 설정창 (U05)
- **Back to the previous tool after erasing(지운 뒤 이전 도구로)**를 지우개 설정창에서 바로 켜고 끌 수 있습니다. 전에는 설정 사이드바에만 있었습니다.
- 확인해 보니 이미 있던 것: 지울 대상 고르기(펜/형광펜/테이프/그림/글상자/잠긴 것), 부분 지우개, 필압 지우개, 이 페이지 지우기·전체 지우기. 레이어를 하나 붙잡아 두면 지우개와 지우기는 그 레이어만 지웁니다.

## 손글씨 인식 결과를 고치고 고르기 (O02)
- 올가미 → OCR 결과가 **고칠 수 있는 글상자**로 나옵니다. 고친 다음 복사하거나 글자로 바꿀 수 있어, 잘못 읽은 글자를 잉크를 지우기 전에 고칠 수 있습니다.
- 줄마다 **다른 인식 결과**(다른 언어, 다음 후보)가 언어 이름과 함께 나옵니다. 고르면 그 줄이 바뀝니다.
- 인식에서 고친 것
  - 설정에서 뺀 언어가 앱을 다시 켤 때까지 계속 쓰이던 문제
  - 여러 언어를 쓸 때 설정한 순서가 아니라 모델을 불러온 순서로 읽던 문제
  - 모든 획의 시간이 0부터 시작해서, 인식기가 획들을 동시에 쓴 것으로 받던 문제. 이제 획을 차례로 이어 붙입니다.
- 언어를 바꿔도, 이미 색인된 페이지는 그 페이지를 다시 열 때 새 언어로 다시 읽습니다. 열지 않은 페이지를 한꺼번에 다시 읽지는 않습니다.

## 필기 중 다른 일 줄이기 (N04)
- 펜이 닿아 있는 동안(이 노트든 옆 창이든) 페이지 썸네일 그리기를 펜이 떨어질 때까지 미룹니다. 너무 오래 쓰면 4초 뒤에는 그립니다.
- 확인해 보니 이미 있던 것: 주변 페이지 미리 읽기와 PDF 렌더도 펜이 닿아 있는 동안 미룹니다. 다만 "PDF renders put off" 숫자가 항상 0으로 나오던 것을 고쳐, 이제 실제로 센 값이 나옵니다.

## 측정 화면에 호환 경로 세부 단계 (N02, N03)
- 설정의 진단(latency) 화면에 **호환 젖은 잉크 경로의 단계별 시간**이 추가됐습니다.
  - geometry 갱신, 표면 잠금 대기, 그리기+게시 시간의 p50/p95/p99
  - 한 프레임에 다시 그린 면적
- 측정을 켜도 예측 방식은 바뀌지 않습니다(이미 분리돼 있었음).
- 예측 점은 확정 획에 섞이지 않습니다. 매 프레임 따로 바뀌고 펜을 떼면 버려집니다. 코드로 확인했습니다.

## 예측 설명 문구 (N05)
- 펜 설정의 예측 설명이 실제 계산과 달랐습니다(60Hz 9ms라고 적혀 있었지만 실제는 8ms). 이제 60Hz 8ms, 90Hz 6ms, 120Hz 4ms, 호환 경로는 12·8·6ms로 실제와 같습니다.

## 하지 않은 것
- **실기기 측정(N02)**: 같은 기기에서 다른 앱과 지연을 비교하는 일은 기기와 사람이 필요해서 하지 않았습니다. 대신 측정 화면을 보강했습니다.
- **다른 앱의 인식 엔진 추적(O01)**: 앱 파일이 필요해서 할 수 없습니다.
- **Noteshelf식 곡선(E02)**: 실제로 써 보고 비교해야 해서 이번에는 넣지 않았습니다.
- 레이저, 필압 길게 눌러 임시 지우개, 양방향 링크, 툴바 도킹, 메뉴 정리, Markdown 개선은 다음 묶음(0.85.0)에서 합니다.

## 확인 방법
- 단위 테스트: 메뉴 위치 계산(위·아래·화면 밖), 연필 농도(기본값은 예전과 같고 단계가 오를수록 진해짐), 저장한 펜의 저장·불러오기
- 실제 화면과 기기에서는 확인하지 못했습니다.

## 기기에서 확인할 것
- 올가미로 고른 뒤 메뉴가 선택한 것 위(또는 아래)에 나오는지, 페이지를 움직이면 따라오는지
- 연필 농도를 바꾸면 종이 결이 비치는 정도가 달라지는지, 예전 연필 획은 그대로인지
- 저장한 펜을 눌렀을 때 설정이 한 번에 돌아오는지
- OCR 결과를 고친 뒤 "글자로 바꾸기"가 고친 글자로 들어가는지
- 화면을 돌려도 떠 있는 노트 창이 화면 안에 있는지
