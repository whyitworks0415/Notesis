# Notesis 0.99.1 (242)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

노트를 쓰는 동안에도 에이전트가 어느 화면에서든 실시간으로 읽고 고칠 수 있게 했고, 노트 밖 필기를 인식하고 에이전트가 노트 밖에도 쓸 수 있게 했습니다. 사이드바에서 이전 대화를 이어 갈 수 있습니다.

## 바뀐 점

### 쓰는 중에도 실시간으로 읽기·편집
- **읽기**: 노트가 열려 있으면, 에이전트가 읽기 전에 화면이 아직 저장하지 않은 내용을 먼저 저장합니다. 방금 쓴 것까지 에이전트가 봅니다(전에는 마지막 자동 저장까지만 보였습니다).
- **편집**: 0.98에서는 노트 화면 하나만 실시간으로 바뀌었습니다. 이제 **분할 화면의 각 칸과 팝업 노트**도 같습니다(잠깐 멈춤 → 변경 → 그 자리에서 다시 읽기). 그래서 "분할·팝업의 노트는 읽기만" 하던 제한이 없어졌습니다.
- 펜으로 쓰는 중이면 획이 끝날 때까지 기다렸다가 바꿉니다. 화면에 열린 노트를 휴지통으로 보내는 것만은 여전히 거절합니다.

### 노트 밖 필기 인식
- 노트 밖(화이트보드)에 쓴 손글씨도 노트 안처럼 손이 쉬는 동안 글로 읽어 둡니다. **앱 검색**이 노트 밖 글씨도 찾고, 에이전트의 `note read`에도 노트 밖 필기 수와 읽은 글이 `board`로 나옵니다.

### 에이전트가 노트 밖에 쓰기
- 쪽 번호 자리에 `board`를 쓰면 노트 밖입니다:
  - `ink add 노트 board --near 3 --path "..."`: 3쪽의 왼쪽 위 모서리 기준으로 그립니다(쪽 너비보다 큰 x는 그 쪽 오른쪽).
  - `ink erase 노트 board --rect … --near 3` 또는 `--all`
  - `ink read 노트 board`: 노트 밖 손글씨를 글로 읽음
- 되돌리기 사본에 노트 밖 필기·테이프 파일도 들어가서, 노트 밖 변경도 `undo`로 되돌아갑니다.
- 노트 밖 필기는 그 노트의 화이트보드가 켜져 있을 때 보입니다.

### 이전 대화 이어 가기 (사이드바)
- 네 에이전트 모두 다음 요청이 같은 대화를 이어 갑니다. 새 대화 버튼으로 새로 시작합니다.
- **이전 대화** 버튼: 그 에이전트의 지난 대화 목록(제목·시각)에서 골라 이어 갈 수 있습니다. 각 에이전트의 공식 방법을 씁니다(Claude Code `--resume`, Codex `exec resume`, Gemini CLI `--resume`, OpenCode `--session`).
- **설정 스크립트를 Termux에서 한 번 다시 실행**해야 합니다(목록을 읽는 도우미가 들어감).

## 어떻게 확인했나
- 단위 테스트 전체 통과(로컬, 네이티브 검사 포함). 새로 시험한 것: 노트 밖에 그리기·지우기·읽기와 되돌리기, `note read`의 board, 대화 id 넘기기·목록 읽기(가짜 에이전트로), 실제 파일에서 열린 노트를 먼저 저장하고 그 위에 바꾸기.
- 분할·팝업의 실시간 반영, 노트 밖 필기 인식은 화면 코드라 **빌드로만 확인했습니다.**

## 하지 않은 것
- **태블릿과 실제 에이전트로 해 보지 않았습니다.** Gemini CLI의 `--resume`을 한 번 실행 모드와 함께 쓰는 것, Codex의 `exec resume`은 설치된 버전에 따라 다를 수 있습니다.
- 노트 밖에는 여전히 그림·글 상자를 놓지 않습니다(에이전트도).

## 태블릿에서 해 볼 것
1. 노트에 방금 쓰고(저장되기 전) 에이전트에게 "방금 쓴 거 읽어 줘" → 방금 쓴 것까지 읽는지.
2. 분할 화면 오른쪽 칸에 연 노트를 에이전트에게 바꿔 달라고 → 그 칸이 바로 바뀌는지. 팝업 노트도.
3. 노트 밖에 손글씨를 쓰고 잠시 뒤 앱 검색으로 그 낱말 찾기.
4. 에이전트에게 "3쪽 오른쪽 바깥에 화살표 그려 줘" → 노트 밖에 그려지는지, 되돌리기.
5. Termux에서 설정 스크립트 다시 실행 → 사이드바 **이전 대화**에서 지난 대화가 나오는지, 골라서 이어 가는지.
