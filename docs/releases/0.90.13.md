# Notesis 0.90.13 (204)

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다. 개발자 코드를 넣은 베타 테스터에게만 보입니다.

## 바뀐 점

### Mornye처럼 쏟아지는 팝업 (내용은 원래 크기 그대로)
Mornye 메뉴 코드(`mornye_context_menu.dart`의 `_MenuFrame`과 `_MenuContent`)를 확인했습니다. Mornye는 팝업 전체를 늘이지 않고, **유리만 실제 크기로 커지게** 합니다. 안의 내용은 원래 크기로 제자리에 두고, 유리가 닿은 부분만 보여 줍니다. 같은 구조로 다시 만들었습니다.
- **바깥 틀**은 다 펼친 크기를 차지합니다. 그 안에서 **유리 바탕**은 버튼 위치의 44pt 물방울에서 시작해, 높이가 먼저 내려오고 50ms 뒤에 폭이 퍼지며 완성 크기가 됩니다.
- **안의 내용**은 처음부터 완성 크기로 배치하고 화면에 고정해 둡니다. 유리 모양으로 잘라서 유리가 닿은 곳만 보입니다. 그래서 글자와 아이콘이 더 이상 찌그러지지 않습니다.
- **모서리**는 물방울일 때 완전히 둥글다가 퍼지면서 패널의 모서리로 조여집니다. 스쿼클 모서리, 렌즈, 테두리, 그림자가 매 프레임 실제 크기에 맞습니다.
- **내용 페이드**: 유리가 대부분 퍼진 뒤에 나타나고, 닫힐 때는 유리보다 먼저 사라집니다. 패널 크기의 레이어 없이 그립니다.
- **적용 범위**: Functions 메뉴, 도구·펜 패널에서 Glassmorphism, Liquid glass, iOS, Mornye 룩에 적용됩니다. Material은 Mornye의 Material처럼 버튼에서 커지는 방식 그대로입니다.

### iOS + Mornye
iOS 룩에 Mornye를 결합했습니다.
- **유리**: iOS의 유리(liquid_glass_widgets 수치)는 그대로입니다.
- **색**: Mornye의 iOS 그룹 색(`#F2F2F7`, `#1C1C1E` 등)을 씁니다. 강조색은 **iOS 파랑**이 기본이고, Mornye와 같은 7가지 색이나 앱 강조색 중에서 고를 수 있습니다(**설정 › 모양 › 유리**).
- **모서리**: Mornye의 스쿼클 모서리를 씁니다. 렌즈도 그 모서리를 따라 굴절합니다. "부드러운 모서리"로 끌 수 있습니다.
- **메뉴 열림**: Mornye처럼 쏟아지며 열립니다(위와 같음).
- **눌림과 선택 이동**: iOS 고유의 스프링을 그대로 씁니다.

### 회색 하이라이트와 눌림 효과 제거
- **모든 룩, 모든 화면**에서 다음을 없앴습니다.
  - 커서(마우스·펜 호버)를 올렸을 때 회색으로 바뀌는 하이라이트
  - 눌렀을 때 잠깐 회색으로 번지는 물결(ripple)
- 버튼은 이제 각 룩의 눌림 모션(유리 부풀기 등)으로만 반응합니다.
- 키보드로 이동할 때의 포커스 표시만 남겼습니다. 키보드 사용자가 위치를 알 수 있어야 해서입니다.

## 확인한 것
- CI에서 빌드, 단위 테스트, 스크린샷 테스트를 돌렸습니다.
- 새 단위 테스트로 다음을 확인합니다.
  - 유리 사각형이 물방울에서 완성 크기로 가는 계산(넘침 35% 포함)
  - 모서리 조임과 내용 페이드
  - iOS가 Mornye 색과 파랑 강조색을 쓰는지, 강조색 저장
  - iOS·Mornye 메뉴가 쏟아짐 방식인지
- **기기(태블릿)에서는 시험하지 못했습니다.** 팝업이 열리는 모습과 성능은 보지 못했고 측정하지도 않았습니다.

## 하지 않은 것
- 홈 화면의 유리 메뉴(GlassMenu)와 다이얼로그는 이번 방식으로 바꾸지 않았습니다.
- Liquid glass(기본)의 렌즈는 둥근 모서리 그대로입니다.

## 태블릿에서 해볼 것
1. Mornye와 iOS 룩에서 Functions 메뉴와 펜 패널을 열고 닫아 봅니다.
   - 유리가 물방울에서 퍼지고 글자는 찌그러지지 않는지 봅니다.
   - 열리다 닫아도 자연스러운지 봅니다.
2. iOS 룩에서 강조색을 바꿔 보고, 색과 모서리가 Mornye처럼 바뀌는지 봅니다.
3. 마우스나 S펜을 버튼 위에 올렸을 때 회색 하이라이트가 없는지, 누를 때 회색 물결이 없는지 봅니다.
4. 설정 › 모양 › 모션의 "늦은 프레임" 숫자를 알려 주세요.
