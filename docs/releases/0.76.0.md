## 새 스타일: Liquid glass · iOS
- 보내 주신 자료집의 링크들을 바탕으로, Apple의 Liquid Glass에 가장 가깝게 만든 스타일입니다. 이제 스타일은 모두 6개입니다.
  - Material, Glassmorphism, Liquid glass, **Liquid glass · iOS**(새로 추가), Liquid glass · Kyant0, Liquid glass · QWEA0
- 기본값은 **liquid_glass_widgets 1.16.1**(MIT)의 iOS 27 regular 프리셋을 그대로 썼습니다. 이 프로젝트가 실제 iOS 컨트롤과 나란히 놓고 측정했다고 밝힌 값입니다.
  - 라이트: 본체 #F8F8F8 53%, 채도 2.1, 블러 0.6, 그 위에 서리(frost) 14를 73%로
  - 렌즈: 두께 32(3x 픽셀), 굴절률 1.24
  - 빛: 위에서 오고, 가장자리 반사광 1, 가장자리 안쪽 어두운 선 1, 가장자리 흡수 0.035, 색수차 0
  - 그림자: 검정 0x04, 흐림 10, 아래로 7
  - 다크: 본체 흰색 12%, 채도 1.4, 서리 85%, 빛은 아래에서, 반사광 1.15, 본체 어둡게 0.28, 그림자 없음
- 값을 실제 모양으로 바꾸는 식도 이 프로젝트의 셰이더 식을 그대로 따릅니다.
  - 가장자리 띠(bevel) = 두께 ÷ 3 dp(약 10.7 dp)
  - 가장자리에서 페이지가 휘는 양 = 두께 × 8 × (굴절률 − 1) ÷ 3(약 20.5 dp). 패널의 짧은 변의 절반을 넘지 않습니다.
  - 휘는 양은 가장자리 띠 안쪽부터 제곱으로 커집니다(paraxial). 이 프로젝트가 iOS에서 잰 "가장자리에 안쪽이 눌려 비치는" 모양입니다.
- 서리는 두 겹으로 그립니다. 살짝 흐린 페이지를 먼저 그리고, 그 위에 많이 흐린 페이지를 73%로 올립니다. 그래서 뒤 글씨가 옅은 그림자처럼 비칩니다.
- 곡률: GlassMenu의 32 dp
- 단위가 다른 값을 그대로 옮기지 않았습니다. 3x 픽셀 → dp 같은 변환은 위에 적은 대로입니다.
- **Settings › Appearance › Glass**에서 조정할 수 있습니다.
  - 렌즈: 두께, 굴절률, 색수차
  - 재질: 블러, 서리, 서리 불투명도, 채도, 본체
  - 가장자리: 반사광, 어두운 선, 흡수
  - 곡률
  - "Back to the presets' values" 버튼으로 프리셋 값으로 되돌릴 수 있습니다.

## 누르기 · 선택 슬라이드 · 메뉴 열기를 각 프로젝트 방식으로 (켜기/끄기)
- iOS, Kyant0, QWEA0 세 스타일의 Glass 탭 아래쪽 **Motion**에 스위치가 3개씩 있습니다.
  - **켜기(기본)**: 그 프로젝트의 동작
  - **끄기**: 지금까지와 같은 동작
  - Press: 툴바의 둥근 버튼(Functions 등)과 유리 버튼을 누를 때
  - Selection slide: 툴바에서 선택이 손가락을 따라가고 도구에 내려앉을 때
  - Menu opening: Functions 메뉴와 Tools 같은 패널이 버튼에서 나오고 들어갈 때

| | iOS (liquid_glass_widgets) | Kyant0 | QWEA0 |
|---|---|---|---|
| 누르기 | 긴 변 기준 17 pt만큼 커짐(56 pt 원은 약 1.3배). 누를 때 snappy 250 ms, 뗄 때 bouncy 280 ms 스프링 | 높이 4 dp만큼 커짐, spring(0.5, 300) | 0.95로 작아짐, 200 ms 감속 |
| 선택 슬라이드 | 끄는 동안 interactive 스프링, 놓으면 snappy 350 ms | spring(1, 1000)으로 따라감. 들릴 때 가로 spring(0.6, 250), 세로 spring(0.7, 250) | 380 ms 오버슈트 1.1에 맞춘 스프링 |
| 메뉴 열기 | GlassMorph 스프링: 열 때 강성 120·감쇠 16, 닫을 때 200·21에 −3.2로 튕기며 들어감. 크기는 linearToEaseOut, 넘칠 때 10% 부풂, 덜 닫힐 때 55% 눌림 | 위에서 48 dp 내려오며 EaseIn으로 나타남. 열 때 spring(0.5, 300), 닫을 때 spring(1, 300) | 0.86에서 250 ms(감속 1.6), 닫을 때 0.88로 150 ms(가속 1.4) |

## Liquid glass · QWEA0: 어둡던 배경 수정, 데모 앱 설정 전부 추가
- **배경이 검게 보이던 원인**
  - 0.75에서는 README 예시의 `adaptiveTint="true"`를 기본값으로 썼습니다.
  - 이 설정은 밝은 페이지 위에서 유리를 **검정 22%** 로 칠합니다.
  - 실제 APK(데모 앱)는 LiquidGlassView의 코드 기본값을 씁니다. 거기서는 이 설정이 꺼져 있고, 유리 색은 **흰색 14%** 입니다.
  - 이제 데모 앱과 같은 기본값을 씁니다.
- **렌즈를 QWEA0 셰이더로 그립니다**
  - QWEA0의 AGSL 렌즈 셰이더(MIT)를 앱으로 옮겨, 앱의 유리 렌더러(Backdrop) 안에서 그대로 돌립니다.
  - 이제 감쇠 곡선(falloff), 접힘 없음(no fold), 바깥쪽 굴절(outward), 가장자리 부드럽게, 연속 색분산, 가장자리 위·아래 두 갈래 하이라이트, 채도 곡선이 데모와 같은 식으로 그려집니다.
- **데모 앱 서랍에 있던 설정을 모두 넣었습니다**
  - 재질 Regular/Clear
  - 기울기 센서 하이라이트(기기를 기울이면 빛 방향이 바뀜)
  - 적응형 색조, 접힘 없음, 바깥쪽 굴절, 적응형 렌즈 크기
  - 가장자리 띠(bevel), 굴절, 감쇠, 색분산, 가장자리 부드럽게
  - 블러 켜기/끄기, 블러 양, 패널 블러 양, 채도, 곡률
  - Over light, 가장자리 하이라이트 켜기/끄기와 불투명도, 그림자
  - 유리 색(색상과 세기), 누르기 크기
- **기본값(LiquidGlassView)**
  - 블러 0.0625(4 + 32 × 값 px), 채도 140%, 재질 Regular
  - 가장자리 띠 48 px, 굴절 160 px, 감쇠 2, 색분산 0.10
  - 하이라이트 100%, 빛은 왼쪽 위
  - 적응형 렌즈 크기 켜짐(110 dp보다 작은 요소는 띠와 굴절을 줄임)
  - 그림자 없음, 누르기 0.95
  - 패널: 대화상자 빌더의 블러 0.6, 곡률 28 dp
- 픽셀 값은 QWEA0처럼 화면의 실제 픽셀입니다.
- 0.75에서 바꾼 QWEA0 설정은 단위가 dp라서 이번에는 가져오지 않고, 기본값으로 시작합니다.

## 공통
- 슬라이더·스위치 같은 컨트롤은 계속 앱의 기존 유리를 씁니다.
- 렌즈와 빛은 **Android 13 이상**에서만 보입니다. Android 12 이하에서는 모든 스타일이 지금처럼 거의 불투명한 패널로 그려집니다.
- 셰이더를 만들 수 없는 GPU에서는 앱이 꺼지지 않고, 렌즈 없이 그립니다.
- 오픈소스 라이선스(About · Help)에 Liquid-Glass-Android(MIT)와 liquid_glass_widgets(MIT)를 추가했습니다.

## 그대로 옮기지 못한 것
- **Apple 공식 자료**: Apple이 내부 셰이더나 물리 상수를 공개하지 않습니다. iOS 스타일의 값은 liquid_glass_widgets가 측정한 값입니다.
- **Figma 공식 키트**: 파일 내부 효과값은 이번에 추출하지 않았습니다.
- **liquid_glass_renderer**: liquid_glass_widgets가 0.2.0-dev.4를 가져와 고쳐 쓴 코드를 기준으로 했습니다. 1.0 개발 버전의 새 API는 쓰지 않았습니다.
- **두 모양이 합쳐지는 효과(metaball)**
  - iOS의 메뉴가 버튼에서 물방울처럼 떨어져 나오는 효과, QWEA0의 액체 합체는 렌더러가 두 모양을 하나로 그려야 합니다.
  - 그래서 메뉴는 같은 스프링·크기 곡선으로 버튼 위치에서 커지고 작아지게만 했습니다.
- **연속 곡률(squircle)**: 앱의 렌즈가 둥근 사각형만 받기 때문에, 모서리는 원호 곡률입니다.
- **QWEA0의 눌렀을 때 렌즈 변화**: 굴절이 커지고 손가락 아래가 부푸는 효과는 넣지 않았습니다. 누르기는 크기 변화만 따릅니다.

## 확인 방법
- 단위 테스트
  - 세 스타일의 기본값이 각 프로젝트 값과 같은지
  - 저장과 불러오기, 범위 밖 값 보정
  - iOS 누르기가 56 pt 원에서 약 1.3배, 132 pt 알약 모양에서 약 1.13배인지(widgets가 측정한 값)
  - 슬라이드·메뉴 스프링 값
  - 스위치를 끄면 앱의 원래 동작으로 돌아가는지
- Android 14 태블릿 에뮬레이터에서 iOS와 QWEA0 스타일로 노트를 열고 Functions 메뉴와 Tools 패널을 열었습니다.
  - 처음 돌렸을 때 이 두 스타일을 고르면 앱이 바로 꺼지는 문제를 찾았습니다. 패널 크기가 정해지기 전에 모서리를 계산하다 생긴 문제였고, 고친 뒤 다시 돌려 꺼지지 않는 것을 확인했습니다.
  - iOS는 하얗게 서리 낀 유리로, QWEA0은 어둡지 않게 그려졌습니다.
- 누르기·슬라이드·메뉴 열기의 움직임은 에뮬레이터에서 눈으로 확인하지 못했습니다. 실제 기기에서는 아무것도 확인하지 못했습니다.

## 기기에서 확인할 것
- Settings › Appearance › Style에서 6개가 보이는지
- **Liquid glass · iOS**: 툴바, Functions 메뉴, Tools 패널이 하얗게 서리 낀 유리로 보이는지, 위쪽 가장자리가 밝은지
- **Liquid glass · QWEA0**: 더 이상 어둡지 않은지, Glass 탭에 데모 앱 설정이 다 있는지
- Glass › Motion 스위치를 끄고 켤 때마다 누르기, 선택 슬라이드, Functions 메뉴 열기가 바뀌는지
- Android 13 이상 기기에서 앱이 꺼지지 않는지(새 셰이더)
