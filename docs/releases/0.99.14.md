# Notesis 0.99.14 (255)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

요청에 따라 **글자 인식(OCR) 기능을 전부 지웠습니다.** 나중에 처음부터 다시 만들 수 있도록 코드에 흔적을 남기지 않았습니다.

## 지운 것
- **올가미 OCR**: 선택 막대의 OCR 버튼과 결과 창, 다섯 가지 읽는 방법을 지웠습니다. 손글씨 획·그림 속 글자·둘 다·Google 렌즈·AI(Gemini)가 모두 포함됩니다.
- **AI 글자 읽기 설정**: Gemini 키, 모델, 정밀도 설정을 지웠습니다.
- **문서 스캔**: 홈 **+ → 문서 스캔**과, 스캔 PDF 글자 읽기(노트 설정)를 지웠습니다.
- **손글씨 검색 색인**:
  - 노트를 쓰는 동안 뒤에서 손글씨를 읽던 작업을 지웠습니다.
  - 홈 카드 메뉴 **"손글씨 검색 색인"**을 지웠습니다.
  - 노트 설정의 **인식 언어**와 **"이 페이지 글자 복사"**를 지웠습니다.
- **AI 채팅 첨부의 "필기를 글자로"** 옵션을 지웠습니다.
- **에이전트 명령**:
  - `ink read`를 지웠습니다.
  - `note read`가 손글씨 인식 결과(`handwriting`)를 더는 주지 않습니다.
  - 안내문은 글자가 없는 쪽을 `page image`(쪽 그림)로 보라고 바꿨습니다.
- **인식 라이브러리 3개**(ML Kit 손글씨·글자 인식·문서 스캐너)와 그 라이선스 안내를 지웠습니다. 관련 한국어 문구 66개도 지웠습니다.

## 그대로인 것
- 필기, 지우기, 올가미 이동·크기·색 바꾸기는 그대로입니다.
- **검색은 제목, PDF 글자, 텍스트 상자에서 그대로 됩니다.** 손글씨 내용으로는 더 이상 찾지 못하고, 검색 안내 문구도 그렇게 바꿨습니다.
- 손으로 쓴 노트의 Markdown 내보내기는 그대로입니다. PDF 글자와 텍스트 상자는 계속 들어가고, 인식된 손글씨만 빠집니다.
- **원래 PDF에 저장**은 OCR 파일 안에 있던 기능이라 별도 파일로 옮겨 남겼습니다. 동작은 같습니다.
- 앱 아이콘 길게 누르기의 **새 노트**, **기본 메모 앱** 등록은 OCR이 아니라서 남겼습니다.

## 저장된 데이터
- 예전에 만들어진 손글씨 인식 결과 파일(`.ink`)은 검색에 더 이상 쓰이지 않습니다. 노트를 다음에 저장할 때 자동으로 지워집니다.
- 문서 스캔으로 만든 노트는 그대로 남습니다. 그때 읽어 둔 페이지 글자도 PDF 글자처럼 검색에 계속 쓰입니다.

## 어떻게 확인했나
- 빌드, 축소(R8) 릴리스 빌드, Android 버전 검사(Lint), 네이티브 커널 점검, 전체 단위 테스트(144개 클래스)를 통과했습니다. 지운 기능의 테스트 3개는 함께 지웠습니다.
- 검색, 채팅 첨부, 노트 명령, 예약 작업 테스트는 지운 부분에 맞게 고쳐서 통과했습니다.
- 서명 전 APK가 약 29MB에서 **약 19.7MB로 작아졌습니다.**

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 직접 써 보지 않았습니다.**

## 태블릿에서 해 볼 것
1. 올가미로 필기를 골랐을 때 선택 막대에 OCR 버튼이 없고, 나머지 버튼이 정상인지.
2. 홈 **+** 메뉴와 노트 카드 메뉴, 노트 설정에 OCR·스캔·색인 항목이 없는지.
3. 노트 안 검색과 홈 검색에서 PDF 글자와 텍스트 상자가 여전히 찾아지는지.
4. AI 패널의 **노트 보내기**가 정상인지(페이지 범위, 필기 포함, PDF/그림).
