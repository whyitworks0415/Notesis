# Notesis 0.33.5

- 연필을 투명한 틈과 작은 흑연 입자가 섞인 질감으로 변경했습니다. 질감은 한 번 생성해 재사용합니다.
- AI·인터넷 패널이 키보드 높이에 맞춰 줄어들도록 했습니다. 웹뷰의 사용자 에이전트 계산을 재사용하고, 백그라운드에서 웹뷰를 일시 정지하며, 렌더러 종료 시 웹뷰를 다시 생성합니다.
- 팝업의 세 손가락 이동·확대는 화면 좌표로 계산하여 팝업 자신의 이동·확대가 다음 제스처 계산에 끼어들지 않도록 했습니다. 확대 종료 시 수동 배율을 유지하고, 손가락 수가 바뀔 때 기준점을 다시 잡습니다.
- 아래로 닫기 동작은 시작 후 작은 손가락 간격 변화로 확대 동작으로 바뀌지 않습니다. 다른 손가락을 팝업에 댄 상태에서도 닫기 버튼을 누를 수 있으며, 펜으로 쓰는 중에는 현재 획이 저장된 뒤 닫습니다.
- 본 화면과 팝업에 같은 노트를 열면 편집 문서를 공유합니다. 함께 보는 동안 필기 메시 교체와 페이지 메모리 해제를 보류하여 편집 충돌을 줄였습니다. 팝업의 이미지 캐시, PDF 취소 정리, 노트 전환 및 로딩 실패 재시도도 보완했습니다.
- 하단 필기 재생·보기 버튼을 제거했습니다.
- Material·Glassmorphism·LiquidGlass 1~4 상단 바에 SpotiGlass와 같은 구성과 네 단계 크기를 적용했습니다. Material은 불투명 Surface와 기본 버튼을 사용하며, 유리 효과·굴절 캡처·변형 애니메이션을 사용하지 않습니다.

검증 결과와 실기기 확인 항목은 `docs/interaction-optimization.md`에 기록했습니다. 연결된 Android 기기가 없어 실제 발열·지연 시간과 키보드·제스처의 실기기 동작은 직접 측정하지 않았습니다.
