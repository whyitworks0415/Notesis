# Notesis 0.33.1

## Spotiglass 도구막대

- 2/4·3/4·4/4에서 도구 박스와 기능 버튼을 둘러싸던 바깥 배경을 제거했습니다.
- 기능 버튼은 누르지 않아도 원본 Liquid Glass 굴절이 적용되는 원형 버튼입니다.
- 1/4의 바깥 배경에도 상시 Liquid Glass를 적용했습니다.
- 왼쪽 n/4 표시와 도구·기능 버튼 아래 이름을 제거했습니다. 모드 변경은 기능 메뉴에서 가능합니다.
- 도구 선택 렌즈가 펜·연필·형광펜·마스킹·도형 위를 지나가면 각 도구에 저장된 색을 미리 보여줍니다.
- 1/4에서 도구와 색상·굵기 옵션을 줄로 나누고, 좁은 화면에서는 도구도 자동으로 줄을 나눕니다. 아래 도구를 가로로 스크롤할 필요가 없습니다.
- 렌즈의 프레임 갱신을 그리기 단계로 옮기고 셰이더 효과를 재사용합니다. 드래그 중 애니메이션 시계도 재시작하지 않습니다.
- 도구막대 너비 전환은 필기 화면 전체를 매 프레임 다시 구성하지 않고 측정 단계에서 처리합니다.
- 최소 모드에서 전체 모드로 펼칠 때 줄 수가 반복해서 바뀌는 현상과 폭이 0인 테두리의 오류를 수정했습니다.

## 검증

- 114개 JVM 테스트: 도구별 색 미리보기, 좁은 화면의 도구 배치, 기존 도구·애니메이션·메뉴 위치 동작.
- Android 에뮬레이터에서 네 가지 모드와 실제 Liquid Glass 셰이더, 도구 드래그 및 기능 메뉴 확인.
