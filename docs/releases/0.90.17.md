# Notesis 0.90.17 (208)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 바뀐 점

- **드래그 시작**: 손가락을 댄 순간부터 선택 작업과 미리 읽기 같은 선택적 작업에 이동 중임을 알립니다. 첫 움직임이 들어온 뒤에야 우선순위를 바꾸던 것을 앞당겼습니다. 탭·길게 누르기 판정과 페이지 이동 배율은 바꾸지 않았습니다.
- **페이지의 이미지와 사용자 배경**: 화면을 그리다 캐시가 비었을 때 파일을 바로 읽지 않습니다. 공유 백그라운드 작업자 하나가 읽고, 준비된 화면을 다음 프레임에 갱신합니다. 같은 파일의 요청은 합치고, 실패한 파일은 매 프레임 다시 읽지 않습니다. 준비 중에는 이미지가 잠깐 비어 보일 수 있습니다.
- **메모리**: 노트와 참조 패널의 기존 이미지 캐시 예산을 유지합니다. 큰 화면 미리보기는 이미지 하나가 예산의 절반을 넘지 않도록 디코딩할 때 축소합니다. 원본 파일, 선택 복사와 캡처의 원본 해상도 읽기, 내보내기 형식은 유지됩니다. 크게 확대하면 큰 이미지·사용자 배경의 화면 미리보기가 원본보다 부드러워 보일 수 있습니다.
- **노트 전환과 닫기**: 닫은 화면의 이미지 작업은 캐시나 새 화면을 갱신하지 않습니다. 참조 패널마다 별도 작업자 풀을 만들지 않습니다.
- **긴 문서**: 페이지 이동 중 폭 맞춤을 위해 전체 페이지를 입력마다 훑던 계산을 문서 레이아웃 캐시에 합쳤습니다. 페이지 패널의 카드 번호도 페이지 ID로 찾습니다.
- **컨트롤과 팝업**: 슬라이더·스위치의 조작 위치는 다음 애니메이션 틱을 기다리지 않고 입력을 따릅니다. 장식적인 유리 움직임과 놓은 뒤 스프링은 유지합니다. 팝업 외곽선의 모양을 유지하면서 프레임마다 생기던 임시 배열 네 개를 없앴습니다.
- **업데이트 검사**: 단위 테스트가 실패하면 서명·배포로 넘어가지 않도록 CI를 바꿨습니다. 검증 전용 check 실행에서는 이미지 작업 수명과 UI 테스트도 통과해야 합니다.

## 호환성

- 노트 저장 형식, 기존 설정 키, 앱 ID, 최소 Android 버전, 의존성 버전, 업데이트 주소와 서명·키 교체 절차는 바꾸지 않았습니다.
- 버전은 207 → 208로 올렸습니다. 배포용 APK의 최종 서명과 기존 설치 위 업데이트는 기존 릴리스 작업과 실제 기기에서 확인해야 합니다.

## 확인 방법

- 공유 캐시의 중복 요청, 큐 제한, 오류 처리, 화면 종료 후 늦은 결과·콜백 차단을 단위 테스트합니다.
- 이미지 디코딩의 메모리·텍스처 한도, 긴 문서 폭 캐시와 무한 용지, 컨트롤의 첫 입력 반영을 회귀 테스트합니다.
- CI check로 release APK 빌드, 전체 release 단위 테스트, Robolectric의 이미지 로딩·원본 해상도·노트 구분과 라이브러리 UI 테스트를 실행합니다. 실제 실행 결과는 PR의 검사 결과를 확인해 주세요.

## 기기에서 확인할 것

실제 태블릿에서는 시험하지 않았습니다. 프레임 수·반응 시간·배터리 개선 수치를 측정하지 않았습니다.

1. 60Hz에서 페이지에 손을 대고 천천히 움직이기, 빠르게 넘기기, 움직이는 페이지를 다시 잡기.
2. 이미지와 사용자 배경이 많은 노트를 처음 열고 스크롤한 뒤 확대하기. 준비된 이미지가 나타나는지와 확대 품질 확인.
3. 참조 패널에서 서로 다른 노트를 빠르게 전환하고 닫기. 사진이 섞이거나 앱이 종료되지 않는지 확인.
4. 슬라이더·스위치 드래그와 팝업 연속 여닫기.
5. 기존 노트에 쓰고 저장·재실행, 이미지 선택 복사·캡처·PDF 내보내기와 기존 APK 위 업데이트 확인.
