# Notesis 0.47.3 (122)

## 꾹 눌러 도형 만들기가 동작하지 않던 문제
- 원인 1: "Hold the pen to make a shape" 설정이 기본으로 꺼져 있어서, 펜 설정에서 켜지 않으면 아무 일도 일어나지 않았습니다. 이번 업데이트에서 모든 사용자에게 한 번 켜 둡니다. 그 뒤에는 직접 끄거나 켜는 대로 유지됩니다.
- 원인 2: 펜을 멈추고 있는 0.5초 동안 같은 자리에서 미세하게 흔들리는 점이 수백 개 들어와, 직선이 꺾인 선으로 읽히거나 도형으로 인식되지 않았습니다. 이제 멈춰 있던 자리(펜이 처음 닿은 자리 포함)는 한 점으로 모으고, 지나치게 촘촘한 점은 합친 뒤 인식합니다.
- 펜을 충분히 오래 멈추면 펜 끝에 작은 고리가 나타나고(진동이 있는 기기는 짧게 진동), 그때 떼면 도형이 됩니다.

## 도형 도구 다시 누르면 도형 고르기
- 도형 도구를 고른 상태에서 한 번 더 누르면 도형 선택 창이 열립니다. 1/4 크기 막대의 도형 버튼도 같은 창을 엽니다.
- 고를 수 있는 도형:
  - 선 종류: 직선, 화살표, 양쪽 화살표, 곡선, 다각형·꺾인 선
  - 닫힌 도형: 사각형, 원, 삼각형, 직각삼각형, 마름모, 평행사변형, 사다리꼴, 오각형, 육각형, 별
  - 체크박스
- 각 도형은 실제로 그려지는 모양 그대로 미리 보여 줍니다.
- 같은 창에서 꾹 눌러 도형 만들기 켜기·끄기와 모서리 둥글기를 바로 바꿀 수 있습니다.
