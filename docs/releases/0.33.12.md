# Notesis 0.33.12

- 필기 비트맵 캐시에 Canvas 확대 변환을 실제로 적용하고, 화면보다 높은 해상도로 그려 얇은 선의 가장자리 품질을 개선했습니다. 캐시는 48MB 이내이며, 큰 페이지는 벡터 렌더링을 사용합니다.
- 기본 획 보정을 0%로 되돌렸습니다. 직접 지정한 보정값은 유지합니다.
- 필기·화면 이동 중 Liquid Glass의 페이지 중복 캡처를 중단하고, 캔버스의 불필요한 전체 화면 오프스크린 합성을 제거했습니다.
- 도구막대의 중복 크기 애니메이션과 그림자를 자르는 클립을 제거했습니다. 폭은 하나의 타이머로 보간합니다.
- 폭이 변할 때 선택 표시의 프레임 타이머가 매번 재시작되지 않도록 수정했습니다. 움직이는 유리 효과는 배경에 적용하고 도구 아이콘의 픽셀은 굴절시키지 않습니다.
- PDF의 작은 페이지 미리보기를 별도 예산 안에 유지해 고해상도 캐시 교체·확대·축소 중 페이지 바탕이 사라지지 않게 했습니다. 배율 변경만으로 진행 중인 렌더를 취소하지 않고, 화면 갱신은 디스플레이 프레임에 맞춥니다.
