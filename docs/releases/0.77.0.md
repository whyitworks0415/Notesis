## 한국어 모드
- **Settings 맨 위 "Language · 언어"** 에서 English / 한국어를 고를 수 있습니다. 고르면 바로 바뀌고, 다음에 앱을 열 때도 유지됩니다.
  - 어느 언어로 되어 있어도 찾을 수 있게, 이 항목 이름만 두 언어로 적었습니다.
- 메뉴, 설정, 대화상자, 알림 메시지(토스트), 튜토리얼, 녹음 알림까지 약 1,380개 문장을 한국어로 옮겼습니다.
  - 기계적으로 옮기지 않고 한국어 앱에서 쓰는 말투로 다듬었습니다. 버튼은 짧게("저장", "다시 시도"), 안내는 "~합니다"로 맞췄습니다.
  - 개수는 한국어 셈법을 따릅니다. 예: "3 notes" → "노트 3개", "12 pages" → "12페이지", "2 pictures" → "사진 2장"
  - 숫자나 이름이 들어가는 문장도 어순을 한국어로 바꿨습니다. 예: `No results for "abc"` → `"abc"에 대한 결과가 없습니다`
- 가독성
  - 한국어일 때는 글자에 한국어 로캘을 지정해 기기의 한국어 글꼴을 씁니다.
  - 줄바꿈은 낱말 사이에서만 일어납니다. 한 낱말이 두 줄로 쪼개지지 않습니다.
- 새로 만드는 **Welcome to Notesis 안내 노트**도 한국어로 만들어집니다. 이미 있는 안내 노트는 그대로이고, **About & help**에서 새로 받으면 한국어로 나옵니다.
- 그대로 영어로 두는 것
  - 앱 이름, 기능 이름처럼 쓰는 고유명사(Notesis, Liquid glass, Kyant0, QWEA0, Material 등), 단위, 단축키
  - 개발자용 Diagnostics 화면의 측정값 이름
  - 펜 커서·눈금처럼 화면에 직접 그리는 글자, 화면 읽기(접근성)용 설명
  - 사전에 없는 문장은 비어 보이지 않도록 영어로 나옵니다.

## 확인 방법
- 단위 테스트: iOS·Kyant0의 새 기본값, 예전 기본값이 새 기본값으로 바뀌는지, 직접 바꾼 값이 유지되는지
- 사전 파일: 모든 문장의 {0}, {1} 자리가 영어와 한국어에서 같은 개수인지 확인했습니다.
- 에뮬레이터나 실제 기기에서는 한국어 화면과 펜 설정창 위치를 눈으로 확인하지 못했습니다.

## 기기에서 확인할 것
- Settings 맨 위에서 한국어를 고르면 메뉴·설정·대화상자가 바로 한국어로 바뀌는지
- 한국어 문장이 어색하거나, 영어로 남은 곳이 있는지
- 긴 한국어 설명이 낱말 중간에서 잘리지 않는지, 버튼 글자가 넘치지 않는지
- 펜 → 연필 → 형광펜 설정창을 차례로 열 때 맨 위 위치가 같은지
- Liquid glass · iOS, Kyant0의 Glass 탭 값이 위에 적은 값으로 나오는지
