# Notesis 0.64.0 (151)

## 1/4 툴바 선택 표시
- 1/4(전체) 툴바에서 도구를 누를 때 선택 유리가 띠 위아래로 튀어나오던 문제를 고쳤습니다.
- 손을 뗀 뒤 선택 표시가 잠깐 진하게 남았다가 연해지던 것을 없앴습니다. 이 크기에서는 선택 표시가 처음부터 연한 상태 그대로 옆 도구로 미끄러집니다. 2/4~4/4 툴바의 유리 효과는 그대로입니다.

## 캡처에 연필 등이 빠지던 문제
- 캡처 이미지를 화면과 같은 GPU 경로로 그리도록 바꿨습니다. 화면에는 보이는데 캡처에서 빠지던 연필(흑연) 획과 입자형 펜(소프트 연필, 스탬프, 버블, 스프레이) 획이 이제 캡처에도 나와야 합니다.
- 같은 방식을 PNG·PDF(크기 지정) 내보내기, 노트 목록 썸네일, 페이지 스크러버·미니맵 썸네일에도 적용했습니다.
- GPU로 그릴 수 없는 경우에는 예전 방식으로 그립니다.

## 처음 설치했을 때의 기본값
- 처음 설치하면 아래 값으로 시작합니다. 이미 쓰고 있던 설정은 바뀌지 않습니다.
  - Scale 90%, Corner 32dp, Frost 12%, Transparency 100%, Reflection 100%, Depth 10dp, Raised, Interaction strength 100%
- 1/4 툴바의 처음 구성:
  - 아래 줄: 제스처, 펜, 연필, 형광펜, 지우개, 도형, 텍스트, 올가미, 캡처, 마스크, AI | 굵기, 팔레트, 페이지, Functions
  - 위 줄: 뒤로가기, 노트 이름, Undo, Redo, 녹음, 검색

## 툴바 상단 고정
- Functions 메뉴에 "Pin to top"을 넣었습니다. 누르면 툴바가 화면 위쪽에 고정되고, 다시 누르면(Unpin bar) 떠 있는 툴바로 돌아갑니다.

## 패널을 끝까지 당기면 닫기
- 설정 사이드바와 노트 옆 AI(웹) 패널은 폭 조절 막대를 최소 폭보다 더 바깥으로 당긴 뒤 놓으면 닫힙니다.
  - 설정 사이드바는 당기는 만큼 손을 따라 밀려나다가, 충분히 당긴 상태에서 놓으면 닫힙니다. 덜 당기면 최소 폭으로 돌아옵니다.
  - AI 패널은 놓으면 닫히는 지점부터 폭 표시선이 빨간색으로 바뀝니다.
