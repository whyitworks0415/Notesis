Spotiglass 상단 도구막대를 사용자 스케치에 맞춰 네 가지 모드로 정리했습니다.

- 1/4: 기존 노트 상단 행과 전체 도구·펜 옵션.
- 2/4: 한 줄의 도구 바와 오른쪽 ‘기능’ 메뉴. 캡쳐와 AI도 바에서 바로 열 수 있습니다.
- 3/4: 읽기·펜·형광펜·마스킹의 작은 바. 나머지 도구와 기능은 메뉴에서 접근합니다.
- 4/4: 드래그할 수 있는 메뉴 버튼 하나. 메뉴에서 도구·기능·바 크기를 선택합니다.
- 기능 메뉴: 마이크·상단 고정·전체화면·노트 바꾸기·필기 설정·캡쳐·UI 설정·노트 회전·검색·AI. 부가 기능은 ‘더보기’에 모았습니다.
- 모드 전환 시 너비와 높이가 부드럽게 변하며 원본 굴절 셰이더로 유리 모핑을 표시합니다. 기능 버튼은 눌렀을 때 커지고, 메뉴는 유리 효과와 함께 열리고 닫힙니다.
- 메뉴 위치를 화면 안으로 보정하며 작은 화면과 RTL에서도 조작할 수 있습니다. 바 크기는 재실행 후에도 유지됩니다.
- 필기 화면을 유지한 채 UI 설정을 열어 돌아오면 현재 도구와 실행취소 상태를 보존합니다.

검증: JVM 테스트, Android GPU·필기 회귀 검사 및 에뮬레이터에서 네 모드·메뉴·설정 복귀 확인.
