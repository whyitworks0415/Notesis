## "페이지로 돌아가기" 버튼이 사라지지 않던 문제
- **증상**: 페이지 패널, 목차, 검색 결과, "페이지로 이동"으로 다른 페이지에 갔다 오면, 위쪽의 **"N페이지로 돌아가기"** 버튼이 계속 남아 있었습니다.
- **원인**
  - 이동할 때마다 "돌아갈 곳"이 하나씩 쌓였고, 버튼은 눌러서 하나씩 되돌아가야만 사라졌습니다.
  - 직접 스크롤해서 원래 페이지로 돌아와도, 시간이 지나도 사라지지 않았습니다.
- **수정**: 다음 중 하나면 버튼이 사라집니다.
  - **8초가 지나면** 저절로 사라집니다. 새로 이동하면 8초가 다시 시작됩니다.
  - **스크롤해서 원래 페이지에 돌아오면** 사라집니다.
  - 버튼 오른쪽의 **✕**를 누르면 바로 사라집니다.
- 같은 곳에서 연달아 이동해도 돌아갈 곳이 하나만 남고, 돌아갈 곳은 최근 5곳까지만 기억합니다.

## 확인 방법
- 빌드와 기존 단위 테스트만 확인했습니다. 기기에서는 확인하지 못했습니다.

## 기기에서 확인할 것
- 페이지 패널로 다른 페이지에 갔을 때 버튼이 나오고, 8초 뒤 사라지는지
- 그 전에 직접 스크롤해서 원래 페이지로 돌아오면 사라지는지
- ✕를 누르면 사라지는지, 버튼을 눌러 돌아가는 것은 그대로 되는지
