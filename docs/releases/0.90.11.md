## 바뀐 점

### Mornye 스쿼클 모서리
Mornye 룩의 유리에 Mornye와 같은 **스쿼클(연속 곡률) 모서리**를 넣었습니다.
- **모양**: 모서리를 원이 아니라 L^n 초타원으로 그립니다.
  - 곡선이 반경의 1.528배 지점에서 직선과 끊김 없이 이어지기 시작합니다.
  - 45° 지점은 같은 반경의 원과 정확히 같은 자리를 지나서, 모서리 크기는 그대로이고 곡선만 더 부드럽습니다.
  - Mornye가 쓰는 liquid_glass_easy 5.1.0(MIT)의 계산을 Kotlin으로 옮겼습니다.
- **같은 모양을 쓰는 곳**: 유리 몸체, 렌즈, 그림자, 테두리가 모두 이 모양을 씁니다. 그래서 모서리에서 유리가 잘리거나 테두리가 어긋나지 않습니다.
  - 유리 렌즈(Backdrop)가 이 모양의 반경을 읽고 모서리를 따라 굴절할 수 있도록, Compose의 모서리 기반 모양(CornerBasedShape)으로 만들었습니다.
  - 효과가 꺼진 상태(절전, 고대비 등)의 대체 표면도 같은 모서리를 씁니다.
- **곡선의 정밀도**: 모서리마다 실제 곡선과 0.05px 이내로 맞도록 점 개수를 정합니다(3~40개).
- **끄기**: **설정 › 모양 › 유리 › 부드러운 모서리**에서 끌 수 있습니다. 기본은 켜짐입니다.

## 확인한 것
- CI에서 빌드, 단위 테스트, 스크린샷 테스트를 돌렸습니다.
- 새 단위 테스트로 다음을 확인합니다.
  - 스쿼클이 반경의 1.528배까지 뻗는지, 짧은 변의 절반을 넘지 않는지
  - 45° 지점이 같은 반경의 원과 일치하는지
  - 외곽선 점이 시계 방향이고 상자 안에 있는지
  - 설정 저장과 불러오기
- **기기(태블릿)에서는 시험하지 못했습니다.** 모서리 모양과 그리는 비용은 보지 못했고 측정하지도 않았습니다.

## 하지 않은 것
- 렌즈 셰이더 자체는 여전히 둥근 사각형 기준으로 굴절합니다. 렌즈가 받는 반경은 같고, 외곽선과 테두리만 스쿼클입니다. Mornye는 셰이더도 스쿼클로 계산합니다.
- 도구 막대 안의 선택 알약 같은 작은 요소는 둥근 모서리 그대로입니다.

## 태블릿에서 해볼 것
1. Mornye 룩에서 도구 막대, Functions 메뉴, 펜 패널의 모서리가 부드럽게 이어지는지 봅니다.
2. 모서리에서 유리가 잘리거나, 테두리나 그림자가 어긋나 보이지 않는지 봅니다.
3. 설정에서 "부드러운 모서리"를 껐다 켜며 차이를 봅니다.
4. 메뉴가 쏟아지듯 열리는 도중에도 모서리가 깨지지 않는지 봅니다.
