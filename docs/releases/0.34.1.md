# Notesis 0.34.1

획이 많은 페이지에서 페이지를 넘길 때 생기던 끊김을 고쳤습니다.

- 0.34.0에서 바꾼 밀집 페이지 캐시를 이전 방식으로 되돌렸습니다. 새 캐시는 페이지를 멈출 때마다 화면 크기의 큰 비트맵을 다시 만들었습니다. 그 작업이 페이지 불러오기와 같은 작업 스레드를 차지해 다음 페이지가 늦게 나타났고, 비트맵을 GPU로 올리는 순간에도 끊겼습니다.
- 메시 렌더링에 쓰는 획 사본을, 페이지가 화면에 처음 그려지는 순간이 아니라 페이지를 불러오는 작업 스레드에서 미리 만듭니다. 이전에는 획이 많은 페이지가 화면에 들어오거나 확대 후 다시 계산될 때, 한 프레임에서 획 수만큼 객체를 만들어 끊겼습니다.

검증: 릴리스 APK 빌드. 실제 기기에서의 체감은 아직 확인하지 않았습니다.
