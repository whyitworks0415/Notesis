## 모션을 180ms로 통일
앱이 직접 움직이는 화면 요소의 애니메이션 길이를 모두 **180ms** 하나로 맞췄습니다. 지금까지는 90ms에서 520ms까지 제각각이었습니다.

| 무엇 | 전 | 이제 |
|---|---|---|
| 툴바 크기 바꾸기(1/4 ↔ 4/4) | 500ms | 180ms |
| Functions 메뉴·펜 설정창·도구 패널이 버튼에서 열리기 / 닫히기 | 240 / 180ms | 180 / 180ms |
| Settings 사이드바 열기 / 닫기 | 380 / 220ms | 180 / 180ms |
| Settings 화면 넘기기 | 160ms | 180ms |
| 펜 설정 "More for this pen" 펼치기 / 접기 | 280 / 220ms | 180 / 180ms |
| 페이지 패널·레이어 패널 들어오기 / 나가기 | 기본 스프링 | 180ms |
| 참고 노트 패널 열기 / 닫기 | 110~190ms, 스프링 | 180ms |
| 페이지 스크러버 나타나기 / 사라지기 | 120 / 220ms | 180ms |
| 페이지 미리보기(펜 올려 두기) 커지기 / 작아지기 | 스프링 / 140ms | 180ms |
| 툴바 선택이 다음 도구로 옮겨 가기 | 약 255ms에 안착 | 180ms에 안착 |
| 버튼 누르기, 슬라이더 손잡이, 스위치, 세그먼트 | 스프링마다 다름 | 180ms에 안착 |
| 유리 버튼 반짝임 켜기 / 끄기 | 140 / 520ms | 180 / 180ms |
| + 버튼 메뉴 항목이 차례로 나오기 | 항목마다 35ms 간격 | 항목마다 12ms 간격 |
| 사용법 안내 표시(코치 마크) 옮겨 가기 | 420ms | 180ms |
| 툴바 숨기기·보이기, 첫 화면 선택 표시 | 스프링마다 다름 | 180ms에 안착 |

- 스프링은 "180ms 안에 자리를 잡도록" 강도를 다시 계산했습니다. 튕기는 정도(감쇠비)는 그대로라서 느낌은 같고 빠르기만 맞춰졌습니다.
- **툴바 크기 바꾸기 시간**(Settings › Customize toolbar의 Switch time)은 이번에 한 번만 180ms로 바뀝니다. 그 뒤에 직접 바꾸면 그 값을 그대로 씁니다.

## 그대로 둔 것
- **Liquid glass · iOS / Kyant0 / QWEA0 의 Motion 스위치가 켜져 있을 때의 움직임**: 각 프로젝트의 값을 따르도록 요청하셨던 부분이라 바꾸지 않았습니다. 스위치를 끄면 위의 180ms 움직임이 됩니다. 이것도 180ms로 맞추길 원하시면 알려 주세요.
- 반복되는 표시: 녹음 중 깜빡이는 원(1.4초 주기), 시계 알림 깜빡임(0.9초 주기), 녹음 소리 크기 막대
- 첫 실행 환영 애니메이션: 정해진 순서로 진행되는 짧은 연출이라 그대로입니다.
- 손가락을 따라가는 움직임: 끄는 동안은 손가락에 바로 붙어 있고, 놓은 뒤 자리 잡는 데 180ms가 걸립니다.

## 확인 방법
- 단위 테스트: 툴바 선택 이동 스프링이 새 값에서도 렌즈 계산과 맞는지(중간 지점까지 약 67ms), 들림과 안착이 그대로인지
- 실제 기기에서는 움직임을 눈으로 확인하지 못했습니다.

## 기기에서 확인할 것
- 툴바 크기 바꾸기, Functions 메뉴, 펜 설정창, Settings 사이드바가 같은 빠르기로 열리고 닫히는지
- 툴바에서 도구를 바꿀 때 선택이 너무 빠르거나 튀지 않는지
