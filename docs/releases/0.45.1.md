# Notesis 0.45.1 (112)

기울인 노트에서 생기던 직선, 획이 많은 곳에서의 끊김, 미니맵 위치, 팝업 노트 이동감을 고쳤습니다.

## 기울인 노트에서 펜 앞에 생기던 직선
- 쓰는 동안에만 보이고 기울인 각도에 따라 방향이 바뀐다는 점에서, 원인은 펜 앞을 미리 그려 주는 "예측" 선이었습니다. 기울인 좌표에서 예측 결과가 틀어져 펜 앞으로 길게 뻗었습니다.
- 노트를 기울였을 때는 예측을 끕니다. 기울이지 않은 상태의 예측은 그대로입니다.
- 기울인 상태에서는 획이 펜을 아주 조금 늦게 따라옵니다.

## 획이 많은 곳에서 확대·이동이 불안정하던 문제
- 지난 버전의 미니맵과 페이지 이동 막대 미리보기가 페이지의 모든 획을 화면을 그리는 흐름 안에서 그려 축소 그림을 만들고 있었습니다. 획이 많은 페이지에서는 이 작업이 확대·이동을 멈칫하게 했습니다.
  - 이제 축소 그림은 별도의 낮은 우선순위 작업으로 그리고, 다 되면 나타납니다.
- 노트를 기울이지 않았을 때는 펜·손가락 입력을 매번 복사하지 않고 그대로 처리합니다(0.44.2에서 늘었던 부담을 되돌림).
- 재사용하려고 보관하는 PDF 조각 이미지는 최대 3개, PDF 조각 저장 공간의 1/6 이내로 줄였습니다.

## 미니맵
- 오른쪽 아래에서 **오른쪽 위**(도구막대 아래, 페이지 이동 막대 왼쪽)로 옮겼습니다.
- 켜고 끄기:
  - 미니맵 모서리의 ×로 끕니다.
  - 기능 메뉴의 "미니맵 켜기/끄기"(Spoti 유리 도구막대)로 켜고 끕니다.
  - 노트 메뉴(⋯)의 "확대했을 때 미니맵" 스위치로도 켜고 끕니다.

## 팝업 노트
- 페이지가 손가락보다 1.65배 빠르게 움직이던 것을 손가락과 똑같이 움직이도록 바꿨습니다(관성 스크롤 포함).
- 페이지를 좌우로 밀어 노트 가장자리 밖으로 내보낼 수 없습니다. 확대했을 때는 페이지 양 끝까지만 움직입니다.
