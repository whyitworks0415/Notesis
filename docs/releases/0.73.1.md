# Notesis 0.73.1 (163)

## Android 11·12에서 기능(Functions) 버튼이 안 눌리던 문제 수정
- Android 11과 12에서 툴바의 **Functions** 버튼을 눌러도 아무것도 나오지 않던 문제를 고쳤습니다.
- 원인: 메뉴는 실제로 열렸지만 **높이 0으로 잘려서 보이지 않았습니다**. 그래서 버튼이 안 눌린 것처럼 보였습니다. 보이지 않는 자리를 누르면 메뉴 항목이 눌리기도 했습니다.
  - Android 12 이하에서는 Liquid glass의 움직임 효과가 항상 꺼집니다. 그때 메뉴에 붙은 "길이 0짜리 크기 애니메이션"이 메뉴를 높이 0에 멈춰 두었습니다.
  - 스킨(Material·Glassmorphism·Liquid glass)과 상관없이 생겼습니다. Android 13 이상에서도 시스템 설정에서 애니메이션을 끄면 같은 일이 생길 수 있었습니다.
- 이제 움직임이 꺼진 경우에는 크기 애니메이션을 아예 붙이지 않아서 메뉴가 바로 보입니다.

## Android 12 이하에서 유리 패널 읽기 쉽게
- Android 12 이하에서는 화면 블러를 쓸 수 없습니다. 그런데 유리 패널이 반투명해서, 패널 뒤 페이지 글씨가 **흐려지지 않은 채로** 패널 글씨와 겹쳐 보였습니다(예: Tools 계산기).
- 블러를 쓸 수 없을 때는 Liquid glass 패널을 거의 불투명하게(95%) 그립니다.
- Glassmorphism도 Android 12 이하에서는 뒤 페이지를 다시 그리지 않고 패널을 불투명하게 칠합니다.

## 확인 방법
- Android 11(API 30)과 Android 14(API 34) 태블릿 에뮬레이터에서 앱을 직접 조작해 확인했습니다. 안내 노트를 열고 Functions 메뉴를 연 다음 마이크, Tools, Layers, Pages & notes, Settings를 차례로 열었습니다.
  - 수정 전 API 30: 메뉴가 화면에 그려지지 않음.
  - 수정 후 API 30: 메뉴가 API 34와 같이 보이고, 메뉴에서 연 창들도 보임.
- 실제 태블릿에서는 확인하지 못했습니다.

## 기기에서 확인할 것
- Android 11 태블릿: Functions 버튼 → 메뉴가 보이는지, 메뉴 안의 버튼(Tools, 마이크, Layers, Pages & notes, Settings)이 열리는지
- 툴바 크기 2/4·3/4·4/4, 세로 툴바에서도 Functions 메뉴가 보이는지
- 유리 패널(Tools, 펜 설정 등)이 뒤 글씨에 가려지지 않고 읽히는지
