# Notesis 0.51.1 (135)

## First-run mode (처음 설치했을 때 모드)
- 홈 화면 About & help에 "First-run mode" 스위치를 넣었습니다.
- 켜 두고 앱을 완전히 껐다 다시 켜면, 새로 설치한 것처럼 처음부터 시작합니다.
  - 환영 애니메이션 → 스킨 고르기 → 홈 화면 안내 → 노트를 열면 툴바 안내 → 필기하다 보면 팁, 순서입니다.
- 노트, 폴더, 설정, 지금 쓰는 스킨은 그대로입니다. 바뀌는 건 "환영·튜토리얼을 이미 봤다"는 기록뿐입니다.
- 안내 노트를 지웠다면 다시 하나 넣어 줍니다. 이미 있으면 그대로 둡니다(중복으로 만들지 않음).
- 켜 두는 동안에는 앱을 켤 때마다 이렇게 시작합니다. 그만 보려면 같은 곳에서 끄면 됩니다.
- 화면 회전처럼 앱이 다시 그려지기만 할 때는 다시 시작하지 않습니다.

## UI 설정(Appearance)의 툴바 미리보기
- 미리보기 위에 툴바 크기 선택(1/4, 2/4, 3/4, 4/4)을 넣었습니다. 고르면 실제 툴바 크기도 바뀝니다. 홈 화면 설정에서 바꾸면 다음에 여는 노트에 적용됩니다.
- 미리보기 툴바를 직접 눌러볼 수 있습니다.
  - 도구를 누르면 선택 하이라이트가 그 도구로 미끄러져 갑니다.
  - Functions 버튼을 누르면 누른 곳에서 메뉴가 나옵니다. 그 안의 크기 선택도 동작합니다.
  - AI 도구를 누르면 AI 목록이 나옵니다.
  - 1/4(전체) 크기에서는 펜 줄의 색 칩과 굵기 슬라이더도 만질 수 있습니다.
- 미리보기 아래에 같은 스킨의 스위치와 슬라이더를 넣어서, 지금 고른 모양으로 켜고 끄고 밀어볼 수 있습니다.
- 미리보기에서 누른 도구나 색은 노트의 실제 도구와 펜에 영향을 주지 않습니다.
- 미리보기 툴바는 노트 툴바 안내(튜토리얼)에 잡히지 않게 했습니다. 툴바 사용자화 화면의 미리보기도 마찬가지입니다.
