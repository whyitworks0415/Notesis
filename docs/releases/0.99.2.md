# Notesis 0.99.2 (243)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

에이전트를 쓸 때의 발열과 렉을 줄인 수정판입니다. Notesis 안에서 에이전트 때문에 불필요하게 일하던 곳 세 군데를 고쳤습니다.

## 바뀐 점
- **기다리는 동안 계속 돌던 애니메이션**: 사이드바에서 에이전트의 답을 기다리는 동안 진행 막대가 계속 움직여서, 몇 분 동안 화면 전체를 매 프레임 다시 그렸습니다. 막대를 없애고 1초에 한 번 바뀌는 경과 시간만 남겼습니다.
- **변경마다 노트 전체를 다시 열던 것**: 에이전트가 열린 노트를 바꿀 때마다 노트를 처음부터 다시 열어 화면의 모든 쪽을 다시 읽고 다시 그렸습니다. 이제 **바뀐 것만** 반영합니다. 목차·종이·책갈피·글 상자 같은 설정은 그 자리에서 바꾸고, 필기가 바뀐 쪽만 다시 읽습니다. 나머지 쪽은 그려 둔 그대로 씁니다. 쪽을 더하거나 빼거나 옮긴 경우와 되돌리기 뒤에만 예전처럼 다시 엽니다.
- **읽을 때마다 노트 표지를 다시 그리던 것**: 에이전트가 열린 노트를 읽거나 바꿀 때마다 노트를 닫을 때 쓰는 저장을 해서, 서재 카드의 첫 쪽 그림(PDF 포함)을 매번 다시 그렸습니다. 이제 에이전트 때문에 하는 저장은 그림을 그리지 않고, 바뀐 것이 없으면 아무것도 쓰지 않습니다. 카드 그림은 노트를 닫을 때 그려집니다.

## 어떻게 확인했나
- 단위 테스트 전체 통과(로컬, 네이티브 검사 포함).
- 바뀐 부분은 화면과 저장 코드라 **빌드와 기존 시험으로만 확인했습니다.** 발열이나 속도는 **재지 않았습니다.**

## 하지 않은 것
- **Termux 쪽의 부담은 앱에서 줄일 수 없습니다.** 에이전트(Node)와 proot의 Debian은 요청마다 시작되고 메모리를 크게 씁니다. 사이드바로 물을 때마다 새로 시작하므로, 여러 번 연달아 물을 때는 Termux에서 에이전트를 열어 두고 직접 대화하는 편이 가볍습니다. Termux 알림의 "Acquire wakelock"이 켜져 있으면 꺼 주세요.
- 태블릿에서 해 보지 않았습니다.

## 태블릿에서 해 볼 것
1. 노트를 연 채로 에이전트에게 여러 번 바꿔 달라고 → 바뀔 때 화면 전체가 다시 그려지며 깜빡이지 않고, 바뀐 곳만 바뀌는지.
2. 사이드바로 오래 걸리는 요청을 보내고 기다리는 동안 기기가 전보다 덜 뜨거운지.
3. 노트를 닫으면 서재 카드 그림이 최신인지.
4. 에이전트가 필기를 지우거나 그린 쪽이 제대로 다시 보이는지, 되돌리기 뒤에도.
