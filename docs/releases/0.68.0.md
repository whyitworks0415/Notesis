# Notesis 0.68.0 (155)

## 연습장 페이지: 페이지 바로 옆에 펼쳐짐
- "Attach…"의 **Practice page**는 이제 새 노트를 만들지 않습니다. 같은 노트 안에서 그 페이지 **바로 오른쪽에 빈 페이지 한 장**이 나란히 놓입니다. 연습장을 붙인 페이지만 두 장이 펼쳐진 것처럼 보이고, 나머지 페이지는 그대로 한 장씩 보입니다(세로 스크롤 보기에서).
- 연습장을 여러 장 붙이면 오른쪽으로 이어서 놓입니다.
- 페이지 패널에서는 연습장 페이지에 "· Practice"가 붙어 보입니다.
- 실행 취소로 되돌릴 수 있고, 일반 페이지처럼 필기·지우기가 됩니다.
- 이전 버전에서 붙인 "다른 노트의 페이지" 탭은 그대로 남아 예전처럼 팝업으로 열립니다. 새로 붙이는 메뉴에서는 빠졌습니다.

## 주석: 한글(HWP) 메모처럼 여백에 선으로 연결
- **Comment**는 페이지 오른쪽 여백 칸에 노란 메모 상자로 보입니다. 메모 상자와 페이지 위의 위치가 점선으로 이어집니다.
- 페이지를 길게 눌러 "Attach to this page…"로 붙이면, 길게 누른 바로 그 자리에 점이 찍히고 선이 그 점까지 이어집니다. 페이지 패널에서 붙이면 위치 없이 여백에만 놓입니다.
- 여백 메모는 세로 스크롤 보기에서 나옵니다. 페이지를 옆으로 넘기는 보기, 2장·4장 보기에서는 옆 페이지를 가리지 않도록 예전처럼 페이지 오른쪽 가장자리의 파란 탭으로 보입니다.
- 메모가 여러 개면 서로 겹치지 않게 아래로 차례로 놓입니다. 메모를 누르면 카드가 열려 링크 열기·수정·삭제·숨기기(Hide)를 할 수 있습니다.
- 페이지 패널 메뉴의 "Hide comments and practice pages"로 그 페이지의 메모와 연습장을 함께 접고, "Show…"로 다시 펼칩니다. 지워지는 것은 없습니다.

## 3/4(그리고 2/4) 툴바가 넓은데 2줄로 나오던 문제
- 원인: Scale(기본 90%)로 툴바는 작게 그리면서, 한 줄에 몇 개가 들어가는지는 100% 크기의 칸으로 계산하고 있었습니다. 그래서 3/4의 도구 4개가 3개 + 1개로 나뉘었습니다.
- 이제 칸 크기도 Scale에 맞춰 계산하고, 2/4·3/4 툴바는 도구가 한 줄에 다 들어가도록 필요한 만큼 넓어집니다(도구를 많이 넣은 경우). 화면이 그보다 좁을 때만 예전처럼 접히거나 세로로 바뀝니다.

## Functions 버튼 드래그로 크기와 방향 바꾸기
- 툴바 오른쪽의 Functions 버튼(세 줄 버튼)을 누른 채로
  - **오른쪽으로** 끌면 툴바가 길어지고(→ 1/4 방향), **왼쪽으로** 끌면 짧아집니다(→ 4/4 방향). 손가락이 처음 닿은 곳에서 56dp 움직일 때마다 한 단계씩 바뀝니다.
  - 화면의 **맨 왼쪽이나 맨 오른쪽 끝까지** 끌면 툴바가 그쪽 옆으로 **세로(vertical) 모드**가 됩니다. 1/4나 4/4였다면 세로에서 쓸 수 있는 2/4·3/4 크기로 바뀝니다.
- 세로 모드에서는 버튼을 위/아래로 끌어 크기를 바꾸고, 화면을 가로질러 끌었다가 놓으면 놓은 쪽(왼쪽/오른쪽)으로 옮겨 가며, **가운데에서 놓으면 다시 가로(위쪽)** 툴바로 돌아갑니다.
- 툴바 크기가 바뀌면서 버튼이 손가락 밑에서 움직여 단계가 엉뚱하게 바뀌던 문제를 고쳤습니다(손가락 위치를 버튼이 아니라 화면 기준으로 셉니다).

## 첫 화면(노트 목록) 디자인 정리와 접근성
- 맨 위에 "Notes"(폴더 안에서는 폴더 이름) 제목과 노트 개수가 크게 보이고, 그 아래에 둥근 검색창이 넓게 놓입니다. 검색어가 있으면 지우기(X) 버튼이 나옵니다.
- 위쪽 아이콘을 줄였습니다: Select, 정렬, 새 폴더, Tools, Tutorial, Display settings, 그리고 **More**(Trash, Library background, About · Help, 폴더 안에서는 폴더 이름 바꾸기/삭제).
- "Folders", "Notes", "Matches in pages" 구역 제목을 화면 읽기(TalkBack)에서 제목으로 읽습니다. 노트 카드의 메뉴 버튼은 "Options for 노트이름"으로 읽힙니다.
- 노트 카드의 날짜·페이지 수 글자를 더 진한 색으로 바꿔 유리 배경 위에서도 잘 보이게 했습니다.
- 노트가 없을 때는 아이콘, 안내 문장, "New note" 버튼이 함께 보입니다.
- 목록 맨 아래에 + 버튼 높이만큼 여백을 두어 마지막 줄 노트가 버튼에 가리지 않습니다.
