# Notesis 0.33.10

- 축소된 도구막대(2/4·3/4·4/4)에서 여는 도구 설정창의 슬라이더가 전체 폭을 사용하고 정상적으로 조작됩니다.
- 스위치와 슬라이더의 유리 효과가 설정창 배경을 직사각형으로 덮어쓰지 않도록 변경했습니다. 투명한 컨트롤 캡처의 알파도 보존합니다.
- 도구 설정창에서 색 팔레트를 바로 열 수 있습니다. 색을 선택해도 형광펜의 투명도는 유지합니다.
- 색 선택 영역과 색조·투명도 막대의 드래그가 설정창 스크롤에 가로채이지 않도록 수정했습니다.
- 선택한 지우개를 다시 누르면 굵기와 예측 on/off를 설정할 수 있습니다.
- 선 스타일·예측 거리·굵기 범위 버튼은 누를 때 잠깐 Liquid Glass로 강조되고 단색 UI로 돌아옵니다.
