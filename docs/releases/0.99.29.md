# Notesis 0.99.29 (270)

iOS 모드에서 팝업이나 사이드바를 열 때 첫 화면에 몰리던 작업을 줄였습니다.

- **사이드바 유리:** 다른 요소가 쓰지 않는 배경 레이어를 만들지 않습니다. 맑은 층과 서리 층을 각각 계산하되, 두 층에 같은 배경 기록을 사용합니다. 사이드바의 해상도, 테두리 빛, 굴절, 색, 그림자 설정은 그대로입니다.
- **팝업과 사이드바:** 처음 화면을 준비할 때부터 현재 유리 배경 기록을 재사용합니다. 열리는 모양과 스프링은 그대로입니다. 펜 설정 팝업의 어두운 배경은 밝기 값이 바뀔 때만 창에 다시 적용합니다.
- **페이지 패널:** 첫 페이지를 그린 뒤 현재 페이지로 이동하던 작업을 없앴습니다. 긴 PDF의 중간에서 열어도 해당 페이지가 있는 줄부터 준비합니다.
- **유리 효과 재사용:** 절반 또는 4분의 1 해상도 유리는 크기와 효과 설정이 같을 때 같은 효과 객체를 씁니다. 배경이 바뀌면 새 배경을 그대로 반영합니다.

릴리스 CI에서 APK 빌드, Android 버전 검사, 단위 테스트와 스크린샷 테스트를 실행합니다. 팝업이 첫 프레임을 기다리는 중 닫혀도 배경 갱신 제한이 정상 해제되는지 시험을 추가했습니다. **실기기의 GPU 모양과 지연 시간은 측정하지 않았습니다.**

태블릿에서는 iOS 모드로 긴 PDF를 열고 펜 설정·페이지·설정·레이어 패널을 처음 열 때와 다시 열 때를 비교해 보세요. 밝은 페이지와 어두운 페이지에서 유리 테두리와 글씨가 이전과 같게 보이는지도 확인해 주세요.
