# Notesis 0.47.0 (119)

화면 구성을 크게 바꿨습니다. 기능 탭과 설정을 새로 정리했고, 앱 안의 글자를 영어로 통일했습니다.

## 없앤 기능
- 확대 필기창, 미니맵, 앱 안의 화면 분할을 없앴습니다. 팝업 노트(참고 패널)는 그대로 있습니다.
- 다른 앱에서 그림을 끌어다 놓는 기능은 그대로 됩니다.

## 기능 탭
- 맨 위에서 도구막대 크기(1/4~4/4)를 고릅니다. 페이지 번호와 헷갈리지 않게 막대 모양 그림으로 표시합니다.
- 기능 탭에는 아래 항목만 있습니다.
  - Undo, Redo
  - Picture, Camera, Layers, Microphone, Capture, Text
  - Clock, Calendar, To-do, Calculator
  - Notes, Add page
  - Settings
- 누를 수 없는 버튼에는 이유가 함께 나옵니다(예: Nothing to undo).
- 4/4 크기에서는 막대에 도구가 없어서, 기능 탭에 3/4의 도구도 함께 보여 줍니다.

## 설정 사이드바
- Settings를 누르면 팝업이 아니라 화면 옆에 사이드바가 열립니다.
  - 위에 큰 뒤로/닫기 버튼과 제목이 있습니다.
  - 안쪽 가장자리를 끌어 폭을 바꿀 수 있고, 바꾼 폭은 기억합니다.
  - 하위 화면은 사이드바 안에서 이동합니다.
- 들어 있는 항목: Quick actions, Pen settings, Appearance, Touch & gestures, Customize toolbar, Note & view, Web & AI, Diagnostics.
- **Pen settings:** 모든 펜에 적용되는 설정만 모았습니다. 색·굵기 같은 펜 하나의 설정은 펜 상세 창에 남습니다.
- **Touch & gestures:** 세 손가락 제스처를 켜고 끌 수 있습니다. 끄면 세 손가락 탭 다시실행, 팝업 노트 열기·닫기, 세 손가락 회전이 동작하지 않습니다.
- **Diagnostics:** 지연 시간, 프레임·입력, 백그라운드 작업, 기기 온도 상태를 항목별 카드로 나눠 보여 줍니다.

## UI 화면 설정 (Appearance)
- 위쪽 미리보기에 실제 2/4 도구막대와 기능 버튼이 나옵니다.
- 미리보기 배경은 세 가지에서 고릅니다: 펜·연필·형광펜으로 쓴 페이지, 차분한 추상 배경, 내 사진.
- Light/Dark, UI 종류(Material, Glass 등)를 바로 바꿉니다.
- Icons / Background / Glass / Colors 칩을 누르면 해당 설정이 아래에 나옵니다.

## 도구 편집 (Customize toolbar)
- 1/4~4/4 크기마다 도구 구성과 순서를 따로 정합니다. 실제 막대 미리보기를 보며 편집합니다.
- 편집할 수 있는 것:
  - 도구를 손잡이로 끌어 순서를 바꾸기(가장자리로 끌면 목록이 스크롤됨)
  - 도구 추가·숨기기
  - 1/4 윗줄 버튼과 펜 줄 항목
- Done / Cancel / Reset이 있습니다. 기능 버튼처럼 꼭 필요한 항목은 없어지지 않습니다.
- Ctrl+1~9는 지금 크기에서 보이는 순서를 따릅니다. 예전 도구 배치는 그대로 옮겨 옵니다.

## 펜 상세 창
- 창이 도구막대에서 자라나듯 열리고 닫힙니다. 높이도 내용에 맞춰 부드럽게 바뀝니다.
- 넓은 화면에서는 색과 굵기를 나란히 놓아 세로 스크롤이 생기지 않게 했습니다.

## 페이지 패널
- 필기를 시작하면 페이지 패널이 자동으로 닫힙니다. 패널을 조작하거나 스크롤할 때는 닫히지 않습니다.
- **노트 본문 검색:**
  - PDF 글자, 텍스트 상자, 이미 인식된 손글씨에서 찾습니다. OCR을 다시 돌리지 않습니다.
  - 결과에 페이지와 앞뒤 문장이 나옵니다. 누르면 그 위치로 가서 잠깐 강조합니다.
  - 이전/다음 버튼과 "n of m" 표시가 있습니다. Ctrl+F로도 열립니다.
- 목록 위아래 가장자리를 흐리게 처리해 화면을 덜 가립니다.

## 캡쳐
- 화면에 보이는 그대로가 아니라 고해상도로 다시 그려서 캡쳐합니다.
- 고를 수 있는 것: Screen, 1×~4× 배율, 긴 변 1080/2048/4096px, PNG 또는 JPEG(품질 70/85/95).
- 저장 전에 결과 크기(예: 3240 × 2160 px)를 보여 줍니다.
- 메모리 한도를 넘으면 줄이고, 그렇다는 안내를 띄웁니다.

## 팝업 노트
- 내려놓기가 잘 안 되던 문제를 고쳤습니다. 세 손가락으로 끄는 방향 그대로 따라오고, 아래 가장자리 밖으로 끌어 놓을 때만 닫힙니다.
- 오른쪽·아래 가장자리와 모서리 손잡이로 가로·세로 크기를 따로 바꿀 수 있습니다.

## 필기
- 필압이 없는 입력(손가락, 마우스, 필압 없는 펜)은 필압 펜에서 굵기가 흔들리지 않도록 일정한 값을 씁니다. S Pen 필압은 그대로입니다.
- 세 손가락 제스처 직후 화면이 미끄러지던 것을 막았습니다.

## 영어로 통일
- 홈 화면, 대화상자, 도구 패널, 시계, 계산기, 업데이트, 라이선스 화면 등 앱의 글자를 영어로 바꿨습니다.
- 노트 제목 같은 사용자 데이터는 그대로입니다.
