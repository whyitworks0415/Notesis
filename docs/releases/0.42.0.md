# Notesis 0.42.0 (105)

계산기 · 할 일 · 캘린더를 추가하고, 도형 도구를 **직선**과 **체크박스**로 정리했습니다.

## 도구 메뉴

노트 툴바와 노트 목록 위쪽의 **도구(계산기 모양) 버튼**에서 시계 · 계산기 · 할 일 · 캘린더를 엽니다. 모두 시계와 같은 리퀴드 글래스 창으로 열리고, 바깥을 누르거나 뒤로 가기로 닫힙니다.

## 계산기

- **계산 / 미분 / 적분** 세 탭.
- 지원: 사칙연산, 괄호, 거듭제곱(xʸ, x²), **√ 제곱근**, ∛ 세제곱근, **sin cos tan** 와 역함수(sin⁻¹ …), sinh cosh tanh, **ln, log(상용로그), log₂, logₙ(밑, 값)**, eˣ, 10ˣ, |x|, x!, %, π, e, 이전 답(Ans).
- `2π`, `3(1+2)`, `2sin(x)` 처럼 붙여 쓰면 곱셈으로 읽습니다. 닫는 괄호는 빠뜨려도 됩니다.
- **2nd** 버튼으로 역삼각함수·쌍곡선함수 등 두 번째 기능 자판으로 바뀝니다.
- 각도 단위 **DEG/RAD** 전환. sin(30°) = 0.5, sin(180°) = 0 처럼 깔끔하게 나옵니다.
- 입력하는 동안 결과를 미리 보여 주고, `=` 로 확정하면 기록(최근 6개)에 남습니다. 기록을 누르면 그 값을 이어서 씁니다.
- **미분**: f(x)를 넣으면 **도함수 식**을 보여 줍니다(예: x³+2x → 3x² + 2, sin(x) → cos(x), eˣ → eˣ). x 값을 넣으면 그 점의 기울기 f′(a)와 함숫값도 보여 줍니다. 식으로 만들 수 없는 경우(x! 등)는 수치 미분으로 기울기를 구합니다.
- **적분**: f(x)와 아래끝·위끝을 넣으면 정적분 값을 **적응형 심프슨 공식**으로 계산합니다(예: ∫₀¹ x² dx = 0.333333333333).
- 미분·적분은 라디안 기준입니다. 입력 칸을 눌러 어느 칸에 입력할지 고르고, `=` 를 누르면 다음 칸으로 넘어갑니다.

## 할 일

- 체크리스트 형태의 할 일 목록입니다. 추가, 체크, 글자를 눌러 고치기(비우면 삭제), 삭제, 완료 항목 한꺼번에 지우기.
- 남은 일이 위, 완료한 일은 취소선과 함께 아래에 모입니다.

## 캘린더

- 월 달력(일요일 시작, 일요일 빨강 · 토요일 파랑, 오늘 표시). 이전/다음 달, **오늘** 버튼.
- **날짜마다 따로 체크리스트**를 넣을 수 있습니다. 날짜를 누르면 아래에 그날의 목록이 나오고, 추가 · 체크 · 수정 · 삭제할 수 있습니다.
- 할 일이 있는 날에는 점이 표시됩니다(남은 일이 있으면 파란 점, 모두 끝나면 초록 점).
- 할 일 목록과 캘린더의 날짜별 목록은 서로 따로 저장됩니다.

## 도형 도구

- 도형 메뉴에는 이제 **직선**과 **체크박스**만 있습니다. 나머지 도형은 버그를 고친 뒤 다시 넣을 예정입니다(이미 그린 도형은 그대로 남습니다).
- **체크박스**: 도형 → 체크박스를 고르고 페이지를 **누르면** 그 자리에 체크박스가 생깁니다. **끌면** 끈 크기만큼 만들어집니다. 펜 색으로 그려집니다.
- 만든 체크박스는 펜·도형·읽기 모드에서 **누르면 체크/해제**됩니다(실행 취소 가능).
- **크기 조절·이동**: 사진·텍스트처럼 선택 도구로 고르면 모서리를 끌어 크기를 바꾸고 옮길 수 있습니다. 확대해도 선명하고, PDF로 내보낼 때도 벡터로 들어갑니다.
