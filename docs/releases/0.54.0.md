# Notesis 0.54.0 (139)

## 페이지 지우기 / 전체 필기 지우기
- 지우개를 한 번 더 눌러 설정을 열면, 지우개 설정 바로 아래 Clear 칸에 버튼 두 개가 있습니다(예전에는 "More" 안에 숨어 있었습니다).
  - Clear this page: 지금 페이지의 필기, 사진, 테이프를 지웁니다.
  - Clear all writing: 노트의 모든 페이지에서 필기만 지웁니다. 사진, 테이프, PDF는 그대로입니다. 지우기 전에 한 번 더 확인합니다.
- 둘 다 실행 취소(Undo) 한 번으로 전부 되돌릴 수 있습니다.
- 잠긴 필기와 다른 레이어의 필기는 지우개 설정과 같은 규칙을 따릅니다.

## 레이저 포인터
- 툴바에 Laser 도구를 다시 넣었습니다(형광펜 뒤). 이미 툴바를 바꿔 둔 경우에도 한 번 자동으로 추가되고, 툴바 사용자화에서 뺄 수 있습니다.
- 펜으로 가리키기만 하고 노트에는 아무것도 저장되지 않습니다.
- Laser를 한 번 더 누르면 설정이 열립니다.
  - Trail: 펜 뒤로 꼬리가 서서히 사라집니다. 빨리 움직일수록 꼬리가 길어집니다.
  - Fades after lifting: 쓰는 동안 선이 그대로 있다가, 펜을 떼고 1초 뒤에 사라집니다. 1초 안에 다시 쓰면 앞의 선도 함께 남습니다.
  - Dot: 펜 아래 점만 보입니다.
  - 색: 빨강, 주황, 노랑, 초록, 파랑, 보라, 분홍, 흰색
- 1/4 툴바의 펜 줄에는 지금 레이저 색과 함께 Laser 버튼이 보여서 바로 설정을 열 수 있습니다.
- 팝업 노트와 분할 노트의 모든 칸에서도 똑같이 가리킬 수 있습니다.
- 읽기(제스처) 모드에서 보이던 펜 자국은 원래 색 그대로입니다.

## Liquid glass / Glassmorphism 버그 수정
- 노트 카드 아래쪽(제목·날짜 부분)이 안쪽 네모로 부자연스럽게 나뉘어 보이던 문제를 고쳤습니다. 펜을 카드 위에 띄우거나 누르거나 포커스가 가면 카드에 그림자가 생겼는데, 반투명한 아래쪽으로 그 그림자가 비쳐 보였습니다. 유리 스킨에서는 카드가 어떤 상태에서도 그림자를 만들지 않게 했습니다.
- Glassmorphism에서 가끔 앱이 튕기던 원인으로 보이는 부분을 고쳤습니다.
  - 절전 모드가 켜지거나 꺼질 때, 또는 흐림·선명도를 0으로 바꿀 때 유리 뒤 배경을 담는 레이어가 해제됐습니다.
  - 이때 팝업·대화상자처럼 따로 떠 있는 창이 그 해제된 레이어를 그리면 앱이 종료됐습니다.
  - 이제 레이어를 화면이 닫힐 때까지 유지하고, 해제된 레이어는 그리지 않고 건너뜁니다.
