# Notesis 0.43.1 (107)

슬라이더가 정해진 값 자리로만 뚝뚝 끊겨 움직이던 것을, 손가락을 따라 부드럽게 움직이도록 바꿨습니다. (0.43.0에서 반대로 고친 것을 바로잡았습니다.)

## 슬라이더

- 끄는 동안 손잡이(와 채워지는 막대)가 **손가락 위치를 그대로 따라 부드럽게** 움직입니다. 값이 1ms·1%처럼 단계로 정해진 슬라이더도 손잡이는 끊기지 않습니다.
- 값은 여전히 정해진 간격으로 정해지고, 손을 떼면 손잡이가 고른 값의 자리로 **짧게 미끄러지며 자리 잡습니다**.
- 적용: 모든 설정 슬라이더(예측, 획 보정, 펜 굵기, 모서리, 불투명도, 화면 설정 등), Material·유리·Spoti 유리 스킨 모두, 그리고 **페이지 이동 막대**.
