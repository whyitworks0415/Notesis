# Notesis 0.31.3 (versionCode 64)

태블릿에 설치할 서명 APK는 아래 Assets에서 받으세요.

## Stylus 입력 hot path

- wet ink에는 원본 `MotionEvent`를 그대로 전달해 AndroidX Ink가 historical sample 전체를 계속 사용합니다.
- prediction filter는 실제 wet stroke를 그릴 때만 기록합니다. 지우개·lasso·도형·캡처·이미지·읽기 동작에서는 사용하지 않을 계산을 제거했습니다.
- 진단 패널이 꺼졌을 때 prediction lead 통계 lock을 MOVE마다 잡지 않습니다.
- lasso 좌표를 boxed `Float` collection 대신 primitive float buffer에 저장하고, batched historical 좌표도 2px 간격으로 반영합니다.
- lasso 점선 효과를 scale별로 재사용하고 overlay redraw를 display frame에 맞춰 합칩니다.
- 지우개는 좌표 배열과 hit collection을 재사용하며, 이전 사각 tip이 이미 덮는 미세 이동의 intersection 검사를 합칩니다. 다음 segment가 전체 이동 경로를 연결하고 pen-up 위치는 항상 검사합니다.
- image drag 좌표 배열, pen-tool 분류 collection, 일반 freehand commit의 singleton list 할당을 제거했습니다.

Prediction의 9ms clipping, stroke stabilization, 필기 궤적, undo 단위와 저장 포맷은 변경하지 않았습니다.

## 구조적 전후 차이

- 지우개/lasso/도형 predictor record: 이벤트당 1회 → 0회
- 진단 OFF 상태 prediction 통계 lock: predicted MOVE당 1회 → 0회
- lasso 좌표 boxing: sample당 `Float` 2개 → 0개
- hit 없는 eraser MOVE 임시 allocation: float array 1개 + filter list 2개 → 0개
- lasso dash allocation: draw당 1개 → scale당 1개
- overlay invalidate: 입력 sample rate → display frame에 coalesce
- 일반 freehand commit singleton list: stroke당 1개 → 0개
