# Notesis 0.59.0 (144)

## 좁은 창에서 나가기 버튼이 툴바에 가려지던 문제
- 창의 폭이 좁아져서 가운데에 놓인 툴바가 왼쪽 위 나가기 버튼에 닿게 되면, 툴바를 나가기 버튼 오른쪽에서 시작하게 하고 남은 폭만큼만 넓어지게 했습니다.
- 툴바가 고정돼 있을 때와 떠 있을 때(처음 놓이는 위치) 모두 적용됩니다. 폭이 충분하면 지금처럼 가운데에 놓입니다.
- 떠 있는 툴바를 직접 옮긴 경우에는 옮긴 자리를 그대로 지킵니다.

## 환영 애니메이션: 사각형과 `>`를 동시에
- 아이콘의 둥근 사각형이 펜 없이 선 하나로 거칠게 그려집니다. 아이콘을 바꾸기 전처럼 선 끝에 작은 점이 따라가며 한 바퀴 돕니다.
- 사각형이 그려지는 동안 펜이 그 안에 `>`를 거칠게 씁니다.
- 둘 다 끝나면 사각형과 `>`가 함께 반듯해집니다.
- 사각형은 떠오르거나 흰 판으로 채워지지 않고, 선으로 된 사각형으로 그대로 남습니다.
- 펜은 지난 버전처럼 들려서 떨어지고, 펜촉과 뒤쪽이 차례로 부딪히며 자리를 잡습니다.
- 결과가 흰 바탕에 검정 `>`와 펜이 되도록, 환영 화면의 배경을 다크 모드에서도 흰색으로 바꿨습니다.
- 전체 길이는 4.75초입니다.
