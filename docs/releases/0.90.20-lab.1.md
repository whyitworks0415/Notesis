## 기존 앱과 분리

- 앱 이름은 **Notesis Lab**, 패키지는 **com.notesis.lab**입니다. 기존 Notesis를 덮어쓰지 않고 앱 내부 노트·설정·위젯·파일 제공자도 분리합니다.
- 기존 노트는 자동으로 가져오지 않습니다. 원본 앱에서 내보낸 노트 또는 백업 **사본**을 가져와 같은 내용으로 비교해 주세요.
- 소스는 기존 비공개 저장소의 `codex/performance-lab-0.90.20` 브랜치에 있습니다. 새 저장소 생성은 GitHub 연결의 권한 부족으로 거부되어, 별도 브랜치·패키지·사전 릴리스로 분리했습니다. 기존 정식 브랜치에는 병합하지 않습니다.
- 배포 태그는 `lab-v0.90.20-lab.1-211-preview`입니다. 끝에 `-preview`를 붙여 기존 Notesis의 업데이트 파서가 거부합니다. Lab도 기존 Notesis APK를 업데이트로 받아들이지 않습니다. 정식 Latest 릴리스를 바꾸지 않습니다.
- Lab의 자동 업데이트 확인은 기본 꺼짐입니다. 개발자 코드 없이 Lab의 수동 빌드를 확인할 수 있습니다.

## Kotlin + C++ 혼합 최적화

- UI·입력·저장과 기존 AndroidX Ink는 유지하고, **대량 필기 경계 검색을 C++ BVH로 보완**했습니다. 작은 페이지는 기존 Kotlin 공간 격자를 사용합니다.
- 좌표·검색 결과를 직접 버퍼에 보관해 조회 때마다 좌표 배열을 JNI로 복사하지 않습니다. 네이티브 포인터를 계속 보유하지 않아 해제 누락을 피합니다. 검색 결과는 Kotlin의 재사용 비트셋으로 문서 순서를 복원해 겹침 순서를 유지합니다.
- 큰 트리는 페이지 로딩 작업자에서 생성합니다. 화면 조회 중에는 작은 트리만 만들고 큰 페이지는 기존 격자로 처리해, 트리 생성이 한 프레임을 막지 않도록 했습니다. 추가된 필기는 꼬리 구간에서 처리합니다.
- **같은 화면 범위의 검색 결과를 재사용**합니다. 수정·지우기·형상 변경 시 무효화합니다.
- **화이트보드도 공간 검색을 사용**합니다. 프레임·지우개 조회마다 전체 선의 네이티브 경계 상자를 다시 얻던 경로를 제거했습니다. 아주 넓은 화면에서는 수십억 개의 빈 격자를 돌지 않게 했습니다.
- 네이티브 모듈을 불러오지 못하면 기존 Kotlin 격자로 처리합니다. 노트 파일 형식과 필기 원본 좌표는 바꾸지 않습니다.

## 불필요한 작업과 유리 효과

- 취소된 페이지 로딩은 병렬 필기 형상 생성도 선 사이에서 중단합니다. 네이티브 형상 생성 도중에 강제로 중단하지 않습니다.
- **모양 설정 → Glass → Efficient glass**를 기본으로 켰습니다. iOS 표면의 두 겹 블러·굴절을 한 겹으로 처리하고 표면 블러를 최대 12dp로 제한합니다. 기존 표현과 다를 수 있으며 끄면 원래 유리 효과로 비교할 수 있습니다.
- 화면 주사율을 낮춰 얻는 성능 모드가 아닙니다. 기존 주사율·입력 예측·모션 설정과 노트 기능을 유지합니다.
- 0.90.19의 다크 모드 가독성·정적 Material 아이콘·연결된 모션을 포함합니다.

## 검증과 한계

- 로컬 전체 Debug 테스트 642개가 실패·오류·건너뜀 없이 통과했습니다. 실제 C++ JNI 호출, 임의 경계 검색, 잘못된 버퍼 거부, 취소 작업, 업데이트 채널 분리, 기존 UI·입력 회귀 검사를 포함합니다.
- C++ 커널은 4,540개 무작위 조회 및 경계·용량 검사, AddressSanitizer·UndefinedBehaviorSanitizer 검사를 통과했습니다.
- 호스트의 합성 10만 사각형/2,000개 화면 범위에서는 평균 약 32.49개의 사각형을 검사했습니다. 같은 호스트·같은 C++ 데이터의 전체 순회와 비교한 결과이며 **실제 노트 앱 FPS·배터리·발열 또는 Kotlin 대비 속도 배수가 아닙니다**. 초기 트리 생성 시간도 별도로 기록합니다. 릴리스에 `Spatial-host-benchmark.txt`를 함께 첨부합니다.
- Android 릴리스 APK·전체 release 단위 테스트·UI/JNI 검사·서명 검증을 통과한 뒤 게시합니다. 실제 실행 결과는 Actions에 기록합니다.
- 실기기에서 설치, 필기 정확도, 60/120Hz 프레임 시간, 장시간 발열·배터리, AGSL 유리 표현은 아직 확인하지 못했습니다.

## 비교할 동작

1. 원본 앱과 Lab에 같은 내보내기 사본을 열고, 같은 주사율·밝기·펜·유리·Light mode 설정으로 맞춥니다.
2. 일반 노트와 필기량이 많은 노트에서 빠른 스크롤·확대·지우개·선택·되돌리기를 비교합니다.
3. 화이트보드에 화면 밖 필기가 많은 상태에서 이동·확대·지우개를 비교합니다.
4. 유리 효과는 Efficient glass를 켠 경우와 끈 경우를 나눠 비교합니다. 모양이 달라지는 선택지입니다.
5. 짧은 조작 반응과 10분 이상 연속 필기의 발열·배터리는 따로 확인합니다.
