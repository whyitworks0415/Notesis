# Notesis 0.66.0 (153)

## 만년필 · 캘리그래피 펜촉 기울기
- 펜 설정에서 Fountain, Fountain (speed), Calligraphy를 고르면 "Nib angle" 슬라이더가 나옵니다. −90°~90°를 5° 단위로 정할 수 있고, 옆에 그 각도로 그린 곡선 미리보기가 보입니다.
- Reset을 누르면 원래 각도(만년필 −30°, 캘리그래피 −45°)로 돌아갑니다.
- 각도는 획마다 저장되므로, 각도를 바꿔도 이미 쓴 글씨는 쓸 때 모양 그대로 남습니다.
- 각도를 저장하려고 페이지 파일 형식을 한 단계 올렸습니다(버전 4). 기존 노트는 그대로 열리고, 다음 저장 때 새 형식으로 다시 써집니다. 이전 버전 앱에서는 새 형식으로 저장된 페이지의 필기를 읽지 못합니다.

## 쓸 때 펜촉 부분이 부자연스럽던 문제
- 빠르게 쓸 때 펜 끝 앞에 그려지던 둥근 예측 머리(그리고 480Hz 잔상)가 만년필·캘리그래피에서는 비스듬한 펜촉 모양과 맞지 않고 선보다 굵게 보였습니다. 펜촉이 있는 펜과 연필에서는 이 둥근 머리를 그리지 않습니다.

## 연필 최적화
- 연필(흑연) 획은 종이 질감을 입혀 그려서 일반 펜보다 그리는 비용이 훨씬 큽니다. 연필 획을 펜 획 4개 분량으로 계산해, 연필이 많은 페이지는 더 일찍 픽셀 캐시(타일)로 그리게 했습니다. 연필을 많이 쓴 페이지에서 스크롤·확대 중 매 프레임 모든 획을 다시 그리던 부담이 줄어듭니다.
- 연필로 쓸 때 펜 끝 앞에 그리던 둥근 예측 머리도 빼서, 펜이 움직일 때마다 생기던 추가 그리기를 없앴습니다.
- 실제 기기에서 속도를 재 보지는 않았습니다.

## 문서를 PDF 노트로 변환
- 문서 보기 화면(텍스트, 마크다운, Word, PowerPoint, Excel, HWP/HWPX 파일)에 "Convert to PDF" 버튼을 넣었습니다.
- 문서 내용(제목, 본문, 목록, 코드, 표)을 A4 PDF로 조판해 PDF 노트로 가져오고, 바로 열어 그 위에 필기할 수 있습니다. 슬라이드·시트처럼 여러 부분이 있는 문서는 부분마다 새 페이지에서 시작합니다.
- 원본의 모양(글꼴, 그림, 배치)이 아니라 파서가 읽은 글자와 표를 다시 조판합니다. 그림은 들어가지 않습니다.
- "Import as note"(마크다운 노트로 가져오기)는 그대로 있습니다.
