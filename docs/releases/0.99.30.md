# Notesis 0.99.30 (271)

iOS 모드에서 팝업이 열리는 순간과 사이드바를 열어 둔 채 필기하거나 화면을 움직일 때 겹치던 작업을 줄였습니다.

- **툴바 선택 렌즈** 팝업을 여는 도구를 손이나 펜으로 탭하면 팝업에 첫 프레임을 준비할 시간을 주고 같은 스프링으로 렌즈를 움직입니다. 렌즈 셰이더는 미리 읽어 두고 여러 툴바에서 다시 씁니다.
- **사이드바와 팝업 유리** 필기하거나 페이지를 움직이는 동안 사이드바의 유리는 마지막 배경을 비춥니다. 입력이 잦아들면 현재 페이지에 맞춰 갱신합니다. 팝업 전환 중에도 유리 뒤의 배경 기록을 가능한 한 재사용합니다.
- **페이지 사이드바** 필기와 이동이 잦아들면 새 썸네일을 요청합니다. 그동안 최근 썸네일을 계속 표시합니다. 종이 템플릿 목록은 백그라운드에서 읽고 템플릿이 바뀔 때 갱신합니다.

릴리스 CI에서 APK 빌드, Android 버전 검사, 단위 테스트와 스크린샷 테스트를 실행합니다. 실기기의 프레임 시간과 터치 지연은 측정하지 않았습니다.

태블릿에서는 iOS 모드에서 도형·펜 설정을 열고, 페이지 사이드바를 펼친 채 스크롤과 핀치 확대를, 레이어 사이드바를 펼친 채 연속 필기를 확인해 주세요.
