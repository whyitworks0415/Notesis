# Notesis 0.32.0 (versionCode 73)

SpotiFLAC-Mobile의 유리 내비게이션을 참고한 **Spotiglass** 스킨을 추가했습니다. 화면 설정에서 Material, Glassmorphism, Liquid Glass, Spotiglass를 선택할 수 있습니다.

- 하단 도구 바에서 선택 렌즈가 탭과 슬라이드에 반응해 이동하고 늘어납니다. 드래그를 놓으면 해당 도구가 선택됩니다.
- 페이지·목차·마스킹 선택 바에도 Spotiglass를 적용했습니다.
- 유리 투명도와 인터랙션 강도 설정을 추가했습니다. 모서리 곡률, 블러, 렌즈 깊이, 굴절량, 색수차와 색도 조절할 수 있습니다.
- 화면 설정의 미리보기에서 바를 직접 누르고 밀어 효과를 확인할 수 있습니다.
- 라이트·다크 모드와 고대비를 지원하며, 유리 효과를 사용할 수 없는 환경에서는 단색 선택 표시를 사용합니다.

단위 테스트 101개와 Android 가상 기기의 설정 저장·복원 및 기존 필기·PDF 회귀 검사를 통과했습니다. 실제 기기의 굴절 표현과 애니메이션 성능은 별도 확인이 필요합니다.

참고: [SpotiFLAC-Mobile](https://github.com/spotiflacapp/SpotiFLAC-Mobile/blob/main/lib/widgets/mornye_chrome.dart)
