# Notesis 0.47.5 (124)

## 연필 렉
- 연필은 촘촘한 점(도장 모양 자국)을 이어 그리는 붓이라, 같은 길이라도 일반 펜보다 그릴 도형이 수십 배 많습니다. 저장된 모양과 질감은 바꾸지 않고, 그리는 방식만 고쳤습니다.
- 호환 필기 경로(S6 Lite 등)에서는 쓰는 중인 연필 획 전체를 매 프레임 처음부터 다시 그렸습니다. 이제 새로 생기거나 바뀐 자국만 다시 읽고, 화면에서 바뀐 부분에 닿는 자국만 그립니다. 그래서 획이 길어져도 느려지지 않습니다.
- 연필 획이 많은 페이지는 이전에는 획 개수만으로 판단해서 타일 캐시를 쓰지 않았고, 펜을 뗄 때와 스크롤할 때마다 모든 연필 자국을 다시 보냈습니다. 이제 실제로 그리는 양을 기준으로 판단해 연필이 많은 페이지도 타일 캐시를 씁니다. 펜만 쓴 페이지는 이전과 같습니다.

## UI 통일
- 모서리 곡률, 간격, 버튼 크기를 하나의 기준으로 정리해 앱 전체에 적용했습니다.
  - 모서리: 작은 칩 12, 버튼 16, 카드·패널 20, 대화상자·사이드바 28
  - 간격: 4 / 8 / 12 / 16 / 24
  - 누르는 영역: 44~48
- 안쪽 요소는 바깥보다 둥글지 않게 맞췄습니다.
- 적용한 곳: 도구막대와 기능 메뉴, 설정 사이드바, 페이지·레이어·검색 패널, 올가미·붙여넣기·이미지 바, 대화상자, 시계·계산기, 홈 화면 카드.
- 유리 스킨에서는 직접 설정한 모서리 값이 그대로 적용됩니다.

## 유리 막대 모드의 세로 페이지 슬라이더
- 가로 유리 슬라이더와 같은 모양과 동작으로 바꿨습니다. 같은 트랙과 렌즈를 쓰고, 평소에는 흰 렌즈였다가 누르면 유리로 바뀝니다.
- 렌즈 위에 쪽 번호를 보여 줍니다. 쪽 이동과 썸네일 미리보기는 그대로입니다.
- 화면 낭독기에서 "Page X of N"으로 읽히고, 값을 정해 쪽을 넘길 수 있습니다.

## 페이지 회전이 유리에 늦게 반영되던 문제
- 필기나 화면 이동 중에는 유리 배경 갱신을 잠시 멈추는데, 그사이 회전이 일어나면 화면이 한동안 쉴 때까지 반영되지 않았습니다. 다른 다시 그리기가 없으면 아예 반영되지 않기도 했습니다.
- 이제 노트 각도가 바뀌면 일시 정지 중이어도 바로 다시 그립니다.
