## 첫 화면 위쪽: 끊김 없이 접히는 머리

- **검색창이 그대로 버튼이 됩니다.** 검색창과 둥근 검색 버튼의 높이를 같게(42dp) 맞췄습니다. 목록을 올리면 검색창이 사라지고 버튼이 갑자기 나타나는 대신, 같은 모양이 스크롤한 만큼 오른쪽으로 좁아지며 둥근 버튼이 됩니다. 돋보기가 처음부터 창 왼쪽의 정사각형 칸 한가운데 있어서, 다 좁아지면 원의 정중앙에 남습니다. 글자는 줄어들지 않고 잘리면서 흐려지고, 창의 바탕이 위 버튼과 같은 유리로 바뀝니다.
- **버튼들이 조절(슬라이더) 버튼으로 흡수됩니다.** 조절 아이콘은 자리도 모양도 그대로이고, 선택·정렬·새 폴더·도구·튜토리얼 버튼이 왼쪽부터 차례로 그 안으로 말려 들어갑니다. 이것도 스크롤한 만큼만 진행되고, 유리 바탕이 버튼들 둘레에 모여 마지막에는 둥근 버튼 하나가 됩니다.
- **높이를 4/5로 줄였습니다.** 위쪽 줄은 56dp에서 44dp로, 제목은 24sp에서 22sp로 줄었습니다.
- **스크롤할 때 목록이 튀던 문제를 고쳤습니다.** 예전에는 접힐 때 위쪽 막대의 높이가 바뀌면서 목록의 여백이 다시 계산되어 화면이 한 번 덜컥였습니다. 이제 머리의 높이는 어느 위치에서나 같고, 제목과 검색창도 목록이 아니라 머리에 있습니다. 접히는 정도는 목록 맨 앞의 빈 칸(72dp)을 얼마나 올렸는지로 재므로, 아래 줄들의 높이와 상관없이 매끄럽게 이어집니다.
- **두 버튼을 따로 펼치고 접습니다.**
  - 접힌 조절 버튼을 누르면 옆의 버튼들만 펼쳐지고, 다시 누르면 접힙니다.
  - 접힌 검색 버튼을 누르면 검색창만 펼쳐지고 바로 입력할 수 있으며, 돋보기를 다시 누르면 접힙니다. 입력 중일 때는 스크롤해도 접히지 않습니다.
  - 맨 위로 돌아가면 둘 다 처음처럼 열린 상태로 돌아갑니다.
- 설정 메뉴(모양, 휴지통, 배경, About · Help 등)는 맨 위에서 조절 버튼을 누르면 열립니다. 스크롤한 상태에서는 조절 버튼을 **길게 누르면** 열립니다.
- 스크롤하는 동안에는 이 움직임을 그리기와 배치 단계에서만 읽기 때문에, 머리 전체를 다시 구성하지 않습니다(측정한 수치는 없습니다).

## 확인한 것 / 못 한 것

- CI에서 릴리스 빌드(`assembleRelease`)가 통과하는 것을 확인했습니다.
- 검색창 위치·폭 계산을 순수 함수(`searchMorphSpan`)로 빼고 단위 테스트(`SearchMorphTest`)를 추가했습니다. 다만 CI는 빌드만 돌리므로 이번에 테스트를 실행하지는 않았습니다.
- **기기에서는 확인하지 못했습니다.** 접히는 속도, 유리 바탕이 흐려지며 나타나는 모습, 그림자가 잘려 보이는지는 태블릿에서 봐 주셔야 합니다.

## 태블릿에서 해 볼 것

1. 첫 화면에서 목록을 천천히 올렸다 내리기: 검색창이 버튼으로, 버튼들이 조절 버튼으로 끊김 없이 바뀌는지, 목록이 튀지 않는지.
2. 다 접힌 상태에서 조절 버튼을 눌러 펼치고 다시 눌러 접기. 검색 버튼도 따로 똑같이.
3. 검색 버튼으로 펼쳐 글자를 입력한 뒤 스크롤하기: 창이 접히지 않는지.
4. 스크롤한 상태에서 조절 버튼을 길게 눌러 메뉴가 열리는지.
5. 폴더 안, 선택 모드, Ctrl+F에서도 머리가 제대로 보이는지.
