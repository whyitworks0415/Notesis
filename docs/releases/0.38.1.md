# Notesis 0.38.1 (100)

도구 설정 창의 색상 영역을 정리하고, 색상 선택기를 하나의 판으로 붙여 보는 모양을 추가했습니다. 릴리스 태그가 실제로 빌드한 코드에 붙도록 고쳤습니다.

## 변경 사항

### 색상 선택 손잡이

- 막대·사각형·링·디스크·투명도의 손잡이를 속이 빈 큰 원에서 **작은 흰색 원**(가장자리에 옅은 테두리)으로 바꿨습니다.
- 손잡이가 끝까지 가도 원 전체가 보입니다. 값의 범위를 트랙 양 끝에서 손잡이 반지름만큼 안쪽으로 잡아, 끝에서 원이 잘리지 않습니다. 앱의 다른 색상 선택 화면(스킨 설정, 색상 템플릿)에도 같이 적용됩니다.

### 색상 영역 정리

- 색상 모드 버튼(사각형·HSV·링·RGB·디스크) 다섯 개가 창 너비를 같은 간격으로 나눠 씁니다.
- H·S·V 막대, 색 미리보기, 팔레트 사이와 바깥 여백을 모두 같은 간격으로 맞췄습니다.
- 팔레트 칸의 위·아래가 왼쪽 색상 영역(선택기·투명도·헥스 입력)의 위·아래와 맞습니다. 팔레트 색은 세 칸 기준으로 줄을 맞춥니다.
- 스포이드를 글자 대신 아이콘 버튼으로 바꾸고, 헥스 입력 칸 오른쪽 끝을 선택기 오른쪽 끝에 맞췄습니다.
- 각 부분 위에 **색상 / 펜 굵기 / 펜 종류(연필 종류) / 선 스타일** 제목과 구분선을 넣었습니다.

### 한 판으로 붙은 색상 선택기 (켜고 끄기)

- **세부 설정 → '색상 선택기를 한 판으로'**를 켜면(기본값 켜짐) 막대·사각형·RGB가 틈 없이 붙은 하나의 둥근 판으로 보입니다.
  - HSV: H·S·V 막대와 색 미리보기가 한 판으로 붙고, 미리보기 위쪽에 H·S·V 값이 표시됩니다.
  - 사각형: 채도·명도 사각형 아래에 색상 띠가 붙습니다.
  - RGB: R·G·B 띠가 붙고, 오른쪽 숫자 칸이 각 띠와 줄을 맞춥니다.
- 끄면 이전처럼 각각 떨어진 모양입니다. 막대 위의 H·S·V 글자 높이만큼 미리보기도 내려와 위아래가 맞습니다.

### 릴리스 태그

- 작업 브랜치에서 만든 릴리스의 태그가 `main`에 붙던 문제를 고쳤습니다. 이제 APK를 빌드한 커밋에 태그가 붙습니다.

## 참고

- 이 환경에는 Android SDK가 없어 빌드와 단위 테스트는 GitHub Actions에서 수행합니다. 실제 기기에서는 확인하지 못했습니다.
