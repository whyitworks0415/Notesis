# Notesis 0.74.0 (164)

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 그림자 켜기/끄기
- **Settings → Look → Readability → Shadows**를 새로 넣었습니다.
- 끄면 툴바, 패널, 메뉴, 버튼, 대화상자에서 그림자가 모두 사라지고 페이지 위에 평평하게 놓입니다.
- Material, Glassmorphism, Liquid glass 등 모든 스킨에 적용됩니다.
- 기본값은 켜짐이고, 기존 설정은 그대로 유지됩니다.

## Liquid glass를 Apple의 Liquid Glass에 더 가깝게
- **그림자가 유리 아래가 아니라 바깥에만 생깁니다.** 지금까지는 패널 아래에 진한 그림자가 깔려서, 투명한 유리를 통해 그림자가 비쳐 보였고 패널 전체가 회색으로 탁해 보였습니다. 이제 그림자는 넓고 옅게 패널 바깥에만 퍼지고, 유리 안쪽은 맑게 보입니다.
- **테두리가 빛을 받는 방식으로 바뀌었습니다.** 흰 선을 덧그리지 않고, 왼쪽 위에서 오는 빛이 유리 가장자리 곡면에 반사되는 것처럼 그립니다(빛을 향한 쪽이 가장 밝음). 흰 종이 위에서도 가장자리가 보이도록 아주 옅은 어두운 선을 안쪽에 더했습니다.
- **렌즈가 더 깊어졌습니다.** 기본 깊이 10 → 14, 굴절 10 → 28. 가장자리에서 뒤 페이지가 더 휘어 보입니다. 렌즈 값을 직접 바꾸지 않았다면 새 기본값으로 바뀌고, 직접 바꾼 값은 그대로 둡니다.
- **누르면 손가락 아래에서 빛이 퍼집니다.** 툴바 버튼과 유리 버튼을 누르고 있으면 누른 자리에서 빛이 번지고, 손을 떼면 서서히 사라집니다.
- 글자가 있는 유리 패널의 최소 불투명도를 조금 낮춰(55% → 45%) 뒤가 더 비쳐 보입니다.

## 제한
- 렌즈 굴절, 가장자리 반사광은 **Android 13 이상**에서만 보입니다. Android 12 이하, 절전 모드, 시스템 애니메이션이 꺼진 경우에는 지금처럼 거의 불투명한 패널로 그립니다(그림자 켜기/끄기는 모든 버전에서 동작).
- Apple의 Liquid Glass를 그대로 복제한 것이 아니라, 같은 인상(맑은 유리, 바깥 그림자, 가장자리 반사, 누르면 빛남)을 내도록 다시 만든 것입니다.

## 확인 방법
- 단위 테스트: 그림자 설정 저장/불러오기, 이전 렌즈 기본값(10/20)에서 새 기본값으로 바뀌는지 확인.
- 실제 기기에서는 확인하지 못했습니다.

## 기기에서 확인할 것
- Settings → Look → Shadows를 끄고 켜면서 툴바, Functions 메뉴, Tools 패널, 펜 설정, 대화상자의 그림자가 사라지고 돌아오는지
- Liquid glass에서 패널 안쪽이 회색으로 탁하지 않은지, 흰 페이지 위에서 가장자리가 보이는지
- 툴바 버튼을 길게 누를 때 빛이 퍼지는지
- Android 11 태블릿에서 메뉴·패널이 그대로 보이고 읽히는지
