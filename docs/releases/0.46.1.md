# Notesis 0.46.1 (117)

발열과 획이 많은 페이지의 렉을 줄였습니다. 기능과 보이는 모습은 그대로입니다.

## 가만히 둘 때의 발열
- **PDF가 같은 페이지를 끝없이 다시 그리던 문제**: 화면에 PDF 페이지가 여러 장 보이면, 새로 그린 페이지가 캐시에서 다른 보이는 페이지를 밀어내고, 밀려난 페이지를 다시 그리는 일이 손대지 않아도 계속 반복될 수 있었습니다. 이제 캐시에 함께 들어갈 수 있는 크기까지만 그리고, 작게 보이는 페이지는 미리보기 이미지를 그대로 씁니다. 미리보기 캐시도 한 화면 분량이 서로 밀어내지 않을 만큼 늘렸습니다.
- 화면 밖 PDF 페이지가 미리 그려질 때마다 캔버스 전체와 그 위의 유리 패널이 다시 그려지던 것을, 화면에 보이는 페이지일 때만 다시 그리도록 했습니다.
- 페이지 화면과 노트 목록 화면을 따로 떼어 그리게 했습니다. 작은 것 하나만 바뀌어도(시계 표시 등) 페이지 배경 기록과 모든 유리 패널이 다시 그려지던 것이 줄어듭니다.
- 시계 표시는 1초에 한 번만 바뀌게 했습니다(이전에는 1초에 4번).
- 타이머·알람 알림 테두리가 깜빡이는 동안 페이지와 유리 패널 전체가 매 프레임 다시 그려지던 것을, 테두리만 다시 그리도록 했습니다.
- 스톱워치가 열려 있을 때 화면 주사율(최대 120Hz)대로 갱신하던 것을 초당 약 30번으로 줄였습니다.
- 앱이 뒤로 가면 웹 패널(AI 사이트 등)의 스크립트와 타이머도 멈춥니다. 이전에는 화면만 멈추고 페이지는 계속 돌았습니다.

## 획이 많은 페이지
- **획을 두 번 만들던 문제**: 화면 표시용 펜 획을 만들 때 같은 획의 모양을 처음부터 다시 계산하고 있었습니다. 이제 이미 계산한 모양을 그대로 씁니다. 페이지를 열 때 펜 획 계산량이 절반 가까이 줄어듭니다.
- 페이지를 낮은 정밀도로 읽고 곧바로 높은 정밀도로 다시 만들던 것을, 처음부터 지금 확대 배율에 맞게 한 번만 만들도록 했습니다(한 페이지가 다 보이는 배율까지).
- 스크롤하다 멈추면, 다 읽어 둔 페이지를 버리고 처음부터 다시 읽는 경우가 있었습니다. 이제 다 읽은 페이지는 그대로 씁니다.
- 미리 읽어 둔 옆 페이지가 화면에 들어오는 순간, 그 페이지 획 수천 개의 화면용 사본을 한 프레임 안에서 만들던 것을 미리 읽을 때 같이 만들어 두도록 했습니다.
- 획이 많은 페이지에서, 쓰지도 않는 보이는 획 목록을 매 프레임 만들던 것을 없앴습니다.
- 링크가 있는 페이지에서 링크 영역을 매 프레임 페이지 전체 획을 훑어 계산하던 것을, 페이지가 바뀔 때만 계산하도록 했습니다.
- 사용자 템플릿 종이를 매 프레임 파일에서 다시 읽던 것을 한 번만 읽도록 했습니다. 읽을 수 없는 그림 파일도 매 프레임 다시 시도하지 않습니다.
- 두 PDF 페이지가 경계에 함께 보일 때, 서로의 선명한 타일을 밀어내던 것을 고쳤습니다.
