## 노트 목록
- **접는 섹션**: 보내 주신 그림처럼 **› Folders / › Notes / › Markdown** 제목을 누르면 접히고(›) 펼쳐집니다(⌄). 상태는 기억됩니다. 예전의 "폴더 숨기기" 버튼은 이것으로 바꿨습니다.
- **하단 플로팅 바(리퀴드 글래스)**: **전체 / 폴더 / 노트 / 마크다운**.
  - 전체: 섹션별로 나눠서 모두 보여 줍니다.
  - 나머지: 그 종류만 보여 줍니다.
- **폴더 꾸미기**: 폴더 카드의 ⋮에서 **폴더 색**(10가지)과 **썸네일**(사진)을 바꿀 수 있습니다. 썸네일은 앱 안에 복사해 둡니다.

## 텍스트와 표
- **누른 자리에 바로 쓰기**: 텍스트 도구로 페이지를 누르면 팝업 대신 그 자리에 입력칸이 뜹니다.
  - 크기는 실제 크기에 가깝게 보입니다.
  - 위의 작은 줄: A−/A+, **서식**(굵게·색 등이 있는 기존 편집기), **완료**
  - 다른 곳을 누르거나, 도구를 바꾸거나, 뒤로를 누르면 그대로 페이지에 들어갑니다.
  - 이미 있는 글상자도 그 자리에서 고칩니다. 단, 서식(색·굵게)을 넣은 상자는 기존 편집기로 엽니다.
- **Markdown 적용**: `# 제목`, `**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``, `- 목록`, `- [ ] 체크`, `> 인용`, `[글](주소)`가 그려집니다. 텍스트 도구 패널에서 끌 수 있습니다.
- **텍스트 도구 패널**: 텍스트 도구를 한 번 더 누르면 뜹니다.
  - **텍스트 / 표**를 바꿉니다. 표로 두면 페이지를 누른 자리에 표가 들어갑니다.
  - Markdown 켜기/끄기, 서식 있는 텍스트·표를 가운데에 추가하는 버튼이 있습니다.
- **표(엑셀식)**:
  - A, B, C… 열과 1, 2, 3… 행이 있고, 위에 **수식 입력줄**이 있습니다.
  - 칸은 누르기 전에는 계산된 값을 보여 주고, 누르면 입력한 내용을 보여 줍니다.
  - 수식: `=SUM(A1:A3)`, `=AVERAGE(B1:B5)`, `MIN`, `MAX`, `COUNT`, 칸 참조(`=A1*B2+3`), 사칙연산. 숫자는 오른쪽 정렬입니다.
  - 행·열 추가/삭제, 제목 행, 글자 크기를 바꿀 수 있습니다.
  - 표를 고르고 편집을 누르면 다시 표 편집기가 열립니다.

## 링크
- 손글씨 노트의 **링크 걸린 개체 위에 펜을 0.6초 올려 두면**, 연결된 노트(또는 페이지)의 썸네일과 이름이 옆에 뜹니다. 누르면 지금처럼 그리로 이동합니다.
- Markdown 노트의 `[[노트]]` 링크는 지금처럼 누르면 이동합니다. **Markdown 노트 안의 미리보기와 페이지 글상자 안의 `[[링크]]`는 이번에 넣지 못했습니다.**

## 페이지 & 노트 사이드바
- **Notes 탭에서 노트를 꾹 누르고 열려 있는 노트 쪽으로 끌어 놓으면**, 놓은 위치에 맞춰 분할로 열립니다.
  - 가까운 가장자리(왼쪽·오른쪽·위·아래)에 열리고, 끄는 동안 열릴 쪽이 표시됩니다.
  - 이미 분할 중이면 놓은 칸을 그 방향으로 다시 나눕니다. 이때 위·왼쪽에 놓아도 새 노트는 오른쪽·아래에 열립니다.
- 꾹 누르고 움직이지 않으면 예전처럼 메뉴가 뜹니다.
- **TOC를 VS Code처럼 트리로**:
  - 들여쓰기 안내선이 있고, 하위 항목이 있으면 접기/펴기 화살표가 생깁니다.
  - 위쪽에 **모두 접기 / 모두 펼치기 / 그림 보이기·숨기기**가 있습니다.
  - 항목마다 ⋮에서 이름 바꾸기, 강조, 안으로/밖으로, 목차에서 빼기를 합니다.
  - 아래 "현재 페이지 추가"는 그대로입니다.

## 그 밖에
- **앱 밝기**: 이제 기기 밝기를 바꾸지 않고 **앱 화면만 어둡게** 합니다(20~100%). 다른 앱과 기기 밝기는 그대로입니다. 단, 앱 위에 뜨는 별도 창(일부 대화상자)과, S6 Lite에서 펜으로 쓰는 중인 획은 어두워지지 않습니다.
- **삭제**:
  - "이 페이지에 첨부" 기능을 뺐습니다(꾹 누르기 메뉴, 페이지 메뉴). 이미 붙어 있는 댓글·연습 페이지는 그대로 보이고 숨기기도 됩니다.
  - **레이저 포인터**를 뺐습니다. 펜 버튼을 레이저로 해 두었다면 지우개로 돌아갑니다.

## 확인 방법과 한계
- CI 빌드와 단위 테스트로만 확인했습니다. **기기에서는 써 보지 못했습니다.**
- 특히 누른 자리 입력(키보드가 올라올 때 위치), 표 편집기, 노트 끌어서 분할, 하단 바와 + 버튼이 작은 화면에서 겹치는지 확인이 필요합니다.

## 기기에서 확인할 것
1. 목록: 섹션 접기/펴기, 하단 바 4가지, 폴더 색·썸네일
2. 텍스트 도구로 페이지 누르기 → 그 자리 입력 → 완료/다른 곳 누르기
3. Markdown 문법이 그려지는지
4. 텍스트 도구 다시 누르기 → 표 → 페이지 누르기 → 표 편집(수식 포함)
5. 링크 걸린 개체에 펜 올려 두기 → 미리보기
6. 사이드바 Notes에서 노트를 꾹 눌러 끌어다 놓기 → 분할
7. TOC 트리 접기/펴기, 항목 메뉴
8. 앱 밝기 슬라이더
