0.98.0의 두 가지 결함을 고친 수정판입니다.

## 바뀐 점
- **에이전트 사이드바에 답이 안 나오고 오류가 뜨던 것**: 변경은 되는데 에이전트의 답 대신 오류가 보였습니다. 원인은 Termux가 "명령을 실행했다"를 Android 방식의 `-1`로 알려 주는데, 이것을 오류로 읽은 것이었습니다. 이제 `-1`을 성공으로 보고 에이전트의 답을 보여 줍니다.
- **팝업 노트(참고 패널) 크기가 처음으로 돌아가던 것**: 크기가 저장되지 않아 다시 열 때마다 처음 크기로 돌아갔습니다. 또 창이 잠깐 작아지면(사이드바, 키보드, 분할) 패널이 줄어든 채로 남았습니다. 이제 손으로 정한 크기를 저장해서 다음에 열 때도 그 크기로 열고, 창이 잠깐 작아져도 다시 커지면 정한 크기로 돌아갑니다.

## 어떻게 확인했나
- 단위 테스트 전체 통과(로컬, 네이티브 검사 포함). Termux의 `-1` 결과를 에이전트의 답으로 보여 주는지 시험을 더했습니다.

## 하지 않은 것
- 태블릿에서 해 보지 않았습니다. 팝업 노트 크기는 화면 코드라 기기에서 확인이 필요합니다.
- 사이드바의 답이 여전히 안 나오면, 오류 문구를 그대로 알려 주세요(이번 원인과 다른 원인일 수 있습니다).

## 태블릿에서 해 볼 것
1. 노트에서 세 손가락으로 팝업 노트를 열고 모서리로 크기를 바꾼 뒤 닫았다가 다시 열기 → 같은 크기인지. 노트를 나갔다 다시 들어와도.
2. 팝업 노트를 연 채로 에이전트 사이드바를 열었다 닫기 → 크기가 줄어든 채로 남지 않는지.
3. 에이전트에게 묻기 → 변경과 함께 에이전트의 답이 사이드바에 나오는지.
