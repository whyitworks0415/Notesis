노트 밖(화이트보드) 필기를 노트 안 필기와 같게 했고, 분할·팝업 노트에서 캡처가 되게 했고, 에이전트 대화에 Markdown을 적용했습니다.

## 바뀐 점

### 노트 밖 필기의 렉
- 원인: 노트 안 필기는 한 번 그려 둔 것을 다시 보여 주는데, 노트 밖 필기는 **매 화면마다 획을 하나하나 다시 그렸고**, 확대 단계가 바뀔 때마다 획을 다시 만들었습니다. 그래서 확대·스크롤할 때 노트 밖 필기만 느렸고, 많이 쓸수록 더 느려졌습니다.
- 이제 노트 밖 필기도 일정 크기의 구역마다 한 번 그려 두고 다시 보여 줍니다. 확대하는 동안에는 그려 둔 것을 늘려 보여 주고, 손을 뗀 뒤에 새 배율로 다시 그립니다(노트 안과 같은 방식). 획을 쓰거나 지우면 그 구역만 다시 그립니다.

### 노트 밖에서도 되는 도구
- **올가미**(선택·이동·복사·삭제), **캡처**, **마스킹 테이프**(읽기 모드에서 눌러 들추기 포함), **직선·도형·다각형**이 노트 밖에서도 됩니다. 펜 버튼으로 여는 올가미도 됩니다.
- 노트 밖 캡처는 걸친 쪽들(PDF·그림·필기)과 노트 밖 필기를 함께 담습니다.
- 노트 밖 마스킹 테이프는 노트 옆에 `board.mask`로 따로 저장됩니다.
- 그대로인 것: 그림·글 상자·체크박스는 쪽에 속하는 것이라 노트 밖에는 놓지 않습니다.

### 분할·팝업 노트의 캡처
- **분할**: 캡처는 됐지만 결과가 원래 노트로 바뀌어 나왔습니다. 캡처 창이 캡처한 칸이 아니라 항상 원래 노트에서 다시 그렸기 때문입니다. 이제 캡처한 칸에서 다시 그리고, "연결해서 가져가기"도 그 칸의 노트로 연결됩니다.
- **팝업 노트(참고 패널)**: 일부러 캡처를 막아 두었던 것을 풀었습니다. 이제 팝업 노트에서도 캡처가 됩니다.

### 에이전트 대화
- 에이전트의 답을 Markdown으로 보여 줍니다(제목, 목록, 굵게, 기울임, 코드, 인용, 링크).

## 어떻게 확인했나
- 단위 테스트 전체 통과(로컬, 네이티브 검사 포함). 에이전트 답의 Markdown 표시 시험을 더했습니다.
- 노트 밖 필기 그리기, 도구, 캡처는 화면과 펜 입력 코드라 **빌드로만 확인했습니다.**

## 하지 않은 것
- **태블릿에서 해 보지 않았습니다.** 특히 노트 밖 필기가 많을 때 확대·스크롤이 실제로 부드러워졌는지, 노트 밖에서 올가미로 옮길 때 모양이 맞는지는 기기에서 확인이 필요합니다. 속도는 재지 않았습니다.
- 노트 밖 마스킹 테이프는 에이전트·터미널 명령의 되돌리기 사본에 들어가지 않습니다(노트 밖 필기도 원래 그렇습니다).
- 들고 있으면 도형으로 바뀌는 기능과 동그라미로 올가미 만들기는 노트 밖에서는 아직 꺼져 있습니다.

## 태블릿에서 해 볼 것
1. 노트 밖에 많이 써 둔 노트에서 확대·스크롤 → 노트 안처럼 부드러운지.
2. 노트 밖에서 올가미로 골라 옮기기·복사·지우기, 되돌리기.
3. 노트 밖에서 직선·사각형·다각형 그리기, 마스킹 테이프 붙이고 읽기 모드에서 눌러 들추기, 노트를 닫았다 열어도 테이프가 남는지.
4. 노트 밖에서 쪽에 걸치게 캡처 → 쪽 내용과 노트 밖 필기가 함께 나오는지.
5. 분할 화면의 다른 칸에서 캡처 → 그 칸의 내용이 나오는지. 팝업 노트에서도 캡처.
6. 에이전트에게 묻기 → 답의 제목·목록·굵은 글씨가 그렇게 보이는지.
