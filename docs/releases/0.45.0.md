# Notesis 0.45.0 (111)

Notein·Xodo 분석에서 고른 13가지를 넣었습니다. 메모리와 끊김을 줄이는 개선 5가지, 새 기능 8가지입니다.

## 속도·안정성
1. **PDF 조각 이미지 재사용**: 확대한 PDF를 그리는 조각 이미지를 매번 새로 만들지 않고, 같은 크기면 다시 씁니다. 확대 상태로 스크롤할 때 메모리 정리로 생기는 끊김이 줄어듭니다.
   - 방금 화면에서 빠진 조각은 1초 쉰 뒤에만 다시 쓰여서, 잠깐 엉뚱한 글자가 비치는 일이 없습니다.
2. **캡처·내보내기 크기 상한**: 영역 캡처와 원본 크기 PNG 내보내기는 앱 메모리의 1/16(최대 64MB), 한 변 4096px 안에서 만듭니다. 큰 영역을 캡처하다 앱이 꺼지던 경우를 막습니다.
3. **PDF 렌더 재시도**: 메모리가 모자라 PDF 페이지를 못 그리면 캐시를 비우고 한 번 더 시도합니다.
4. **부분 지우개 정확도**: 지운 자리에서 남은 획이 마지막 점에서 뚝 끊기지 않고, 지우개 가장자리까지 정확히 이어집니다. 빠르게 쓴 획일수록 차이가 큽니다.
5. **획 보정 "구간 평균" 방식 추가**: 펜 설정 › 세부 설정의 획 보정에서 "적응형"(기존)과 "구간 평균"을 고를 수 있습니다.
   - 구간 평균은 최근 몇 ms 동안의 펜 위치를 평균합니다.
   - 보정 50%는 20ms, 100%는 100ms입니다.
   - 느리게 그은 떨리는 선이 더 곧아지는 대신, 그만큼 뒤따라옵니다.

## 새 기능
6. **화면 색 (기본·세피아·야간)**: 노트 메뉴(⋯)에서 고릅니다.
   - 화면에 보이는 색만 바뀌고, 노트와 내보내기는 원래 색입니다.
   - 야간은 밝기만 뒤집고 색조는 지켜서, 검은 글씨는 밝게 바뀌고 빨간 밑줄은 빨강으로 남습니다.
   - 쓰는 중인 획은 펜을 뗄 때까지 원래 색으로 보입니다.
7. **페이지 이동 막대 미리보기**: 막대를 끄는 동안 손가락 아래 페이지의 축소 그림과 쪽 번호가 옆에 뜹니다.
8. **사각형 올가미와 색 바꾸기**
   - 올가미 아래 막대에서 "자유형"과 "사각형"을 고릅니다.
   - 선택한 뒤 팔레트 버튼을 누르면 현재 펜 색과 빠른 색 중에서 골라 색을 바꿉니다.
9. **녹음 재생**
   - 재생 중 막대에 -15초·+15초, 속도(0.5~2배, 음높이 유지), 끝난 뒤 동작(멈춤·다음 녹음·한 곡 반복)이 있습니다.
   - 녹음 창에서도 끝난 뒤 동작을 고를 수 있습니다.
10. **미니맵**
    - 150% 이상 확대하면 오른쪽 아래에 현재 페이지 축소 그림과 지금 보이는 영역이 표시됩니다.
    - 미니맵을 누르거나 끌면 그 위치로 이동합니다.
    - 노트 메뉴에서 끌 수 있습니다.
11. **오려 붙이며 연결하기**
    - 영역 캡처 후 "링크로 가져가기"를 누른 다음, 원하는 노트·쪽으로 가서 위쪽의 "여기에 붙이기"를 누르면 캡처가 그림으로 붙습니다.
    - 붙은 그림을 읽기 모드에서 누르면 캡처한 원래 쪽으로 이동합니다.
    - 다른 노트에 붙여도 원래 노트의 그 쪽으로 열립니다.
12. **"두 쪽 · 표지 따로" 보기**: 노트 메뉴의 보기 방식에 추가했습니다. 첫 쪽은 책 표지처럼 오른쪽에 혼자 놓이고, 2·3쪽부터 두 쪽씩 펼쳐집니다.
13. **확대 수치 글자 폭 고정**: 97%와 100%처럼 숫자가 바뀌어도 폭이 같아서 옆 버튼이 흔들리지 않습니다.
