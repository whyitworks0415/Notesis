# Notesis 0.33.13

- 앱의 61개 UI 아이콘 역할을 Reicon 1.2.5 outline 벡터 아이콘으로 교체했습니다. SVG 경로·선 폭·곡선·채움 규칙을 Compose ImageVector로 변환하고 MIT 라이선스를 APK assets에 포함했습니다. 지우개와 삭제는 서로 다른 아이콘을 사용합니다.
- 도구막대의 배경과 아이콘을 하나의 Liquid Glass 굴절 캡처로 합쳐 아이콘에도 곡률이 적용됩니다. 폭 변화 때 프레임 타이머가 재시작되지 않도록 한 수정은 유지합니다.
- 일반 펜·형광펜·마스킹에 고유 clientBrushFamilyId를 지정했습니다. 같은 브러시 정의 때문에 일반 펜이 형광펜으로 분류되고 Multiply 합성으로 PDF 글자에 가려지던 원인을 수정했습니다.
- 기존 v1 파일의 불투명한 형광펜 기록은 일반 펜으로 복원합니다. 기존 반투명 형광펜은 유지합니다. 새 v2 파일에서는 명시적으로 불투명하게 만든 형광펜도 도구 종류를 유지합니다. v1 파일은 계속 읽을 수 있으며 새로 저장한 v2 획 파일은 이 버전 이상의 앱에서 사용합니다.
- 형광 팔레트 색은 알파 0x66(불투명도 40%, 투명도 60%)로 지정했습니다. 도구 설정창과 도구바 팔레트 모두 이를 적용하고, RGB-only 팔레트 색은 사용자가 지정한 도구 불투명도를 유지합니다.
