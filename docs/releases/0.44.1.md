# Notesis 0.44.1 (109)

노트를 기울였을 때 노트가 잘려 보이고, 펜으로 쓰는 위치와 획이 나타나는 위치가 어긋나던 문제를 고쳤습니다.

## 화면 기울이기
- 노트를 화면(창) 전체째로 돌리던 방식을 버리고, 캔버스 안에서 페이지만 돌리도록 바꿨습니다.
  - 돌린 사각형 모양대로 잘리던 노트의 모서리가 이제 화면 끝까지 그려집니다.
  - 기울이는 동안 노트가 작게 줄어들지 않습니다.
- 펜을 대는 곳에 바로 획이 나타납니다. 쓰는 중에 보이는 획이 화면을 따라 돌지 못해 펜과 다른 곳에 그려지던 것을 바로잡았습니다.
- 지우개, 올가미, 손가락 이동·확대도 기울어진 노트 기준으로 정확한 위치에 작동합니다.
