# Notesis 0.90.26 (226)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

## 바뀐 점

### 1. 펜 설정 선택 막대 되돌림
- 0.90.25에서 Liquid glass로 바꾼 펜 설정의 선택 막대(Setting·Color 탭, 펜 종류, 연필 종류, 선 모양, 색상 보기)를 원래 막대로 되돌렸습니다. 손가락을 대면 그림으로 바뀌는 동작도 돌아옵니다.
- 0.90.25의 다른 변경(끝에서 막힘, 색상 보기 즉시 전환)은 그대로입니다.

### 2. 선택 이동은 가감속으로
- 펜 설정의 선택 막대와, Liquid glass가 아닌 외관의 툴바 선택 표시가 이제 스프링으로 튕기지 않습니다. 천천히 출발해 빨라졌다가 천천히 멈추는 가감속(0.26초, 모션 속도에 맞춰 바뀜)으로 옮겨 가고, 넘치지 않고 제자리에 멈춥니다.
- Liquid glass 툴바의 렌즈는 바꾸지 않았습니다.

### 3. 모션 블러, 강도 조절
- 설정 → 외관 → 모션의 "60Hz 모션 블러" 스위치가 **모션 블러** 슬라이더(0~100%)로 바뀌었습니다. 기본값은 35%이고, 0%면 꺼집니다. 예전에 스위치를 켜 두었다면 50%로 시작합니다.
- 적용 대상:
  - **팝업**: 툴바 메뉴, 펜 설정 같은 도구 패널, 공통 메뉴, 확인창이 열리고 닫히는 가장 빠른 순간
  - **스크롤**: 첫 화면 목록, 도구 패널, 팝업 메뉴를 빠르게 스크롤할 때 세로 방향으로만
- 렉을 줄이려고 이렇게 했습니다.
  - 블러가 0.5px보다 작으면(천천히 움직일 때) 아예 그리지 않습니다. 블러가 없을 때는 화면을 따로 한 번 더 그리지 않습니다.
  - 스크롤은 세로 한 방향만 흐리게 해서 계산이 한 번으로 끝납니다.
  - 속도는 목록 내부를 다시 그리지 않고 레이어 속성만 바꿔 반영합니다.
  - 60Hz 화면에서만 쓰입니다(더 빠른 화면에서는 프레임 사이가 짧아 필요 없음). 가벼운 모드와 Android 11 이하에서는 꺼집니다.

## 확인 방법

- 단위 테스트로 확인했습니다. 블러 강도별 크기(0%면 없음, 상한, 120Hz에서 없음), 스크롤 속도 다듬기, 가감속 곡선이 넘치지 않고 양 끝에서 느린지 봅니다.
- CI에서 릴리스 빌드, 전체 단위 테스트, UI 테스트를 통과해야 게시됩니다.

## 하지 않은 것 / 모르는 것

- **기기에서는 시험하지 않았습니다.** 블러가 S6 Lite GPU에서 얼마나 무거운지 재지 못했습니다. 스크롤이 무거워지면 슬라이더를 낮추거나 0%로 꺼 주세요.
- 설정 사이드바와 페이지 패널이 미끄러질 때는 블러를 넣지 않았습니다.

## 태블릿에서 해 볼 것

1. 펜 설정의 탭과 펜 종류를 바꿔 선택이 튕기지 않고 부드럽게 멈추는지 봅니다.
2. 설정 → 외관 → 모션에서 모션 블러를 0%, 35%, 100%로 바꿔 가며 팝업을 열고 첫 화면을 빠르게 스크롤해 봅니다.
3. 블러를 켠 상태와 끈 상태에서 스크롤이 더 무거워지지 않는지 비교합니다.
