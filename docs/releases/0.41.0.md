# Notesis 0.41.0 (104)

Notewise · Samsung Notes · Flexcil 분석 보고서에서 Notesis에 효과가 있을 것으로 본 항목을 한꺼번에 넣었습니다. 모두 실제 기기에서 재 보지는 못했고, 효과는 코드 구조로 예측한 것입니다.

## 새 펜

- **연필 → 소프트**: 작은 흑연 입자를 겹쳐 그리는 부드러운 연필입니다. 누르는 힘에 따라 **진하기**가 아주 연한 선부터 진한 선까지 바뀌고, 굵기는 그대로입니다(실제 연필처럼). 가장자리에 종이 결 같은 작은 점이 흩어집니다.
- **펜 → 만년필(속도)**: 빨리 쓸수록 선이 가늘어지는 만년필입니다(가장 빠를 때 약 60%). 속도 변화는 부드럽게 따라갑니다.
- 기존 펜·연필은 그대로입니다. 이미 쓴 글씨의 모양은 바뀌지 않습니다.

## 연필 품질

- **흑연 연필의 기울기 떨림 줄이기**: 펜 기울기 값을 짧은 거리에 걸쳐 부드럽게 만들어, 연필을 눕혀 칠할 때 굵기·진하기가 들쭉날쭉하던 것을 줄였습니다. 기울기를 알려 주는 펜에서만 효과가 있습니다. 다시 열어도 같은 모양이 나오도록 시간이 아니라 거리를 기준으로 합니다.

## 필기 예측

- **화면 밀도에 맞춘 예측**: 예측을 켜고 얼마나 앞서 그릴지 정하는 속도 기준을 화면 픽셀이 아니라 실제 펜 이동 거리(mm)로 바꿨습니다. 화면이 촘촘한 기기에서도 같은 손 속도면 같은 예측이 나옵니다.
- **최근 20개 구간 평균 속도**: 한 샘플의 속도 대신 최근 구간 평균을 써서, 예측 길이가 샘플마다 바뀌며 흔들리던 것을 줄였습니다.
- **멈출 때 튀는 꼬리 방지**: 펜이 급히 느려지면(멈추거나 꺾기 직전) 예측을 줄이거나 끕니다. 글자 끝에서 선이 살짝 튀어나왔다 돌아가는 현상이 줄어듭니다.
- **손떨림 보정과 함께 쓸 때**: 보정이 강할수록 예측 꼬리를 짧게 합니다(최대 보정에서 40%).
- **Galaxy Tab S6 Lite(호환 필기 경로)**: 자동 예측일 때, 입력이 화면 갱신 주기의 어디쯤 들어왔는지에 따라 예측 길이를 정합니다. 화면에 늦게 나타날 입력일수록 조금 더 앞서 그립니다.

## PDF · 메모리

- **보이는 PDF 페이지 수에 맞춘 해상도**: 두 페이지가 함께 보일 때 캐시에 둘 다 들어가는 해상도를 고릅니다. 메모리가 적은 기기에서 두 페이지가 번갈아 흐려지던 문제를 없앴습니다.
- **주변 페이지 미리 그리기 제한**: 미리 그리는 페이지를 캐시에 들어가는 만큼만 최고 해상도로, 다음 몇 장은 낮은 해상도로, 나머지는 미리보기로만 준비합니다. 가까운 페이지가 먼 페이지 때문에 밀려나 다시 그려지던 낭비를 줄였습니다.
- **확대 직후 선명도**: 새 해상도의 조각이 오기 전까지, 이미 있는 바로 위·아래 해상도 조각으로 빈 곳을 채웁니다. 확대·축소 직후 흐릿하게 보이는 시간이 줄어듭니다.
- **메모리 크기별 예산**: 램이 7GB 이상인 기기에서는 PDF 캐시(최대 384MB)와 필기 캐시(96MB)를 더 넉넉하게 씁니다. 3GB 미만은 더 작게 씁니다.
- **팝업 노트 메모리 절반**: 참조 팝업의 PDF는 메인 노트의 절반 예산만 씁니다.
- **방금 닫은 PDF 잠시 보관**: 노트나 팝업을 닫은 뒤 20초 안에 같은 노트를 다시 열면, PDF를 처음부터 열지 않고 그려 둔 페이지를 그대로 씁니다.
- **메모리 부족 신호에 반응**: 앱이 뒤로 가거나 메모리가 부족하면 다시 만들 수 있는 캐시(PDF 조각·페이지, 필기 비트맵)를 내놓습니다. 백그라운드에서 강제 종료되는 일이 줄어듭니다.
- **큰 사진 가져오기**: 사진을 원본 크기로 다 읽은 뒤 줄이지 않고, 처음부터 2의 거듭제곱 단위로 줄여 읽습니다. 4800만 화소 사진도 순간 메모리가 크게 줄어 앱이 꺼질 위험이 사라집니다(사진, 노트 표지, 페이지 템플릿).

## 편의

- **녹음이 백그라운드에서도 계속됨**: 녹음 중 다른 앱으로 넘어가도 녹음이 끊기지 않습니다. 녹음하는 동안 알림에 "녹음 중"이 표시됩니다.
- **마우스 휠·트랙패드**: 휠로 위아래 스크롤, Shift+휠로 좌우, Ctrl(또는 Cmd)+휠로 포인터 위치를 중심으로 확대·축소합니다.

## 넣지 않은 것

- Samsung의 신경망 예측기·연필 전용 그래픽 코드·자체 필기 표시 엔진, Notewise의 GL 렌더러는 해당 앱 전용이라 가져올 수 없거나 지금 구조와 맞지 않습니다.
- 팝업과 메인 노트가 같은 PDF를 **동시에** 함께 쓰는 구조는 큰 작업이라 이번에는 예산 절반과 잠시 보관으로 대신했습니다.
- 연필 입자에 흑연 결 텍스처를 입히는 것은 사용하는 필기 라이브러리 버전에서 지원 여부를 확인할 수 없어 넣지 않았습니다. 대신 소프트 연필이 입자로 결을 표현합니다.
