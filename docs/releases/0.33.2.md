# Notesis 0.33.2

- 0.33.1에서 Liquid Glass의 실제 굴절이 사라지던 문제를 수정했습니다. Android RenderEffect는 셰이더 값을 고정하므로, 굴절값이 변할 때 효과도 함께 갱신합니다. 고정된 배경은 값이 같을 때만 효과를 재사용합니다.
- 1/4 배경과 기능 버튼의 굴절·빛 반사를 복원했습니다.
- 1/4는 두 줄로 유지합니다. 도구 아이콘과 간격을 줄여 두께·색상·기능 버튼을 도구와 같은 줄에 배치하고, 좁은 화면에서도 전체 줄을 축소해 좌우 스크롤 없이 표시합니다.
- 누르는 선택 렌즈 안에서는 도구 바의 흐림을 제거합니다. 선명한 배경과 아이콘이 실제로 굴절되고, 도구의 설정 색은 아이콘 중심으로 표시됩니다.
- 도구에 손을 대면 즉시 렌즈가 올라오고, 놓은 뒤에는 원래 선택 표시로 돌아옵니다.
- 실제 앱에서 사용하는 효과로 GPU 검증을 변경해, 이전 굴절값이 고정되는 오류를 확인할 수 있도록 했습니다.

검증: 114개 JVM 테스트, Android GPU 효과 갱신/굴절 검증, 에뮬레이터의 1/4 배경과 누름·드래그 렌즈 확인.
