# Notesis 0.75.0 (165)

## Liquid glass 3가지 → 스타일 총 5개
- 스타일 고르는 곳(첫 실행, 툴바의 Look 버튼, Settings › Appearance › Style)에서 이제 5개를 고를 수 있습니다.
  - **Material**
  - **Glassmorphism**
  - **Liquid glass**(지금까지의 Notesis 유리)
  - **Liquid glass · Kyant0**(새로 추가)
  - **Liquid glass · QWEA0**(새로 추가)
- 새로 추가한 두 스타일은 각 GitHub 프로젝트가 쓰는 설정 항목과 초기값을 그대로 가져왔습니다. **Settings › Appearance › Glass**에서 조정할 수 있고, "Back to …'s values" 버튼으로 프로젝트 기본값으로 되돌릴 수 있습니다.

### Liquid glass · Kyant0 ([Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass), Apache 2.0)
- 앱의 유리가 원래 이 라이브러리(Backdrop)로 그려지므로, 그 데모 앱(catalog)의 값을 그대로 씁니다.
- 툴바·버튼: 하단 탭(LiquidBottomTabs) 값
  - 채도 1.5배(vibrancy), 블러 8 dp, 렌즈 높이 24 dp / 굴절 24 dp
  - #FAFAFA 표면 40%(다크 모드는 #121212 40%), 기본 하이라이트
- 패널·메뉴·대화상자: 대화상자(DialogContent) 값
  - 블러 16 dp(다크 8 dp), 렌즈 24 / 48 dp + 깊이 효과, 밝기 +0.2, 표면 60%, Plain 하이라이트
- 작은 둥근 버튼: LiquidButton 값(블러 2 dp, 렌즈 12 / 24 dp)
- 그림자: 라이브러리 기본 그림자(24 dp, 검정 10%)
- 설정 항목: Refraction height, Refraction amount, Depth effect, Chromatic aberration, Blur radius, Vibrancy, Surface, Highlight

### Liquid glass · QWEA0 ([QWEA0/Liquid-Glass-Android](https://github.com/QWEA0/Liquid-Glass-Android), MIT)
- 이 라이브러리는 View용이라 직접 쓰지 않고, 같은 숫자로 앱의 렌즈를 움직입니다.
- 렌즈: README 예시 값(bevelWidth 24 dp, refractionHeight 12 dp, dispersionStrength 0.12)
- 블러: blurAmount 0.0625(블러 반경 4 + 32 × 0.0625 px)
- 패널·메뉴·대화상자: 대화상자 빌더 값 blurAmount 0.6
- 채도 140%, 가장자리 하이라이트 100%
- 적응형 색조: 밝은 페이지 위에서는 회색 22%, 어두운 페이지 위에서는 밝게
- 그림자 없음(LiquidGlassView 기본값)
- 재질 2가지
  - **Regular**: 블러 100%, 적응형 색조
  - **Clear**: 블러 35%, 16% 어둡게, 하이라이트 1.2배
- 작은 요소는 렌즈 폭을 줄입니다(adaptiveLensScale).
- 설정 항목: Material, Bevel width, Refraction height, Dispersion, Blur amount, Panel blur amount, Saturation, Adaptive tint, Edge highlight, Shadow

### 공통
- 지금까지의 Liquid glass는 이름과 설정이 그대로입니다.
- 슬라이더·스위치 같은 컨트롤은 세 스타일 모두 기존 유리를 씁니다.
- 툴바에서 선택이 미끄러지는 렌즈도 세 스타일 모두 같습니다.
- 렌즈와 반사광은 Android 13 이상에서만 보입니다. Android 12 이하에서는 세 스타일 모두 지금처럼 거의 불투명한 패널로 그립니다.

## 한 손가락 두 번 탭으로 툴바 올리기
- 전에는 페이지 **오른쪽 가장자리(약 56 dp 폭)** 를 두 번 탭할 때만 툴바가 올라갔습니다. 그 밖의 곳에서 한 손가락으로 두 번 탭하면 아무 일도 없었습니다.
- 이제 **페이지 어디서든** 한 손가락으로 두 번 탭하면 툴바와 패널이 위로 올라가고, 한 번 더 두 번 탭하면 내려옵니다. 위쪽 탭을 끌어내려도 돌아옵니다.
- **Settings › Touch & gestures › Taps and zoom › One-finger double tap**에서 동작을 바꿀 수 있습니다.
  - 고를 수 있는 동작: Hide toolbar(기본), Zoom, Undo, Redo, Pages panel, Nothing
- 전에 "One-finger double tap zooms"를 켜 두었다면 Zoom으로 이어집니다.
- 오른쪽 가장자리 1·2·3번 탭 설정은 그대로입니다.

## Pages 펜 미리보기 0.8초
- Pages 패널에서 펜을 페이지 위에 올려 두면 미리보기가 뜨기까지 걸리는 시간을 2초에서 **0.8초**로 줄였습니다.

## 폴더 삭제, 노트·폴더 이름 바꾸기
- **노트 이름 바꾸기**: 노트 카드 메뉴 → **Rename**
- **폴더 이름 바꾸기 / 삭제**: 라이브러리의 폴더 타일 오른쪽 **⋮** 버튼을 누르거나 타일을 길게 누르면 **Rename folder**, **Delete folder**가 나옵니다.
  - 지금까지는 폴더 안에 들어가서 ⋮ 메뉴를 열어야만 보였습니다.
- 폴더를 지울 때 안에 노트가 있으면 두 가지 중에서 고릅니다.
  - **Move to Trash**: 노트를 함께 휴지통으로 보냅니다. 휴지통에서 노트를 복원하면 폴더도 돌아옵니다.
  - **Keep notes**: 노트를 라이브러리 맨 위로 옮깁니다.
- 빈 폴더는 바로 지웁니다.

## 확인 방법

- 폴더 타일 ⋮ → Rename folder / Delete folder, 노트 카드 메뉴 → Rename
