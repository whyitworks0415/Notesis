# Notesis 0.99.15 (256)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

**화면 회전을 켜고 끌 수 있게** 했습니다. 태블릿을 책상에 눕히거나 비스듬히 들고 쓸 때 화면이 갑자기 돌아가는 것을 막을 수 있습니다.

## 어디서 켜고 끄나
- **노트 안 빠른 메뉴**: 노트 설정을 열면 위쪽 빠른 동작에 **"화면 회전 켜짐 / 화면 회전 잠김"** 버튼이 있습니다. 누를 때마다 바뀝니다.
- **설정 → 모양(화면) → 화면 회전 → "태블릿을 돌리면 화면도 회전"** 스위치로도 바꿀 수 있습니다.
- 페이지만 돌리는 **"회전 · 90°"**(노트 보기 회전)와는 다른 기능입니다. 이것은 앱 화면 전체가 태블릿을 따라 도는지를 정합니다.

## 어떻게 동작하나
- 끄면 **그 순간의 방향을 정확히 그대로** 고정합니다. 세로·가로뿐 아니라 거꾸로 든 방향까지 고정합니다.
- 고정한 방향은 **앱을 다시 열어도 유지**됩니다.
- 켜면 다시 태블릿을 따라 돌아갑니다. 기본값은 켜짐이라 지금까지와 같습니다.
- Android 시스템의 자동 회전이 꺼져 있으면, 이 스위치를 켜도 시스템 설정을 따릅니다.

## 어떻게 확인했나
- 빌드, 축소(R8) 릴리스 빌드, Android 버전 검사(Lint), 네이티브 커널 점검, 전체 단위 테스트(145개 클래스)를 통과했습니다.
  - Lint가 Android 10에서 없는 함수 호출을 하나 잡아서 고쳤습니다.
- "지금 방향 그대로 고정" 계산에 테스트를 추가했습니다. 원래 세로인 기기와 원래 가로인 기기에서 네 방향을 모두 확인합니다.
- 전체 테스트 중 에이전트 승인 카드 UI 테스트가 한 번 실패했습니다. 따로 두 번 돌렸을 때와 전체를 다시 돌렸을 때는 통과해서, 부하 때문에 흔들린 것으로 봅니다. 이번 변경과는 관계없는 부분입니다.

## 하지 않은 것 / 확인하지 못한 것
- **태블릿에서 직접 돌려 보지 않았습니다.**
- 지금은 끄는 순간의 방향으로만 고정합니다. "항상 가로" 같은 방향 고르기는 넣지 않았습니다.

## 태블릿에서 해 볼 것
1. 노트 설정 빠른 메뉴에서 **화면 회전 잠김**으로 바꾼 뒤 태블릿을 돌리기 → 화면이 그대로인지.
2. 거꾸로 든 상태에서 잠그기 → 그 방향 그대로 유지되는지.
3. 앱을 완전히 닫았다 열기 → 잠근 방향으로 열리는지.
4. 다시 **화면 회전 켜짐**으로 바꾸기 → 태블릿을 따라 도는지.
