# Notesis 0.91.0 (229)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ **주의: Liquid glass·Glassmorphism을 쓰고 있다면 이 업데이트를 설치하지 마세요.**
> 이 버전부터 앱은 **Material 화면만** 씁니다. 유리 스타일은 앱에서 빠졌고, 설치하면 바로 Material로 바뀝니다. 유리 스타일을 계속 쓰려면 0.90.28에 머무르세요.
> 저장해 둔 유리 설정은 지우지 않았습니다. 나중에 유리가 다시 들어오면 그대로 이어집니다.

## 바뀐 점

### 1. 유리 스타일을 빼고 Material만 남김
- 소유자 요청입니다. 기능과 최적화를 먼저 끝내고, 유리 느낌은 마지막에 다시 적용합니다.
- 빠진 것:
  - Glassmorphism, Liquid glass와 그 스타일(Notesis, iOS, Mornye)
  - 설정의 UI 스타일 고르기, Glass 탭, 툴바 위의 스타일 버튼, 첫 실행 때의 스타일 고르기
  - 유리 전용 설정: 반투명, 서리(흐림), 반사, 렌즈, 부분별 투명도·색
  - 유리 라이브러리(Kyant Backdrop)
- 빠진 코드는 저장소의 `archive/`에 그대로 보관했습니다. 빌드에는 들어가지 않습니다. 다시 적용할 때 쓰는 방법은 `archive/README.md`에 적었습니다.

### 2. 팝업은 누른 곳에서 자라나는 하나의 움직임으로
- 유리에서 쓰던 "버튼에서 쏟아지는" 애니메이션은 따로 보관하고 코드에서 뺐습니다.
- 메뉴·툴 패널·대화상자 모두 누른 곳에서 둥근 면으로 자라나 패널이 되고, 닫을 때 그 자리로 돌아갑니다. Material의 컨테이너 스프링이라 넘치지 않고 멈춥니다.
- 대화상자도 이제 가운데서 커지지 않고, 연 손가락 자리에서 나옵니다.

### 3. 가벼워진 것
- 화면 뒤를 매 프레임 다시 녹화하던 일이 없어졌습니다. 첫 화면과 노트 화면 모두, 유리 패널이 보려고 페이지를 한 번 더 그리던 작업입니다.
- 창 뒤 흐림(대화상자·메뉴)과 유리 미리 데우기도 없어졌습니다.
- **얼마나 빨라졌는지는 재지 않았습니다.** 설정 → 진단 → 성능 기록으로 재서 보내 주시면 숫자로 비교하겠습니다.

### 4. 정리
- 첫 화면 아래 필터 막대, 세그먼트 선택, 스위치, 슬라이더를 Material로 다시 만들었습니다. 선택 표시는 가감속으로 미끄러집니다.
- 모서리 둥글기와 팝업 뒤 어둡게는 그대로 설정할 수 있습니다.

## 확인 방법

- 이 컨테이너에 Android SDK를 깔아 앱과 시험을 직접 빌드했습니다.
- 단위 테스트와 Robolectric 시험(설정 저장·읽기, 유리 설정 보존, 팝업 모양 계산, 팝업 스프링, 첫 실행 순서, 화면 캡처 시험).
- CI에서 릴리스 빌드와 전체 시험을 통과해야 게시됩니다.

## 하지 않은 것

- **기기에서는 시험하지 않았습니다.** 팝업이 자라나는 모습, 대화상자가 손가락 자리에서 나오는지는 태블릿에서 봐야 합니다.
- 성능 변화는 재지 않았습니다.
- Todo.md의 다음 단계(최적화 O, 디자인 A·B, AI 첨부, 명령·터미널, 문서 편집)는 아직입니다.
- 유리를 쓰던 기기만 따로 막는 장치는 넣지 않았습니다. 이 업데이트는 수동이라 개발자 코드를 넣은 기기에만 보입니다.
