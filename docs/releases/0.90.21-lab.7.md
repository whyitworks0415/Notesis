# Notesis Lab 0.90.21-lab.7 (218)

<!-- update: manual -->

> 기존 Notesis Lab에 업데이트하는 수동 사전 릴리스입니다. 정식판과 별도로 설치됩니다.

- 정식 0.90.20 (211)과 팝업·도구 모음·모션 코드를 비교했습니다. 팝업의 열림·닫힘 곡선, 시간, 앵커와 펼쳐지는 윤곽 코드는 같았지만 Lab의 기본 유리 렌더링과 선택 표시 색상이 달랐습니다.
- Lab에서 기본 켜졌던 가벼운 유리 효과를 끕니다. iOS 유리의 두 겹 렌즈·서리 합성과 설정한 블러 값을 복원합니다. 기존 Lab도 이번 업데이트 후 첫 로드에서 한 번 적용하며, 이후 설정에서 명시적으로 다시 켠 선택은 유지합니다.
- 도구 모음 선택 표시를 정식판 색상으로 복원합니다. Material은 primaryContainer, 유리 계열은 강조색의 반투명 표시를 사용합니다.
- 사용자 애니메이션 속도·곡선·모양·테마 설정은 초기화하지 않습니다. 정식판과 Lab은 설정 저장소가 별도이므로 두 앱에서 사용자 설정이 다르면 움직임도 다를 수 있습니다.
- 필기·부분 지우개·페이지 로딩·타일 작업 제한과 계측은 유지합니다. 원래 유리 품질을 복원하므로 간소화 모드보다 UI 렌더 비용이 늘 수 있습니다. 필요하면 가벼운 유리 효과를 다시 켤 수 있습니다.
- 설정 마이그레이션, 재시작 후 명시적 선택 유지와 기존 모션/UI 검사를 거쳐 릴리스 빌드·서명 검증 후 게시합니다.

실기기의 정식판과 나란히 본 외관·프레임 비교는 아직 하지 못했습니다. 같은 테마·유리 프리셋·애니메이션 속도에서 펜·색상 팝업, 설정 패널, 도구 전환을 비교해 주세요. 빠르게 열고 닫거나 닫히는 도중 다시 열 때도 확인해 주세요.
