# Notesis 0.99.4 (245)

<!-- update: manual -->

> 수동 업데이트입니다. 앱이 먼저 알리지 않으며, **About · Help → Check for updates**에서 설치할 수 있습니다.

> ⚠️ 0.91.0부터 앱은 **Material 화면만** 씁니다. Liquid glass·Glassmorphism을 계속 쓰려면 0.90.28에 머무르세요.

Chrome에서 연 PDF의 펜 버튼으로 바로 Notesis에서 필기할 수 있게 했습니다.

## 바뀐 점
- Chrome의 PDF 보기는 Android의 PDF 보기를 쓰고, 오른쪽 아래 **펜 버튼**은 "이 PDF에 필기할 앱"을 찾는 요청(`ANNOTATE`)을 보냅니다. 지금까지는 그 요청을 받는다고 알린 앱이 Google Drive뿐이라 바로 Drive로 갔습니다. 이제 Notesis도 그 요청을 받는다고 알리므로, 펜 버튼을 누르면 **Drive와 Notesis 중에서 고르는 창**이 뜹니다. Notesis를 고르면 PDF가 새 노트로 들어와 바로 열립니다(Drive에서 사본을 만들 필요 없음).
- 다른 앱의 "편집(EDIT)" 요청도 같은 방식으로 받습니다.

## 어떻게 확인했나
- 빌드와 단위 테스트, 앱 설정(매니페스트)이 정상적으로 합쳐지는지 확인했습니다.

## 하지 않은 것
- **태블릿의 Chrome에서 실제로 눌러 보지 않았습니다.** Chrome 버전에 따라 펜 버튼이 다른 앱을 찾지 않고 Drive만 바로 여는 경우에는 이 변경으로도 목록에 나오지 않습니다. 그때는 Chrome의 ⋮ → 열기 / 공유로 Notesis를 고르면 됩니다.

## 태블릿에서 해 볼 것
1. Chrome에서 PDF를 받아 Chrome 안에서 열기 → 오른쪽 아래 펜 버튼 → 목록에 **Notesis**가 있는지, 고르면 새 노트로 열리는지.
2. "항상" 대신 "이번만"을 고르면 다음에도 고를 수 있습니다.
