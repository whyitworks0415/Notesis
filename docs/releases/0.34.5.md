# Notesis 0.34.5 (92)

Galaxy Tab S6 Lite에서 필기가 펜을 뗀 뒤에야 보이고, S펜 버튼 지우개가 동작하지 않던 문제를 고쳤습니다.

## 변경 사항

- **S펜 버튼 지우개**: 삼성 기기는 S펜 버튼을 누른 채 화면에 닿으면 표준 DOWN/MOVE/UP 대신 삼성 전용 동작 코드(211/213/212, 취소 214)로 입력을 보냅니다. 기존 코드는 이 코드를 처리하지 않아 버튼을 누른 입력이 모두 버려졌습니다. 이제 표준 동작으로 바꿔 처리하고 버튼을 누른 입력으로 간주하므로 펜 모드에서는 지우개, 읽기 모드에서는 기존 버튼 제스처(영역 캡처·텍스트 선택)가 동작합니다.
- **쓰는 동안 필기 표시**: AndroidX Ink의 front-buffer 레이어는 S6 Lite에서 문제가 알려진 경로입니다(라이브러리에도 이 기기용 우회 코드가 있습니다). 이 기기에서는 입력은 들어가지만 화면에는 펜을 뗄 때 한 번에 나타났습니다. 이제 진행 중인 획을 같은 브러시·좌표·시간 정보로 일반 View에도 그리는 "호환 필기 표시"를 추가했습니다. 저장되는 획은 이전과 같이 InProgressStrokesView가 만듭니다.
- 호환 필기 표시는 Galaxy Tab S6 Lite(SM-P61x/P62x)에서 기본으로 켜지고, 펜 설정 창에서 켜고 끌 수 있습니다. 다른 기기에서도 같은 증상이 있으면 켜면 됩니다.

## 참고

- 호환 표시는 일반 화면 갱신 주기를 따르므로 front-buffer보다 한두 프레임 늦게 보일 수 있습니다.
- front-buffer가 일부라도 표시되는 기기에서 함께 켜면 반투명 형광펜이 쓰는 동안 더 진하게 보일 수 있습니다. 그런 경우 이 설정을 끄세요.
- 실제 S6 Lite 기기에서의 확인은 아직 하지 못했습니다. 빌드는 GitHub Actions에서 수행합니다.
